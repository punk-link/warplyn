# Review writing style

Use **Review writing style** when you want to compare an *Article* with your saved *Style Profile*. The Assistant looks for concrete differences from the profile's voice characteristics and rules. A low-confidence profile is treated as tentative.

Before sending the request, add writing samples or manual guidance in [Style Profile](../style-profile.md) and rebuild the profile. Then open **Quick actions**, choose **Review writing style**, and select **Send editorial request**. Select a passage to focus the review; otherwise, it uses the full *Article*.

::: tip Example
Ask, "Compare this passage about Ana at the river with the close point of view in my writing samples. Point out one difference and explain which profile trait it relates to."
:::

::: tip Review suggested changes
Read the *Proposal* and its supporting *Findings*. Each *Finding* should point to a profile trait or rule. Decide which suggestions fit the *Article* before accepting changes.
:::

Style review needs an available *Style Profile* and an AI connection. The raw writing samples are not sent; the Assistant uses the compact locally derived profile. The request may send the *Article* or selected passage to your configured AI provider.
