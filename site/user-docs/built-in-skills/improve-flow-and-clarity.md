# Improve flow and clarity

Use **Improve flow and clarity** when the writing feels difficult to follow and you want a clearer structure or smoother transitions. It aims to improve readability while preserving the *Article*'s meaning, claims, uncertainty, and voice.

Open **Quick actions**, choose **Improve flow and clarity**, and select **Send editorial request**. You can ask for a particular focus, such as clarifying how a discovery changes a character's next choice. Select a passage to limit the replacement to that passage; otherwise, the Assistant works on the full *Article*.

::: tip Example
Ask, "Suggest a small revision that makes the move from watching the current to opening the notebook clearer. Keep the scene's quiet mood and don't change any events."
:::

Review the *Proposal* for meaning, technical details, and author voice before applying it. For a request to cut length, use [Shorten text](shorten-text.md).
