# Develop key points

Use **Develop key points** when you want a concise list of the main ideas in your notes or *Article*. It prepares three to five distinct points by default and does not rewrite the *Article*.

Open **Quick actions**, choose **Develop key points**, add any direction in the Composer, then select **Send editorial request**. If you select a passage, that selection and the material in your message guide the result. Without a selection, the Assistant follows your message first and uses the *Article* when your message is empty.

::: tip Example
Select the scene where Ana sits beside the river and ask, "Give me three possible readings of Ana's relationship with the river, grounded in this passage."
:::

The returned points may need correction or a different emphasis. Review them before using them in an *Article*. For a complete draft based on supplied material, see [Turn ideas into a draft](turn-ideas-into-a-draft.md).
