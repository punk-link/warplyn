# Skill Creator

The Assistant uses the built-in Skill Creator when you explicitly ask it to create, revise, restore, or delete a reusable *Skill*. It manages local Markdown instructions and keeps a separate history for each *Skill*.

Describe the repeated task and the rules or references the *Skill* should follow. The Assistant may ask a short follow-up if an unclear purpose or procedure would change the result. A newly created *Skill* is available for later requests; creating it does not run it on the current *Article*.

::: tip Example
Ask, “Create a Skill called ‘Quiet fiction line edit’. Tighten Ana’s sentences while preserving her voice, the river setting, and the scene’s events. Don’t add details; flag unclear passages instead.”
:::

You can ask the Assistant to revise, restore, or delete a *Skill* by name. Restoration creates a new live version and keeps its earlier *Skill Revisions*. See [Create and manage Skills](../skills.md) for the full workflow and local editing options.
