# Check facts

Use **Check facts** when you want to verify factual claims in an *Article*. It researches claims with sources and prepares advisory *Findings*; it does not rewrite the *Article*.

Open **Quick actions**, choose **Check facts**, review the claims the Assistant selects, and deselect any you do not want checked. Then select **Send editorial request**. You can select a passage to focus the check. Results are tied to the saved *Revision* being checked.

::: tip Example
In a chapter set beside the river, Ana says the full moon will raise the water enough to cover the path. Ask **Check facts** to check that detail against sources relevant to the story's setting.
:::

::: tip Review the evidence
Open **Fact Check** and read each *Finding*, its sources, dates, and uncertainty. Sources can be incomplete or outdated, so use the evidence to decide what to verify or change.
:::

Fact checking needs an AI connection and a model that supports sourced fact checking. Provider charges may apply. A *Finding* is advice, not proof that a claim is wrong. For checks focused on technical terminology, see [Check technical terms](check-technical-terms.md).
