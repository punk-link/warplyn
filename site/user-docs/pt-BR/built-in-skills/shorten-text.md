# Encurtar texto

Use **Encurtar texto** quando quiser uma versão mais curta de um texto existente. O recurso corta repetições, conteúdo supérfluo e frases prolixas, preservando o sentido, as evidências, as incertezas e a voz.

Abra **Ações rápidas**, escolha **Encurtar texto** e selecione **Enviar solicitação editorial**. Dê orientações sobre o que manter ou onde cortar. Selecione uma passagem para encurtar somente aquele texto; caso contrário, o assistente trabalhará no *artigo* inteiro.

::: tip Exemplo
Peça: “Sugira uma versão mais enxuta da frase sobre o rio que serpenteia entre os salgueiros. Mantenha a imagem prateada e o clima tranquilo.”
:::

O resultado precisa ser mais curto que o texto de origem. Se não for possível encurtá-lo com segurança, o assistente retorna o texto original sem alterações. Revise a *proposta* antes de aplicá-la; nomes, afirmações, links, código, citações e termos técnicos devem permanecer corretos. Para fazer alterações que melhorem a clareza sem pedir um texto mais curto, use [Melhorar fluidez e clareza](improve-flow-and-clarity.md).
