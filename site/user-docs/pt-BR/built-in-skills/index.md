# Habilidades integradas

As *habilidades* integradas ajudam o assistente editorial a realizar tarefas comuns de escrita. Escolha uma *habilidade* editorial em **Ações rápidas** ou descreva sua solicitação para que o assistente identifique uma *habilidade* relevante. Você pode enviar sozinho o chip de uma habilidade selecionada; adicione uma mensagem somente se tiver contexto extra ou alguma restrição. Selecione **Enviar solicitação editorial** para começar. Para criar ou gerenciar uma *habilidade* reutilizável, peça diretamente ao assistente; **Criador de habilidades** não é uma ação rápida do Composer.

Cada página explica para que serve a *habilidade* e o que revisar no resultado. O assistente prepara um trabalho que pode ser revisado; consulte [Assistente editorial](../editorial-assistant.md) e [Revisar artigos](../reviewing-articles.md) para saber como trabalhar com os resultados.
