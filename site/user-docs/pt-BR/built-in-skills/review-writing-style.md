# Avaliar estilo de escrita

Use **Revise o estilo de redação** quando quiser comparar um *artigo* com seu *Perfil de estilo* salvo. O assistente procura diferenças concretas em relação às características de voz e às regras do perfil. Um perfil com baixa confiança é tratado como provisório.

Antes de enviar a solicitação, adicione exemplos de escrita ou orientações manuais no [Perfil de estilo](../style-profile.md) e reconstrua o perfil. Depois, abra **Ações rápidas**, escolha **Revise o estilo de redação** e selecione **Enviar solicitação editorial**. Selecione uma passagem para direcionar a avaliação; caso contrário, o recurso usará o *artigo* inteiro.

::: tip Exemplo
Peça: “Compare esta passagem sobre Ana no rio com o ponto de vista próximo dos meus exemplos de escrita. Aponte uma diferença e explique a qual característica do perfil ela se relaciona.”
:::

::: tip Revisar alterações sugeridas
Leia a *proposta* e os *apontamentos* que a sustentam. Cada *apontamento* deve indicar uma característica ou regra do perfil. Antes de aceitar alterações, decida quais sugestões se encaixam no *artigo*.
:::

A avaliação de estilo precisa de um *Perfil de estilo* disponível e de uma conexão de IA. Os exemplos de escrita ficam no seu dispositivo. O assistente usa o resumo que o Warplyn cria a partir desses textos. A solicitação pode enviar o *artigo* ou a passagem selecionada ao provedor de IA configurado.
