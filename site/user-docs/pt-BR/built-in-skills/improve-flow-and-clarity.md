# Melhorar fluidez e clareza

Use **Melhore o fluxo e a clareza** quando o texto estiver difícil de acompanhar e você quiser uma estrutura mais clara ou transições mais naturais. O recurso busca melhorar a legibilidade preservando o sentido, as afirmações, as incertezas e a voz do *artigo*.

Abra **Ações rápidas**, escolha **Melhore o fluxo e a clareza** e selecione **Enviar solicitação editorial**. Você pode pedir um foco específico, como esclarecer de que maneira uma descoberta muda a próxima decisão de uma personagem. Selecione uma passagem para limitar a substituição a ela; caso contrário, o assistente trabalhará no *artigo* inteiro.

::: tip Exemplo
Peça: “Sugira uma pequena revisão que deixe mais clara a transição entre observar a correnteza e abrir o caderno. Mantenha o clima tranquilo da cena e não altere os acontecimentos.”
:::

Antes de aplicar, revise a *proposta* para conferir o sentido, os detalhes técnicos e a voz do autor. Para pedir um texto mais curto, use [Encurtar texto](shorten-text.md).
