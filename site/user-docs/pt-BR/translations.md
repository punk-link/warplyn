# Traduções

O Warplyn cria um *artigo* para cada *tradução* e o vincula ao original. A tradução tem título, *rascunho* e histórico de *versões salvas* próprios. Você pode editá-la sem alterar o original.

## Solicitar uma tradução

Abra o *artigo* de origem e escolha **Nova tradução…** em **Traduções**. A janela pode pré-selecionar o idioma do *artigo* atual. Se não houver um idioma visualizado disponível, ela oferece os idiomas preferidos em **Configurações** → **Padrões de idioma**. Selecione e confirme cada idioma de destino. O Warplyn usa o *artigo* inteiro para a tradução, mesmo que você tenha selecionado uma passagem no editor. Se a origem tiver edições não salvas, salve-as primeiro como uma *versão salva* para que a *tradução* possa identificar exatamente o texto usado.

O assistente cria um resultado de *tradução* revisável para cada idioma. Abra um resultado para comparar o título e o texto com o original. Escolha **Lado a lado** para comparar passagens completas ou **Parágrafos alinhados** para ver juntos os parágrafos correspondentes. Texto protegido, como nomes, números, URLs e código, deve permanecer intacto. O Warplyn sinaliza resultados que alteram texto protegido ou usam uma *versão salva* anterior da origem. Confira esses avisos antes de continuar.

::: warning Salve a origem primeiro
Uma solicitação de *tradução* usa uma *versão salva*. Se a origem tiver edições não salvas, salve-as como uma *versão salva* antes de solicitar a tradução, para vincular o resultado ao texto desejado.
:::

## Criar ou atualizar um artigo de tradução

Quando um resultado estiver pronto, use **Editar** para abrir o *artigo de tradução* vinculado. Se ainda não existir, o Warplyn o cria. Revise a *tradução* e salve o *rascunho* ou escolha **Salvar versão** quando estiver pronto. O *artigo* de origem permanece inalterado.

Para usar um resultado mais recente em uma *tradução* existente, escolha **Atualizar** e confirme o *artigo* de destino. O Warplyn adiciona o texto traduzido como uma nova *versão salva* e mantém o título e o histórico anterior da *tradução*. A atualização é bloqueada se a origem ou o destino tiver mudado desde a revisão, se houver um *rascunho* de destino não salvo ou se o resultado já não passar pela validação.

Escolha **Rejeitar** para remover um resultado gerado do fluxo de aprovação. Isso não exclui a origem nem um *artigo de tradução* já criado. Os resultados anteriores continuam disponíveis. Você pode criar outro resultado em **Nova tradução…**.

::: tip A atualização preserva o histórico da tradução
Quando você escolhe **Atualizar**, o Warplyn adiciona o resultado como uma nova *versão salva* ao *artigo de tradução* vinculado. O título e as *versões salvas* anteriores continuam disponíveis.
:::

Cada idioma mantém seus próprios resultados. Use as abas de idioma e o seletor de resultados para rever uma *tradução* ou comparar uma nova tentativa com uma anterior. O resultado informa quando foi criado e qual *versão salva* da origem usou. Se a origem mudou, o resultado está desatualizado e não pode criar um novo *artigo* vinculado. Solicite uma nova *tradução* e revise-a com base na *versão salva* atual da origem.
