# 写作助理

需要撰写、修改、核查事实、审阅风格或准备翻译时，可以使用写作助理。由你决定何时发起请求。从 **快捷操作** 中选择操作，只会将*技能*模板放入输入框。选择 **发送编辑请求** 才会开始处理。

选中文字后，助理只会修改这一部分。所选文字较短时，前后文中的定义和语气线索有助于理解这段内容。为此，Warplyn 也会向提供商发送一部分未选中的文字。如果选区请求需要*文章*文本，Warplyn 会将选区以及前后各最多 500 个字符作为单独的只读上下文发送。只有选中的段落可以被替换。发送前输入框会说明这一点；如果附近文本敏感，请勿发送。一般建议和*技能*管理不需要这些文本。Warplyn 不会在你不知情时将范围扩展到整篇*文章*。如果上下文不足，请明确提供相关段落，或更换选区后重新请求。

::: tip 示例
修改短篇小说时，选中一段并提出：“改善行文流畅度，同时保留 Ana 的视角和安静的氛围。不要添加新事件。”助理会为 **提案审核** 准备一份*待审核提案*。你也可以让它检查章节中是否从过去时切换到了现在时；风格审阅的*审查意见*会显示在 **风格档案** 中。
:::

助理工作时会显示简短的状态消息。若处理时间过长，可选择 **停止请求** 取消。取消或失败的请求不会更改*文章*；要再次运行，请选择 **重试**。助理不会暴露提示词、私密输入、凭据或提供商错误。处理完成后，可以从结果卡片打开对应的视图：

- **提案审核**：查看生成或修改后的文本。
- **事实核查**：查看建议性的*审查意见*。
- **风格档案**：查看风格审阅的*审查意见*。
- **翻译**：查看翻译的*待审核提案*。

打开结果不会更改*文章*。接受更改前请审阅*待审核提案*。*审查意见*仅供参考，翻译会作为单独关联的*文章*保存。有关提案、历史、恢复和事实核查，请参阅[审阅文章](reviewing-articles.md)。有关比较和使用翻译结果，请参阅[翻译](translations.md)。

若要专门检查技术术语，请从 **快捷操作** 中选择 **检查技术术语**。带来源的*审查意见*会显示在 **事实核查** 中。步骤和限制请参阅[检查技术术语](built-in-skills/check-technical-terms.md)。

在 **提案审核** 中，你可以在 **左右并排** 或 **上下排列** 布局下直接编辑 **提案** 文本。**原文** 为只读。编辑时，每项更改的 **接受** 或 **拒绝** 决定都会保留。请逐项接受或拒绝更改，然后选择 **应用** 完成审阅。接受的文本会创建一个新的*已保存版本*。如果拒绝所有建议，**应用**会关闭审阅，不更改*文章*，也不创建*已保存版本*。若要接受全部更改，请从 **设置所有决定…** 中选择 **全部标记为接受**，然后应用。**全部标记为拒绝** 会保持*文章*不变。**重置所有决定** 会将所有建议恢复为待决定，并保留你对提议文本所做的编辑。选择 **关闭提案** 可清除审阅。

切换布局或工作区视图时，未应用的编辑仍会保留。重新加载、切换*文章*、关闭*待审核提案*或生成新提案会清除这些编辑。应用失败时，编辑会保留，以便重试。请保持提议中的数字、链接、代码和技术术语不变。过期、不可靠或已接受的*待审核提案*为只读。如果你修改事实更正的措辞，应用后相关*审查意见*仍仅供参考。

*技能*有助于组织请求，但不会授予权限。如果你没有指定*技能*，助理会根据请求选择合适的*技能*。普通请求不会自动进入默认编辑工作流。未经你批准，Warplyn 不会在后台工作、直接发布或更改*文章*。

如果某个流程需要重复使用，可以让助理创建一个可复用的[技能](skills.md)。当目的、步骤或参考资料不明确时，它可能会简短追问。创建的*技能*会立即可用，并拥有独立的本地*技能已保存版本*历史。创建技能不会读取你的*文章*正文，也不会更改其*草稿*、*待审核提案*或*已保存版本*。

你可以让写作助理检查 **版本历史**、已保存的编辑工作、发布建议或风格语料是否就绪。经明确请求后，它可以将当前不可变的*已保存版本*加入本地风格语料，并重建风格档案。它不能接受*待审核提案*、恢复*已保存版本*、解决*审查意见*、编辑*草稿*、删除风格样本或发布内容。

若要查看写作样本、可复用建议或排版规则，请打开[风格档案](style-profile.md)。风格审阅的*审查意见*会显示在那里，并与*文章*分开保存。
