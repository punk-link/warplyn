# AI 提供商费用

你可以按需使用 AI 助理。Warplyn 不收取请求费用。请求发出后，AI 提供商可能会向你的账户计费。

## 哪些因素会影响费用

提供商自行制定费率。请求费用可能取决于：

- 你选择的提供商和模型；
- 请求中包含多少*文章*文本和指令上下文；
- 模型返回多少文本。

选中的段落较短时，前后的文字可以帮助模型理解这段内容。如果你选中了文字，且请求需要用到*文章*内容，Warplyn 会发送所选文字，并在前后各附上最多 500 个字符，合计最多 1,000 个额外字符。这些文字仅供参考，只有你选中的部分可以被修改。不选择文本时，请求可能包含整篇*文章*和相关上下文。请求范围越小，费用可能越低，具体取决于提供商费率。

::: tip API 计费
订阅提供商的聊天服务可能不包含 API 使用费用。配置 API 密钥前，请查看提供商当前的 API 定价和计费条款。
:::

对于润色段落或针对性修改等日常任务，可以先尝试费用较低的模型。如果结果不理想，再尝试能力更强、费用也更高的模型。

## 查看使用情况

请在提供商账户中查看使用量、费用、提醒和支出限额。Warplyn 不会显示提供商账单，也不会强制执行支出限额。有关计费、退款或账户费用，请联系提供商。

所用模型会影响请求费用。前往 **设置** → **AI助理**，选择 **默认模型**、**应用模型** 和特定任务的模型。设置方法请参阅 [AI 提供商和模型](providers.md)。

::: tip 无需 AI 也能工作
即使没有 AI 连接，你仍可撰写和管理*文章*。编辑、保存*已保存版本*和使用本地备份都不会发送 AI 请求。
:::
