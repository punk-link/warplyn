# 使用 AI 修改文章并逐项审阅更改

如果场景包含正确的事件，但节奏不够流畅，Warplyn 的写作助理可以帮你修改。你可以处理一段文字或整篇*文章*，比较建议的措辞，并应用想要保留的更改。

Warplyn 是适用于 Windows 和 Linux 的开源、本地优先写作工作区。你的写作内容保存在自己的电脑上。AI 助理需要互联网连接、受支持的提供商连接和你的 API 密钥。相关文本和上下文会发送给该提供商，并适用其定价和数据政策。

## 从具体请求开始

打开你的*文章*并选中要修改的段落。在输入框中说明需要改进和保留的内容。例如，编辑《暮色之河》时可以这样请求：

> 改善行文流畅度，同时保留 Ana 的视角和安静的氛围。不要添加新事件。

选择 **发送编辑请求**。Warplyn 会将选区及前后各最多 500 个字符作为只读上下文发送。只有选中的段落可以被替换。发送敏感写作内容前，请查看输入框对上下文的说明。详情请参阅[写作助理](editorial-assistant.md)。

## 比较原文和建议文本

请求完成后，从结果卡片打开 **提案审核**。比较 **原文** 和 **提案**，确认修改保留了场景事件、视角和语气。

[![提案审核界面比较原文和提案文本，并显示单项决定和应用控件。](/images/proposal-review.png)](/images/proposal-review.png)

*《暮色之河》的审阅示例。生成的措辞会因请求和模型而异。*

为单项更改选择 **接受** 或 **拒绝**。应用前可以编辑 **提案** 文本。如果 Warplyn 无法安全拆分*待审核提案*，它会说明你需要整体审阅。

## 应用更改并保留历史记录

为每项更改做出决定后，选择 **应用**。接受的文本会创建新的*已保存版本*。拒绝所有更改会使*文章*保持不变，也不会创建*已保存版本*。仅选择决定不会更改你的写作内容。

打开 **版本历史** 查看较早的已保存版本。恢复某一版本会再创建一个*已保存版本*，并保留中间的历史记录。有关恢复选项和过期的*待审核提案*，请参阅[审阅文章](reviewing-articles.md)。

AI 修改可能无法符合你的意图，也可能更改你希望保留的细节。应用前请审阅结果；必要时可以缩小请求范围后重试。取消或失败的请求不会更改*文章*。

## 用自己的写作内容试一试

[下载 Warplyn](https://github.com/punk-link/warplyn/releases/latest)，按照[安装指南](installation.md)操作，并连接受支持的 [AI 提供商](providers.md)。Windows 安装程序尚未签名；安装指南说明了你可能看到的警告。
