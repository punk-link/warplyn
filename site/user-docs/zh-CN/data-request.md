# 请求访问或删除你的数据

请发送邮件至 [kirill.taran@punk.link](mailto:kirill.taran@punk.link)，咨询 Warplyn 项目收到的个人数据，或请求访问、更正或删除数据。请说明请求涉及哪些数据或交互。项目负责人会通过邮件回复，也可能询问查找数据或验证请求所需的信息。

首次发送邮件时，请勿包含*文章*内容、API 密钥、密码或身份证明文件。

## 可选的桌面版遥测

如果你启用了诊断和使用数据共享：

1. 打开 **设置** → **常规** → **隐私与诊断**，然后选择 **复制ID**。
2. 将该 ID 发送到上述邮箱，并说明你的请求。
3. 若要停止后续收集，请关闭 **分享诊断和使用数据**。

请先复制 ID 再关闭共享，因为关闭后设备上的 ID 会被清除。关闭共享无法撤回已发送的事件。对于删除请求，项目负责人会删除对应的假名化记录并通过邮件确认。

收集字段和共享控件请参阅[诊断和使用数据](telemetry.md)。

## 你的写作内容和 AI 提供商

你的*文章*及其历史记录保存在本地。向项目负责人提出请求不会删除你电脑上的文件或应用数据。删除本地数据前，请先备份要保留的写作内容。

使用 AI 功能时，相关文本和上下文会发送给你选择的提供商。有关该提供商所持数据的请求应另行联系提供商。

## 网站分析

网站分析与桌面版遥测是分开的。如果请求涉及网站访问，请提供大致日期和页面地址。桌面版遥测 ID 无法识别网站访问；我们可能无法从分析数据中识别某次具体访问。

有关使用的服务以及可停用跟踪的浏览器隐私信号，请参阅[网站分析](telemetry.md#website-analytics)。
