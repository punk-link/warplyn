# 撰写和整理文章

*文章*是 Warplyn 资料库中的写作内容。编辑时，Warplyn 会保存可恢复的检查点。*已保存版本*是*文章*历史记录中的一个已保存节点。这样你可以持续写作，不必把每次编辑都当作完成稿。

## 撰写并保存文章

在资料库中选择 **新建文章** 开始写作。通过标题栏重命名*文章*。使用格式工具栏设置标题、列表、强调、链接、引用和代码。粘贴富文本时，Warplyn 会保留受支持的文本格式，并移除不安全或不支持的标记。*文章*以 Markdown 存储，因此复杂页面布局和嵌入内容不会保留。

编辑时，Warplyn 会自动保存当前*草稿*。检查点是可恢复的工作文本，并非版本历史中的新条目。若要确认最近的编辑是否已写入检查点，请查看文章状态栏中的保存状态指示器。切换*文章*或打开设置时，Warplyn 也会保存待处理的检查点。

[![写作工作区显示编辑器中的《暮色之河》、格式工具栏、资料库和草稿已保存指示器。](/images/writing-workspace.png)](/images/writing-workspace.png)

若要将当前*草稿*作为具名节点保存在历史记录中，请选择 **保存版本**。保存*已保存版本*不会移除较早版本。如果本地文本与已保存的*草稿*不再一致，请参阅[审阅文章](reviewing-articles.md#recover-a-draft)。

## 查找和整理文章

使用资料库搜索查找*文章*，包括已归档的文章。选择 **文章** 浏览固定和最近的工作，或选择 **归档** 浏览已归档的*文章*组。折叠的导航栏提供 **新建文章**、**搜索文章**、**文章** 和 **归档** 快捷入口。在资料库菜单中固定原始*文章*，即可在侧栏保留快捷入口。使用 **上移** 或 **下移** 调整固定*文章*的顺序。固定和排序不会更改*文章*内容。通过*文章*标题栏可以重命名文章。

选择 **归档文章**，可将某组*文章*从活动列表移入 **归档**。选择已归档的文章组并点击 **取消归档文章** 可将其恢复。删除*文章*需要确认，并会同时删除其*已保存版本*和可恢复的*草稿*。删除源文章也会删除关联的*翻译*；删除*翻译*则会保留源*文章*。如果只是暂时不需要，请将其归档。

## 使用拼写辅助

编辑器使用设备的拼写检查功能标记可能拼错的词。在桌面版中，右键单击被标记的单词，可选择建议的替换词或 **添加到词典**。替换是普通编辑，可以撤销，并会成为当前*草稿*的一部分。拼写检查在设备本地进行，不会将*文章*文本发送给 AI 提供商。

在桌面版的 **设置** → **拼写** 中，使用 **筛选语言** 查找语言，在 **准备离线写作** 下选择该语言，然后选择 **下载词典**。待状态显示为 **已下载** 后再依赖离线词典。**可用** 表示支持该语言，并不表示词典已下载完成。选择 **卸载** 可在本次会话中停止使用已准备的词典。准备词典不会更改*文章*语言。下载需要互联网连接。在 Windows 上，添加或删除个人词语也会影响操作系统词典，可能波及其他应用。

在 **个人词典** 中搜索已保存的词语，或在 **要添加的单词** 下每行输入一个词语或技术术语，然后选择 **添加单词**。每次最多可添加 500 个词语。删除已保存的词语后，拼写辅助会重新标记它们。该列表由不同*文章*和语言共享。浏览器版使用浏览器的拼写设置，不提供词典管理功能。

写作时使用 **专注模式** 隐藏两个辅助面板；再次选择可恢复面板。使用各面板的折叠控件关闭或重新打开面板；拖动旁边的分隔线可调整大小。窗口较窄时，面板可以作为临时抽屉覆盖在编辑器上方。

使用键盘时，按 **Tab** 和 **Shift + Tab** 可在资料库、文章标题栏、视图、格式工具栏、编辑器、状态栏和助理之间移动。在编辑器、搜索框和输入框中，常用文本编辑键仍然有效。设置有自己的键盘导航方式。在桌面版侧栏中，使用 **Up**、**Down**、**Home** 或 **End** 在分区间移动，再按 **Enter** 或 **Space** 打开分区。

有关将完整*文章*导入或导出 Warplyn，请参阅[文章文件](article-files.md)。有关整个工作区的备份，请参阅[备份与恢复](backups-and-recovery.md)。
