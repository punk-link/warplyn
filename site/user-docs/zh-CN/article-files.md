# 文章文件

使用 **保存到文件** 和 **从文件加载**，可在 Warplyn 与其他写作工具之间传入完整的*文章*。桌面版和 Web 版都支持这些操作。

## 保存到文件

1. 打开要保存的*文章*。
2. 在文章标题栏中，选择 **保存版本** 旁边的 **保存到文件**。也可以在资料库中右键点击某篇*文章*，不打开它就选择 **保存到文件…**。
3. 在桌面版保存窗口中，从文件类型下拉菜单选择 Markdown、HTML、DOCX 或 RTF，然后选择文件名和位置。保留相应的扩展名。在 Web 版中，选择 **文件格式**，然后选择 **下载**，并使用浏览器的下载控件。

文件包含当前完整的*草稿*，包括尚未保存的编辑。选中文字不会限制保存内容。此操作不会创建*已保存版本*。**保存版本** 仍用于将当前*草稿*加入历史记录。

::: tip 需要可携带的工作区副本？
*文章*文件只包含写作内容。若要保留历史记录、助理工作、*技能*和设置，请改为创建[备份](backups-and-recovery.md)。
:::

Web 版将文件交给浏览器时会显示 **已开始下载文章**。请在浏览器下载列表中查看是否完成或出错。

## 从文件加载

1. 在文章标题栏中选择 **保存版本** 旁边的 **从文件加载**，或在资料库中右键点击某篇*文章*并选择 **从文件加载…**。如果资料库为空，请先选择 **创建**。
2. 选择一个 `.md`、`.html`、`.htm`、`.docx` 或 `.rtf` 文件。
3. 对于 HTML、DOCX 和 RTF，请勾选 **检查要导入的文章**，然后选择 **导入**。你可以取消审阅。Markdown 文件会直接打开。
4. Warplyn 会将导入的文本作为一篇独立的*文章*打开。原来的*文章*及其可恢复的*草稿*仍保留在资料库中。

文件开头的一级标题会成为新标题；否则 Warplyn 使用不带扩展名的文件名。该标题仍保留在*文章*正文中。再次加载同一文件会创建另一篇独立的*文章*。

::: warning 导入会创建另一篇文章
加载文件不会替换你打开文件选择器时所在的*文章*。请审阅导入的*文章*，再根据需要移动或删除其中一篇。
:::

文件大小不得超过 10 MiB。Markdown 和 HTML 必须使用 UTF-8。使用 DOCX 和 RTF 无需安装 Microsoft Office。

在源格式支持的范围内，Warplyn 会保留段落、标题、可编辑的嵌套列表和编号、粗体、斜体、删除线、安全链接、引用、代码和 Unicode 文本。页面布局、字体、图片、嵌入对象以及复杂的格式专属功能可能会被省略或简化。表格文本会变为普通的*文章*内容。继续前请检查导入预览。不受支持的 Markdown 扩展也可能在编辑器中丢失格式。

你可以取消文件选择器，而不导入任何内容。如果当前*草稿*无法保存以供恢复，请先修复保存错误，再重试加载。

## 将已保存版本保存到文件

1. 打开 **版本**。
2. 打开要导出的*已保存版本*。
3. 在其详细信息旁选择 **保存到文件**。

文件包含该*已保存版本*中的完整*文章*，与当前*草稿*无关。导出不会还原该*已保存版本*，也不会更改历史记录。建议的文件名会包含*已保存版本*编号。

导出文件同样受 10 MiB 大小限制。如果桌面版保存失败，请选择有写入权限的位置并重试。替换失败时，目标位置中的现有文件会保持不变。

导出的文件只包含*文章*文本，不包含完整历史记录、对话或设置。请使用[备份与恢复](backups-and-recovery.md)保护整个工作区。
