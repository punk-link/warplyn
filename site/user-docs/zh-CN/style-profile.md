# 风格档案

使用 **风格档案** 为助理提供写作样本和可复用的建议。样本保存在此设备上，不会成为*文章*或*已保存版本*的一部分。

从文章库工具区域打开 **风格档案**。使用侧边菜单，或在窄窗口中使用分区选择器，选择 **写作样本**、**手动规则** 或 **排版规则**。**返回** 会返回你离开时的*文章*和视图。

::: tip 选择起点
若要识别语气特征，请添加写作样本；如果你已经清楚想提供哪些建议，可添加 **手动规则**。二者可以单独使用。
:::

## 添加写作样本

若要让助理从你现有的写作中学习，请打开 **写作样本**。选择 **添加写作样本** 粘贴文本，或上传 `.txt`、`.md` 文件。也可以选择 **添加此文章**，将某篇*文章*的已保存版本用作样本。为样本命名，方便以后识别。

使用样本旁的复选框将其纳入档案或排除。排除样本不会将其从列表删除。不再需要时可以移除样本。移除会删除 风格档案 中的样本，因此需要确认。

## 添加建议并重建档案

在 **手动规则** 中描述助理应遵循的偏好。例如，你可以要求保留第一人称叙述，或在缩写首次出现时进行解释。即使没有样本，也可以添加建议。

更改样本或建议后，选择 **重建风格档案** 更新已识别的特征。档案会显示使用了哪些样本以及重建时间。在重建之前，已识别特征可能仍对应以前的样本集。风格审阅的*审查意见*仅为建议，与*文章*文本分开保存。

::: details 手动规则示例
添加体现 Ana 近距离视角和安静意象的场景，排除不希望使用的内容，然后重建档案。如果希望某项偏好即使未在样本中清晰体现也始终生效，可以添加“叙述始终贴近 Ana 的视角”这样的规则。

## 排版规则

打开 **排版规则**，然后选择 **排版语言**。每种写作语言的约定都会单独保存，与界面语言无关。**规则应用范围**可在 **此语言的所有文章**和**仅此文章**之间选择。*翻译*使用自己的语言和偏好。

状态栏的 **原文语言** 菜单包含预设目录中的区域语言。对于其他语言，请选择 **其他语言…** 并输入语言代码，例如日语的 `ja`。随后可为该语言保存自定义排版规则，无需内置预设。

使用 **添加规则** 选择引号、行文破折号、省略号、标点间距、重复空格或不可拆分的词语组合，例如 `10 kg`。**自定义配对** 支持设置开引号、闭引号及引号内的间距。**标点直接替换** 可精确替换标点或间距。规则需要判断语境时，请使用 **上下文排版指示**。

::: info 语言和范围
选择写作语言，并设置规则应用于该语言的所有*文章*还是仅当前*文章*。*翻译*拥有自己的语言和排版偏好。
:::

**规范预设** 显示区域约定预览。标有 **等待母语使用者审核** 的预览暂时无法应用；你可以自行配置规则。区域约定不会自动应用于其他地区。如果之前的规则是全局规则，选择 **将之前的规则复制到此语言** 可复制到当前语言，同时保留原规则。

*文章*规则会继承该语言已保存的约定。编辑继承规则会创建覆盖项；移除覆盖项会在对应范围内禁用该规则。**恢复继承规则** 会清除覆盖项。只要 风格档案 保持打开，切换语言时未保存的规则编辑仍会保留。

规则会以简短摘要显示，并标记为 **已保存** 或 **未保存**。选择 **编辑** 打开规则；每次只能编辑一条。**保存** 会保存所选范围。保存语言偏好时，也会在本地使用当前纳入的样本和已保存建议重建*风格档案*，包括样本是否纳入的更改。*文章*覆盖项会保存在对应的*文章*中。其他表单中未保存的文本仍不会保存。不需要写作样本也能使用明确的排版规则；但识别语气特征需要样本。

保存当前*草稿*，然后选择 **检查排版**，即可在没有 AI 连接的情况下检查所选*文章*。检查会使用已保存的*已保存版本*及其语言，该语言显示在状态栏中。检查时，请在 **排版语言** 中选择相同语言。代码、URL、技术标识符和有歧义的引号情况会保持不变。语境规则需要通过助理完整执行 **审查写作风格**。如果某种语言没有适用的机械规则，本地排版检查就不覆盖该语言；请先添加并保存自己的规则。

打开 **审核提案** 检查更正和支持这些更正的规则。将希望接受的更正标记为已接受，然后选择 **应用**。接受的更正会创建新的*已保存版本*；拒绝全部更正则保持*文章*不变。保存规则或运行检查不会应用更正。审阅结果会保留当时使用的语言和规则定义；更改语言或相关偏好后，系统会提示重新运行。排版检查无法识别混合语言段落中的语言边界。有歧义的情况会保持不变。
