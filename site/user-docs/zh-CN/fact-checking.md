# 事实核查

使用 **核查事实** 可研究*文章*中可验证的陈述，例如历史细节或地点信息。助理会返回带有解释、来源和不确定性说明的建议性*审查意见*。核查不会更改你的文本。

事实核查需要支持基于来源进行核查的 [AI 连接和模型](providers.md)。提供商可能会收费。

## 开始核查

1. 打开*文章*。如需聚焦特定内容，请选中一段文字。
2. 打开 **快捷操作** 并选择 **核查事实**。你也可以直接让助理核查文中的事实。
3. 审阅助理选出的陈述，取消选择不想核查的内容。
4. 选择 **发送编辑请求**。
5. 打开 **事实核查**，查看此次核查所针对的*已保存版本*结果。

::: tip 示例
在《暮色之河》中，Ana 说满月会让水位上涨到淹没小路。请根据与河流和故事背景相关的来源核查这一说法。更改场景前，请确认来源描述的是否确实是那条河。
:::

核查期间，你可以继续写作或前往其他位置。如果核查未完成，只有已经完成的*审查意见*可用。请再次核查未完成的陈述。

## 阅读判定结果和来源

在 **事实核查** 中选择一项陈述，即可查看其解释、来源、核查日期和不确定性。

| 判定结果 | 含义 |
| --- | --- |
| **有证据支持** | 找到的证据支持该陈述。仍建议确认来源是否符合你的语境。 |
| **存在争议** | 找到的证据对该陈述提出质疑。决定修改前，请阅读解释和来源。 |
| **无法验证** | 根据现有证据无法确认该陈述。这本身并不意味着陈述是错误的。 |

打开来源链接，检查其相关性、日期和措辞。*审查意见*是建议，不是证明。核查日期表示检查陈述的时间，并不意味着所有来源都在那天发布。

## 决定如何处理审查意见

对于当前*已保存版本*最近一次核查中尚未解决的*审查意见*，请根据决定选择相应操作。

| 操作 | 结果 |
| --- | --- |
| **按原文接受** | 记录你打算保留原陈述。该*审查意见*会显示 **已按原文接受**。 |
| **接受证据** | 记录你已经审阅并接受证据。该*审查意见*会显示 **已接受证据**。 |
| **提出修正建议** | 对于 **存在争议** 或 **无法验证** 陈述，请求助理准备更正用的*待审核提案*。应用更改前请先审阅。 |

这两种接受操作都会将*审查意见*标记为已解决、移除其决定按钮，并停止在文章资料库中提示需要处理。它们都不会更改*文章*或判定结果，只记录不同的决定理由，对审阅流程的影响相同。

例如，**Disputed · 已接受证据** 表示核查结果质疑该陈述，而你接受了所提供的证据。这**不**代表陈述已更正或已得到支持。如果文本需要更改，请先编辑*文章*或请求更正，再解决该*审查意见*。

若要一次请求多项更正，请选择尚未解决且判定为 **存在争议** 或 **无法验证** 的陈述，然后选择 **提出修正建议**。在 [提案审核](reviewing-articles.md#review-a-proposal) 中检查建议措辞，并应用你接受的更改。应用已接受的文本会创建新的*已保存版本*。

## 更改后重新核查

*审查意见*属于被核查的*已保存版本*。当另一*已保存版本*成为当前版本时，旧的*审查意见*仍可阅读，但会过期。使用前请选择 **重新运行事实核查**。

使用 **事实核查历史** 查看之前的核查记录。之前的记录为只读；只有针对当前*已保存版本*的最近一次核查可供操作。

后续核查识别出未更改的事实时，可能会复用证据和接受决定，包括重新措辞的陈述。复用结果会显示 **复用了版本的证据**，并保留原来的核查日期。事实含义发生变化时，可能需要重新搜索。

重新核查并不保证会为每项未变化的陈述开展新研究。对于时效性较强的细节，请检查来源和核查日期，并明确要求助理根据当前来源重新验证。
