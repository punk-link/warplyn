# 备份与恢复

## 创建备份

在 **设置** → **数据与备份** 中选择 **备份文件夹**，然后点击 **创建备份**。在受支持的浏览器中，Warplyn 只会请求向该目录写入备份的权限。

[![“数据与备份”设置界面显示备份目录、“创建备份”和“恢复备份”控件以及自动备份选项。](/images/backups-and-recovery.png)](/images/backups-and-recovery.png)

*桌面版的“数据与备份”设置。*

::: tip 备份包含哪些内容
新的 `.skladno` 备份包含数据库、当前作者*技能*、其*技能已保存版本*历史以及文件清单。备份不包含 `.env` 文件或 API 密钥。
:::

::: tip 浏览器备份限制
通过浏览器备份时，单个文件最多 100 MB，所有文件合计最多 500 MB。数据量更大时，请使用桌面版。
:::

在桌面版中，每个数据库快照旁边都有一个 `.sqlite.skills` 文件夹，其中包含当前作者*技能*、其*技能已保存版本*历史、你的个人拼写词和文件清单。复制或恢复快照时，请将 `.sqlite` 文件和 `.sqlite.skills` 文件夹放在一起。浏览器备份不包含个人拼写词。

较旧的 `.sqlite` 备份只包含数据库。恢复这类备份会保留当前的*技能*文件和历史记录。

## 自动备份

将 **自动备份** 设置为 **每天**，即可在 Warplyn 启动后不久创建快照；应用保持运行时，之后每 24 小时创建一次。在浏览器中，Warplyn 需要使用所选目录的权限。如果自动备份失败，请检查目录并手动备份；Warplyn 仍会按计划尝试下一次自动备份。

**自动备份保留策略** 用于设置 Warplyn 保留的自动快照数量。它只会删除较旧的自动快照；手动创建的备份始终保留。

## 恢复备份

1. 在 **设置** → **数据与备份** 中选择 **恢复备份**。
2. 选择要恢复的备份。Warplyn 会检查备份文件，并保留当前数据库和*技能*文件的本地恢复副本。
3. 恢复完成后，请检查你的*文章*和*已保存版本*。

恢复 `.skladno` 备份或包含配套文件夹的桌面快照会替换数据库和已保存的*技能*。恢复较旧的、仅含数据库的 `.sqlite` 备份则只替换数据库。

恢复桌面备份还会将其中保存的个人拼写词添加到词典。现有词语会保留。不含个人词语的旧备份不会更改词典。已下载的语言词典和拼写预加载选项不在备份中。

::: warning 恢复后的 AI 设置
恢复时会保留此安装中现有的 AI 连接、凭据和模型选择。如果没有配置任何连接，Warplyn 会从备份恢复环境变量名称和引用，但不会恢复 API 密钥或环境变量值。请在此电脑上设置缺少的变量，然后前往 **设置** → **AI助理** 选择模型。使用已保存 API 密钥的连接不会导入到全新安装中；请在设置中重新添加。其他设置会恢复。恢复失败并回滚时，之前的 AI 配置会保留。
:::

## 手动恢复仅含数据库的备份

以下步骤仅适用于旧版 `.sqlite` 备份。在数据库恢复到原位之前，请不要启动 Warplyn。

1. 复制当前本地数据库。
2. 将备份复制到 Warplyn 配置的数据目录，并覆盖 `skladno.sqlite`。
3. 启动 Warplyn，检查你的*文章*和*已保存版本*。

若要恢复包含*技能*的备份，请在 **设置** 中使用 **恢复备份**，这样 Warplyn 也能检查并恢复文件清单和*技能*历史。

## 无法创建备份时

当前数据库和正在编辑的内容都不会受到影响。请检查目标目录是否存在，以及你的账户是否有写入权限，然后重试。

## 文件权限

默认情况下，本地服务将数据库存储在 `~/.warplyn`。设置 `WARPLYN_DATA_DIR` 可选择其他目录。Warplyn 会忽略 `SKLADNO_DATA_DIR`，也不会使用与 Skladno 旧数据位置重叠的目录。如果你要从 Skladno 迁移，请为 Warplyn 选择单独目录并恢复备份。

在 POSIX 系统中，Warplyn 会将数据目录和 SQLite 文件的访问限制为你的账户，包括升级后。Windows 文件权限由 Windows 管理。浏览器创建的备份文件使用你所选目录的权限，因此请将备份放在私有目录中；使用共享或同步位置前，请检查共享设置。
