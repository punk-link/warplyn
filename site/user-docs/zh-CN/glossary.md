# Warplyn 术语表

这里解释 Warplyn 界面和用户指南中常见的术语。

## 文章和版本

- **文章**：可独立恢复的编辑作品。Warplyn 使用“文章”，而不使用“文档”。
- **文章库**：作者本地的*文章*集合。**当前文章**是工作区中打开的文章；**文章列表**显示整个集合。
- **草稿**：正在编辑但尚未保存为*已保存版本*的*文章*文本。
- **草稿检查点**：本地保存的、可恢复且可变的*草稿*状态，并关联到基础*已保存版本*。它本身不是*已保存版本*。**当前草稿**基于*文章*当前的*已保存版本*；**过期草稿**则基于较早的*已保存版本*。
- **已保存版本**：*文章*在某个时间点保存的副本。保存后，这份副本不会再被改动。
- **保存为新版本**：作者明确将当前*草稿*保存为新的*已保存版本*。此操作只会清除相应的检查点。
- **提案**：由 AI 生成、需要作者明确批准的候选内容或更改。
- **提案基准版本**：用于审阅并生成*待审核提案*的*已保存版本*。当*待审核提案*不再对应当前*已保存版本*时，它会过期。
- **更改选择**：作者从*待审核提案*中选定要接受的更改。接受后会创建新的*已保存版本*。
- **审查意见**：建议性的输出，例如事实核查或风格审阅结果，不会更改*文章*。
- **源文章**和**译文文章**：关联但可独立恢复的*文章*。翻译永远不是其源文的*已保存版本*。

## 编辑工作

- **编辑能力**：经过验证的 Warplyn 操作，会声明可使用的*文章*上下文、前置条件和结果。工作区视图和助理技能可以调用同一项功能。
- **技能**：可复用的指令包，帮助助理为作者请求选择并安排编辑功能。*技能*不授予任何功能或权限。**内置技能**随 Warplyn 提供。**作者创建的技能**是在助理对话中创建的本地 Markdown 包，并拥有独立的*技能已保存版本*历史。
- **编辑操作**：作者请求的助理活动，例如撰写、润色、事实核查、风格审阅或翻译。
- **编辑请求**：一次编辑操作调用。
- **编辑会话**：编辑请求的交互序列和活动历史。
- **编辑指示**：作者在编辑请求中输入的指令或上下文。
- **风格语料**：作者提供的本地写作样本。**风格档案**概括了从这些样本中识别出的写作特征。
- **工作阶段**：作者可选的进度提示。它不会运行 AI，也不会更改*文章*内容。

## 发布和设置

- **发布配置**：可配置的平台建议，包括字符限制。默认配置只适用于新*文章*。
- **发布文本**：通过文章状态栏明确从当前*文章*复制的 Markdown 或纯文本。Warplyn 不提供工作区内的发布预览视图。
- **应用设置**：工作区偏好、AI 配置、发布配置和本地数据管理。设置不属于*文章*的已保存版本历史。
- **AI 连接**：保存在服务端、带名称和凭据来源的提供商配置。新的编辑请求使用**活动 AI 连接**。
- **凭据来源**：AI 连接使用的私密来源，可以是环境变量引用或托管凭据。
- **托管凭据**：保存在操作系统凭据存储中的 API 密钥。Warplyn 会保存连接元数据，但绝不会将密钥写入 SQLite 或备份快照。
- **模型偏好**：默认模型标识符，或针对特定编辑操作的模型覆盖设置。
- **界面语言**：Warplyn 界面的语言，与*文章*和翻译所用语言分开。
- **默认文章语言**：未另行指定时分配给新*文章*的语言。
- **默认翻译语言**：翻译请求中优先显示的有序语言列表。它们不会自动启动翻译。
- **备份位置**：Warplyn 写入备份快照的本地目录。
- **备份快照**：特定时间点的本地数据一致性副本，与活动数据库分开保存且不含凭据。
- **数据位置**：包含 Warplyn SQLite 数据的活动本地目录。
- **数据迁移**：经作者确认的复制和重启流程，可将 Warplyn 切换到新的数据目录，同时保留旧副本以供恢复。
- **恢复快照**：Warplyn 恢复数据时、替换活动数据前保留的备份快照。
- **应用更新**：较新的 Warplyn 打包版本。桌面客户端可以检查、下载，并且只能通过作者控制的步骤应用。更新本身不会更改*文章*内容。
- **安全更新**：发布标签带有 `.security` 后缀的应用更新。Warplyn 会发出提醒，但不会强制检查、下载或重启。
- **待应用更新**：已下载、等待作者选择“重启并更新”的应用更新。普通关闭应用不会应用它。
- **更新前快照**：应用待应用更新前创建的本地数据备份快照。恢复此快照需要匹配的旧版应用。
- **诊断事件**：为启动或可恢复故障支持而写入宿主进程日志的本地脱敏记录。它不包含私密*文章*内容、模型正文或环境变量值。

### 界面术语

- **编辑备注**：作者附加到*文章*某段文字上的指示，与正文分开保存。作者明确请求助手处理该段文字时，助手会参考相关且已关联的备注。备注不会包含在复制或导出的文章正文中。如果无法确定备注对应的文字，需要重新关联备注。
- **编辑工作区**：主要写作界面，包含文章库面板、文章工作区和写作助理面板。
- **文章库面板**：文章搜索、文章列表和工作区级入口。折叠后为 **导航栏**；在小屏幕上临时显示为 **导航抽屉**。
- **文章库面板工具区域**：展开的文章库面板底部区域，包含风格档案、设置、必要时的更新控件，以及当前文章的语言代码和**本地**标签。
- **保存状态指示器**：文章状态栏中的状态，显示当前*草稿*已保存、正在保存或需要处理。
- **文章工作区**：文章标题栏、工作区标签栏、选中的工作区视图和文章状态栏。
- **文章标题栏**：工作区标签栏上方的标题和元数据控件。
- **工作区标签栏**：用于选择工作区视图的标签栏。
- **工作区视图**：选中的文章编辑器或辅助视图：提案审核、版本历史、事实核查或翻译。
- **风格档案**：独立页面，展示识别出的特征、风格审阅*审查意见*、排版规则、手动建议和写作样本。
- **文章编辑器**：写作视图。主要编辑区域称为**写作区域**。
- **文章状态栏**：选中工作区视图下方的栏，显示文章状态和元数据、语言选择、发布配置建议和复制控件。
- **写作助理面板**：编辑建议、操作、请求状态和活动。小屏幕上的临时形式称为**助理抽屉**。
- **快捷操作**：助理消息输入框上方的下拉菜单，用于向请求插入内置技能。
- **助理消息输入框**：写作助理面板底部的消息输入框，作者可在此输入编辑建议并发送请求。
- **应用设置导航**：在 **常规**、**快捷键**、**服务商**、**AI助理**、**发布准备**、**默认语言**、**拼写**、**数据与备份** 和 **关于Warplyn** 之间导航。
