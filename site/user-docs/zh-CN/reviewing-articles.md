# 审阅文章

写作助理可以提出更改，但由你决定哪些内容进入*文章*。**提案审核** 可让你在更改成为*已保存版本*前进行检查。

[![提案审核界面显示三项待处理更改、原文和提案文本、单项决定以及应用控件。](/images/proposal-review.png)](/images/proposal-review.png)

*《暮色之河》的提案审核示例。*

## 审阅待审核提案 {#review-a-proposal}

从助理结果卡片或工作区标签栏打开**提案审核**。阅读修改内容以及有关内容保留的警告。可以切换并排或上下排列的比较布局，选择较易阅读的一种；若想在两个版本中标记已更改的措辞，请开启**突出显示更改**。接受前，请检查更改文本中的姓名、数字、陈述、链接和语气。

为单项更改选择**接受**或**拒绝**。若要统一设置所有决定，请在**设置所有决定…**中选择**全部标记为接受**或**全部标记为拒绝**。然后选择**应用**完成审阅。接受的文本会成为新的*已保存版本*。如果拒绝所有建议，**应用**会关闭审阅，不更改*文章*，也不创建*已保存版本*。**重置所有决定**会将所有建议恢复为待决定，并保留你对提议文本所做的编辑。仅选择决定不会更改*文章*。**关闭提案**会清除审阅而不应用文本。若某份*待审核提案*无法安全拆分，系统会提示你整体审阅。

::: tip 按自己的节奏审阅
应用前，你可以编辑提议措辞并切换比较布局。只有选择 **应用** 后，决定才会生效。
:::

如果 Warplyn 无法安全应用所选更改，它会说明何时只能接受整份*待审核提案*。过期的*待审核提案*基于较早的*已保存版本*创建，因此无法应用到当前文本。请关闭它，或返回对应历史记录并重新发起请求。

## 浏览或恢复已保存版本

打开 **版本历史** 阅读已保存版本。选择某个*已保存版本*会打开只读预览，不会更改当前工作。标记为 **非当前版本** 的*已保存版本*属于后来被恢复操作替换的分支；你仍可查看或恢复它们。

选择 **恢复此版本** 可将较早版本设为当前版本。Warplyn 会使用该文本创建一个新的*已保存版本*，不会删除中间的历史记录。如果有未完成的*草稿*，恢复前请选择将它保存为*已保存版本*还是丢弃。

## 恢复草稿 {#recover-a-draft}

编辑期间保存的检查点包含可恢复的文本。如果编辑器中的本地文本与已保存检查点或当前*已保存版本*冲突，Warplyn 会将保留的本地文本与已保存选项并列显示。比较后选择 **保留我的草稿**、**使用最新草稿** 或 **使用最新已保存版本**。使用已保存选项可能替换本地文本，因此 Warplyn 会先请求确认。

## 选择如何应用助理编辑

新对话默认使用 **提出修改供审核**。如果你明确请求的编辑不需要*待审核提案*，可以在输入框中选择 **直接应用修改**。直接编辑成功后会生成新的*已保存版本*。如果你选中了文本，修改范围会限制在该选区内。当*草稿*或已更改的*已保存版本*可能导致替换不安全时，直接编辑会被阻止。请先处理当前工作再重新请求。其他生成结果仍需审阅。

若要从之前某条消息继续对话，请选择该消息上的 **从此处编辑**。确认 **恢复对话**前，Warplyn会列出将被拒绝的后续工作，例如*待审核提案*、*审查意见*或翻译结果。它也会说明*文章*是否会返回较早的*已保存版本*，或未发送的输入框文本是否会被替换。如果*草稿*需要处理，请选择 **保存当前工作并恢复** 或 **丢弃草稿并恢复**。较新和当前的*已保存版本*仍会保留在版本历史中。此操作不会恢复或更改*技能*。

## 阅读事实核查意见

打开 **事实核查** 查看建议性的*审查意见*及其来源。接受决定会解决某项*审查意见*，但不会更改*文章*或判定结果。更正用的*待审核提案*需先审阅，相关更改才会写入文本。完整流程、判定结果、接受方式以及如何重新核查旧结果，请参阅[事实核查](fact-checking.md)。
