# AI 提供商和模型

Warplyn 会将 AI 请求发送给你在 **设置** → **AI助理** 中配置的提供商。你需要拥有该提供商的账户和 API 密钥。提供商可能会收取 API 使用费用。

## 添加连接

在桌面版中打开 **设置** → **AI助理**。在 **您希望如何提供密钥？** 下选择 **添加API密钥** 或 **环境变量**。

- **添加API密钥：**选择提供商，为连接命名并输入密钥。Warplyn 会将其存储在 Windows Credential Manager 或 Linux Secret Service 中。密钥不会再次显示，也不会存储在 Warplyn 数据库或备份中。
- **环境变量：**选择提供商，为连接命名，并输入存放密钥的环境变量名称。Warplyn 只保存名称，不保存变量值。应用服务启动时必须能够读取该变量。

::: tip 关于凭据
要让 Warplyn 保存 API 密钥，请使用桌面版，并确保系统的凭据服务可用。在 Linux 上，Secret Service 必须处于解锁状态。浏览器版支持环境变量连接，但无法管理操作系统凭据。安装程序不会创建或导入 `.env` 文件。
:::

添加 API 密钥连接时，Warplyn 会向提供商验证密钥。添加环境变量连接时，只会保存设置。刷新模型或发送 AI 请求时，Warplyn 会再次联系提供商。这些检查不会包含*文章*内容。

连接会列在 **设置** → **AI助理** 中。连接状态显示为 **已启用** 时，Warplyn 可以用它处理新请求。要更改状态，请选择 **启用** 或 **停用**。选择 **重命名** 可更改连接的本地显示名称；选择 **移除** 并确认可从 Warplyn 中移除连接。移除环境变量连接不会删除变量或密钥。

::: tip 刷新模型失败时
请确认连接为 **已启用**，已保存的密钥有效或应用服务可以读取环境变量，并且提供商账户有权访问其 API。
:::

## 选择提供商和模型

Warplyn 支持 OpenAI、OpenCode Zen、Anthropic、Google Gemini API、xAI Grok 和 DeepSeek。OpenCode Zen 的目录中也提供其他供应商的模型。

在 **设置** → **AI助理** 中选择 **刷新可用模型**，然后选择 **默认模型**。若要为某个*技能*使用不同模型，请在 **特定任务模型** 下选择。如果希望某项任务继续使用默认模型，请选择 **使用默认模型**。

更改连接后或想查看提供商当前目录时，请刷新模型列表。可使用 **搜索模型**、**按提供商筛选模型** 和 **收藏** 缩小范围。模型选择只影响之后的请求。如果所选的 OpenAI 模型显示 **推理级别**，你可以调整它。推理级别越高，模型可能需要的时间就越长。AI 设置中的可选 **应用模型** 与默认模型不同，用于摘要、标题等 Warplyn 辅助任务。

::: tip 模型可用性
可用的编辑操作因模型而异。有些模型不支持带来源的事实核查、结构化输出或推理控制。OpenCode Zen 模型的功能和可用性以其目录为准。
:::

### 应用模型

**应用模型**处理简短的辅助任务，例如为*待审核提案*生成摘要、拟定标题，或判断你想让助理做什么。如果未设置，Warplyn 会使用默认模型。

请选择高效且费用较低的文本模型。**GPT-6 Luna** 是 OpenAI 为此类专门任务提供的一种选择（[模型详情](https://developers.openai.com/api/docs/models/gpt-6-luna)）。使用其他提供商时，请选择相近的模型。如果结果不够理想，可以尝试能力更强的模型。
