# 翻译

*翻译*是单独关联的*文章*，拥有自己的标题、*草稿*和*已保存版本*历史，因此一种语言的工作不会覆盖源文。

## 请求翻译

打开源*文章*，在 **翻译** 中选择 **新建翻译…**。对话框可能会预选当前*文章*的语言。如果没有可用的查看语言，它会显示 **设置** → **默认语言** 中的首选语言。选择并确认每个目标语言。即使你在编辑器中选中了某个段落，Warplyn 仍会翻译整篇*文章*。如果源文有未保存的编辑，请先将其保存为*已保存版本*，这样*翻译*结果才能指明所使用的确切文本。

助理会为每种语言创建一份可审阅的*翻译*结果。打开结果，将标题和文本与源文比较。选择 **左右并排** 比较完整段落，或选择 **段落对齐** 并排查看对应段落。姓名、数字、URL 和代码等受保护文本必须保持不变。若结果更改了受保护文本或使用较旧的源*已保存版本*，Warplyn 会显示标记。继续前请检查这些提示。

::: warning 先保存源文
*翻译*请求使用已保存的*已保存版本*。如果源文有未保存的编辑，请在请求翻译前将其保存为*已保存版本*，以确保结果对应你想翻译的文本。
:::

## 创建或更新翻译文章

结果准备好后，使用 **编辑** 打开关联的*翻译文章*。如果它尚不存在，Warplyn 会创建一篇。审阅*翻译*，准备好后保存其*草稿*或选择 **保存版本**。源*文章*保持不变。

若要将较新的结果用于已有*翻译*，请选择 **更新** 并确认目标*文章*。Warplyn 会将译文添加为新的*已保存版本*，并保留*翻译*标题及先前历史记录。如果源文或目标自审阅后发生更改、目标有未保存的*草稿*，或结果不再通过验证，则无法更新。

选择 **拒绝** 可从待批准结果中移除生成的内容。这不会删除源文或已经创建的*翻译文章*。旧结果仍可用。你可以通过 **新建翻译…** 创建另一个结果。

::: tip 更新会保留翻译历史
选择 **更新** 后，Warplyn 会将结果作为新的*已保存版本*添加到关联的*翻译文章*。该文章的标题和之前的*已保存版本*仍然保留。
:::

每种语言都有自己的结果。使用语言标签和结果选择器重新查看*翻译*，或将新结果与较早的尝试比较。结果会标明创建时间以及所用的源*已保存版本*。如果源文已经更改，该结果就会过期，不能用于创建新的关联*文章*。请针对当前源*已保存版本*重新请求并审阅*翻译*。
