# 创建和管理技能

*技能*是本地 Markdown 指令包，告诉助理该用哪些编辑功能，以及按什么顺序使用。它们不会授予权限，也不会更改*文章*。

## 创建和管理自己的技能

用日常语言让助理创建可复用的*技能*。说明要重复完成的任务以及所需规则或参考资料。如果缺少的信息会影响*技能*，助理会简短追问，而不是猜测。

::: tip 示例
若要按安静河边场景的风格修改小说，可以这样请求：“创建一个名为‘安静小说逐句编辑’的*技能*。在保留 Ana 的语气、河边背景和场景事件的前提下，让句子更简洁。不要添加细节；请标记不清楚的段落。”每当你要求逐句编辑时，助理都可以复用这些说明。
:::

*输入框中的技能创建请求示例。发送前请连接提供商。*

创建后，你就可以在新的助理请求中使用该*技能*。创建请求不会将你的*文章*正文发送给模型，也不会更改*文章*、*草稿*、*待审核提案*或*已保存版本*。

每个创建的*技能*都有本地、不可变的*技能已保存版本*历史，与*文章*的已保存版本历史分开。你也可以直接编辑本地 Markdown 指令包。Warplyn 会在下一个请求时刷新目录。删除 `SKILL.md` 文件会将该*技能*从可用*技能*列表中移除。

让助理按名称修改或删除某个*技能*时，它会先读取当前指令包，并检查文件从读取后是否发生过变化。修改会保留*技能* ID，并新增一个*技能已保存版本*。删除会使该*技能*不再用于新请求，但其历史记录仍会保留。

若要恢复以前的指令，请让助理列出该*技能*的*已保存版本*，并指出要恢复哪一个。恢复操作会让旧指令重新生效，并在历史中新增一个*技能已保存版本*。也可以用此方式恢复已删除的*技能*。恢复助理聊天检查点不会恢复或更改任何*技能*；恢复*技能*需要单独请求。
