# 应用设置

应用设置用于控制 Warplyn 的外观和行为，不属于*文章*的*已保存版本*历史。请从 **文章库面板工具区域** 打开 **设置**。部分设置仅适用于桌面版，文中会注明。

## 设置外观和语言

在 **常规** → **外观与语言** 中，为 **首选外观** 选择 **跟随系统**、**浅色** 或 **深色**。**跟随系统** 会跟随设备设置，并在 Warplyn 运行期间更新。选择 **界面语言** 可设置菜单和消息的语言。目前只有英文界面已完整翻译。这些选项不会改变*文章*的写作语言或排版规则。

在 **日期与时间** 中选择日期格式、12 小时或 24 小时制，以及时区。系统选项跟随设备设置。这些选项只改变 Warplyn 中已保存时间的显示方式，不会改变时间本身。

## 设置写作默认值

在 **默认语言** 中为新*文章*设置 **默认文章语言**。设置 **默认翻译语言** 后，申请*翻译*时这些目标语言会优先显示。输入语言名称、区域变体或代码，然后选择 **添加**。Warplyn 仍会要求你确认每个翻译请求。

## 设置助理行为

在 **AI助理** 中，可将 **提出修改供审核** 设为新*文章*对话的默认方式，也可以为明确请求的编辑启用 **直接应用修改**。此默认值不会更改现有对话，其他生成结果仍需审阅。

**请求时限** 适用于每个新请求和重试，默认是两分钟。对于耗时较长的任务，可设置更长时间或选择 **无限制**。请求超时不会更改你的*文章*。

选择 **Enter** 或 **Ctrl + Enter** 作为助理的发送键。其他应用快捷键可在 **快捷键** 中更改。保存快捷键前，Warplyn 会指出冲突。

## 设置发布建议

在 **发布准备** 中为新*文章*选择默认配置。**LinkedIn帖子** 和 **LinkedIn文章** 等配置会在文章状态栏中显示字符数建议。你也可以选择 **无限制**，或添加包含名称和整数字符上限的自定义配置。默认配置仅用于新*文章*；现有*文章*可以保留自己的配置。字符限制仅供参考，不会阻止复制。在文章状态栏中选择 **复制Markdown**，或打开菜单并选择 **复制纯文本**。Warplyn 会按你的要求复制文本，但不会直接发布。

## 查看 AI 模型选项

在 **AI助理** 中可以保留多个提供商连接，只启用需要使用的连接，并为通用助理任务和特定*技能*分配不同模型。除非任务另有指定，AI 工作会使用 **默认模型**。可选的 **应用模型** 用于 Warplyn 的摘要、标题等任务；未设置时则使用默认模型。可使用 **收藏**、搜索或供应商筛选器查找模型。受支持的 OpenAI 模型会显示 **推理级别**。可用任务和控件取决于模型。连接设置和提供商限制请参阅 [AI 提供商和模型](providers.md)。

在 **快捷键** 中选择某项操作旁的快捷键，然后按下所需组合键。你可以为保存*已保存版本*、切换视图或开关 Focus 模式设置快捷键。Warplyn 会指出已占用冲突快捷键的操作，请选择其他组合键。**发送方式** 用于设置按 **Enter** 还是 **Ctrl + Enter** 发送助理请求。更改快捷键不会修改*文章*内容。

## 检查桌面版更新

已打包的桌面应用可通过 **设置** → **关于Warplyn** → **更新** 检查新版本。首先允许 **允许联网更新**。这样 Warplyn 才能联系 GitHub，获取公开的版本信息以及你选择下载的更新。然后选择是否 **自动检查更新** 和是否 **包含预发布更新**。随时可以选择 **立即检查**。有可用版本时会显示其说明。Windows 和 Linux AppImage 安装提供 **下载** 和 **重启并更新** 操作。Debian 安装则使用 **查看发布说明**，随后通过软件包管理器升级或安装更新的 `.deb` 文件。如果更新导致应用无法启动，请参阅[桌面版更新恢复](update-recovery.md)。

## 删除本地数据

在桌面应用中，**删除本地数据** 会永久删除 Warplyn 当前使用的数据，包括*文章*、*已保存版本*、检查点、助理历史、风格数据、设置，以及存储在该数据目录中的本地备份。如果已设置备份目录，确认窗口会提供 **删除前创建备份**。Warplyn 必须先完成备份，之后才会删除任何数据。删除成功后应用会关闭。正常卸载不会删除你的写作数据。保存在操作系统词典中的个人拼写词仍会保留；如需删除，也可前往 **设置** → **拼写** 单独移除。

请打开 **设置** → **关于Warplyn** 查找用户指南、源代码仓库、问题跟踪器和许可证。选择 **打开快速入门** 可再次查看首次启动介绍。
