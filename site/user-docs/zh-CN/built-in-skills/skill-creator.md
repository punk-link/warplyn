# 技能创建工具

当你明确要求创建、修改、恢复或删除可复用的*技能*时，助理会使用内置的“技能创建工具”。它管理本地 Markdown 指令，并为每个*技能*单独保留历史记录。

请描述需要重复完成的任务，以及*技能*应遵循的规则或参考资料。如果目的或流程不明确且会影响结果，助理可能会简短追问。创建后，你可以在新的请求中使用这个*技能*。当前*文章*不会自动运行该技能。

::: tip 示例
提出：“创建一个名为‘安静小说逐句编辑’的技能。在保留 Ana 的语气、河边背景和场景事件的前提下，让句子更简洁。不要添加细节；请标记不清楚的段落。”
:::

你可以按名称让助理修改、恢复或删除某个*技能*。恢复会创建新的生效版本，并保留较早的*技能已保存版本*。完整工作流和本地编辑选项请参阅[创建和管理技能](../skills.md)。
