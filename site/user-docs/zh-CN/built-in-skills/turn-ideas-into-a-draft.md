# 将想法转化为草稿

如果你有源材料，但需要一份连贯的初稿，请使用 **将想法整理为草稿**。它会将提供的想法整理成直白易懂的叙述，同时保留原意并避免无依据的陈述。

打开 **快捷操作**，选择 **将想法整理为草稿**，说明希望的方向，然后选择 **发送编辑请求**。选中段落后，请求会使用该段以及你在消息中明确提供的材料。未选中段落时，它可以结合当前*文章*和你的指示生成内容。

::: tip 示例
选中 Ana 打开笔记本的段落，并提出：“根据这段中已有的细节，帮我起草一个可能的下一段。保持页面空白，不要解释为什么河流似乎认得她。”
:::

助理会准备一份供审阅的*待审核提案*。接受更改前，请检查其结构、陈述和措辞。提案本身不会保存或更改*文章*。若要改写现有文本，请参阅[改善行文流畅度和清晰度](improve-flow-and-clarity.md)。
