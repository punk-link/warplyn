# 提炼关键要点

需要从笔记或*文章*中提炼简明的主要思想列表时，请使用 **扩展核心要点**。默认会整理出三到五个不同的要点，不会改写*文章*。

打开 **快捷操作**，选择 **扩展核心要点**，可在输入框中说明希望关注什么，然后选择 **发送编辑请求**。如果选中一段文字，结果会结合该选区和消息中提供的内容。未选中内容时，助理会优先遵循你的消息；如果消息为空，则使用*文章*。

::: tip 示例
选中 Ana 坐在河边的场景，并提出：“根据这段内容，给出三种可能的解读，说明 Ana 与河流之间的关系。”
:::

返回的要点可能需要修正或调整侧重点。用于*文章*前请先审阅。若要根据提供的材料生成完整草稿，请参阅[将想法转化为草稿](turn-ideas-into-a-draft.md)。
