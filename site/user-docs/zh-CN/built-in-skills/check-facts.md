# 核查事实

想要核实*文章*中的事实陈述时，请使用 **核查事实**。它会查找来源并准备建议性的*审查意见*，但不会改写*文章*。

打开 **快捷操作**，选择 **核查事实**，审阅助理选出的陈述，并取消选择不想核查的内容。然后选择 **发送编辑请求**。你可以选中某个段落以聚焦核查范围。结果会关联到正在核查的*已保存版本*。

::: tip 示例
在一章以河边为背景的故事中，Ana 说满月会让水位上涨到淹没小路。请 **核查事实** 根据与故事背景相关的来源核实这一细节。
:::

::: tip 审阅证据
打开 **事实核查**，阅读每条*审查意见*、来源、日期和不确定性说明。来源可能不完整或过时，请根据证据决定要核实或更改什么。
:::

有关判定结果、接受决定、更正和复用证据，请参阅[事实核查指南](../fact-checking.md)。事实核查需要 AI 连接和支持来源核查的模型。提供商可能会收费。*审查意见*是建议，并不能证明某项陈述有误。若要检查技术术语，请参阅 [检查技术术语](check-technical-terms.md)。
