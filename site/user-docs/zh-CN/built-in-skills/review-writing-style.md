# 审阅写作风格

需要将*文章*与已保存的 *风格档案* 比较时，请使用 **审查写作风格**。助理会查找与档案中语气特征和规则的具体差异。置信度较低的档案会被视为暂定结果。

发送请求前，请在 [风格档案](../style-profile.md) 中添加写作样本或手动建议，并重建档案。然后打开 **快捷操作**，选择 **审查写作风格**，再选择 **发送编辑请求**。选中一段文字可聚焦审阅范围；否则会使用整篇*文章*。

::: tip 示例
提出：“请将这段关于 Ana 在河边的文字与我写作样本中贴近人物的视角进行比较。指出一处差异，并说明它对应档案中的哪项特征。”
:::

::: tip 审阅建议的更改
阅读*待审核提案*及其支持性*审查意见*。每条*审查意见*都应指向一项档案特征或规则。接受更改前，请判断哪些建议适合这篇*文章*。
:::

风格审阅需要可用的 *风格档案* 和 AI 连接。原始写作样本不会发送；助理使用本地提取的精简档案。请求可能会将*文章*或所选段落发送给你配置的 AI 提供商。
