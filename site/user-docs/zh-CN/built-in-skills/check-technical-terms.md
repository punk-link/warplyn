# 检查技术术语

使用 **检查技术术语** 检查 IT *文章*中的术语。它会查找混淆的概念、容易误导的缩写展开、不正确的产品或 API 名称，以及同一概念名称不一致的问题。它会根据相关领域和版本的来源进行比较，同时考虑本地定义和不断变化的术语。

打开你的*文章*。如需聚焦核查，可选中某段文字。在助理中打开 **快捷操作**，选择 **检查技术术语**，然后选择 **发送编辑请求**。完成后在 **事实核查** 中打开结果，检查每条*审查意见*、解释、关联来源和不确定性说明。

::: tip 示例
在一篇关于树木识别应用的*文章*中，作者把柳树称为针叶树。请 **检查技术术语** 根据植物学来源核实该术语。
:::

此核查需要 AI 连接和支持来源核查的模型。你的*文章*或选中段落会发送给已配置的 AI 服务；研究查询可能包含其中的技术术语和陈述上下文。提供商可能会收费。来源可能不完整，也可能因领域不同而对术语有不同用法。*审查意见*仅为建议，不会改写正文、代码或标识符。系统不会在后台扫描术语。
