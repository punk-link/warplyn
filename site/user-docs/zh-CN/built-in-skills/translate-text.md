# 翻译文本

使用 **翻译文本** 可将整篇*文章*翻译成所选语言，供你审阅。它会翻译标题和正文，同时保留陈述、数字、语气和 Markdown 格式。即使你只选中了某段文字，此*技能*仍会使用整篇*文章*。

打开*文章*的 **翻译** 视图并选择 **新建翻译…**。选择目标语言并确认请求。如果源文有未保存的编辑，请先将其保存为*已保存版本*，这样，翻译就会以你刚保存的文本为准。

::: tip 示例
请求翻译 Ana 河边场景的草稿，同时保留对话、视角、安静的氛围、姓名和受保护文本。使用 **编辑** 打开关联的*翻译文章*，或使用 **更新** 将结果作为新的*已保存版本*添加到现有文章。
:::

翻译会与源文分开保存。有关比较结果、更新关联*文章*以及处理过期结果，请参阅[翻译](../translations.md)。
