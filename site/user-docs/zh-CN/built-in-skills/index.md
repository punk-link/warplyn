# 内置技能

内置*技能*帮助写作助理完成常见的写作任务。可从 **快捷操作** 中选择编辑*技能*，也可以直接说你想做什么，由助理判断适合用哪些*技能*。选中的技能标签可以单独发送；只有在需要补充上下文或限制时才添加消息。选择 **发送编辑请求** 开始处理。要创建或管理可复用的*技能*，请直接询问助理；**技能创建工具** 不是输入框的快捷操作。

每个页面都会说明*技能*的用途以及需要审阅的结果。助理会准备可供审阅的内容；如何处理结果请参阅[写作助理](../editorial-assistant.md)和[审阅文章](../reviewing-articles.md)。
