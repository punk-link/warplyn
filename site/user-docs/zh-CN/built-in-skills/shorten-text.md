# 缩短文本

需要缩短现有文本时，请使用 **精简文本**。它会删减重复、填充词和冗长措辞，同时保留含义、证据、不确定性和语气。

打开 **快捷操作**，选择 **精简文本**，然后选择 **发送编辑请求**。补充说明要保留什么或从哪里删减。选中一段文字可只缩短该段；否则助理会处理整篇*文章*。

::: tip 示例
提出：“请改写关于河流在柳树间蜿蜒那句话，让它更简练。保留银色意象和安静氛围。”
:::

结果必须比原文更短。如果无法安全缩短，助理会原样返回文本。应用前请审阅*待审核提案*；姓名、陈述、链接、代码、引文和技术术语都应保持准确。如果希望提高文本清晰度而不要求缩短，请使用 [改善连贯性和清晰度](improve-flow-and-clarity.md)。
