# 改善行文流畅度和清晰度

如果写作内容不易理解，且你希望结构更清晰、过渡更自然，请使用 **改善连贯性和清晰度**。它旨在提高可读性，同时保留*文章*的含义、陈述、不确定性和语气。

打开 **快捷操作**，选择 **改善连贯性和清晰度**，然后选择 **发送编辑请求**。你可以指定重点，例如说明某个发现如何改变角色的下一步选择。选中一段文字可将替换范围限制在该段；否则助理会处理整篇*文章*。

::: tip 示例
提出：“建议做一处小修改，让从观察水流到打开笔记本的转折更清楚。保持场景安静的氛围，不要改变任何事件。”
:::

应用前请检查*待审核提案*的含义、技术细节和作者语气。如果希望缩短文本，请使用 [精简文本](shorten-text.md)。
