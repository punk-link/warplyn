# AI プロバイダーの利用料金

AI 支援は任意です。リクエストに対して Warplyn が料金を請求することはありません。Warplyn がリクエストを送信すると、AI プロバイダーがお客様のアカウントに料金を請求する場合があります。

## 料金に影響する要素

プロバイダーごとに料金が設定されています。リクエストの料金は、次の要素によって変わることがあります。

- 選択したプロバイダーとモデル
- リクエストに含まれる *記事*のテキストと指示コンテキストの量
- モデルが返すテキストの量

短い選択範囲を解釈する際、周辺のテキストが役立つことがあります。その場合、未選択の文章も一部送信されます。*記事*のテキストが必要な選択リクエストでは、選択した一節に加えて、その前後それぞれ最大 500 文字、合計で最大 1,000 文字が読み取り専用のコンテキストとして送信されます。編集対象になるのは選択範囲だけです。選択範囲がない場合、リクエストに *記事*全体と関連コンテキストが含まれることがあります。プロバイダーの料金体系によっては、範囲を絞ったリクエストの方が安くなる場合があります。

::: tip API の請求
プロバイダーのチャットサービスへのサブスクリプションに、API の利用が含まれていない場合があります。キーを接続する前に、プロバイダーの最新の API 料金と請求条件を確認してください。
:::

文章の流れを整える、一節を集中的に改稿するなどの日常的な作業では、まず低コストのモデルを試してください。結果から、より高性能なモデルが必要だと分かった場合に切り替えます。

## 利用状況を確認する

利用状況、料金、アラート、支出上限は、プロバイダーのアカウントで確認してください。Warplyn はプロバイダーの請求額を表示せず、支出上限も適用しません。請求、返金、アカウントの料金についてはプロバイダーにお問い合わせください。

リクエストに使用するモデルは料金に影響します。**設定** → **AIアシスタント** で **既定のモデル**、**アプリ用モデル**、タスク別のモデルを選択します。設定方法は [AI プロバイダーとモデル](providers.md)を参照してください。

::: tip AI なしでも作業できます
AI 接続がなくても *記事*の執筆と管理ができます。編集、*保存済みバージョン*の保存、ローカルバックアップの利用では AI リクエストは送信されません。
:::
