# ファクトチェック

**事実を確認** を使うと、歴史的な詳細や場所に関する記述など、*記事*内の検証可能な主張を調査できます。編集アシスタントは説明、出典、不確実性を含む参考情報としての *指摘事項*を返します。確認によって文章が変更されることはありません。

事実確認には、出典に基づく確認に対応した[AI 接続とモデル](providers.md)が必要です。プロバイダー料金が発生する場合があります。

## 確認を始める

1. *記事*を開きます。範囲を絞る場合は、一節を選択します。
2. **クイックアクション** を開いて **事実を確認** を選択します。文章の事実確認を編集アシスタントに依頼することもできます。
3. 編集アシスタントが選んだ主張を確認し、確認したくないものは選択を解除します。
4. **編集リクエストを送信** を選択します。
5. **ファクトチェック** を開き、確認対象の保存済み *バージョン*に対する結果を確認します。

::: tip 例
「夕暮れの川辺」で、アナは満月によって水位が上がり、道が水没すると言います。その主張を、川や物語の舞台に関係する出典で確認してください。場面を変更する前に、出典がその川について説明しているか読んでください。
:::

確認の実行中も執筆や別の画面への移動を続けられます。処理が未完了の場合、完了した *指摘事項*だけを確認できます。未完了の主張については、改めて確認を依頼してください。

## 判定と出典を読む

**ファクトチェック** で主張を選択すると、説明、出典、確認日、不確実性を確認できます。

| 判定 | 意味 |
| --- | --- |
| **裏付けあり** | 見つかった証拠は主張を裏付けています。それでも、出典が文脈に適しているか確認してください。 |
| **異論あり** | 見つかった証拠は主張に異議を唱えています。変更する前に説明と出典を読んでください。 |
| **検証不能** | 利用できる証拠から主張を確認できませんでした。これだけで主張が誤りだとは限りません。 |

出典へのリンクを開き、関連性、日付、記述内容を確認してください。*指摘事項*は助言であり、証明ではありません。確認日は主張を確認した日を示します。すべての出典がその日に公開されたという意味ではありません。

## 指摘事項への対応を決める

現在の *保存済みバージョン*に対する最新の確認に、未解決の *指摘事項*がある場合は、判断に合った操作を選びます。

| 操作 | 結果 |
| --- | --- |
| **原文のまま採用** | 主張を現在の文言のまま残す意向を記録します。*指摘事項*には **原文のまま採用済み** と表示されます。 |
| **根拠を採用** | 証拠を確認し、受け入れたことを記録します。*指摘事項*には **根拠を採用済み** と表示されます。 |
| **修正を提案** | **異論あり** または **検証不能** の主張について、編集アシスタントに訂正の *提案*を作成するよう依頼します。変更を適用する前に確認してください。 |

どちらの承認操作でも *指摘事項*は解決済みとなり、判断ボタンが消えて、記事ライブラリ で要対応として表示されなくなります。どちらも *記事*や判定結果は変更しません。判断理由はそれぞれ記録されますが、レビューの流れに対する効果は同じです。

たとえば **Disputed · 根拠を採用済み** は、確認で主張に異議が示され、その証拠を受け入れたことを意味します。主張が訂正された、または裏付けられたという意味では**ありません**。文章を変更する必要がある場合は、*指摘事項*を解決する前に *記事*を編集するか、訂正を依頼してください。

複数の訂正をまとめて依頼するには、未解決の **異論あり** または **検証不能** の主張を選び、**修正を提案** を選択します。[提案の確認](reviewing-articles.md#review-a-proposal)で提案された文言を確認し、承認する変更を適用してください。承認したテキストを適用すると、新しい *保存済みバージョン*が作成されます。

## 変更後に再確認する

*指摘事項*は確認対象となった *保存済みバージョン*に属します。別の *保存済みバージョン*が現在のものになると、以前の *指摘事項*は読めますが、古い情報になります。対応する前に **ファクトチェックを再実行** を選んでください。

以前の実行結果を確認するには **ファクトチェックの履歴** を使います。以前の結果は読み取り専用です。操作できるのは、現在の *保存済みバージョン*に対する最新の結果だけです。

変更されていない事実（言い換えられた主張を含む）を認識すると、後の確認で証拠や承認の判断が再利用されることがあります。再利用した結果には **バージョンの根拠を再利用しています** と表示され、以前の確認日が保持されます。事実の意味が変わった場合は、新たな調査が必要になることがあります。

再確認しても、変更のない主張すべてに対して新たな調査が行われるとは限りません。時間とともに変わりうる情報は、出典と確認日を調べ、現在の出典に基づいて検証するよう編集アシスタントに明示的に依頼してください。
