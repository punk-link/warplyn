# Warplyn 用語集

ここでは、執筆者に見える概念と Warplyn 全体で使われる用語を説明します。

## 記事とバージョン

- **記事 (Article)**：個別に復旧できる編集コンテンツ。Warplyn では “document” ではなく “Article” を使います。
- **記事ライブラリ (記事ライブラリ)**：執筆者の記事をローカルに集めたもの。**現在の記事 (current Article)** は作業スペースで開いている記事、**記事一覧 (Article list)** は記事の一覧です。
- **下書き (Draft)**：編集中で、まだ *保存済みバージョン*として保存されていない *記事*のテキストです。
- **チェックポイント (Draft checkpoint)**：ベースとなる *保存済みバージョン*に紐づいてローカルに保存される、変更可能で復旧できる *下書き*の状態です。*保存済みバージョン*ではありません。**現行の下書き (Current Draft)** は *記事*の現在の *保存済みバージョン*に基づき、**古い下書き (stale Draft)** は以前の *保存済みバージョン*に基づきます。
- **保存済みバージョン (Revision)**：*記事*の不変な保存時点のスナップショットです。
- **現行の下書きの保存 (Revision promotion)**：執筆者が **現行の下書き**を新しい *保存済みバージョン*として明示的に保存することです。対応する *下書き*のチェックポイントだけが消去されます。
- **提案 (Proposal)**：AI が生成する候補の文章や変更で、執筆者の明示的な承認が必要です。
- **提案の基準バージョン (Proposal base Revision)**：*提案*を作成するために確認した *保存済みバージョン*です。現在の *保存済みバージョン*と一致しなくなると、*提案*は古くなります。
- **変更の選択 (Change selection)**：執筆者が受け入れることを選んだ *提案*の一部です。受け入れると、新しい *保存済みバージョン*が作成されます。
- **指摘事項 (Finding)**：事実確認やスタイルレビューの結果など、*記事*を変更しない参考情報です。
- **翻訳元の記事 (Source Article)** と **翻訳記事 (translation Article)**：互いにリンクされ、それぞれ独立して復旧できる *記事*です。翻訳が翻訳元の *保存済みバージョン*になることはありません。

## 編集作業

- **編集機能 (Editorial capability)**：Warplyn の検証済み操作で、利用できる *記事*のコンテキスト、前提条件、結果が定義されています。作業スペースのビューとアシスタントのスキルから、同じ機能を実行できます。
- **スキル (Skill)**：執筆者の依頼に対して、編集アシスタントが編集機能を選び、実行順序を決めるための再利用可能な指示パッケージです。*スキル*が機能や権限を付与することはありません。Warplyn に組み込まれたものを **組み込みスキル (built-in Skill)** と呼びます。**執筆者が作成したスキル (Author-created Skill)** は、アシスタントのチャットで作成するローカルな Markdown パッケージで、独自の *スキルの保存済みバージョン*履歴を持ちます。
- **編集操作 (Editorial operation)**：文章作成、文章の調整、事実確認、スタイルレビュー、翻訳など、執筆者が編集アシスタントに依頼する作業です。
- **編集リクエスト (Editorial request)**：編集操作を 1 回実行することです。
- **編集セッション (Editorial session)**：編集リクエストのやり取りと作業履歴です。
- **編集指針 (編集の指示)**：編集リクエストに添えて執筆者が入力する指示やコンテキストです。
- **スタイルコーパス (Style corpus)**：執筆者が提供するローカルの文章例です。**スタイルプロファイル (style profile)** は、そこから導き出された簡潔な表現です。
- **ワークフローの段階 (Workflow stage)**：執筆者が任意で選択する進捗の目安です。AI を実行したり *記事*を変更したりすることはありません。

## 公開と設定

- **公開プロファイル (Publishing profile)**：文字数上限など、公開先のプラットフォームに合わせた設定可能な指針です。既定値が適用されるのは新しい *記事*だけです。
- **公開用テキスト (Publishing copy)**：Article Status Bar を通じ、現在の *記事*から明示的にコピーした Markdown またはプレーンテキストです。Warplyn に公開プレビュー用の作業スペースビューはありません。
- **アプリケーション設定 (Application Settings)**：作業スペースの設定、AI の構成、公開プロファイル、ローカルデータの管理です。設定が *記事*の保存済みバージョン履歴に含まれることはありません。
- **AI 接続 (AI connection)**：認証情報の取得元を含む、名前付きのサーバー側プロバイダー設定です。新しい編集リクエストには **有効な AI 接続 (active AI connection)** が使われます。
- **認証情報の取得元 (Credential source)**：AI 接続で使用する非公開情報の取得元です。環境変数への参照または管理対象の認証情報です。
- **管理対象の認証情報 (管理された資格情報)**：OS の認証情報ストアに保持される API キーです。Warplyn は接続のメタデータを保存しますが、キーを SQLite やバックアップのスナップショットに書き込むことはありません。
- **モデルの設定 (Model preference)**：既定のモデル識別子、または編集操作ごとの上書き設定です。
- **インターフェイスの言語 (Interface locale)**：Warplyn のインターフェイスの言語です。*記事*や翻訳の言語とは別です。
- **記事の既定言語 (新規記事の言語)**：言語を指定せずに新しい *記事*を作成したときに割り当てられる言語です。
- **翻訳先の既定言語 (翻訳先の言語)**：翻訳リクエストで優先して提示される、順序付きの言語です。翻訳が自動的に開始されることはありません。
- **バックアップ先 (Backup destination)**：Warplyn がバックアップのスナップショットを書き込むローカルディレクトリーです。
- **バックアップのスナップショット (Backup snapshot)**：ある時点のローカルデータを一貫した状態で複製したものです。アクティブなデータベースとは別に保存され、認証情報は含まれません。
- **データの保存場所 (Data location)**：Warplyn の SQLite データを含む、現在使用中のローカルディレクトリーです。
- **データの移動 (Data relocation)**：執筆者が確認したうえでデータをコピーして再起動し、古いコピーを復旧用に残して Warplyn の使用場所を新しいデータ保存先へ切り替えることです。
- **復旧用スナップショット (Recovery snapshot)**：復元の際に Warplyn がアクティブなデータを置き換える前に保持するバックアップスナップショットです。
- **アプリケーションの更新 (Application update)**：デスクトップクライアントが確認、ダウンロードできる Warplyn の新しいパッケージ版です。執筆者が操作した場合にのみ適用され、更新そのものが *記事*を変更することはありません。
- **セキュリティ更新 (セキュリティ更新)**：リリースタグの末尾に `.security` が付くアプリケーション更新です。Warplyn は警告しますが、確認、ダウンロード、再起動を強制することはありません。
- **適用待ちの更新 (Staged update)**：ダウンロード済みで、執筆者が 再起動して更新 を選ぶのを待っているアプリケーション更新です。通常の終了では適用されません。
- **更新前のスナップショット (Pre-update snapshot)**：Warplyn が適用待ちの更新を適用する前に作成するローカルデータのバックアップスナップショットです。復元には対応する以前のアプリケーションバージョンが必要です。
- **診断イベント (Diagnostics event)**：起動や復旧可能なエラーへの対応に使うため、ホストプロセスのログに書き込まれる、機密情報を除いたローカルサービスの記録です。非公開の *記事*の内容、モデルの本文、環境変数の値は含まれません。

## インターフェイス

### 作業スペースの構成

デスクトップの両サイドパネルを展開し、Article Editor を選択したレイアウトです。枠は位置と内包関係を示すもので、正確なサイズを表していません。

│ Collapse control         │ Title and Article metadata   │ Collapse control         │
├──────────────────────────┼──────────────────────────────┼──────────────────────────┤
│ Article search           │ Workspace Tab Bar            │ Conversation             │
├──────────────────────────┼──────────────────────────────┤ Request status           │

### インターフェイス用語

- **Editorial Workspace**：記事ライブラリパネル、Article Workspace、編集アシスタントパネル を含む執筆のメイン画面です。
- **記事ライブラリパネル**：記事の検索と一覧、および作業スペース全体への入口です。折りたたむと **Navigation Rail** になり、小さな画面では一時的に **Navigation Drawer** として表示されます。
- **記事ライブラリパネルのツール領域**：展開した 記事ライブラリパネル のフッターです。文体プロファイル、Settings、必要に応じた更新操作、現在の記事の言語コード、**ローカル** ラベルが含まれます。
- **保存状態インジケーター (Save-state indicator)**：現在の *下書き*が保存済みか、保存中か、対応を必要としているかを Article Status Bar に表示します。
- **Article Workspace**：Article Header、Workspace Tab Bar、選択中の Workspace View、Article Status Bar で構成されます。
- **Article Header**：Workspace Tab Bar の上にあるタイトルとメタデータの操作項目です。
- **Workspace Tab Bar**：Workspace View を選択するためのタブです。
- **Workspace View**：選択中の Article Editor、または 提案の確認、バージョン履歴、ファクトチェック、Translations などの補助画面です。
- **文体プロファイル**：検出した特徴、スタイルレビューの *指摘事項*、タイポグラフィのルール、手動の指針、文章例を管理する独立した画面です。
- **Article Editor**：執筆画面です。主な編集領域を **writing surface** と呼びます。
- **Article Status Bar**：選択中の Workspace View の下にあるバーです。記事の状態とメタデータ、言語の選択、公開プロファイルの指針、コピー操作を表示します。
- **編集アシスタントパネル**：編集指針、操作、リクエストの状態、作業状況を表示します。小さな画面では一時的に **Assistant Drawer** として表示されます。
- **クイックアクション**：アシスタントの Composer 上部にあるドロップダウンです。リクエストに組み込みスキルを挿入できます。
- **Composer**：編集アシスタントパネル の下部にある入力欄です。執筆者が編集指針を入力し、リクエストを送信します。
- **Application 設定のナビゲーション**：**一般**、**ショートカット**、**プロバイダー**、**AIアシスタント**、**公開準備**、**言語の初期設定**、**スペルチェック**、**データとバックアップ**、**Warplynについて** の各項目を移動するナビゲーションです。
