# Warplyn 用語集

ここでは、執筆者に見える概念と Warplyn 全体で使われる用語を説明します。

## 記事とバージョン

- **記事**：個別に復旧できる編集コンテンツ。Warplyn では「文書」ではなく「記事」を使います。
- **記事ライブラリ**：執筆者の記事をローカルに集めたもの。**現在の記事**は作業スペースで開いている記事、**記事一覧**は記事の一覧です。
- **下書き**：編集中で、まだ *保存済みバージョン*として保存されていない *記事*のテキストです。
- **下書きチェックポイント**：ベースとなる *保存済みバージョン*に紐づいてローカルに保存される、変更可能で復旧できる *下書き*の状態です。*保存済みバージョン*ではありません。**現在の下書き**は *記事*の現在の *保存済みバージョン*に基づき、**古い下書き**は以前の *保存済みバージョン*に基づきます。
- **保存済みバージョン**：*記事*の不変な保存時点のスナップショットです。
- **下書きの保存**：執筆者が **現在の下書き**を新しい *保存済みバージョン*として明示的に保存することです。対応する *下書き*のチェックポイントだけが消去されます。
- **提案**：AI が生成する候補の文章や変更で、執筆者の明示的な承認が必要です。
- **提案の基準バージョン**：*提案*を作成するために確認した *保存済みバージョン*です。現在の *保存済みバージョン*と一致しなくなると、*提案*は古くなります。
- **変更の選択**：執筆者が受け入れることを選んだ *提案*の一部です。受け入れると、新しい *保存済みバージョン*が作成されます。
- **指摘事項**：事実確認やスタイルレビューの結果など、*記事*を変更しない参考情報です。
- **翻訳元の記事**と**翻訳記事**：互いにリンクされ、それぞれ独立して復旧できる *記事*です。翻訳が翻訳元の *保存済みバージョン*になることはありません。

## 編集作業

- **編集機能**：Warplyn の検証済み操作で、利用できる *記事*のコンテキスト、前提条件、結果が定義されています。作業スペースのビューとアシスタントのスキルから、同じ機能を実行できます。
- **スキル**：執筆者の依頼に対して、編集アシスタントが編集機能を選び、実行順序を決めるための再利用可能な指示パッケージです。*スキル*が機能や権限を付与することはありません。Warplyn に組み込まれたものを **組み込みスキル** と呼びます。**執筆者が作成したスキル**は、アシスタントのチャットで作成するローカルな Markdown パッケージで、独自の *スキルの保存済みバージョン*履歴を持ちます。
- **編集操作**：文章作成、文章の調整、事実確認、スタイルレビュー、翻訳など、執筆者が編集アシスタントに依頼する作業です。
- **編集リクエスト**：編集操作を 1 回実行することです。
- **編集セッション**：編集リクエストのやり取りと作業履歴です。
- **編集指示**：編集リクエストに添えて執筆者が入力する指示やコンテキストです。
- **スタイルコーパス**：執筆者が提供するローカルの文章例です。**スタイルプロファイル**は、そこから導き出された簡潔な表現です。
- **作業段階**：執筆者が任意で選択する進捗の目安です。AI を実行したり *記事*を変更したりすることはありません。

## 公開と設定

- **公開プロファイル**：文字数上限など、公開先のプラットフォームに合わせた設定可能な指針です。既定値が適用されるのは新しい *記事*だけです。
- **公開用テキスト**：記事のステータスバーを通じ、現在の *記事*から明示的にコピーした Markdown またはプレーンテキストです。Warplyn に公開プレビュー用の作業スペースビューはありません。
- **アプリケーション設定**：作業スペースの設定、AI の構成、公開プロファイル、ローカルデータの管理です。設定が *記事*の保存済みバージョン履歴に含まれることはありません。
- **AI 接続**：認証情報の取得元を含む、名前付きのサーバー側プロバイダー設定です。新しい編集リクエストには **有効な AI 接続**が使われます。
- **認証情報の取得元**：AI 接続で使用する非公開情報の取得元です。環境変数への参照または管理対象の認証情報です。
- **管理対象の認証情報**：OS の認証情報ストアに保持される API キーです。Warplyn は接続のメタデータを保存しますが、キーを SQLite やバックアップのスナップショットに書き込むことはありません。
- **モデルの設定**：既定のモデル識別子、または編集操作ごとの上書き設定です。
- **インターフェイスの言語**：Warplyn のインターフェイスの言語です。*記事*や翻訳の言語とは別です。
- **記事の既定言語**：言語を指定せずに新しい *記事*を作成したときに割り当てられる言語です。
- **翻訳先の既定言語**：翻訳リクエストで優先して提示される、順序付きの言語です。翻訳が自動的に開始されることはありません。
- **バックアップ先**：Warplyn がバックアップのスナップショットを書き込むローカルディレクトリーです。
- **バックアップスナップショット**：ある時点のローカルデータを一貫した状態で複製したものです。アクティブなデータベースとは別に保存され、認証情報は含まれません。
- **データの保存場所**：Warplyn の SQLite データを含む、現在使用中のローカルディレクトリーです。
- **データの移動**：執筆者が確認したうえでデータをコピーして再起動し、古いコピーを復旧用に残して Warplyn の使用場所を新しいデータ保存先へ切り替えることです。
- **復旧用スナップショット**：復元の際に Warplyn がアクティブなデータを置き換える前に保持するバックアップスナップショットです。
- **アプリケーションの更新**：デスクトップクライアントが確認、ダウンロードできる Warplyn の新しいパッケージ版です。執筆者が操作した場合にのみ適用され、更新そのものが *記事*を変更することはありません。
- **セキュリティ更新**：リリースタグの末尾に `.security` が付くアプリケーション更新です。Warplyn は警告しますが、確認、ダウンロード、再起動を強制することはありません。
- **適用待ちの更新**：ダウンロード済みで、執筆者が再起動して更新を選ぶのを待っているアプリケーション更新です。通常の終了では適用されません。
- **更新前のスナップショット**：Warplyn が適用待ちの更新を適用する前に作成するローカルデータのバックアップスナップショットです。復元には対応する以前のアプリケーションバージョンが必要です。
- **診断イベント**：起動や復旧可能なエラーへの対応に使うため、ホストプロセスのログに書き込まれる、機密情報を除いたローカルサービスの記録です。非公開の *記事*の内容、モデルの本文、環境変数の値は含まれません。

## インターフェイス

### 作業スペースの構成

デスクトップの両サイドパネルを展開し、記事エディターを選択したレイアウトです。枠は位置と内包関係を示すもので、正確なサイズを表していません。

```text
編集ワークスペース
┌──────────────────────────┬──────────────────────────────┬──────────────────────────┐
│ 記事ライブラリパネル     │ 記事ワークスペース           │ 編集アシスタントパネル   │
├──────────────────────────┼──────────────────────────────┼──────────────────────────┤
│ Warplyn · 新しい記事     │ 記事ヘッダー                 │ アシスタントの見出し     │
│ 折りたたみコントロール   │ タイトルと記事のメタデータ   │ 折りたたみコントロール   │
├──────────────────────────┼──────────────────────────────┼──────────────────────────┤
│ 記事の検索                │ ワークスペースタブ           │ 会話                     │
├──────────────────────────┼──────────────────────────────┤ リクエスト状態           │
│ 記事一覧                  │ ワークスペースビュー         │ とアクティビティ         │
│                          │                              │                          │
│                          │ 記事エディター               │                          │
│                          │ ┌──────────────────────────┐ │                          │
│                          │ │ 執筆エリア                 │ │                          │
│                          │ │                          │ │                          │
│                          │ └──────────────────────────┘ │                          │
├──────────────────────────┤                              ├──────────────────────────┤
│ 記事ライブラリ            │                              │ クイックアクション       │
│ ツール領域               │                              │ メッセージ入力欄         │
│ 文体プロファイル・設定   ├──────────────────────────────┤ 編集指示                 │
│ 更新・言語               │ 記事のステータスバー         │ と送信                   │
│ 言語・ローカル                  │ 保存状態・メタデータ・コピー                │                          │
└──────────────────────────┴──────────────────────────────┴──────────────────────────┘
```

展開レイアウトでは、記事ライブラリパネル下部のフッターが **記事ライブラリパネルのツール領域** です。一番下の行には現在の *記事*の言語コードと **ローカル** ラベルが表示されます。中央の記事ビューの下にある **記事のステータスバー** には、保存状態が表示されます。

### インターフェイス用語

- **編集ワークスペース**：記事ライブラリパネル、記事ワークスペース、編集アシスタントパネルを含む執筆のメイン画面です。
- **記事ライブラリパネル**：記事の検索と一覧、および作業スペース全体への入口です。折りたたむと **ナビゲーションバー** になり、小さな画面では一時的に **ナビゲーションドロワー** として表示されます。
- **記事ライブラリパネルのツール領域**：展開した記事ライブラリパネルのフッターです。文体プロファイル、設定、必要に応じた更新操作、現在の記事の言語コード、**ローカル**ラベルが含まれます。
- **保存状態インジケーター**：現在の *下書き*が保存済みか、保存中か、対応を必要としているかを記事のステータスバーに表示します。
- **記事ワークスペース**：記事ヘッダー、ワークスペースタブ、選択中のワークスペースビュー、記事のステータスバーで構成されます。
- **記事ヘッダー**：ワークスペースタブの上にあるタイトルとメタデータの操作項目です。
- **ワークスペースタブ**：ワークスペースビューを選択するためのタブです。
- **ワークスペースビュー**：選択中の記事エディター、または提案の確認、バージョン履歴、ファクトチェック、翻訳などの補助画面です。
- **文体プロファイル**：検出した特徴、スタイルレビューの *指摘事項*、タイポグラフィのルール、手動の指針、文章例を管理する独立した画面です。
- **記事エディター**：執筆画面です。主な編集領域を**執筆エリア**と呼びます。
- **記事のステータスバー**：選択中のワークスペースビューの下にあるバーです。記事の状態とメタデータ、言語の選択、公開プロファイルの指針、コピー操作を表示します。
- **編集アシスタントパネル**：編集指針、操作、リクエストの状態、作業状況を表示します。小さな画面では一時的に**アシスタントドロワー**として表示されます。
- **クイックアクション**：アシスタントのメッセージ入力欄上部にあるドロップダウンです。リクエストに組み込みスキルを挿入できます。
- **アシスタントのメッセージ入力欄**：編集アシスタントパネルの下部にある入力欄です。執筆者が編集指針を入力し、リクエストを送信します。
- **アプリ設定のナビゲーション**：**一般**、**ショートカット**、**プロバイダー**、**AIアシスタント**、**公開準備**、**言語の初期設定**、**スペルチェック**、**データとバックアップ**、**Warplynについて** の各項目を移動するナビゲーションです。
