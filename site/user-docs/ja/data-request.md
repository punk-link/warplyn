# データへのアクセスまたは削除を依頼する

Warplyn プロジェクトが受け取った個人データについての問い合わせ、データへのアクセスや訂正、削除を希望する場合は、[kirill.taran@punk.link](mailto:kirill.taran@punk.link) にメールを送ってください。対象となるデータや操作を説明してください。プロジェクトの管理者がメールで返信し、データの特定や依頼の確認に必要な情報を尋ねることがあります。

最初のメールには *記事*の内容、API キー、パスワード、本人確認書類を含めないでください。

## 任意のデスクトップテレメトリー

診断データと利用データの共有を有効にしている場合：

1. **設定** → **一般** → **プライバシーと診断** を開き、**IDをコピー** を選択します。
2. 上記のメールアドレスに ID を送り、依頼内容を説明します。
3. 今後の収集を停止するには、**診断データと使用状況を共有** をオフにします。

共有をオフにすると ID がデバイスから消去されるため、先に ID をコピーしてください。共有を無効にしても、送信済みイベントを取り消すことはできません。削除依頼を受けると、プロジェクトの管理者が一致する仮名化レコードを削除し、メールで完了を通知します。

収集項目と共有設定については、[診断データと利用データ](telemetry.md)を参照してください。

## 執筆データと AI プロバイダー

*記事*とその履歴はローカルに保存されています。プロジェクトの管理者に依頼しても、コンピューター上のファイルやアプリデータは削除されません。ローカルデータを削除する前に、残しておきたい執筆データのバックアップを作成してください。

AI 機能を使うと、関連するテキストとコンテキストが選択したプロバイダーに送信されます。そのプロバイダーが保持するデータに関する依頼は、別途プロバイダーに問い合わせてください。

## Web サイトの分析

Web サイトの分析データはデスクトップのテレメトリーとは別です。Web サイトへの訪問に関する依頼では、おおよその日付とページアドレスを記載してください。デスクトップの テレメトリーID から Web サイトの訪問を特定することはできません。また、分析データから個々の訪問を特定できない場合があります。

使用するサービスと、トラッキングを無効にするブラウザーのプライバシー信号については、[Web サイトの分析](telemetry.md#website-analytics)を参照してください。
