# 文章を短くする

既存の文章を短くしたいときは **文章を短くする** を使います。意味、根拠、不確実性、文体を保ちながら、繰り返しや不要な言葉、冗長な表現を削ります。

**クイックアクション** を開き、**文章を短くする** を選んで、**編集リクエストを送信** を選択します。残したい内容や削る箇所について指示を加えてください。一節を選択すると、そのテキストだけが短縮の対象になります。選択しない場合は、編集アシスタントが *記事*全体を扱います。

::: tip 例
「川が柳の間を縫うように流れる様子を描いた文を、もっと簡潔にしてください。銀色のイメージと静かな雰囲気は残してください」と依頼します。
:::

結果は元の文章より短くなります。安全に短縮できない場合、編集アシスタントは元の文章を変更せずに返します。適用前に *提案*を確認し、名前、主張、リンク、コード、引用、技術用語が正確に保たれていることを確かめてください。短縮せずに明瞭さを改善するには、[文章の流れと明瞭さを改善する](improve-flow-and-clarity.md)を使います。
