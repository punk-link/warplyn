# 文章を翻訳する

選択した言語で *記事*全体の翻訳を作成するには **文章を翻訳** を使います。タイトルと本文を翻訳し、主張、数値、文体、Markdown の書式を保ちます。一節だけを選択していても、翻訳の対象は *記事*全体です。

*記事*の **翻訳** ビューを開き、**新しい翻訳…** を選びます。翻訳先の言語を選択し、依頼を確定してください。翻訳元に未保存の編集がある場合は、意図したテキストに結果が紐づくよう、先に *保存済みバージョン*として保存します。

::: tip 例
アナの川辺の場面を、会話、視点、静かな雰囲気、名前、保護対象のテキストを保って下書き翻訳するよう依頼します。**編集** を使うと、リンクされた翻訳 *記事*を開けます。既存の翻訳記事に結果を新しい *保存済みバージョン*として追加するには **更新** を使います。
:::

翻訳は翻訳元とは別に保持されます。結果の比較、リンクされた *記事*の更新、古くなった結果の扱いについては[翻訳](../translations.md)を参照してください。
