# 文章の流れと明瞭さを改善する

文章が分かりにくく、構成を整理したり、つなぎを滑らかにしたりしたい場合は **流れと明瞭さを改善** を使います。*記事*の意味、主張、不確実性、文体を保ちながら、読みやすくすることを目指します。

**クイックアクション** を開き、**流れと明瞭さを改善** を選んで、**編集リクエストを送信** を選択します。たとえば、ある発見によって登場人物の次の選択がどう変わるのかを明確にするなど、特定の点に絞って依頼できます。一節を選択すると、その部分だけが置き換えの対象になります。選択しない場合は、*記事*全体が対象です。

::: tip 例
「流れを見つめる場面からノートを開く場面への移行を、少しだけ分かりやすくする案をください。場面の静かな雰囲気を保ち、出来事は変えないでください」と依頼します。
:::

適用する前に、*提案*の意味、技術的な詳細、作者の文体を確認してください。文章を短くする依頼には、[文章を短くする](shorten-text.md)を使います。
