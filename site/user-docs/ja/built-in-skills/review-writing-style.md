# 文体をレビューする

保存済みの *文体プロファイル*と *記事*を比較するには **文体をレビュー** を使います。編集アシスタントは、プロファイルの文体の特徴やルールとの具体的な違いを探します。信頼度が低いプロファイルは暫定的なものとして扱われます。

依頼を送信する前に、[文体プロファイル](../style-profile.md) に文章例や手動の指針を追加し、プロファイルを再構築してください。その後 **クイックアクション** を開き、**文体をレビュー** を選んで **編集リクエストを送信** を選択します。確認範囲を絞るには一節を選択します。選択しない場合は、*記事*全体が対象です。

::: tip 例
「アナの川辺での一節を、私の文章例にある視点の近さと比較してください。違いを 1 つ挙げ、どのプロファイル特性に関係するか説明してください」と依頼します。
:::

::: tip 提案された変更を確認する
*提案*と、それを支える *指摘事項*を読みます。各 *指摘事項*は、プロファイルの特性またはルールを示している必要があります。変更を承認する前に、各提案が *記事*に適しているか判断してください。
:::

スタイルレビューには、利用可能な *文体プロファイル*と AI 接続が必要です。文章例は端末に残ります。編集アシスタントが使うのは、Warplyn が文章例の特徴を端末上でまとめたプロファイルです。リクエストでは、*記事*または選択した一節が設定済みの AI プロバイダーに送信される場合があります。
