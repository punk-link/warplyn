# スキル作成

再利用可能な *スキル*の作成、改訂、復元、削除を明示的に依頼すると、編集アシスタントは組み込みの スキル作成 を使います。ローカルの Markdown 指示を管理し、*スキル*ごとに独立した履歴を保持します。

繰り返し行う作業と、*スキル*に従わせたいルールや参照先を説明してください。目的や手順が不明確で結果が変わりそうな場合、編集アシスタントは短い確認質問をすることがあります。新しい *スキル*は以後のリクエストですぐに利用できます。作成しても、現在の *記事*に対して実行されることはありません。

::: tip 例
「『静かな小説の行単位編集』という *スキル*を作成してください。アナの文を引き締めつつ、彼女の文体、川辺の舞台、場面で起きる出来事を維持してください。詳細は追加せず、不明瞭な箇所があれば代わりに指摘してください」と依頼します。
:::

名前を指定して、*スキル*の改訂、復元、削除を編集アシスタントに依頼できます。復元すると新しい有効なバージョンが作成され、以前の *スキルの保存済みバージョン*も保持されます。全体の手順とローカル編集の方法については、[スキルの作成と管理](../skills.md)を参照してください。
