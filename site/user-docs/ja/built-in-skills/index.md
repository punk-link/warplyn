# 組み込みスキル

組み込みの *スキル*は、編集アシスタントが一般的な執筆作業を行うのに役立ちます。**クイックアクション**から編集用の *スキル*を選ぶか、依頼内容を説明して適切な *スキル*を編集アシスタントに判断させます。*スキル*を選んだら、そのまま送信できます。背景や条件を伝えたいときは、メッセージを添えてください。開始するには**編集リクエストを送信**を選択します。再利用可能な *スキル*の作成や管理は、編集アシスタントに直接依頼してください。**スキル作成**は入力欄のクイックアクションではありません。

各ページでは、その *スキル*の用途と、結果で確認する内容を説明しています。編集アシスタントはレビュー可能な作業結果を準備します。結果の扱い方は[編集アシスタント](../editorial-assistant.md)と[記事のレビュー](../reviewing-articles.md)を参照してください。
