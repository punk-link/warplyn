# アイデアから下書きを作成する

メモやアイデアをひとつの文章にまとめたいときは、**アイデアを下書きにする** を使います。編集アシスタントは、元の意図をくみ取り、根拠のない主張を加えずに、読みやすい下書きを作ります。

**クイックアクション** を開き、**アイデアを下書きにする** を選んで、希望する方向性を説明し、**編集リクエストを送信** を選択します。一節を選択した場合、リクエストにはその範囲とメッセージ内で明示的に加えた資料が使われます。何も選択していない場合、現在の *記事*と指示を使うことができます。

::: tip 例
アナがノートを開く場面を選択し、「この一節にある詳細を使って、次の段落の下書き案を 1 つ作ってください。ページは白紙のままにし、川がなぜ彼女を認識しているように見えるのかは説明しないでください」と依頼します。
:::

編集アシスタントはレビュー用の *提案*を作成します。変更を承認する前に、その構成、主張、表現を確認してください。提案だけで *記事*が保存または変更されることはありません。既存の文章を書き換えるには、[文章の流れと明瞭さを改善する](improve-flow-and-clarity.md)を参照してください。
