# 事実を確認

**事実を確認**では、*記事*の記述が出典と合っているかを調べます。編集アシスタントは調べた結果を *指摘事項*にまとめます。*記事*の本文はそのままです。

**クイックアクション** を開き、**事実を確認** を選択して、編集アシスタントが選んだ主張を確認します。確認しない主張は選択を解除してください。その後 **編集リクエストを送信** を選択します。一節を選択すると確認範囲を絞れます。結果は確認対象となった保存済み *バージョン*に紐づきます。

::: tip 例
川のそばを舞台にした章で、アナは満月によって水位が上がり、道が水没すると言います。**事実を確認** に、その物語の舞台に関係する出典を使ってこの詳細を確認するよう依頼します。
:::

::: tip 証拠を確認する
**ファクトチェック** を開き、各 *指摘事項*と出典、日付、不確実性を読みます。出典が不完全または古い場合もあるため、証拠を参考に何を確認または変更するか判断してください。
:::

判定、承認の判断、訂正、再利用された証拠については、[ファクトチェック ガイド](../fact-checking.md)を参照してください。事実確認には、出典に基づく確認に対応した AI 接続とモデルが必要です。プロバイダー料金が発生する場合があります。*指摘事項*は助言であり、主張が誤りであることの証明ではありません。技術用語に絞った確認については、[技術用語の確認](check-technical-terms.md)を参照してください。
