# 技術用語を確認する

IT 分野の *記事*で用語を確認するには **専門用語を確認** を使います。編集アシスタントは、混同されている概念や、略語の誤った説明、製品名や API 名の間違いを探します。同じ概念に異なる名称を使っていないかも確認します。分野とバージョンに関係する出典と用法を照合し、独自の定義や変化する用語も考慮します。

*記事*を開きます。確認範囲を絞る場合は一節を選択してください。編集アシスタントで **クイックアクション** を開き、**専門用語を確認** を選んで **編集リクエストを送信** を選択します。結果の準備ができたら **ファクトチェック** を開き、各 *指摘事項*、その説明、リンク先の出典、不確実性を確認します。

::: tip 例
樹木識別アプリについての記事で、作者がヤナギを針葉樹と呼んでいるとします。**専門用語を確認** に、植物学の出典を使って用語を確認するよう依頼します。
:::

この確認には、出典に基づく事実確認に対応した AI 接続とモデルが必要です。*記事*または選択した一節は、設定済みの AI サービスに送信されます。調査用の検索クエリには、技術用語や主張のコンテキストが含まれる場合があります。プロバイダー料金が発生することがあります。出典は不完全な場合や、分野によって異なる用語を使う場合があります。*指摘事項*は助言であり、文章、コード、識別子を書き換えることはありません。バックグラウンドで用語をスキャンする機能はありません。
