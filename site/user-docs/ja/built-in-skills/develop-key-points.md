# 要点をまとめる

メモや *記事*の主な考えを簡潔にまとめたいときは **要点を膨らませる** を使います。既定では、互いに異なる要点を 3～5 個作成し、*記事*自体は書き換えません。

**クイックアクション**を開き、**要点を膨らませる**を選んで、必要な指示を入力欄に入力し、**編集リクエストを送信**を選択します。一節を選択すると、その範囲とメッセージの内容に基づいて結果が作成されます。選択範囲がない場合は、まずメッセージの指示に従い、メッセージが空なら *記事*を使います。

::: tip 例
アナが川のそばに座る場面を選択し、「この一節を根拠に、アナと川の関係について考えられる解釈を 3 つ挙げてください」と依頼します。
:::

*記事*に取り入れる前に、要点を読み返してみてください。説明を補ったり、どの点を強調するか見直したりするとよい場合があります。提供した資料を基に下書き全体を作成するには、[アイデアから下書きを作成する](turn-ideas-into-a-draft.md)を参照してください。
