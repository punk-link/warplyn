# スキルの作成と管理

*スキル*はローカルに保存される Markdown の指示パッケージです。編集アシスタントが、編集機能を選び実行順序を決めるのに役立ちます。権限を追加したり、*記事*を変更したりするものではありません。

## 自分のスキルを作成、管理する

再利用可能な *スキル*の作成を、編集アシスタントに普段の言葉で依頼してください。繰り返し行う作業と、必要なルールや参照先を説明します。不足している情報によって *スキル*の内容が変わる場合は、編集アシスタントは推測せず、簡単な確認質問をします。

::: tip 例
静かな川辺の場面のような文体で小説を改稿するには、次のように依頼します。「小説の静かな行単位編集」という *スキル*を作成してください。アナの文を引き締めながら、彼女の文体、川辺の舞台、場面で起きる出来事を保ってください。詳細は追加せず、不明瞭な箇所は代わりに指摘してください。」編集アシスタントは、行単位の編集を依頼するたびにこの指示を再利用できます。
:::

*Composer でのスキル作成依頼の例。送信前にプロバイダーを接続してください。*

作成が完了すると、*スキル*は以後の編集アシスタントへのリクエストですぐに利用できます。作成依頼によって *記事*本文がモデルに送信されたり、*記事*、*下書き*、*提案*、*保存済みバージョン*が変更されたりすることはありません。

作成した各 *スキル*には、ローカルで管理される不変の *スキルの保存済みバージョン*履歴があります。これは *記事*の保存済みバージョン履歴とは別です。ローカルの Markdown パッケージを直接編集することもできます。Warplyn は次のリクエスト時にカタログを更新します。`SKILL.md` を削除すると、利用可能な *スキル*の一覧からそのスキルが削除されます。

名前を指定して、*スキル*の改訂や削除を編集アシスタントに依頼します。変更前に現在のパッケージを読み込み、ファイルがその間に変更されていないか確認します。改訂では *スキル*の ID を維持し、新しい *スキルの保存済みバージョン*を追加します。削除すると新しいリクエストでは使えなくなりますが、履歴は保持されます。

以前の指示を復元するには、その *スキル*の保存済みバージョンを表示するよう依頼し、復元するものを指定してください。復元すると新しい有効なバージョンが書き込まれ、別の *スキルの保存済みバージョン*が追加されます。この方法で削除済みの *スキル*を復元することもできます。編集アシスタントのチャットチェックポイントを復元しても、*スキル*は復元または変更されません。*スキル*の復元は別の依頼です。
