# 記事の執筆と整理

*記事*は Warplyn のライブラリに保存する文章です。編集中の *下書き*は自動で保存され、必要なときに復元できます。*保存済みバージョン*は、保存した時点の文章を記事の履歴に残したものです。

## 文章の一節に指示を残す {#editor-notes}

*編集メモ*を使うと、後でアシスタントに依頼する際の指示を、該当箇所に残せます。視点を保ちたい場面や、伏線をまだ明かしたくない場面に役立ちます。メモは記事本文とは別に保存され、本文のコピーや書き出しには含まれません。

エディターで対象の文章を選択します。書式設定ツールバーまたは右クリックメニューから **編集メモを追加…** を選びます。**アシスタントへの指示** に指示を入力し、**メモを保存** を選びます。メモを保存しても依頼は送信されず、記事のリビジョンも作成されません。

::: tip 『夕暮れの川』の例
アナが船に気づく段落を選び、「船の持ち主について、アナが確信を持てない状態を保つ。川の音を残し、乗客の正体は明かさない」と記入します。後でその箇所を選び、アシスタントにテンポの改善を依頼できます。
:::

書式設定ツールバーの **編集メモ**、または本文脇の小さな番号付きマーカーからメモを開きます。マーカーにポインターを合わせるか、キーボードでフォーカスすると、対象箇所が一時的に強調表示されます。一覧の文章プレビューを選ぶと、その箇所に移動します。**メモを編集…** で指示を変更し、**メモを保存** で保存します。削除ボタンを押しても、本文は残ります。

画面を閉じたり別のメモに切り替えたりする前に保存してください。未保存の変更がある場合は、キャンセルして編集を続けるか、**変更を破棄** で変更を破棄できます。

**再添付が必要です** は、元の文章を特定できなくなったことを示します。メモは残りますが、再度添付するまでは指示として使われません。メモ画面を閉じ、新しい文章を選択してから、**編集メモ** と **メモを編集…** でメモを開き直します。**選択したテキストに添付**、**メモを保存** の順に選びます。

添付済みのメモは、その箇所を扱う明示的な依頼に含まれます。文章を選択した依頼では、選択範囲と重なる箇所のメモだけが送信されます。送信前に入力欄の **このリクエストに添付するメモ** を確認してください。今回の作業は入力欄に書き、継続して守りたい指示はメモに残します。

記事をまたいで使う手順は [Skills](skills.md)、文体の見本や全体的な方針は[スタイルプロファイル](style-profile.md)を参照してください。

## 記事を書いて保存する

ライブラリで **新しい記事** を選ぶと、新しい記事を作成できます。タイトル欄で *記事*の名前を変更します。書式設定ツールバーを使って、見出し、リスト、強調、リンク、引用、コードを適用します。リッチテキストを貼り付けると、Warplyn は対応する書式を保持し、安全でない形式や未対応のマークアップを削除します。*記事*は Markdown で保存されるため、複雑なページレイアウトや埋め込み項目は引き継がれません。

編集中の *下書き*はWarplynによって自動保存されます。チェックポイントは復旧用の作業テキストであり、バージョン履歴に新しい項目として追加されるものではありません。最近の編集がチェックポイントに保存されたか確認するには、記事のステータスバーの保存状態インジケーターを確認してください。*記事*の切り替え時や設定を開いたときにも、保留中のチェックポイントが保存されます。

現在の *下書き*を名前付きの履歴として残すには **バージョンを保存** を選択します。*保存済みバージョン*を保存しても、以前の *保存済みバージョン*は削除されません。ローカルのテキストと保存済みの *下書き*が一致しなくなった場合は、[記事のレビュー](reviewing-articles.md#recover-a-draft)を参照してください。

## 記事を検索して整理する

ライブラリの検索を使うと、アーカイブ済みの記事も含めて *記事*を検索できます。**記事**を選択してピン留めした記事や最近の作業を表示するか、**アーカイブ**でアーカイブ済みの記事グループを閲覧します。折りたたまれたナビゲーションバーには**新しい記事**、**記事を検索**、**記事**、**アーカイブ**のショートカットがあります。元の記事をライブラリのメニューからピン留めすると、ナビゲーションバーにショートカットを追加できます。ピン留めした *記事*の順序は**上へ移動**または**下へ移動**で変更します。ピン留めや並べ替えによって *記事*の内容が変わることはありません。タイトル欄を使って *記事*の名前を変更できます。

**記事をアーカイブ** を選択すると、*記事*のグループはアクティブな一覧から外れ、**アーカイブ** に残ります。アーカイブしたグループを選択して **記事をアーカイブから戻す** を選ぶと元に戻せます。*記事*の削除には確認が必要で、関連する *保存済みバージョン*と復旧可能な *下書き*も削除されます。元の記事を削除すると、リンクされた *翻訳記事*も削除されます。*翻訳記事*を削除しても、翻訳元の *記事*は残ります。一時的にしまっておきたい場合は、削除せずアーカイブしてください。

## スペルチェックを使う

エディターは、デバイスのスペルチェック機能を使って、スペルミスと思われる語句に印を付けます。デスクトップアプリでは、印の付いた単語を右クリックして、候補の置き換えまたは **辞書に追加** を選びます。置き換えは通常の編集として取り消せ、現在の *下書き*に反映されます。スペルチェックはデバイス上で行われ、*記事*のテキストが AI プロバイダーに送信されることはありません。

デスクトップアプリの **設定** → **スペルチェック** で **言語を絞り込む** を使って言語を検索し、**オフライン執筆の準備** で選択してから **辞書をダウンロード** を選びます。オフラインで使う前に、状態が **ダウンロード済み** になるまで待ってください。**利用可能** はその言語に対応していることを示すだけで、辞書のダウンロード完了を意味しません。準備済みの辞書をこのセッションで使わない場合は **読み込みを解除** を選びます。辞書を準備しても *記事*の言語は変わりません。ダウンロードにはインターネット接続が必要です。Windows では、個人用の単語を追加または削除すると OS の辞書にも反映され、ほかのアプリに影響する場合があります。

**ユーザー辞書** では、保存済みの単語を検索するか、**追加する単語** に 1 行につき 1 単語または専門用語を入力して **単語を追加** を選びます。一度に追加できる単語は最大 500 個です。再びスペルチェックで指摘させるには、保存済みの単語を削除します。この一覧は *記事*や言語をまたいで共有されます。ブラウザーアプリではブラウザーのスペルチェック設定が使われ、辞書の管理はできません。

執筆中に補助パネルを両方隠すには **集中モード** を使います。もう一度選ぶと表示されます。各パネルの折りたたみコントロールを使って閉じたり開いたりできます。パネル横の仕切りをドラッグするとサイズを変更できます。ウィンドウが狭い場合、パネルは一時的なドロワーとしてエディターの上に開きます。

キーボードでは **Tab** と **Shift + Tab** を使って、ライブラリ、記事ヘッダー、ビュー、書式設定ツールバー、エディター、ステータスバー、編集アシスタントパネルの間を移動できます。エディター、検索、入力欄内では通常のテキスト編集キーが使えます。設定には専用のキーボード操作があります。デスクトップ版のサイドバーでは **Up**、**Down**、**Home**、**End** でセクションを移動し、**Enter** または **Space** で開きます。

Warplyn への *記事*の取り込みや書き出しについては、[記事ファイル](article-files.md)を参照してください。ワークスペース全体のバックアップについては、[バックアップと復旧](backups-and-recovery.md)を参照してください。
