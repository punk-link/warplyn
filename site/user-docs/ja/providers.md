# AI プロバイダーとモデル

Warplyn は **設定** → **AIアシスタント** で設定したプロバイダーに AI リクエストを送信します。そのプロバイダーのアカウントと API キーが必要です。API の利用料金が発生する場合があります。

## 接続を追加する

デスクトップアプリで **設定** → **AIアシスタント** を開きます。**キーの指定方法を選択してください** で **APIキーを追加** または **環境変数** を選択します。

- **APIキーを追加:** プロバイダーを選び、接続名とキーを入力します。Warplyn はキーを Windows Credential Manager または Linux Secret Service に保存します。キーは再表示されず、Warplyn のデータベースやバックアップにも保存されません。
- **環境変数:** プロバイダーと接続名を選び、キーを保持する環境変数名を入力します。Warplyn が保存するのは名前であり、値ではありません。アプリケーションサービスは、その変数が設定された環境で起動する必要があります。

::: tip 認証情報について
管理対象の API キーを使うには、デスクトップアプリと、利用可能な OS の認証情報サービスが必要です。Linux では Secret Service のロックを解除してください。ブラウザーアプリは環境変数を使う接続に対応していますが、OS の認証情報は管理できません。インストーラーは `.env` ファイルを作成またはインポートしません。
:::

API キーを使う接続を追加すると、プロバイダーに対してキーが検証されます。環境変数を使う接続では、設定が保存されるだけです。モデル一覧を更新したり AI リクエストを送信したりすると、Warplyn は改めてプロバイダーに接続します。これらの確認で *記事*の内容が送信されることはありません。

接続は **設定** → **AIアシスタント** に一覧表示されます。**有効**、**有効化**、**無効化** を使い、新しいリクエストに使用できる接続を選びます。**名前を変更** を選ぶと接続のローカル表示名を変更できます。**削除** を選んで確認すると Warplyn から接続が削除されます。環境変数接続を削除しても、変数やそのキーは削除されません。

::: tip モデル一覧を更新できない場合
接続が **有効** であること、保存したキーが有効であること、または環境変数がアプリケーションサービスから利用可能であること、プロバイダーのアカウントで API にアクセスできることを確認してください。
:::

## プロバイダーとモデルを選ぶ

Warplyn は OpenAI、OpenCode Zen、Anthropic、Google Gemini API、xAI Grok、DeepSeek に対応しています。OpenCode Zen のカタログには、ほかのベンダーのモデルもあります。

**設定** → **AIアシスタント** で **一覧を更新** を選び、**既定のモデル** を選択します。特定の *スキル*に別のモデルを使うには、**作業別のモデル** で選びます。**既定のモデルを使用** に設定されたタスクでは 既定のモデル が使われます。

接続を変更した後や、プロバイダーの最新カタログを確認したいときはモデル一覧を更新してください。**モデルを検索**、**提供元でモデルを絞り込む**、**お気に入り** を使って一覧を絞り込みます。モデルの選択は次のリクエストから適用されます。選択した OpenAI モデルで **推論レベル** が表示される場合に設定できます。値を高くすると、処理に時間がかかることがあります。**設定** → **AIアシスタント** の任意設定 **アプリ用モデル** は既定のモデルとは別に、要約やタイトルなど Warplyn の補助タスクを処理します。

::: tip モデルの対応状況
利用可能な編集操作はモデルによって異なります。出典付きの事実確認、構造化出力、推論の制御に対応していないモデルもあります。OpenCode Zen のモデルは、そのカタログでの機能と提供状況に従います。
:::

### アプリ用モデル

**アプリ用モデル** は、*提案*の要約、タイトル、編集アシスタントへの依頼意図の理解など、短い補助タスクを処理します。未設定の場合、Warplyn は 既定のモデル を使います。

効率がよく、比較的低コストなテキストモデルを選んでください。こうした目的に適した OpenAI モデルの一つに **GPT-6 Luna** があります（[モデルの詳細](https://developers.openai.com/api/docs/models/gpt-6-luna)）。ほかのプロバイダーでは同程度のモデルを選びます。結果が不十分な場合は、より高性能なモデルを試してください。
