# 編集アシスタント

文章の作成、改稿、事実確認、スタイルのレビュー、翻訳の準備を手伝ってほしいときは、編集アシスタントを使います。**クイックアクション**で *スキル*を選ぶと、入力欄に追加されます。**編集リクエストを送信** を選ぶと、アシスタントが作業を始めます。

テキストを選択すると、その箇所に絞って編集できます。前後の定義や文体の手がかりは短い選択範囲を解釈する助けになりますが、共有すると未選択の文章もプロバイダーに送られます。一節を選んでいて、依頼に *記事*の本文が必要なときは、Warplyn が選択した箇所と、その前後それぞれ最大 500 文字を送ります。前後の文章は文脈を伝えるためだけに使われます。置き換えられるのは選択した箇所だけです。送信される範囲は、送信前に入力欄で確認できます。前後の文章に機密情報が含まれる場合は送信しないでください。一般的な助言や *スキル*の管理には、このテキストは必要ありません。Warplynが暗黙のうちに対象を *記事*全体へ広げることはありません。コンテキストが足りない場合は、関連する文章を明示的に入力するか、別の範囲を選択して再度依頼してください。

::: tip 例
短編を改稿するときに一節を選択し、「アナの視点と静かな雰囲気を保ちながら、文章の流れを改善してください。新しい出来事は追加しないでください」と依頼します。編集アシスタントは **提案の確認** で確認できる *提案*を作成します。また、章の中で過去形と現在形が切り替わる箇所を確認するよう依頼することもできます。スタイルレビューの *指摘事項*は **文体プロファイル** に表示されます。
:::

[![小説の改稿依頼を行い、スキルを選択した Warplyn の編集アシスタント。](/images/editorial-assistant-example.png)](/images/editorial-assistant-example.png)

*入力欄での依頼例。送信前にプロバイダーを接続してください。スクリーンショットには以前のスキル名が表示されています。*

処理中は、リクエストの進み具合が短いメッセージで表示されます。時間がかかりすぎる場合は **リクエストを停止** を選択してキャンセルしてください。キャンセルまたは失敗したリクエストでは *記事*は変更されません。再実行するには **再試行** を選びます。編集アシスタントがプロンプト、非公開の入力、認証情報、プロバイダーのエラーを表示することはありません。処理が完了したら、結果カードから結果を開きます。

- 生成または改稿したテキストは **提案の確認**。
- 参考情報としての *指摘事項*は **ファクトチェック**。
- スタイルレビューの *指摘事項*は **文体プロファイル**。
- 翻訳の *提案*は **翻訳**。

結果を開いても *記事*は変更されません。変更を承認する前に *提案*を確認してください。*指摘事項*はあくまで参考情報で、翻訳はリンクされた別の *記事*として保持されます。提案、履歴、復旧、ファクトチェック については[記事のレビュー](reviewing-articles.md)を参照してください。翻訳結果の比較と利用については[翻訳](translations.md)を参照してください。

技術用語に絞って確認するには、**クイックアクション** から **専門用語を確認** を選択します。出典付きの *指摘事項*は **ファクトチェック** に表示されます。手順と制限については[技術用語の確認](built-in-skills/check-technical-terms.md)を参照してください。

**提案の確認** では **左右に並べる** または **上下に並べる** レイアウトで **提案** のテキストを直接編集できます。**原文** は読み取り専用です。編集しても、各変更に対する **採用** または **却下** の判断は保持されます。すべての変更を判断してから **適用** を選択し、レビューを完了してください。承認した文言は 1 つの新しい *保存済みバージョン*になります。すべての提案を拒否した場合、適用 によりレビューは終了しますが、*記事*は変更されず、*保存済みバージョン*も作成されません。すべての変更を承認するには **すべての判断を設定…** から **すべて採用にする** を選んで適用します。**すべて却下にする** を選ぶと *記事*は変更されません。**すべての判断をリセット** を選ぶと、提案文の編集を保持したまま、すべての判断が 保留 に戻ります。レビューを消去するには **提案を閉じる** を選択してください。

適用前の編集内容は、レイアウトやワークスペースビューを切り替えても保持されます。再読み込み、*記事*の切り替え、*提案*の破棄、新しい提案の生成を行うと、それらの編集内容は消去されます。適用に失敗した場合は、再試行できるよう編集内容が保持されます。提案内の数値、リンク、コード、技術用語は変更せずに保ってください。古くなった提案、信頼性の低い提案、すでに承認された *提案*は読み取り専用です。事実訂正の文言を編集して適用した後も、関連する *指摘事項*は参考情報のままです。

*スキル*は依頼の内容を整えるのに役立ちますが、権限を追加するものではありません。タグのない依頼では、編集アシスタントが関連する *スキル*を選びます。通常の依頼を既定の編集ワークフローに通すことはありません。Warplyn はバックグラウンド処理を実行せず、直接公開せず、承認なしに *記事*を変更しません。

手順を再利用したい場合は、編集アシスタントに[スキル](skills.md)の作成を依頼してください。目的、手順、参照先が不明確な場合、短い追加質問をすることがあります。作成した *スキル*はすぐに利用でき、専用のローカルな *スキルの保存済みバージョン*履歴を持ちます。作成時に *記事*本文が読み取られたり、*下書き*、*提案*、*保存済みバージョン*が変更されたりすることはありません。

明示的に依頼すると、編集アシスタントは **バージョン履歴**、保存済みの編集作業、公開の指針、スタイルコーパスの準備状況を確認できます。依頼に応じて、現在の不変な *保存済みバージョン*をローカルのスタイルコーパスに追加し、文体プロファイル を再構築できます。ただし、*提案*の承認、*保存済みバージョン*の復元、*指摘事項*の解決、*下書き*の編集、スタイルサンプルの削除、公開は行えません。

執筆例、再利用可能な指針、タイポグラフィのルールを管理するには、[文体プロファイル](style-profile.md)を開きます。スタイルレビューの *指摘事項*はここに表示され、*記事*とは別に保たれます。
