# AI で記事を改稿し、すべての変更を確認する

場面の出来事は適切でも、展開のテンポにばらつきがあると感じたら、Warplyn の編集アシスタントが改稿を支援します。一節または記事全体を対象にし、提案された文章を比較して、残したい変更を適用できます。

Warplyn は Windows と Linux 向けの、オープンソースでローカル優先の執筆環境です。執筆データはコンピューターに保存されます。AI 支援にはインターネット接続と、API キーで設定した対応プロバイダーへの接続が必要です。関連するテキストとコンテキストはそのプロバイダーに送信され、料金やデータポリシーはプロバイダーのものが適用されます。

## 依頼内容を絞って始める

記事を開き、改稿したい箇所を選択します。Composer で、改善したい点と維持したい点を説明してください。たとえば「夕暮れの川辺」という作品に取り組んでいる場合は、次のように依頼します。

> アナの視点と静かな雰囲気を保ちながら、文章の流れを改善してください。新しい出来事は追加しないでください。

**編集リクエストを送信** を選択します。Warplyn は選択範囲と、その前後最大 500 文字を読み取り専用のコンテキストとして送信します。置き換えられるのは選択した箇所だけです。機微な文章を送る前に、Composer に表示されるコンテキストの説明を確認してください。詳しくは[編集アシスタント](editorial-assistant.md)を参照してください。

[![小説の改稿依頼を入力した Warplyn の Composer。](/images/editorial-assistant-example.png)](/images/editorial-assistant-example.png)

*Composer での依頼例。スクリーンショットには以前のスキル名が表示されています。*

## 元の文章と提案された文章を比較する

依頼が完了したら、結果カードから **提案の確認** を開きます。**原文** と **提案** を比較し、場面の出来事、視点、文体が維持されているか確認してください。

[![原文 と 提案 の文章、個別の判断、適用 を比較する 提案の確認。](/images/proposal-review.png)](/images/proposal-review.png)

*「夕暮れの川辺」のレビュー例。生成される文章は依頼内容とモデルによって異なります。*

変更ごとに **採用** または **却下** を選択します。適用する前に **提案** の文章を編集できます。Warplyn が *提案*を安全に分割できない場合は、全体を確認する必要があることを説明します。

## 変更を適用して履歴を残す

すべての変更を判断したら **適用** を選択します。承認したテキストは新しい *保存済みバージョン*になります。すべての変更を拒否した場合、*記事*は変更されず、*保存済みバージョン*も作成されません。判断しただけでは執筆内容は変わりません。

以前に保存したバージョンを確認するには **バージョン履歴** を開きます。以前のものを復元すると新しい *保存済みバージョン*が追加され、間の履歴も保持されます。復旧方法や古くなった *提案*については、[記事のレビュー](reviewing-articles.md)を参照してください。

AI による改稿では、意図が反映されなかったり、残したかった詳細が変わったりすることがあります。適用前に結果を確認し、必要に応じて条件を絞って再度依頼してください。キャンセルまたは失敗した依頼では、*記事*は変更されません。

## 自分の文章で試す

[Warplyn をダウンロード](https://github.com/punk-link/warplyn/releases/latest)し、[インストールガイド](installation.md)に従って、対応する [AI プロバイダー](providers.md)に接続してください。Windows インストーラーには署名がありません。表示される警告についてはインストールガイドで説明しています。
