# アプリケーションの設定

アプリケーション設定では Warplyn の外観と動作を調整します。*記事*の *保存済みバージョン*履歴には含まれません。**記事ライブラリパネルのツール領域** から **設定** を開きます。一部の設定はデスクトップ版専用で、以下に記載しています。

## 外観と言語を設定する

**一般** → **外観と言語** で、**外観** に **システム**、**ライト**、**ダーク** のいずれかを選びます。**システム** はデバイスの設定に従い、Warplyn の起動中に変更が反映されます。メニューやメッセージの **表示言語** を選びます。現在、インターフェイス全体に対応している言語は英語のみです。これらの設定は、*記事*の執筆言語やタイポグラフィのルールには影響しません。

**日付と時刻** では、日付形式、12 時間または 24 時間表示、タイムゾーンを選びます。システム設定の選択肢はデバイスに従います。この設定で変わるのは Warplyn での保存時刻の表示方法であり、保存された時刻自体ではありません。

## 執筆の既定値を設定する

**言語の初期設定** で、新しい *記事*に使う **新規記事の言語** を設定します。**翻訳先の言語** を設定すると、*翻訳*を依頼する際に、その言語が翻訳先の候補として先に表示されます。言語名、地域別の言語名、コードを入力し、**追加** を選択します。翻訳を依頼するたびに、Warplyn は引き続き確認を求めます。

## アシスタントの動作を設定する

**AIアシスタント** で、新しい *記事*の会話に対する既定値として **確認用に編集を提案** を選ぶか、明示的に依頼した編集に **編集を直接適用** を使う設定にします。この既定値は既存の会話には適用されず、ほかの生成結果も引き続き確認が必要です。

**リクエストの制限時間** は、新しいリクエストと再試行のそれぞれに適用されます。既定は 2 分です。より長い処理が必要な場合は、長い制限時間または **無制限** を選択してください。タイムアウトしても *記事*は変更されません。

アシスタントの送信キーに **Enter** または **Ctrl + Enter** を選びます。ほかのアプリケーションのショートカットは **ショートカット** で変更できます。Warplyn は保存前に競合を知らせます。

## 公開時の指針を設定する

**公開準備** で新しい *記事*の既定プロファイルを選びます。**LinkedIn Post** や **LinkedIn Article** などのプロファイルは、記事のステータスバーに文字数の目安を表示します。**制限なし** を選ぶか、名前と整数の文字数上限を指定したカスタムプロファイルを追加することもできます。既定値が適用されるのは新しい *記事*です。既存の *記事*は個別のプロファイルを維持できます。上限は目安であり、コピーを妨げることはありません。記事のステータスバーで **Markdownをコピー** を選ぶか、メニューから **プレーンテキストをコピー** を選びます。Warplyn は指示されたときにテキストをコピーしますが、直接公開はしません。

## AI モデルの選択肢を確認する

**AIアシスタント** では複数のプロバイダー接続を保持し、使用する接続だけを有効にして、アシスタントの一般的な作業や特定の *スキル*に別々のモデルを割り当てられます。タスクごとの選択がない場合、AI 作業には **既定のモデル** が使われます。任意設定の **アプリ用モデル** は要約やタイトルなど Warplyn の補助タスクを処理します。未設定の場合は 既定のモデル が使われます。モデルを探すには **お気に入り**、検索、ベンダーフィルターを使います。対応する OpenAI モデルでは **推論レベル** が表示されます。利用可能なタスクや操作項目はモデルによって異なります。接続方法とプロバイダーの制限については[AI プロバイダーとモデル](providers.md)を参照してください。

**ショートカット** では操作の横にあるショートカットを選び、設定したいキーの組み合わせを押します。*保存済みバージョン*の保存、ビューの切り替え、集中モード の切り替えにショートカットを設定できます。Warplyn は競合中のショートカットを使用している操作名を表示します。別の組み合わせを選んでください。**送信キー** は **Enter** と **Ctrl + Enter** のどちらでアシスタントのリクエストを送信するかを制御します。ショートカットを変更しても *記事*の内容は変わりません。

## デスクトップの更新を確認する

インストール済みのデスクトップアプリでは **設定** → **Warplynについて** → **更新** からリリースを確認できます。まず **更新のためのネットワークアクセスを許可** を許可します。これにより Warplyn は GitHub に接続し、公開リリースの詳細や、ダウンロードを選んだ更新情報を取得できます。次に **更新を自動的に確認** と **プレリリース版を含める** を選択します。いつでも確認するには **今すぐ確認** を選びます。更新がある場合はリリースノートが表示されます。Windows と Linux AppImage のインストールでは **ダウンロード** と **再起動して更新** を使えます。Debian では **更新内容** を使い、その後パッケージマネージャーでアップグレードするか、新しい `.deb` インストーラーを使用します。更新後にアプリが起動しない場合は、[デスクトップ更新の復旧](update-recovery.md)を参照してください。

## ローカルデータを削除する

デスクトップアプリの **ローカルデータを削除** は、*記事*、*保存済みバージョン*、チェックポイント、アシスタントの履歴、スタイルデータ、設定、そのデータフォルダー内のローカルバックアップなど、Warplyn で現在使用中のデータを完全に削除します。バックアップフォルダーが設定されている場合、確認画面に **削除前にバックアップを作成** が表示されます。Warplyn は削除を始める前にバックアップを完了する必要があります。削除が成功するとアプリは終了します。通常のアンインストールでは執筆データは削除されません。OS の辞書に保存された個人用スペル単語も残ります。削除する場合は、**設定** → **スペルチェック** から別途削除してください。

ユーザーガイド、ソースリポジトリー、課題トラッカー、ライセンスを確認するには **設定** → **Warplynについて** を開きます。初回起動時の紹介をもう一度見るには **クイックスタートを開く** を選びます。
