# 記事のレビュー

編集アシスタントは変更を提案できますが、*記事*に反映する内容は自分で決めます。**提案の確認** では、変更を *保存済みバージョン*にする前に確認できます。

[![提案の確認 に保留中の変更が 3 件表示され、原文 と 提案 の文章、個別の判断、適用 コントロールが見える画面。](/images/proposal-review.png)](/images/proposal-review.png)

*「夕暮れの川辺」の 提案の確認 の例。*

## 提案を確認する {#review-a-proposal}

アシスタントの結果カードまたは Workspace Tab Bar から **提案の確認** を開きます。変更内容と、内容を維持するための警告を確認してください。読みやすい方に合わせて左右並列または上下配置の比較に切り替えます。両方の文章で変更箇所を強調するには **変更を強調表示** をオンにします。承認する前に、変更後の文章にある名前、数値、主張、リンク、文体を確認してください。

変更ごとに **採用** または **却下** を選びます。すべての判断を一括で設定するには、**すべての判断を設定…** から **すべて採用にする** または **すべて却下にする** を選びます。その後、**適用** を選んでレビューを完了します。承認したテキストは新しい *保存済みバージョン*になります。すべての提案を拒否した場合、適用 によりレビューは終了しますが、*記事*は変更されず、*保存済みバージョン*も作成されません。**すべての判断をリセット** を選ぶと、提案文の編集を保持したまま、すべての判断が 保留 に戻ります。判断しただけでは *記事*は変更されません。**提案を閉じる** はテキストを適用せずにレビューを消去します。安全に分割できない *提案*には通知が表示され、全体を確認する必要があります。

::: tip 自分のペースで確認する
適用前に提案された文言を編集したり、比較レイアウトを切り替えたりできます。判断が反映されるのは **適用** を選択したときだけです。
:::

選択した変更を安全に適用できない場合、*提案*全体を承認する方法だけが利用できることを説明します。古くなった *提案*は以前の *保存済みバージョン*を基に作成されています。その変更は現在のテキストには適用できません。提案を破棄するか、対応する履歴に戻って新しく依頼してください。

## 保存済みバージョンの履歴を確認または復元する

保存済みのバージョンを読むには **バージョン履歴** を開きます。*保存済みバージョン*を選択すると読み取り専用のプレビューが開き、現在の作業は変更されません。**非アクティブ** と表示された *保存済みバージョン*は、その後の復元によって置き換えられた履歴上の経路に属します。引き続き確認や復元ができます。

以前のバージョンを現在の状態にするには **このバージョンを復元** を選びます。Warplyn はそのテキストを含む新しい *保存済みバージョン*を追加し、間の履歴を消去しません。未完了の *下書き*がある場合は、復元前にそれを *保存済みバージョン*として保存するか、破棄するかを選びます。

## 下書きを復旧する {#recover-a-draft}

チェックポイントは、編集中に保存された復旧可能なテキストです。ローカルのエディターテキストが保存済みチェックポイントまたは現在の *保存済みバージョン*と競合すると、Warplyn は保持されたローカルテキストと保存済みの選択肢を並べて表示します。比較してから **自分の下書きを保持**、**最新の下書きを使用**、**最新の保存済みバージョンを使用** のいずれかを選びます。保存済みの選択肢を使うとローカルテキストが置き換わる場合があるため、Warplyn は事前に確認を求めます。

## アシスタントの編集方法を選ぶ

新しい会話では、既定で **確認用に編集を提案** が使われます。明示的に依頼した編集を *提案*なしで適用したい場合は、Composer で **編集を直接適用** を選択できます。直接編集が成功すると、新しい *保存済みバージョン*として表示されます。テキストを選択している場合、編集対象はその選択範囲内にとどまります。*下書き*または変更された *保存済みバージョン*によって置き換えが危険になる場合、直接編集は実行されません。現在の作業を解決してから、もう一度依頼してください。ほかの生成結果は引き続き確認が必要です。

以前のメッセージから会話を続けるには、そのメッセージで **ここから編集** を選びます。**会話を復元** を確定する前に、Warplyn は破棄される後続の作業を一覧表示します。たとえば *提案*、*指摘事項*、翻訳結果などです。また、*記事*が以前の *保存済みバージョン*に戻る場合や、送信前の Composer のテキストが置き換わる場合も通知します。*下書き*に対応が必要な場合は、**現在の作業を保存して復元** または **下書きを破棄して復元** を選択します。後のものを含む *保存済みバージョン*は バージョン履歴 に残ります。この操作で *スキル*が復元または変更されることはありません。

## ファクトチェック の指摘事項を読む

参考情報としての *指摘事項*とその出典を確認するには **ファクトチェック** を開きます。承認の判断によって *指摘事項*は解決されますが、*記事*や判定結果は変更されません。訂正の *提案*は、文章に反映する前に確認が必要です。全体の手順、判定、承認方法、以前の結果の再確認については[ファクトチェック](fact-checking.md)を参照してください。
