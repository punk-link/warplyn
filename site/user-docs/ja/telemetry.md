# 診断データと利用データを共有する

共有をオンにすると、Windows または Linux のデスクトップ版 Warplyn は、アプリの動作や利用状況に関するデータを米国バージニア州の PostHog Cloud に送ります。各イベントには仮名化した ID が付きます。共有は既定でオフです。利用状況を把握して Warplyn を改善するため、共有を有効にしてください。**設定** → **一般** → **プライバシーと診断** で設定を変更できます。

共有をオフにすると、Warplyn はデータの収集をやめ、未送信のイベントとテレメトリー ID を端末から削除します。共有を再開すると、新しい ID が作られます。送信済みのイベントは残ります。

未送信のイベントはアプリのローカルプロファイルに保存され、接続が戻ると Warplyn が再送を試みます。アプリが次にキューを確認したとき、24 時間を超えたイベントは破棄されます。共有をオフにするとキューも削除されます。

## Warplyn が収集する情報

イベントには次の情報が含まれます。

- 接続の検証が成功または失敗したこと（接続名やプロバイダーの詳細は含まない）
- アプリの起動と、安全な分類にまとめられた起動時、レンダラー、子プロセスのエラー
- AI 操作と各段階の完了、失敗、キャンセル（該当する場合は失敗の分類と HTTP ステータスを含む）
- 明示的な *提案*のレビューと集計済みチェックポイント
- バックアップと復旧の結果

イベントに *記事*のテキスト、プロンプト、AI の回答、API キーは含まれません。

::: details その他のイベント項目
各イベントには、デスクトップ分析の送信元、スキーマのバージョン、アプリのバージョン、プラットフォーム、アーキテクチャ、OS のバージョン、タイムスタンプが含まれます。イベント固有の項目は、既知の分類、0 以上のカウンター、または上限付きの所要時間に限られます。

AI 操作や段階のイベントには、同じ操作のイベントを関連付けるランダムな ID が含まれることがあります。この ID は *記事*やリクエストの ID とは別です。

イベントに *記事*や *保存済みバージョン*の ID またはタイトル、環境変数の値、ファイルパス、URL、生のエラー、プロセス終了の詳細、リクエストや応答の本文は含まれません。
:::

## データの削除を依頼する

アクセス、訂正、その他のプライバシーに関する依頼は、[データに関する依頼](data-request.md)を参照してください。

1. **設定** → **一般** → **プライバシーと診断** で **IDをコピー** を選択します。
2. ID を [kirill.taran@punk.link](mailto:kirill.taran@punk.link) にメールで送り、削除を依頼します。
3. **診断データと使用状況を共有** をオフにします。

共有をオフにする前に ID をコピーしてください。オフにすると ID はデバイスから消去されます。プロジェクトの管理者が一致する仮名化レコードを削除し、メールで完了を通知します。

## Web サイトの分析 {#website-analytics}

ランディングページと料金プランページでは、PostHog を使って訪問、参照元やキャンペーン情報、ダウンロードリンクのクリックを計測します。PostHog のダウンロードイベントには、ページ内でのボタンの位置も含まれます。Google Analytics は、ランディングページ、料金プランページ、ユーザーガイドから最新リリースへのリンクを開いたときにも `download_clicked` イベントを記録します。これらのクリックから、ダウンロードやインストールの完了は確認できません。

Web サイトの PostHog トラッキングでは Cookie やブラウザーのストレージを使わず、個人プロフィール、セッションのリプレイ、一般的なクリック操作の記録も作成しません。PostHog はサーバーで生成したハッシュを使って訪問者数を推定します。Web サイトのイベントはデスクトップの テレメトリーID とは別に保管され、デスクトップアプリの共有設定で Web サイトのトラッキングが制御されることはありません。

ランディングページとユーザーガイドでは Google Analytics も使用しており、訪問やトラフィックの参照元を計測するため Cookie を使う場合があります。ブラウザーが Do Not Track または Global Privacy Control を送信すると、Google Analytics と PostHog のトラッキングはどちらも行われません。前述の Cookie を使わない動作は PostHog に適用されます。
