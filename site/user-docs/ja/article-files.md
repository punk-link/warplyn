# 記事ファイル

**ファイルに保存** と **ファイルから読み込む** を使うと、記事全体を Warplyn とほかの執筆ツールの間でやり取りできます。デスクトップアプリと Web アプリのどちらでも利用できます。

## ファイルに保存する

1. 保存する *記事*を開きます。
2. 記事ヘッダーで **バージョンを保存** の隣にある **ファイルに保存** を選びます。記事を開かずに、ライブラリ内の *記事*を右クリックして **ファイルに保存…** を選ぶこともできます。
3. デスクトップアプリの保存ウィンドウで、ファイル形式のドロップダウンから Markdown、HTML、DOCX、RTF を選び、ファイル名と保存場所を指定します。対応する拡張子を付けてください。Web アプリでは **ファイル形式** を選び、**ダウンロード** を選択して、ブラウザーのダウンロード機能を使います。

ファイルには保存前の編集も含め、現在の *下書き*全体が含まれます。一節を選択していても、ファイルに保存されるのは *下書き*全体です。この操作では *保存済みバージョン*は作成されません。現在の *下書き*を履歴に追加するには、引き続き **バージョンを保存** を使います。

::: tip ワークスペースを持ち運べる形で保存するには
*記事*ファイルに含まれるのは文章だけです。履歴、アシスタントの作業、*スキル*、設定を保持するには、代わりに[バックアップ](backups-and-recovery.md)を作成してください。
:::

Web アプリでファイルがブラウザーに渡されると、**記事のダウンロードを開始しました** と表示されます。ダウンロードの完了またはエラーは、ブラウザーのダウンロード一覧で確認してください。

## ファイルから読み込む

1. 記事ヘッダーで **バージョンを保存** の隣にある **ファイルから読み込む** を選ぶか、ライブラリ内の *記事*を右クリックして **ファイルから読み込む…** を選びます。ライブラリが空の場合は、先に **作成** を選択します。
2. `.md`、`.html`、`.htm`、`.docx`、`.rtf` のいずれか 1 ファイルを選択します。
3. HTML、DOCX、RTF の場合は **インポートする記事を確認** にチェックを入れ、**インポート** を選択します。レビューはキャンセルできます。Markdown は直接開きます。
4. Warplyn は読み込んだテキストを別の *記事*として開きます。以前の *記事*と復旧可能な *下書き*はライブラリに残ります。

先頭にレベル 1 の見出しがある場合、それが新しいタイトルになります。ない場合は、拡張子を除いたファイル名が使われます。見出しは *記事*本文にも残ります。同じファイルを再度読み込むと、別の *記事*が作成されます。

::: warning 読み込みでは別の記事が作成されます
ファイルを読み込んでも、ファイル選択を開いた元の *記事*は置き換わりません。読み込んだ *記事*を確認し、必要に応じてどちらかを移動または削除してください。
:::

10 MiB 以下のファイルを選んでください。Markdown と HTML は UTF-8 を使用する必要があります。DOCX と RTF は Microsoft Office がインストールされていなくても扱えます。

元の形式で対応している範囲で、段落、見出し、編集可能な入れ子のリストと番号、太字、斜体、取り消し線、安全なリンク、引用、コード、Unicode テキストが保持されます。ページレイアウト、フォント、画像、埋め込みオブジェクト、形式固有の複雑な機能は省略または簡略化される場合があります。表のテキストは通常の *記事*内容になります。続行する前にインポートのプレビューを確認してください。未対応の Markdown 拡張構文は、エディターで書式が失われることもあります。

ファイルを読み込まずに、選択画面を閉じることもできます。復旧用に現在の *下書き*を保存できない場合は、保存エラーを修正してから再度読み込んでください。

## 保存済みバージョンをファイルに保存する

1. **履歴** を開きます。
2. 書き出す保存済み *バージョン*を開きます。
3. 詳細の横にある **ファイルに保存** を選びます。

ファイルには現在の *下書き*ではなく、その *保存済みバージョン*の *記事*全体が含まれます。書き出しても *保存済みバージョン*は復元されず、履歴も変わりません。推奨ファイル名には *保存済みバージョン*の番号が含まれます。

ファイルの書き出しにも 10 MiB の上限があります。デスクトップアプリで保存に失敗した場合は、書き込み可能な場所を選んで再試行してください。置き換えに失敗しても、保存先にあったファイルは保持されます。

書き出したファイルに含まれるのは *記事*のテキストであり、履歴、会話、設定全体ではありません。ワークスペース全体を保護するには、[バックアップと復旧](backups-and-recovery.md)を使ってください。
