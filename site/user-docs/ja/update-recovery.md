# デスクトップ更新の復旧

プレビュー版の更新は任意です。更新後に Warplyn が起動しない場合は、以前のプレビュー版を再インストールし、更新前に作成された対応スナップショットを復元してください。

::: warning 新しいデータベースを開かない
新しいプレビュー版で作成したデータベースを古いバージョンで開かないでください。先に更新前として記録されたスナップショットを復元してください。
:::

1. [GitHub のリリース](https://github.com/punk-link/warplyn/releases)から以前のプレビュー版をダウンロードして再インストールします。
2. 更新前に Warplyn が記録した、対応する更新前の SQLite スナップショットを復元します。
3. 以前のプレビュー版を起動し、*記事*、*下書き*、*保存済みバージョン*、設定を確認します。

## Linux AppImage

AppImage は書き込み可能なフォルダーに置いてください。実行要件、起動方法、任意のデスクトップ統合については[Warplyn のインストール](installation.md#linux-appimage)を参照してください。AppImage をインストールしたデスクトップ環境での受け入れ確認は保留中です。

GitHub への更新アクセスを許可した後、**ダウンロード**、続いて **再起動して更新** を使います。通常の終了ではダウンロード済み更新はインストールされません。Debian パッケージでは引き続きパッケージマネージャーを使います。

AppImage の更新後に起動できない場合は、Warplyn を終了してください。以前の実行ファイルは、`.previous` というサフィックスを付けてイメージの隣に保持されています。上記の警告に従い、以前のバージョンを起動する前に対応する更新前のスナップショットを復元してください。復旧が完了するまで両方の実行ファイルとスナップショットを保管します。イメージのフォルダーに書き込めない場合は、自分が所有するフォルダーに移動するか、置き換え用ファイルを手動でダウンロードしてください。イメージを起動するために Electron のサンドボックスを無効にしないでください。
