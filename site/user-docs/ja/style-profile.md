# 文体プロファイル

**文体プロファイル** を使うと、自分の文章例や再利用できる指針を編集アシスタントに提供できます。文章例はこのデバイス内に保管され、*記事*や *保存済みバージョン*には含まれません。

記事ライブラリのツール領域から **文体プロファイル** を開きます。サイドメニュー、またはウィンドウが狭い場合はセクション選択メニューを使い、**文章サンプル**、**手動のルール**、**組版ルール** を選びます。**戻る** を選ぶと、作業していた *記事*と画面に戻ります。

::: tip まずはどちらかを選ぶ
文体の特徴を検出するには文章例を追加します。指針が決まっている場合は **手動のルール** を追加します。どちらか一方だけでも利用できます。
:::

## 文章例を追加する

既存の文章から編集アシスタントに学習させるには **文章サンプル** を開きます。**文章サンプルを追加** を選んでテキストを貼り付けるか、`.txt` または `.md` ファイルをアップロードします。保存済みの *記事*を文章例として使うには **この記事を追加** も選べます。後で見分けやすい名前を付けてください。

文章例のチェックボックスを使って、文体プロファイル に含めるか除外するかを切り替えます。除外した文章例も一覧には残ります。不要になったら削除します。削除すると文章例自体が 文体プロファイル から消えるため、確認が求められます。

## 指針を追加して再構築する

編集アシスタントが従うべき好みを記述するには **手動のルール** を使います。たとえば、一人称の語りを保つ、略語を初出時に説明する、といった指示を追加できます。文章例がなくても指針を追加できます。

文章例や指針を変更した後、**プロファイルを再構築** を選ぶと検出された特徴が更新されます。プロファイルには、使用した文章例と再構築日時が表示されます。それまでは、検出された特徴が以前の文章例に基づいている場合があります。スタイルレビューの *指摘事項*は助言であり、*記事*のテキストとは別に保たれます。

[![Ana の視点に関する全体ルールと プロファイルを再構築 コントロールを示す 文体プロファイル の 手動のルール 画面。](/images/style-profile-rules.png)](/images/style-profile-rules.png)

*文体プロファイル の手動ルールの例。*

::: details 手動ルールの例
アナの視点に近い語りと静かな情景描写が見られる場面を追加し、使いたくないものは除外してからプロファイルを再構築します。文章例で明確に示されていなくてもその好みを適用したい場合は、「語りはアナの視点から離れないようにする」のようなルールを追加します。
:::

## タイポグラフィのルール

**組版ルール** を開き、**組版の言語** を選択します。規則はインターフェイスの言語とは別に、執筆言語ごとに保存されます。**ルールの適用先** で **この言語のすべての記事** または **この記事のみ** を選択します。*翻訳*には独自の言語と設定があります。

ステータスバーの **原文の言語** メニューには、プリセットカタログにある地域別の言語が表示されます。別の言語を使うには **その他の言語…** を選び、`ja` のような言語コードを入力します。組み込みプリセットがなくても、その言語のカスタムタイポグラフィルールを保存できます。

**ルールを追加** では、引用符、文章用ダッシュ、省略記号、句読点の間隔、連続する空白、`10 kg` のような分割禁止の語句ペアを設定できます。**独自のペア** では、開きと閉じの引用符、および内側の空白を指定できます。**句読点の直接置換** は、句読点や空白の規則を文字どおり適用します。文脈に応じた判断が必要な場合は **文脈に依存する組版の指示** を使います。

::: info 言語と適用範囲
執筆言語を選び、その言語のすべての *記事*にルールを適用するか、現在の *記事*だけに適用するかを指定します。*翻訳*には専用の言語設定とタイポグラフィ設定があります。
:::

**組版規則のプリセット** には地域ごとの規則のプレビューが表示されます。**母語話者による確認待ち** と表示されたプレビューは、まだ適用できません。独自のルールは設定できます。地域ごとの規則はほかの地域に自動適用されません。以前のルールが全体に適用されていた場合、**以前のルールをコピー** を選ぶと、元のルールを削除せずにコピーをこの言語に割り当てます。

*記事*のルールには、言語ごとに保存された規則が継承されます。継承したルールを編集すると上書きになり、削除するとその適用範囲で無効になります。**継承ルールに戻す** を選ぶと上書きが解除されます。文体プロファイル を開いている間は、言語を切り替えても保存前のルール編集が保持されます。

ルールは **保存済み** または **未保存** のラベル付きで簡潔に表示されます。**編集** を選ぶとルールを編集できます。一度に編集できるルールは 1 つだけです。**保存** を選ぶと、選択した適用範囲に保存されます。言語設定を保存すると、現在対象に含まれる文章例と保存済みの指針から、ローカルで *文体プロファイル* も再構築されます。文章例を含めるかどうかの変更も反映されます。*記事*固有の上書きは、その *記事*に保存されます。ほかの入力欄にある未保存のテキストはそのまま未保存です。明示的なタイポグラフィルールは文章例なしでも利用できます。文体の特徴を導き出すには文章例が必要です。

現在の *下書き*を保存してから **組版をチェック** を選ぶと、AI 接続なしで選択中の *記事*を確認できます。確認には、ステータスバーに表示された保存済み *バージョン*とその言語が使われます。確認時は **組版の言語** でも同じ言語を選びます。コード、URL、技術識別子、判断が難しい引用符の用例は変更されません。文脈依存のルールを使うには、編集アシスタントによる **文体をレビュー** が必要です。機械的に適用できるルールがない言語は、ローカルのタイポグラフィ確認の対象外です。確認前に独自ルールを追加して保存してください。

訂正内容と根拠となるルールを確認するには **提案を確認** を開きます。適用したい訂正を承認済みにしてから **適用** を選択します。承認した訂正は新しい *保存済みバージョン*になります。すべての訂正を拒否すると、*記事*は変更されません。ルールの保存や確認の実行によって、訂正が適用されることはありません。レビューには、実行時に使われた言語とルールの定義が保持されます。言語または適用中の設定を変更すると、再確認を促す通知が表示されます。タイポグラフィ機能は、複数言語が混在する文章の言語境界を検出しません。判断が難しい箇所は変更されません。
