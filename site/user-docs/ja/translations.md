# 翻訳

Warplyn は *翻訳*を別の *記事*として作成し、元の記事にリンクします。翻訳にはそれぞれタイトル、*下書き*、*保存済みバージョン*の履歴があります。翻訳を編集しても原文は変わりません。

## 翻訳を依頼する

翻訳元の *記事*を開き、**翻訳** で **新しい翻訳…** を選びます。ダイアログでは現在の *記事*の言語があらかじめ選択されることがあります。使用できる表示中の言語がない場合は、**設定** → **言語の初期設定** に設定された優先言語が候補として表示されます。翻訳先を選び、それぞれ確定してください。エディターで一節を選択していても、Warplyn は *記事*全体を翻訳します。元に未保存の編集がある場合は、使用したテキストを特定できるよう、先に *保存済みバージョン*として保存してください。

編集アシスタントは、言語ごとにレビュー可能な *翻訳*結果を作成します。結果を開いて、タイトルとテキストを元の記事と比較してください。文章全体を並べて比較するには **左右に並べる**、対応する段落を並べるには **段落を対応させる** を選択します。名前、数値、URL、コードなどの保護対象テキストは維持してください。保護対象テキストが変更された結果や、古い元の *保存済みバージョン*を使った結果には、Warplyn が印を付けます。続行する前に、これらの通知を確認してください。

::: warning 先に元の記事を保存する
翻訳の依頼には保存済みの *バージョン*が使われます。元の記事に未保存の編集がある場合は、意図したテキストに結果が紐づくよう、翻訳を依頼する前に *保存済みバージョン*として保存してください。
:::

## 翻訳記事を作成または更新する

結果が準備できたら、**編集** を使ってリンク先の *翻訳記事*を開きます。まだ存在しない場合は、Warplyn が作成します。*翻訳*を確認し、準備ができたら *下書き*として保存するか **バージョンを保存** を選びます。翻訳元の *記事*は変更されません。

既存の *翻訳記事*に新しい結果を反映するには、**更新** を選び、対象の *記事*を確定します。Warplyn は翻訳文を新しい *保存済みバージョン*として追加し、*翻訳記事*のタイトルと以前の履歴を維持します。レビュー後に翻訳元または対象が変更された場合、対象に未保存の *下書き*がある場合、または結果が検証に通らなくなった場合は、更新できません。

生成結果を承認対象から外すには **却下** を選びます。これによって翻訳元や、すでに作成した *翻訳記事*が削除されることはありません。以前の結果も引き続き利用できます。**新しい翻訳…** から別の結果を作成できます。

::: tip Update しても翻訳の履歴は保持されます
**更新** を選ぶと、Warplyn は結果をリンクされた *翻訳記事*の新しい *保存済みバージョン*として追加します。タイトルと以前の *保存済みバージョン*も引き続き確認できます。
:::

言語ごとに結果が保持されます。言語タブと結果セレクターを使って、以前の *翻訳*を再表示したり、新しい結果と過去の結果を比較したりできます。各結果には作成日時と、使用された翻訳元の *保存済みバージョン*が記録されています。翻訳元が変更されると、結果は古くなり、新しいリンク付き *記事*を作成できません。新しい *翻訳*を依頼し、現在の翻訳元の *保存済みバージョン*と比較して確認してください。
