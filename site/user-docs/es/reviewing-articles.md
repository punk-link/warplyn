# Revisar artículos

El asistente editorial puede sugerir cambios, pero tú decides qué se incorpora a un *artículo*. La **Revisión de propuestas** permite inspeccionar los cambios antes de que se conviertan en una *versión guardada*.

[![Revisión de propuestas con tres cambios pendientes, texto original y propuesto, decisiones individuales y el control Aplicar.](/images/proposal-review.png)](/images/proposal-review.png)

*Ejemplo de revisión de propuestas para «El río al anochecer».*

## Revisar una propuesta {#review-a-proposal}

Abre la **Revisión de propuestas** desde la tarjeta de resultado del asistente o la Barra de pestañas del espacio de trabajo. Lee los cambios y los avisos sobre contenido que debe conservarse. Alterna entre la comparación en paralelo y apilada si una resulta más fácil de leer. Activa **Resaltar cambios** para marcar las formulaciones modificadas en ambas versiones. Antes de aceptar, comprueba los nombres, cifras, afirmaciones, enlaces y la voz del texto revisado.

Elige **Aceptar** o **Rechazar** para cada cambio. Usa **Marcar todo como aceptado** o **Marcar todo como rechazado**, en **Establecer todas las decisiones…**, para decidir sobre todos a la vez. Después elige **Aplicar** para terminar la revisión. El texto aceptado se convierte en una nueva *versión guardada*. Si se rechazan todas las sugerencias, **Aplicar** cierra la revisión sin modificar el *artículo* ni crear una *versión guardada*. **Restablecer todas las decisiones** devuelve todas las sugerencias a Pendiente y conserva las ediciones realizadas en el texto propuesto. Las decisiones por sí solas no modifican el *artículo*. **Descartar propuesta** cierra la revisión sin aplicar el texto. Si una *propuesta* no se puede dividir de forma segura, se muestra un aviso y debe revisarse completa.

::: tip Revisa a tu ritmo
Puedes editar la redacción propuesta y cambiar el diseño de comparación antes de aplicar los cambios. Tus decisiones solo se hacen efectivas cuando seleccionas **Aplicar**.
:::

Si Warplyn no puede aplicar de forma segura los cambios seleccionados, explica cuándo solo es posible aceptar la *propuesta* completa. Una *propuesta* obsoleta se creó a partir de una *versión guardada* anterior. Sus cambios no se pueden aplicar al texto actual. Descártala o vuelve al historial correspondiente y crea una solicitud nueva.

## Consultar o restaurar una versión guardada

Abre el **Historial de versiones** para leer las versiones guardadas. Al seleccionar una *versión guardada*, se abre una vista previa de solo lectura que no modifica tu trabajo actual. Las *versiones guardadas* marcadas como **Inactivas** pertenecen a una ruta reemplazada por una restauración posterior. Siguen disponibles para consultarlas o restaurarlas.

Elige **Restaurar esta versión** para convertir una versión anterior en la actual. Warplyn añade una nueva *versión guardada* con ese texto; no borra el historial intermedio. Si tienes un *borrador* sin terminar, antes de restaurar decide si quieres guardarlo como *versión guardada* o descartarlo.

## Recuperar un borrador {#recover-a-draft}

Un punto de control de *borrador* es el texto recuperable que se guarda mientras editas. Si el texto local del editor entra en conflicto con un punto de control guardado o con la *versión guardada* actual, Warplyn muestra el texto local conservado junto a las opciones guardadas. Compáralas y elige **Conservar mi borrador**, **Usar el borrador más reciente** o **Usar la versión más reciente**. Como una opción guardada puede reemplazar el texto local, Warplyn te pide confirmación.

## Elegir cómo se aplican las ediciones del asistente

De forma predeterminada, las conversaciones nuevas usan **Proponer ediciones para revisar**. En el Composer puedes elegir **Aplicar ediciones directamente** cuando quieras que una edición solicitada expresamente se aplique sin una *propuesta*. Una edición directa correcta aparece como nueva *versión guardada*. Si seleccionaste texto, la edición se limita a esa selección. Las ediciones directas se bloquean cuando un *borrador* o una *versión guardada* modificada podrían hacer que el reemplazo no fuera seguro. Resuelve el trabajo actual y vuelve a solicitarlo. Los demás resultados generados requieren revisión.

Elige **Editar desde aquí** en uno de tus mensajes anteriores para continuar la conversación desde ese punto. Antes de que confirmes **Restaurar conversación**, Warplyn enumera el trabajo posterior que se descartará, como *propuestas*, *observaciones* o resultados de traducción. También indica si el *artículo* volverá a una *versión guardada* anterior o si se reemplazará el texto del Composer que no hayas enviado. Si hay que resolver un *borrador*, elige **Guardar el trabajo actual y restaurar** o **Descartar borrador y restaurar**. Las *versiones guardadas* actuales y posteriores permanecen en el Historial de versiones. Esta acción no restaura ni modifica ninguna *habilidad*.

## Leer las observaciones de la verificación de datos

Abre **Verificación de datos** para revisar las *observaciones* orientativas y sus fuentes. Las decisiones de aceptación resuelven una *observación* sin modificar el *artículo* ni su veredicto. Las *propuestas* de corrección deben revisarse antes de incorporar los cambios al texto. Consulta [Verificar datos](fact-checking.md) para ver el flujo completo, los veredictos, las opciones de aceptación y cómo volver a comprobar resultados anteriores.
