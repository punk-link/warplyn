# Revisar el estilo de escritura

Usa **Revisar el estilo de escritura** cuando quieras comparar un *artículo* con tu *Perfil de estilo* guardado. El asistente busca diferencias concretas respecto a las características de voz y las reglas del perfil. Si el perfil tiene poca confianza, se considera provisional.

Antes de enviar la solicitud, añade muestras de escritura o indicaciones manuales en el [Perfil de estilo](../style-profile.md) y regenera el perfil. Después abre **Acciones rápidas**, elige **Revisar el estilo de escritura** y selecciona **Enviar solicitud editorial**. Selecciona un pasaje para centrar la revisión; de lo contrario, se utiliza el *artículo* completo.

::: tip Ejemplo
Pregunta: «Compara este pasaje sobre Ana junto al río con el punto de vista cercano de mis muestras de escritura. Señala una diferencia y explica con qué característica del perfil se relaciona».
:::

::: tip Revisar los cambios sugeridos
Lee la *propuesta* y las *observaciones* que la respaldan. Cada *observación* debería señalar una característica o regla del perfil. Antes de aceptar cambios, decide qué sugerencias encajan con el *artículo*.
:::

La revisión de estilo necesita un *Perfil de estilo* disponible y una conexión de IA. Las muestras de escritura originales no se envían; el asistente usa el perfil compacto derivado localmente. La solicitud puede enviar el *artículo* o el pasaje seleccionado al proveedor de IA configurado.
