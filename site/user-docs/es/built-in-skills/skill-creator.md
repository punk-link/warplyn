# Creador de habilidades

Pide al asistente que cree, edite, restaure o elimine una *habilidad* reutilizable. Para hacerlo, usará **Creador de habilidades**. Gestiona instrucciones Markdown locales y mantiene un historial independiente para cada *habilidad*.

Describe la tarea recurrente y las reglas o referencias que debe seguir la *habilidad*. Si un propósito o procedimiento poco claro puede cambiar el resultado, el asistente quizá te haga una pregunta breve. Puedes usar la nueva *habilidad* en solicitudes posteriores. Al crearla, el asistente no la aplica al *artículo* abierto.

::: tip Ejemplo
Pregunta: «Crea una habilidad llamada “Pulir escenas tranquilas”. Haz más concisas las frases de Ana y conserva su voz, el entorno del río y los acontecimientos de la escena. No añadas detalles; marca los pasajes que no estén claros».
:::

Puedes pedir al asistente que revise, restaure o elimine una *habilidad* por su nombre. Al restaurarla, se crea una nueva versión activa y se conservan las *versiones de habilidad* anteriores. Consulta [Crear y gestionar habilidades](../skills.md) para ver el flujo completo y las opciones de edición local.
