# Verificar términos técnicos

Usa **Verificar términos técnicos** para revisar la terminología de un *artículo* sobre informática. Busca conceptos confundidos, desarrollos engañosos de siglas, nombres incorrectos de productos o API y nombres incoherentes para un mismo concepto. Compara el uso con fuentes pertinentes al campo y la versión, teniendo en cuenta las definiciones locales y la evolución de la terminología.

Abre tu *artículo*. Selecciona un pasaje si quieres centrar la comprobación. En el asistente, abre **Acciones rápidas**, elige **Verificar términos técnicos** y selecciona **Enviar solicitud editorial**. Abre el resultado terminado en **Verificación de datos** e inspecciona cada *observación*, su explicación, las fuentes vinculadas y la incertidumbre.

::: tip Ejemplo
En un *artículo* sobre una aplicación para identificar árboles, el Author llama conífera a un sauce. Pide a **Verificar términos técnicos** que compruebe el término en una fuente botánica.
:::

Esta comprobación requiere una conexión de IA y un modelo compatible con la verificación basada en fuentes. El *artículo* o el pasaje seleccionado se envía al servicio de IA configurado; las consultas de investigación pueden incluir sus términos técnicos y el contexto de las afirmaciones. El proveedor podría cobrarte por su uso. Las fuentes pueden estar incompletas o usar términos de forma distinta según el campo. Una *observación* es una recomendación; no reescribe la prosa, el código ni los identificadores. No se realiza una revisión de terminología en segundo plano.
