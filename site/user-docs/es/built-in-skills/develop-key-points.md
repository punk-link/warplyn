# Desarrollar puntos clave

Usa **Desarrollar puntos clave** cuando quieras una lista concisa de las ideas principales de tus notas o de un *artículo*. De forma predeterminada, prepara entre tres y cinco puntos distintos y no reescribe el *artículo*.

Abre **Acciones rápidas**, elige **Desarrollar puntos clave**, añade las indicaciones que quieras en el cuadro de mensaje y selecciona **Enviar solicitud editorial**. Si seleccionas un pasaje, tanto esa selección como el contenido de tu mensaje orientan el resultado. Sin una selección, el asistente sigue primero las indicaciones de tu mensaje y usa el *artículo* si el mensaje está vacío.

::: tip Ejemplo
Selecciona la escena en la que Ana se sienta junto al río y pregunta: «Dame tres interpretaciones posibles de la relación de Ana con el río, basadas en este pasaje».
:::

Es posible que los puntos devueltos necesiten correcciones o un énfasis distinto. Revísalos antes de utilizarlos en un *artículo*. Para crear un borrador completo a partir del material proporcionado, consulta [Convertir ideas en un borrador](turn-ideas-into-a-draft.md).
