# Mejorar el ritmo y la claridad

Usa **Mejorar el ritmo y la claridad** cuando el texto sea difícil de seguir y quieras una estructura más clara o transiciones más fluidas. Su objetivo es mejorar la legibilidad y conservar el sentido, las afirmaciones, la incertidumbre y la voz del *artículo*.

Abre **Acciones rápidas**, elige **Mejorar el ritmo y la claridad** y selecciona **Enviar solicitud editorial**. Puedes indicar un aspecto concreto, por ejemplo, aclarar cómo un descubrimiento cambia la siguiente decisión de un personaje. Selecciona un pasaje para limitar el reemplazo a ese fragmento; de lo contrario, el asistente trabaja con el *artículo* completo.

::: tip Ejemplo
Pregunta: «Sugiere una pequeña revisión que aclare la transición entre observar la corriente y abrir el cuaderno. Conserva la atmósfera tranquila de la escena y no cambies ningún acontecimiento».
:::

Antes de aplicarla, revisa la *propuesta* para comprobar el sentido, los detalles técnicos y la voz del Author. Para pedir que se acorte el texto, usa [Acortar texto](shorten-text.md).
