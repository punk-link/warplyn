# Verificar datos

Usa **Verificar datos** cuando quieras comprobar afirmaciones factuales de un *artículo*. El asistente investiga las afirmaciones con fuentes y prepara *observaciones* orientativas; no reescribe el *artículo*.

Abre **Acciones rápidas**, elige **Verificar datos**, revisa las afirmaciones que seleccione el asistente y quita la selección de las que no quieras comprobar. Después selecciona **Enviar solicitud editorial**. Puedes seleccionar un pasaje para centrar la comprobación. Los resultados están vinculados a la *versión guardada* que se comprueba.

::: tip Ejemplo
En un capítulo situado junto al río, Ana dice que la luna llena hará subir el agua lo suficiente como para cubrir el camino. Pide a **Verificar datos** que compruebe esa afirmación con fuentes pertinentes al entorno de la historia.
:::

::: tip Revisar las pruebas
Abre **Verificación de datos** y lee cada *observación*, sus fuentes, fechas e incertidumbre. Las fuentes pueden estar incompletas o desactualizadas; usa las pruebas para decidir qué comprobar o cambiar.
:::

Para consultar los veredictos, las decisiones de aceptación, las correcciones y las pruebas reutilizadas, visita la [guía de Verificación de datos](../fact-checking.md). Esta función requiere una conexión de IA y un modelo compatible con la verificación basada en fuentes. El proveedor podría cobrarte por su uso. Una *observación* es una recomendación, no una prueba de que una afirmación sea incorrecta. Para revisar términos técnicos, consulta [Verificar términos técnicos](check-technical-terms.md).
