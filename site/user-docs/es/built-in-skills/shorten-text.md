# Acortar texto

Usa **Acortar texto** si quieres recortar un texto que ya has escrito. El asistente quita repeticiones y palabras de relleno, y acorta las frases largas. Conserva el sentido, las pruebas, los matices de duda y tu voz.

Abre **Acciones rápidas**, elige **Acortar texto** y selecciona **Enviar solicitud editorial**. Indica qué se debe conservar o dónde conviene recortar. Selecciona un pasaje para acortar solo ese texto; de lo contrario, el asistente trabaja con el *artículo* completo.

::: tip Ejemplo
Pregunta: «Sugiere una versión más concisa de la frase sobre el río que serpentea entre los sauces. Conserva la imagen plateada y la atmósfera tranquila».
:::

El resultado debe ser más breve que el original. Si no es posible acortarlo de forma segura, el asistente devuelve el texto original sin cambios. Revisa la *propuesta* antes de aplicarla; los nombres, las afirmaciones, los enlaces, el código, las citas y los términos técnicos deben seguir siendo correctos. Si quieres mejorar la claridad sin pedir que se acorte, usa [Mejorar el ritmo y la claridad](improve-flow-and-clarity.md).
