# Habilidades integradas

Las *habilidades* integradas ayudan al asistente editorial a realizar tareas de escritura habituales. Elige una *habilidad* editorial en **Acciones rápidas** o describe lo que necesitas y deja que el asistente deduzca cuál es pertinente. Una vez elegida la *habilidad*, puedes enviarla directamente. Añade un mensaje si necesitas aportar contexto o indicar alguna condición. Selecciona **Enviar solicitud editorial** para empezar. Para crear o gestionar una *habilidad* reutilizable, pídeselo directamente al asistente; **Creador de habilidades** no es una acción rápida del cuadro de mensaje.

Cada página explica para qué sirve la *habilidad* y qué debes revisar en el resultado. Consulta [Asistente editorial](../editorial-assistant.md) y [Revisar artículos](../reviewing-articles.md) para saber cómo trabajar con los resultados.
