# Traducciones

Warplyn guarda cada *traducción* como un *artículo* vinculado al original. La traducción tiene su propio título, *borrador* e historial de *versiones guardadas*. Puedes editarla sin cambiar el original.

## Solicitar una traducción

Abre el *artículo* de origen y elige **Nueva traducción…** en **Traducciones**. Es posible que el cuadro de diálogo seleccione de antemano el idioma del *artículo* actual. Si no hay un idioma visible que se pueda usar, ofrece los idiomas preferidos de **Configuración** → **Idiomas predeterminados**. Selecciona y confirma cada destino. Warplyn usa el *artículo* completo para traducir, aunque hayas seleccionado un pasaje en el editor. Si el original tiene cambios sin guardar, guárdalos primero como *versión guardada* para que la *traducción* pueda identificar el texto exacto utilizado.

El asistente crea un resultado de *traducción* revisable para cada idioma. Abre un resultado para comparar el título y el texto con el original. Elige **En paralelo** para comparar pasajes completos o **Párrafos alineados** para ver juntos los párrafos correspondientes. El texto protegido, como nombres, cifras, URL y código, debe conservarse intacto. Warplyn señala los resultados que modifican texto protegido o usan una *versión guardada* anterior del original. Revisa estos avisos antes de continuar.

::: warning Guarda primero el original
La solicitud de *traducción* utiliza una *versión guardada*. Si el original tiene cambios sin guardar, guárdalos como una *versión guardada* antes de solicitarla para que el resultado corresponda al texto que quieres traducir.
:::

## Crear o actualizar un artículo de traducción

Cuando haya un resultado, usa **Editar** para abrir el *artículo de traducción* vinculado. Si todavía no existe, Warplyn lo crea. Revisa la *traducción* y guarda su *borrador* o selecciona **Guardar versión** cuando esté lista. El *artículo* de origen permanece sin cambios.

Para usar un resultado nuevo en una *traducción* existente, elige **Actualizar** y confirma el *artículo* de destino. Warplyn añade el texto traducido como nueva *versión guardada* y conserva el título y el historial anterior de la *traducción*. La actualización se bloquea si el original o el destino han cambiado desde la revisión, si el destino tiene un *borrador* sin guardar o si el resultado ya no supera la validación.

Elige **Rechazar** para retirar un resultado generado de la aprobación. Esto no elimina el original ni el *artículo de traducción* que ya hayas creado. Los resultados anteriores siguen disponibles. Puedes generar otro con **Nueva traducción…**.

::: tip Actualizar conserva el historial de traducción
Al elegir **Actualizar**, Warplyn añade el resultado como una nueva *versión guardada* al *artículo de traducción* vinculado. Su título y las *versiones guardadas* anteriores siguen disponibles.
:::

Cada idioma conserva sus propios resultados. Usa las pestañas de idioma y el selector de resultados para volver a una *traducción* o comparar un nuevo intento con uno anterior. El resultado indica cuándo se creó y qué *versión guardada* del original utilizó. Si el original ha cambiado, el resultado queda obsoleto y no puede crear un nuevo *artículo* vinculado. Solicita una *traducción* nueva y revísala con respecto a la *versión guardada* actual del original.
