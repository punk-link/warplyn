# Redaktioneller Assistent

Nutzen Sie den Redaktionellen Assistenten, wenn Sie Hilfe beim Formulieren, Überarbeiten, Prüfen von Fakten, Bewerten des Schreibstils oder Vorbereiten einer Übersetzung möchten. Unter **Schnellaktionen** können Sie eine *Fähigkeit* zum Nachrichtenfeld hinzufügen. Die Anfrage startet, sobald Sie **Editorial-Anfrage senden** wählen.

Wenn Sie Text auswählen, bleiben Änderungen auf diese Passage beschränkt. Definitionen und sprachliche Merkmale in den umliegenden Sätzen können dem Assistenten helfen, eine kurze Passage zu verstehen. Dafür kann Ihr Anbieter auch Text außerhalb der Auswahl erhalten. Wenn eine Anfrage Text aus dem *Artikel* benötigt, sendet Warplyn die ausgewählte Passage und bis zu 500 Zeichen auf jeder Seite. Der umliegende Text dient nur als Kontext. Ersetzt werden kann nur die ausgewählte Passage. Im Nachrichtenfeld wird vor dem Senden erklärt, welche Inhalte geteilt werden. Senden Sie die Anfrage nicht, wenn der umgebende Text vertraulich ist. Allgemeine Beratung und die Verwaltung von *Fähigkeiten* benötigen diesen Text nicht. Warplyn erweitert den Kontext niemals stillschweigend auf den gesamten *Artikel*. Reicht der Kontext nicht aus, fügen Sie die relevante Passage ausdrücklich ein oder stellen Sie mit einer anderen Auswahl eine neue Anfrage.

Halte wiederkehrende Hinweise als [Redaktionsnotiz](writing-and-articles.md#editor-notes) an einer Passage fest. Prüfe vor dem Senden **Notizen zu dieser Anfrage**. Allein das Speichern einer Notiz startet keine Anfrage.

::: tip Beispiel
Wählen Sie beim Überarbeiten einer Kurzgeschichte eine Passage aus und fragen Sie: „Verbessere den Lesefluss, aber behalte Anas Perspektive und die ruhige Stimmung bei. Füge keine neuen Ereignisse hinzu.“ Der Assistent erstellt einen *Vorschlag* für die **Vorschlagsprüfung**. Sie können ihn auch bitten, ein Kapitel auf Wechsel zwischen Vergangenheit und Gegenwart zu prüfen; Hinweise zur Stilprüfung erscheinen im **Stilprofil**.
:::

Während der Arbeit zeigt der Assistent eine kurze Statusmeldung. Wählen Sie **Anfrage stoppen**, um eine zu lange laufende Arbeit abzubrechen. Eine abgebrochene oder fehlgeschlagene Anfrage ändert den *Artikel* nicht. Wählen Sie **Erneut versuchen**, wenn Sie sie nochmals ausführen möchten. Der Assistent zeigt keine Prompts, privaten Eingaben, Anmeldedaten oder Anbieterfehler an. Sobald die Ergebniskarte erscheint, können Sie von dort die passende Ansicht öffnen:

- **Vorschlagsprüfung** für generierten oder überarbeiteten Text.
- **Faktenprüfung** für beratende *Hinweise*.
- **Stilprofil** für Hinweise zur Stilprüfung.
- **Übersetzungen** für einen Übersetzungs-*Vorschlag*.

Das Öffnen eines Ergebnisses ändert den *Artikel* nicht. Prüfen Sie einen *Vorschlag*, bevor Sie Änderungen annehmen. *Hinweise* bleiben beratend; Übersetzungen bleiben separate, verknüpfte *Artikel*. Informationen zu Vorschlägen, Verlauf und Wiederherstellung sowie zur Faktenprüfung finden Sie unter [Artikel prüfen](reviewing-articles.md). Unter [Übersetzungen](translations.md) erfahren Sie, wie Sie Übersetzungsergebnisse vergleichen und verwenden.

Für eine gezielte Prüfung technischer Begriffe wählen Sie unter **Schnellaktionen** die Option **Technische Begriffe prüfen**. Die belegten *Hinweise* erscheinen in der **Faktenprüfung**. Die Prüfschritte und Grenzen finden Sie unter [Technische Begriffe prüfen](built-in-skills/check-technical-terms.md).

Bearbeiten Sie in der **Vorschlagsprüfung** den Text unter **Vorschlag** direkt im Layout **Nebeneinander** oder **Untereinander**. **Original** bleibt schreibgeschützt. Ihre Bearbeitung lässt die Entscheidung **Annehmen** oder **Ablehnen** für jede Änderung bestehen. Entscheiden Sie über jede Änderung und wählen Sie dann **Anwenden**, um die Prüfung abzuschließen. Angenommene Formulierungen erstellen eine neue *Version*. Wenn Sie alle Vorschläge ablehnen, schließt **Anwenden** die Prüfung, ohne den *Artikel* zu ändern oder eine *Version* zu erstellen. Um alle Änderungen anzunehmen, wählen Sie unter **Alle Entscheidungen festlegen…** die Option **Alle annehmen markieren** und wenden Sie sie anschließend an. **Alle ablehnen markieren** lässt den *Artikel* unverändert. **Alle Entscheidungen zurücksetzen** setzt jeden Vorschlag auf „Ausstehend“ und behält Ihre Textbearbeitungen im Vorschlag bei. Mit **Vorschlag verwerfen** schließen Sie die Prüfung und entfernen den Vorschlag.

Noch nicht angewendete Bearbeitungen bleiben erhalten, wenn Sie das Layout oder die Arbeitsbereichsansicht wechseln. Beim Neuladen, Wechseln des *Artikels*, Verwerfen des *Vorschlags* oder Erstellen eines neuen Vorschlags werden sie gelöscht. Wenn das Anwenden fehlschlägt, bleiben Ihre Bearbeitungen für einen weiteren Versuch erhalten. Bewahren Sie vorgeschlagene Zahlen, Links, Code und technische Begriffe unverändert. Veraltete, unzuverlässige und bereits angenommene *Vorschläge* sind schreibgeschützt. Wenn Sie den Wortlaut einer Faktenkorrektur bearbeiten, bleiben die zugehörigen *Hinweise* auch nach der Anwendung beratend.

*Fähigkeiten* helfen dabei, eine Anfrage zu gestalten, erweitern aber keine Berechtigungen. Wenn Sie keine *Fähigkeit* auswählen, sucht der Assistent anhand Ihrer Anfrage nach passenden *Fähigkeiten*. Gewöhnliche Anfragen leitet er nicht über einen standardmäßigen Bearbeitungsablauf. Warplyn führt keine Hintergrundarbeiten aus, veröffentlicht nicht direkt und ändert keinen *Artikel* ohne Ihre Zustimmung.

Bitten Sie den Assistenten, eine wiederverwendbare [Fähigkeit](skills.md) zu erstellen, wenn ein Verfahren später erneut verfügbar sein soll. Sind Zweck, Schritte oder Referenzen unklar, kann er eine kurze Rückfrage stellen. Eine erstellte *Fähigkeit* ist sofort verfügbar und hat einen eigenen lokalen Verlauf von *Fähigkeitsversionen*. Ihre Erstellung liest weder den Text Ihres *Artikels* noch ändert sie dessen *Entwurf*, *Vorschlag* oder *Version*.

Sie können den Redaktionellen Assistenten ausdrücklich bitten, den **Versionsverlauf**, gespeicherte redaktionelle Arbeit, Veröffentlichungshinweise oder die Bereitschaft des Stil-Korpus zu prüfen. Auf ausdrückliche Anfrage kann er die aktuelle unveränderliche *Version* in den lokalen Stil-Korpus aufnehmen und das Stilprofil neu erstellen. Er kann keine *Vorschläge* annehmen, *Versionen* wiederherstellen, *Hinweise* auflösen, *Entwürfe* bearbeiten, Stilbeispiele löschen oder veröffentlichen.

Öffnen Sie für Schreibproben, wiederverwendbare Hinweise oder typografische Regeln das [Stilprofil](style-profile.md). Hinweise zur Stilprüfung erscheinen dort und bleiben vom *Artikel* getrennt.
