# Fakten prüfen

Verwenden Sie **Fakten prüfen**, um überprüfbare Behauptungen in einem *Artikel* zu recherchieren, zum Beispiel historische Details oder Aussagen über einen Ort. Der Assistent liefert beratende *Hinweise* mit Erklärungen, Quellen und Angaben zur Unsicherheit. Eine Prüfung ändert Ihren Text nicht.

Für die Faktenprüfung benötigen Sie eine [KI-Verbindung und ein Modell](providers.md), die beleggestützte Faktenprüfung unterstützen. Es können Gebühren des Anbieters anfallen.

## Eine Prüfung starten

1. Öffnen Sie den *Artikel*. Wählen Sie eine Passage aus, wenn Sie die Prüfung darauf eingrenzen möchten.
2. Öffnen Sie **Schnellaktionen** und wählen Sie **Fakten prüfen**. Sie können den Assistenten auch bitten, Behauptungen in Ihrem Text zu prüfen.
3. Prüfen Sie die vom Assistenten ausgewählten Behauptungen und heben Sie die Auswahl für alle auf, die nicht geprüft werden sollen.
4. Wählen Sie **Editorial-Anfrage senden**.
5. Öffnen Sie **Faktenprüfung**, um die Ergebnisse für die gespeicherte *Version* zu prüfen, auf die sich die Prüfung bezieht.

::: tip Beispiel
In „Der Fluss in der Abenddämmerung“ sagt Ana, der Vollmond werde das Wasser so weit steigen lassen, dass der Weg überflutet wird. Prüfen Sie diese Behauptung anhand von Quellen zum Fluss und zum Schauplatz der Geschichte. Lesen Sie nach, ob die Quellen genau diesen Fluss beschreiben, bevor Sie die Szene ändern.
:::

Während die Prüfung läuft, können Sie weiterschreiben oder woanders hin navigieren. Ist ein Durchlauf unvollständig, stehen nur abgeschlossene *Hinweise* zur Verfügung. Starten Sie für nicht bearbeitete Behauptungen eine weitere Prüfung.

## Bewertung und Quellen lesen

Wählen Sie in der **Faktenprüfung** eine Behauptung aus, um ihre Erklärung, Quellen, das Prüfdatum und Angaben zur Unsicherheit zu lesen.

| Bewertung | Bedeutung |
| --- | --- |
| **Gestützt** | Die gefundenen Belege stützen die Behauptung. Prüfen Sie trotzdem, ob die Quellen zu Ihrem Kontext passen. |
| **Umstritten** | Die gefundenen Belege stellen die Behauptung infrage. Lesen Sie Erklärung und Quellen, bevor Sie entscheiden, was geändert werden soll. |
| **Nicht verifizierbar** | Die Behauptung ließ sich anhand der verfügbaren Belege nicht bestätigen. Das bedeutet für sich genommen nicht, dass sie falsch ist. |

Öffnen Sie die Quellenlinks und prüfen Sie Relevanz, Datum und Wortlaut. Ein *Hinweis* ist eine Empfehlung, kein Beweis. Das Prüfdatum gibt an, wann die Behauptung geprüft wurde; es bedeutet nicht, dass alle Quellen an diesem Tag veröffentlicht wurden.

## Entscheiden, wie Sie mit einem Hinweis umgehen

Wählen Sie bei einem ungelösten *Hinweis* aus der letzten Prüfung der aktuellen *Version* die passende Aktion.

| Aktion | Ergebnis |
| --- | --- |
| **In der vorliegenden Form annehmen** | Hält fest, dass Sie die Behauptung in der vorliegenden Form beibehalten möchten. Der *Hinweis* wird als **In der vorliegenden Form angenommen** angezeigt. |
| **Belege annehmen** | Hält fest, dass Sie die Belege geprüft und angenommen haben. Der *Hinweis* wird als **Belege angenommen** angezeigt. |
| **Korrektur vorschlagen** | Bittet den Assistenten bei einer **Umstrittenen** oder **Nicht verifizierbaren** Behauptung, einen Korrektur-*Vorschlag* vorzubereiten. Prüfen Sie ihn, bevor Sie Änderungen anwenden. |

Beide Annahmeaktionen lösen den *Hinweis* auf, entfernen seine Entscheidungsschaltflächen und sorgen dafür, dass er in der Artikelbibliothek keine Aufmerksamkeit mehr anfordert. Keine davon ändert den *Artikel* oder die Bewertung. Sie halten unterschiedliche Gründe für Ihre Entscheidung fest, wirken sich ansonsten aber gleich auf den Prüfablauf aus.

Zum Beispiel bedeutet **Umstritten · Belege angenommen**, dass die Prüfung die Behauptung infrage gestellt und Sie die vorgelegten Belege angenommen haben. Es bedeutet **nicht**, dass die Behauptung korrigiert wurde oder nun gestützt ist. Muss der Text geändert werden, bearbeiten Sie den *Artikel* oder fordern Sie eine Korrektur an, bevor Sie den *Hinweis* auflösen.

Um mehrere Korrekturen gemeinsam anzufordern, wählen Sie ungelöste **Umstrittene** oder **Nicht verifizierbare** Behauptungen aus und wählen Sie **Korrekturen vorschlagen**. Prüfen Sie in der [Vorschlagsprüfung](reviewing-articles.md#review-a-proposal) die vorgeschlagenen Formulierungen und wenden Sie die von Ihnen angenommenen Änderungen an. Angenommener Text erstellt eine neue *Version*.

## Nach Änderungen erneut prüfen

*Hinweise* beziehen sich auf die geprüfte *Version*. Sobald eine andere *Version* aktuell wird, bleiben frühere *Hinweise* lesbar, sind aber veraltet. Wählen Sie **Faktenprüfung erneut ausführen**, bevor Sie danach handeln.

Im **Verlauf der Faktenprüfung** können Sie frühere Durchläufe ansehen. Frühere Durchläufe sind schreibgeschützt; nur der letzte Durchlauf für die aktuelle *Version* erlaubt Aktionen.

Eine spätere Prüfung kann Belege und Annahmeentscheidungen wiederverwenden, wenn sie eine unveränderte Tatsache erkennt – auch bei umformulierter Behauptung. Wiederverwendete Ergebnisse sind mit **Belege aus Version wiederverwendet** gekennzeichnet und behalten ihr ursprüngliches Prüfdatum. Hat sich die Tatsachenbedeutung geändert, kann neue Recherche nötig sein.

Eine erneute Prüfung garantiert nicht, dass zu jeder unveränderten Behauptung neu recherchiert wird. Prüfen Sie bei zeitkritischen Details die Quelle und das Prüfdatum und bitten Sie den Assistenten ausdrücklich, die Behauptung anhand aktueller Quellen zu verifizieren.
