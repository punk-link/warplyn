# Fähigkeiten erstellen

Der Assistant verwendet den integrierten Fähigkeiten erstellen, wenn Sie ihn ausdrücklich bitten, einen wiederverwendbaren *Skill* zu erstellen, zu überarbeiten, wiederherzustellen oder zu löschen. Er verwaltet lokale Markdown-Anweisungen und führt für jeden *Skill* einen eigenen Verlauf.

Beschreiben Sie die wiederkehrende Aufgabe sowie die Regeln oder Referenzen, denen der *Skill* folgen soll. Wenn ein unklarer Zweck oder Ablauf das Ergebnis verändern könnte, stellt der Assistant möglicherweise eine kurze Rückfrage. Ein neu erstellter *Skill* steht für spätere Anfragen zur Verfügung; seine Erstellung führt ihn nicht für den aktuellen *Artikel* aus.

::: tip Beispiel
Fragen Sie: „Erstelle einen Skill namens ‚Ruhiger Belletristik-Zeilenschliff‘. Straffe Anas Sätze und bewahre dabei ihre Stimme, den Schauplatz am Fluss und die Ereignisse der Szene. Füge keine Einzelheiten hinzu, sondern markiere unklare Passagen.“
:::

Sie können den Assistant anhand des Namens bitten, einen *Skill* zu überarbeiten, wiederherzustellen oder zu löschen. Beim Wiederherstellen wird eine neue aktive Version erstellt; frühere *Skill-Versionen* bleiben erhalten. Den vollständigen Ablauf und lokale Bearbeitungsmöglichkeiten finden Sie unter [Skills erstellen und verwalten](../skills.md).
