# Fähigkeiten erstellen

Der Assistent verwendet die integrierte Funktion Fähigkeiten erstellen, wenn Sie ihn ausdrücklich bitten, eine wiederverwendbare *Fähigkeit* zu erstellen, zu überarbeiten, wiederherzustellen oder zu löschen. Sie verwaltet lokale Markdown-Anweisungen und führt für jede *Fähigkeit* einen eigenen Verlauf.

Beschreiben Sie die wiederkehrende Aufgabe sowie die Regeln oder Referenzen, denen die *Fähigkeit* folgen soll. Wenn ein unklarer Zweck oder Ablauf das Ergebnis verändern könnte, stellt der Assistent möglicherweise eine kurze Rückfrage. Eine neu erstellte *Fähigkeit* steht für spätere Anfragen zur Verfügung; ihre Erstellung führt sie nicht für den aktuellen *Artikel* aus.

::: tip Beispiel
Fragen Sie: „Erstelle eine Fähigkeit namens ‚Ruhiger Belletristik-Zeilenschliff‘. Straffe Anas Sätze und bewahre dabei ihre Stimme, den Schauplatz am Fluss und die Ereignisse der Szene. Füge keine Einzelheiten hinzu, sondern markiere unklare Passagen.“
:::

Sie können den Assistenten anhand des Namens bitten, eine *Fähigkeit* zu überarbeiten, wiederherzustellen oder zu löschen. Beim Wiederherstellen wird eine neue aktive Version erstellt; frühere *Fähigkeitsversionen* bleiben erhalten. Den vollständigen Ablauf und lokale Bearbeitungsmöglichkeiten finden Sie unter [Fähigkeiten erstellen und verwalten](../skills.md).
