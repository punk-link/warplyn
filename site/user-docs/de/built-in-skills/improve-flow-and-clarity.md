# Lesefluss und Klarheit verbessern

Verwenden Sie **Lesefluss und Klarheit verbessern**, wenn der Text schwer verständlich wirkt und Sie einen klareren Aufbau oder flüssigere Übergänge wünschen. Der Assistent schlägt Änderungen vor, die das Lesen erleichtern und den Sinn, die Aussagen, die Vorbehalte und Ihren Schreibstil bewahren.

Öffnen Sie **Schnellaktionen**, wählen Sie **Lesefluss und Klarheit verbessern** und wählen Sie **Editorial-Anfrage senden**. Sie können einen bestimmten Schwerpunkt vorgeben, zum Beispiel klarzustellen, wie eine Entdeckung die nächste Entscheidung einer Figur beeinflusst. Wählen Sie eine Passage aus, um den Ersatz darauf zu begrenzen; andernfalls bearbeitet der Assistent den gesamten *Artikel*.

::: tip Beispiel
Fragen Sie: „Schlage eine kleine Überarbeitung vor, die den Übergang vom Beobachten der Strömung zum Öffnen des Notizbuchs klarer macht. Behalte die ruhige Stimmung der Szene bei und ändere keine Ereignisse.“
:::

Prüfen Sie vor dem Anwenden des *Vorschlags*, ob Sinn, technische Einzelheiten und Ihr Schreibstil erhalten geblieben sind. Wenn Sie den Text kürzen möchten, verwenden Sie [Text kürzen](shorten-text.md).
