# Aus Ideen einen Entwurf machen

Verwenden Sie **Aus Ideen einen Entwurf machen**, wenn Ihnen Ausgangsmaterial vorliegt, Sie aber einen zusammenhängenden ersten Entwurf benötigen. Der Assistent macht aus Ihren Ideen einen zusammenhängenden Text. Er hält sich an den Sinn der Vorlage und vermeidet unbelegte Behauptungen.

Öffnen Sie **Schnellaktionen**, wählen Sie **Aus Ideen einen Entwurf machen**, beschreiben Sie die gewünschte Richtung und wählen Sie anschließend **Editorial-Anfrage senden**. Wenn Sie eine Passage ausgewählt haben, verwendet die Anfrage diese Passage und das Material, das Sie ausdrücklich in Ihre Nachricht aufnehmen. Ohne Auswahl kann der aktuelle *Artikel* zusammen mit Ihren Vorgaben verwendet werden.

::: tip Beispiel
Wählen Sie die Passage, in der Ana ihr Notizbuch öffnet, und fragen Sie: „Hilf mir, einen möglichen nächsten Absatz mit den bereits in dieser Passage enthaltenen Einzelheiten zu entwerfen. Lass die Seite leer und erkläre nicht, warum der Fluss sie wiederzuerkennen scheint.“
:::

Lesen Sie den *Vorschlag* und achten Sie auf Aufbau, Aussagen und Formulierungen, bevor Sie Änderungen annehmen. Die Fähigkeit speichert und ändert den *Artikel* nicht selbst. Informationen zum Umschreiben vorhandener Prosa finden Sie unter [Lesefluss und Klarheit verbessern](improve-flow-and-clarity.md).
