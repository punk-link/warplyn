# Kernpunkte entwickeln

Verwenden Sie **Kernpunkte entwickeln**, wenn Sie eine knappe Liste der Hauptgedanken in Ihren Notizen oder Ihrem *Artikel* benötigen. Der Assistent nennt in der Regel drei bis fünf verschiedene Punkte. Der *Artikel* bleibt unverändert.

Öffnen Sie **Schnellaktionen**, wählen Sie **Kernpunkte entwickeln**, geben Sie bei Bedarf im Nachrichtenfeld weitere Vorgaben ein und wählen Sie dann **Editorial-Anfrage senden**. Wenn Sie eine Passage auswählen, bestimmen diese Auswahl und der Text Ihrer Nachricht das Ergebnis. Wenn Sie keine Passage markieren, richtet sich der Assistent nach Ihrer Nachricht. Ohne Nachricht verwendet er den *Artikel*.

::: tip Beispiel
Wählen Sie die Szene aus, in der Ana am Fluss sitzt, und fragen Sie: „Nenne drei mögliche Deutungen von Anas Beziehung zum Fluss, die sich auf diese Passage stützen.“
:::

Vielleicht möchten Sie einzelne Punkte genauer formulieren oder anders gewichten. Prüfen Sie sie, bevor Sie sie in einem *Artikel* verwenden. Wie Sie auf Basis des bereitgestellten Materials einen vollständigen Entwurf erstellen, erfahren Sie unter [Aus Ideen einen Entwurf machen](turn-ideas-into-a-draft.md).
