# Fakten prüfen

Mit **Fakten prüfen** können Sie Aussagen in einem *Artikel* anhand von Quellen überprüfen lassen. Der Assistent fasst seine Ergebnisse in *Hinweisen* zusammen. Der Text bleibt unverändert.

Öffnen Sie **Schnellaktionen**, wählen Sie **Fakten prüfen**, prüfen Sie die vom Assistenten ausgewählten Behauptungen und heben Sie die Auswahl für alle auf, die nicht geprüft werden sollen. Wählen Sie anschließend **Editorial-Anfrage senden**. Sie können eine Passage auswählen, um die Prüfung darauf einzugrenzen. Die Ergebnisse beziehen sich auf die gespeicherte *Version*, die geprüft wird.

::: tip Beispiel
In einem Kapitel am Fluss sagt Ana, dass der Vollmond das Wasser so weit steigen lässt, dass der Weg überflutet wird. Wählen Sie **Fakten prüfen** und bitten Sie den Assistenten, nach Quellen zum Schauplatz der Geschichte zu suchen.
:::

::: tip Belege prüfen
Öffnen Sie die **Faktenprüfung** und lesen Sie jeden *Hinweis*, seine Quellen, Datumsangaben und Unsicherheiten. Quellen können unvollständig oder veraltet sein. Nutzen Sie die Belege, um zu entscheiden, was Sie überprüfen oder ändern möchten.
:::

Bewertungen, Annahmeentscheidungen, Korrekturen und wiederverwendete Belege werden in der [Anleitung zur Faktenprüfung](../fact-checking.md) erklärt. Für die Faktenprüfung benötigen Sie eine KI-Verbindung und ein Modell, das beleggestützte Faktenprüfung unterstützt. Es können Gebühren des Anbieters anfallen. Ein *Hinweis* ist eine Empfehlung und kein Beweis dafür, dass eine Behauptung falsch ist. Für Prüfungen technischer Fachbegriffe siehe [Fachbegriffe prüfen](check-technical-terms.md).
