# Text kürzen

Verwenden Sie **Text kürzen**, wenn eine Passage oder ein ganzer *Artikel* zu lang geraten ist. Die Fähigkeit entfernt Wiederholungen, Füllwörter und weitschweifige Formulierungen und bewahrt dabei Bedeutung, Belege, Unsicherheit und Schreibstimme.

Öffnen Sie **Schnellaktionen**, wählen Sie **Text kürzen** und wählen Sie **Editorial-Anfrage senden**. Geben Sie an, was erhalten bleiben oder wo gekürzt werden soll. Wählen Sie eine Passage aus, um nur diesen Text zu kürzen; andernfalls bearbeitet der Assistent den ganzen *Artikel*.

::: tip Beispiel
Fragen Sie: „Schlage eine knappere Fassung des Satzes über den Fluss vor, der sich durch die Weiden schlängelt. Behalte das silberne Bild und die ruhige Stimmung bei.“
:::

Das Ergebnis muss kürzer als die Vorlage sein. Kann der Assistent den Text nicht kürzen, ohne wichtige Inhalte zu verlieren, gibt er ihn unverändert zurück. Prüfen Sie den *Vorschlag*, bevor Sie ihn anwenden. Namen, Behauptungen, Links, Code, Zitate und Fachbegriffe müssen korrekt bleiben. Wenn Sie Klarheit verbessern möchten, ohne eine Kürzung anzufordern, verwenden Sie [Lesefluss und Klarheit verbessern](improve-flow-and-clarity.md).
