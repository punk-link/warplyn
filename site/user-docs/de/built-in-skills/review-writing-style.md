# Schreibstil prüfen

Verwenden Sie **Schreibstil prüfen**, wenn Sie einen *Artikel* mit Ihrem gespeicherten *Stilprofil* vergleichen möchten. Der Assistent sucht nach konkreten Abweichungen von den Merkmalen und Regeln des Profils. Ein Profil mit geringer Zuverlässigkeit wird als vorläufig behandelt.

Fügen Sie vor dem Senden der Anfrage im [Stilprofil](../style-profile.md) Schreibproben oder manuelle Vorgaben hinzu und erstellen Sie das Profil neu. Öffnen Sie anschließend **Schnellaktionen**, wählen Sie **Schreibstil prüfen** und wählen Sie **Editorial-Anfrage senden**. Wählen Sie eine Passage aus, um die Prüfung darauf einzugrenzen; andernfalls wird der ganze *Artikel* verwendet.

::: tip Beispiel
Fragen Sie: „Vergleiche diese Passage über Ana am Fluss mit der personalen Perspektive in meinen Schreibproben. Zeige einen Unterschied auf und erkläre, auf welches Merkmal des Profils er sich bezieht.“
:::

::: tip Vorgeschlagene Änderungen prüfen
Lesen Sie den *Vorschlag* und die zugehörigen *Hinweise*. Jeder *Hinweis* sollte auf ein Merkmal oder eine Regel des Profils verweisen. Entscheiden Sie, welche Vorschläge zum *Artikel* passen, bevor Sie Änderungen annehmen.
:::

Für die Stilprüfung brauchen Sie ein *Stilprofil* und eine KI-Verbindung. Die Schreibproben bleiben auf Ihrem Gerät. Der Assistent arbeitet mit dem kurzen Profil, das Warplyn daraus erstellt. Die Anfrage kann den *Artikel* oder die ausgewählte Passage an Ihren konfigurierten KI-Anbieter senden.
