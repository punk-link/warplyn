# Fachbegriffe prüfen

Verwenden Sie **Fachbegriffe prüfen**, um die Terminologie in einem IT-*Artikel* zu kontrollieren. Die Fähigkeit sucht nach verwechselten Konzepten, irreführenden Auflösungen von Abkürzungen, falschen Produkt- oder API-Namen und uneinheitlichen Bezeichnungen desselben Konzepts. Sie vergleicht die Verwendung mit Quellen aus dem passenden Fachgebiet und der relevanten Version und berücksichtigt dabei lokale Definitionen und sich entwickelnde Terminologie.

Öffnen Sie Ihren *Artikel*. Wählen Sie eine Passage aus, wenn Sie die Prüfung darauf eingrenzen möchten. Öffnen Sie beim Assistenten **Schnellaktionen**, wählen Sie **Fachbegriffe prüfen** und anschließend **Editorial-Anfrage senden**. Öffnen Sie das abgeschlossene Ergebnis in der **Faktenprüfung** und prüfen Sie jeden *Hinweis*, seine Erklärung, verknüpfte Quellen und Angaben zur Unsicherheit.

::: tip Beispiel
In einem *Artikel* über eine App zur Baumbestimmung bezeichnet der Author eine Weide als Nadelbaum. Bitten Sie **Fachbegriffe prüfen**, den Begriff anhand einer botanischen Quelle zu überprüfen.
:::

Diese Prüfung benötigt eine KI-Verbindung und ein Modell, das beleggestützte Faktenprüfung unterstützt. Ihr *Artikel* oder die ausgewählte Passage wird an den konfigurierten KI-Dienst gesendet; Rechercheanfragen können die darin enthaltenen Fachbegriffe und den Kontext der Behauptung umfassen. Es können Gebühren des Anbieters anfallen. Quellen können unvollständig sein oder Begriffe je nach Fachgebiet unterschiedlich verwenden. Ein *Hinweis* ist eine Empfehlung; er schreibt weder Prosa noch Code oder Bezeichner um. Es gibt keine Hintergrundprüfung der Terminologie.
