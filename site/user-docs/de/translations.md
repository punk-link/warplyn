# Übersetzungen

Warplyn legt jede *Übersetzung* als eigenen *Artikel* an und verknüpft sie mit dem Original. Die Übersetzung hat einen eigenen Titel, *Entwurf* und *Versionsverlauf*. Änderungen an der Übersetzung lassen das Original unverändert.

## Eine Übersetzung anfordern

Öffnen Sie den Quell-*Artikel* und wählen Sie unter **Übersetzungen** die Option **Neue Übersetzung…**. Im Dialog ist möglicherweise die Sprache des aktuellen *Artikels* vorausgewählt. Wenn keine angezeigte Sprache verwendet werden kann, bietet der Dialog die bevorzugten Sprachen aus **Einstellungen** → **Sprachvorgaben** an. Wählen und bestätigen Sie jedes Ziel. Warplyn verwendet für die Übersetzung den gesamten *Artikel*, auch wenn Sie im Editor nur eine Passage ausgewählt haben. Hat der Quelltext ungespeicherte Änderungen, speichern Sie sie zuerst als *Version*, damit die *Übersetzung* genau den verwendeten Text zuordnen kann.

Der Assistent erstellt für jede Sprache ein prüfbares *Übersetzungsergebnis*. Öffnen Sie ein Ergebnis, um Titel und Text mit der Quelle zu vergleichen. Wählen Sie **Nebeneinander**, um vollständige Passagen zu vergleichen, oder **Absätze zuordnen**, wenn die jeweiligen Absätze zusammen angezeigt werden sollen. Geschützte Inhalte wie Namen, Zahlen, URLs und Code müssen unverändert bleiben. Warplyn kennzeichnet Ergebnisse, die geschützte Inhalte ändern oder eine ältere Quell-*Version* verwenden. Prüfen Sie diese Hinweise, bevor Sie fortfahren.

::: warning Speichern Sie zuerst die Quelle
Eine *Übersetzungs*-Anfrage verwendet eine gespeicherte *Version*. Wenn der Quelltext ungespeicherte Änderungen enthält, speichern Sie sie vor der Anfrage als *Version*. So bezieht sich das Ergebnis auf den gewünschten Text.
:::

## Einen Übersetzungsartikel erstellen oder aktualisieren

Wenn ein Ergebnis bereit ist, öffnen Sie mit **Bearbeiten** den verknüpften *Übersetzungsartikel*. Gibt es noch keinen, erstellt Warplyn ihn. Prüfen Sie die *Übersetzung* und speichern Sie ihren *Entwurf* oder wählen Sie **Version speichern**, sobald Sie bereit sind. Der Quell-*Artikel* bleibt unverändert.

Um ein bestehendes *Übersetzungsergebnis* zu verwenden, wählen Sie **Aktualisieren** und bestätigen Sie den Ziel-*Artikel*. Warplyn fügt den übersetzten Text als neue *Version* hinzu und behält Titel und bisherigen Verlauf der *Übersetzung* bei. Die Aktualisierung ist gesperrt, wenn sich Quelle oder Ziel seit der Prüfung geändert haben, der Zieltext einen ungespeicherten *Entwurf* enthält oder das Ergebnis die Validierung nicht mehr besteht.

Wählen Sie **Ablehnen**, um ein generiertes Ergebnis aus der Freigabe zu nehmen. Dadurch wird weder die Quelle noch ein bereits erstellter *Übersetzungsartikel* gelöscht. Frühere Ergebnisse bleiben verfügbar. Über **Neue Übersetzung…** können Sie ein weiteres Ergebnis erstellen.

::: tip Aktualisieren erhält den Übersetzungsverlauf
Wenn Sie **Aktualisieren** wählen, fügt Warplyn das Ergebnis als neue *Version* zum verknüpften *Übersetzungsartikel* hinzu. Der Titel und frühere *Versionen* bleiben verfügbar.
:::

Für jede Sprache bleiben die Ergebnisse getrennt. Verwenden Sie die Sprachregisterkarten und die Ergebnisauswahl, um eine *Übersetzung* erneut aufzurufen oder einen neuen Versuch mit einem früheren zu vergleichen. Ein Ergebnis zeigt, wann es erstellt wurde und welche Quell-*Version* verwendet wurde. Wenn sich die Quelle geändert hat, ist das Ergebnis veraltet und kann keinen neuen verknüpften *Artikel* erstellen. Fordern Sie eine neue *Übersetzung* an und prüfen Sie sie anhand der aktuellen Quell-*Version*.
