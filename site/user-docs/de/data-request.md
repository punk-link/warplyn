# Auskunft über eigene Daten oder deren Löschung beantragen

Schreiben Sie an [kirill.taran@punk.link](mailto:kirill.taran@punk.link), wenn Sie Fragen zu personenbezogenen Daten haben, die beim Warplyn-Projekt eingegangen sind, Auskunft oder Berichtigung wünschen oder eine Löschung beantragen möchten. Geben Sie an, um welche Daten es geht oder wann Sie mit dem Projekt in Kontakt waren. Der Projektinhaber antwortet per E-Mail und kann Informationen erfragen, die zum Auffinden der Daten oder zur Überprüfung der Anfrage erforderlich sind.

Fügen Sie Ihrer ersten E-Mail keine *Artikel*-Inhalte, API-Schlüssel, Passwörter oder Identitätsdokumente bei.

## Optionale Desktop-Telemetrie

Wenn Sie die Freigabe von Diagnose- und Nutzungsdaten aktiviert haben:

1. Öffnen Sie **Einstellungen** → **Allgemein** → **Datenschutz und Diagnose** und wählen Sie **Telemetrie-ID kopieren**.
2. Senden Sie die ID an die obige E-Mail-Adresse und beschreiben Sie Ihr Anliegen.
3. Deaktivieren Sie **Diagnose- und Nutzungsdaten teilen**, um die künftige Erfassung zu beenden.

Kopieren Sie die ID, bevor Sie die Freigabe ausschalten, da sie dadurch von Ihrem Gerät gelöscht wird. Wenn Sie die Freigabe ausschalten, bleiben bereits gesendete Ereignisse gespeichert. Bei Löschanfragen löscht der Projektinhaber den passenden pseudonymen Datensatz und bestätigt dies per E-Mail.

Unter [Diagnose- und Nutzungsdaten](telemetry.md) erfahren Sie, welche Daten Warplyn erfasst und wie Sie die Freigabe ändern.

## Eigene Texte und KI-Anbieter

Ihre *Artikel* und deren Verlauf werden lokal gespeichert. Eine Anfrage an den Projektinhaber löscht keine Dateien oder App-Daten auf Ihrem Computer. Sichern Sie Texte, die Sie behalten möchten, bevor Sie lokale Daten entfernen.

Wenn Sie KI-Funktionen verwenden, werden relevante Texte und Kontext an den von Ihnen gewählten Anbieter gesendet. Anfragen zu Daten, die dieser Anbieter gespeichert hat, müssen Sie separat an den Anbieter richten.

## Website-Analyse

Website-Analysen sind von der Desktop-Telemetrie getrennt. Wenn sich Ihre Anfrage auf einen Websitebesuch bezieht, nennen Sie ungefähr das Datum und die Seitenadresse. Mit der Telemetrie-ID der Desktop-App lässt sich kein Websitebesuch zuordnen. Auch mit Datum und Seitenadresse finden wir den Besuch möglicherweise nicht in den Analysedaten.

Unter [Website-Analyse](telemetry.md#website-analytics) finden Sie die verwendeten Dienste und Browser-Datenschutzsignale, die das Tracking deaktivieren.
