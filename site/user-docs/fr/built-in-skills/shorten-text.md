# Raccourcir un texte

Utilisez **Raccourcir le texte** pour obtenir une version plus courte d’un texte existant. La compétence supprime les répétitions, les phrases de remplissage et les formulations trop longues tout en préservant le sens, les éléments étayant le texte, les incertitudes et la voix.

Ouvrez **Actions rapides**, choisissez **Raccourcir le texte**, puis sélectionnez **Envoyer**. Indiquez ce qu’il faut conserver ou les passages à raccourcir. Sélectionnez un passage pour ne raccourcir que ce texte ; sinon, l’assistant travaille sur l’*article* entier.

::: tip Exemple
Demandez : « Propose une version plus concise de la phrase sur la rivière qui serpente parmi les saules. Garde l’image argentée et l’atmosphère calme. »
:::

Le résultat doit être plus court que le texte source. Si la compétence ne peut pas le raccourcir sans risque, l’assistant renvoie le texte source sans le modifier. Examinez la *proposition* avant de l’appliquer. Les noms, les affirmations, les liens, le code, les citations et les termes techniques doivent rester exacts. Pour clarifier un texte sans demander de le raccourcir, utilisez [Améliorer la fluidité et la clarté](improve-flow-and-clarity.md).
