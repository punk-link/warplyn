# Compétences intégrées

Les *compétences* intégrées aident l’assistant éditorial à effectuer les tâches d’écriture courantes. Choisissez une *compétence* éditoriale dans **Actions rapides**, ou décrivez votre demande et laissez l’assistant choisir une compétence pertinente. Vous pouvez envoyer seule la pastille de compétence sélectionnée ; ajoutez un message uniquement si vous avez un contexte ou une contrainte à préciser. Sélectionnez **Envoyer** pour commencer. Pour créer ou gérer une *compétence* réutilisable, demandez-le directement à l’assistant ; **Créateur de compétences** n’est pas une action rapide du Composer.

Chaque page explique l’utilité de la *compétence* et les éléments à vérifier dans son résultat. L’assistant prépare un travail que vous pouvez examiner. Consultez [Assistant éditorial](../editorial-assistant.md) et [Relire des articles](../reviewing-articles.md) pour savoir comment traiter les résultats.
