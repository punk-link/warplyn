# Vérifier les faits

Utilisez **Vérifier les faits** pour vérifier les affirmations factuelles d’un *article*. La compétence recherche des sources et prépare des *observations* informatives ; elle ne réécrit pas l’*article*.

Ouvrez **Actions rapides**, choisissez **Vérifier les faits**, examinez les affirmations sélectionnées par l’assistant et désélectionnez celles que vous ne souhaitez pas vérifier. Sélectionnez ensuite **Envoyer**. Vous pouvez choisir un passage pour cibler la vérification. Les résultats sont liés à la *version enregistrée* vérifiée.

::: tip Exemple
Dans un chapitre situé près de la rivière, Ana affirme que la pleine lune fera assez monter l’eau pour recouvrir le sentier. Demandez à **Vérifier les faits** de vérifier ce détail à l’aide de sources adaptées au cadre de l’histoire.
:::

::: tip Examiner les éléments
Ouvrez **Vérification des faits** et lisez chaque *observation*, ses sources, leurs dates et les incertitudes. Les sources peuvent être incomplètes ou obsolètes. Appuyez-vous sur les éléments disponibles pour décider quoi vérifier ou modifier.
:::

Pour les verdicts, les décisions d’acceptation, les corrections et les éléments réutilisés, consultez le [guide Vérification des faits](../fact-checking.md). La vérification des faits nécessite une connexion à un fournisseur d’IA et un modèle prenant en charge la recherche de sources. Des frais du fournisseur peuvent s’appliquer. Une *observation* est un avis, pas la preuve qu’une affirmation est fausse. Pour cibler les termes techniques, consultez [Vérifier les termes techniques](check-technical-terms.md).
