# Développer les points clés

Utilisez **Développer les idées** pour obtenir une liste concise des idées principales de vos notes ou d’un *article*. Par défaut, la compétence prépare trois à cinq points distincts sans réécrire l’*article*.

Ouvrez **Actions rapides**, choisissez **Développer les idées**, ajoutez vos indications dans la zone de saisie, puis sélectionnez **Envoyer**. Si vous sélectionnez un passage, le résultat s’appuie sur cette sélection et sur le contenu de votre message. Sans sélection, l’assistant suit d’abord vos indications et utilise l’*article* si votre message est vide.

::: tip Exemple
Sélectionnez la scène où Ana s’assoit près de la rivière et demandez : « Donne-moi trois interprétations possibles de la relation d’Ana avec la rivière, en t’appuyant sur ce passage. »
:::

Les points proposés peuvent nécessiter une correction ou un autre angle. Vérifiez-les avant de les reprendre dans un *article*. Pour créer un brouillon complet à partir de contenu fourni, consultez [Transformer vos idées en brouillon](turn-ideas-into-a-draft.md).
