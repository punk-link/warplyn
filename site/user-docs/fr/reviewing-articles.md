# Relire des articles

L’assistant éditorial peut suggérer des modifications, mais vous décidez de celles qui entrent dans un *article*. **Examen des propositions** vous permet d’examiner les changements avant qu’ils deviennent une *version enregistrée*.

[![Examen des propositions affiche trois modifications en attente, les textes Original et Proposition, les décisions individuelles et la commande Appliquer.](/images/proposal-review.png)](/images/proposal-review.png)

*Exemple de Examen des propositions pour « La rivière au crépuscule ».*

## Vérifier une proposition {#review-a-proposal}

Ouvrez **Examen des propositions** depuis la carte de résultat de l’assistant ou la Workspace Tab Bar. Lisez les modifications et les avertissements sur les éléments à préserver. Passez de la comparaison côte à côte à la vue empilée si l’une est plus facile à lire. Activez **Mettre les modifications en évidence** pour mettre en évidence les formulations modifiées dans les deux versions. Avant d’accepter, vérifiez les noms, les nombres, les affirmations, les liens et la voix du texte modifié.

Choisissez **Accepter** ou **Rejeter** pour chaque modification. Pour définir toutes les décisions à la fois, choisissez **Tout accepter** ou **Tout rejeter** dans **Tout décider…**. Sélectionnez ensuite **Appliquer** pour terminer la vérification. Le texte accepté crée une nouvelle *version enregistrée*. Si vous rejetez toutes les suggestions, Appliquer ferme la vérification sans modifier l’*article* ni créer de *version enregistrée*. **Tout réinitialiser** remet chaque suggestion à l’état En attente et conserve les modifications apportées au texte proposé. Les décisions seules ne modifient pas l’*article*. **Écarter la proposition** ferme la vérification sans appliquer le texte. Si une *proposition* ne peut pas être divisée sans risque, un avis vous demande de l’examiner dans son ensemble.

::: tip Prenez le temps de vérifier
Vous pouvez modifier le texte proposé et changer la disposition de comparaison avant d’appliquer les modifications. Vos décisions ne prennent effet que lorsque vous sélectionnez **Appliquer**.
:::

Si Warplyn ne peut pas appliquer les modifications sélectionnées sans risque, l’application indique quand il est possible d’accepter uniquement la *proposition* entière. Une *proposition* obsolète a été créée à partir d’une *version enregistrée* antérieure. Ses modifications ne peuvent pas être appliquées au texte actuel. Fermez-la ou revenez à l’historique correspondant et faites une nouvelle demande.

## Parcourir ou restaurer une version enregistrée

Ouvrez **Historique des versions enregistrées** pour lire les versions enregistrées. La sélection d’une *version enregistrée* ouvre un aperçu en lecture seule sans modifier votre travail actuel. Les *versions enregistrées* marquées **Inactive** appartiennent à une branche remplacée par une restauration ultérieure. Vous pouvez toujours les consulter ou les restaurer.

Choisissez **Restaurer** pour rétablir une version antérieure. Warplyn ajoute une nouvelle *version enregistrée* contenant ce texte ; l’historique intermédiaire n’est pas supprimé. Si vous avez un *brouillon* inachevé, choisissez de l’enregistrer comme *version enregistrée* ou de l’abandonner avant la restauration.

## Récupérer un brouillon {#recover-a-draft}

Le point de contrôle contient le texte récupérable enregistré pendant que vous écrivez. Si le texte local de l’éditeur entre en conflit avec un point de contrôle enregistré ou avec la *version enregistrée* actuelle, Warplyn affiche le texte local conservé à côté des options enregistrées. Comparez-les avant de choisir **Conserver mon brouillon**, **Utiliser le dernier brouillon** ou **Utiliser la dernière version enregistrée**. Comme un choix enregistré peut remplacer le texte local, Warplyn vous demande de confirmer.

## Choisir comment l’assistant applique ses modifications

Les nouvelles conversations utilisent **Proposer des retouches** par défaut. Dans le Composer, vous pouvez sélectionner **Appliquer directement** pour demander explicitement une modification appliquée sans *proposition*. Une modification directe réussie apparaît comme une nouvelle *version enregistrée*. Si vous avez sélectionné du texte, la modification reste limitée à cette sélection. Les modifications directes sont bloquées lorsqu’un *brouillon* ou une *version enregistrée* modifiée pourrait rendre le remplacement risqué. Résolvez votre travail actuel, puis faites une nouvelle demande. Les autres résultats générés doivent toujours être vérifiés.

Choisissez **Modifier à partir d’ici** sur l’un de vos messages précédents pour reprendre la conversation à partir de ce point. Avant que vous confirmiez **Restaurer la conversation**, Warplyn répertorie les travaux ultérieurs qui seront rejetés, comme les *propositions*, les *observations* ou les résultats de traduction. L’application indique aussi si l’*article* reviendra à une *version enregistrée* antérieure ou si le texte non envoyé du Composer sera remplacé. Si un *brouillon* nécessite votre attention, choisissez **Enregistrer et restaurer** ou **Abandonner et restaurer**. Les *versions enregistrées* actuelles et ultérieures restent dans Historique des versions enregistrées. Cette action ne restaure ni ne modifie une *compétence*.

## Lire les observations de Vérification des faits

Ouvrez **Vérification des faits** pour examiner les *observations* informatives et leurs sources. Les décisions d’acceptation permettent de résoudre une *observation* sans modifier l’*article* ni son verdict. Les *propositions* de correction doivent être vérifiées avant que leurs modifications soient intégrées au texte. Consultez [Vérifier les faits](fact-checking.md) pour le processus complet, les verdicts, les options d’acceptation et la nouvelle vérification des résultats précédents.
