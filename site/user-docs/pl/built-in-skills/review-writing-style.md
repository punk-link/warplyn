# Przejrzyj styl pisania

Użyj **Przejrzyj styl pisania**, aby porównać *artykuł* z zapisanym *Profil stylu*. Asystent wyszukuje konkretne różnice względem cech stylu i zasad z profilu. Profil o niskim poziomie pewności jest traktowany jako wstępny.

Przed wysłaniem zlecenia dodaj próbki tekstu lub ręczne wskazówki w [Profil stylu](../style-profile.md) i przebuduj profil. Następnie otwórz **Szybkie działania**, wybierz **Przejrzyj styl pisania**, a potem **Wyślij żądanie redakcyjne**. Zaznacz fragment, aby skupić przegląd; w przeciwnym razie zostanie użyty cały *artykuł*.

::: tip Przykład
Poproś: „Porównaj ten fragment o Anie nad rzeką z bliskim punktem widzenia w moich próbkach tekstu. Wskaż jedną różnicę i wyjaśnij, z którą cechą profilu jest związana”.
:::

::: tip Sprawdź sugerowane zmiany
Przeczytaj *propozycję* i wspierające ją *uwagi*. Każda *uwaga* powinna wskazywać cechę lub zasadę profilu. Zdecyduj, które sugestie pasują do *artykułu*, zanim zaakceptujesz zmiany.
:::

Przegląd stylu wymaga dostępnego *Profil stylu* i połączenia AI. Surowe próbki tekstu nie są wysyłane; asystent korzysta ze zwięzłego profilu utworzonego lokalnie. Zlecenie może wysłać do skonfigurowanego dostawcy AI *artykuł* lub zaznaczony fragment.
