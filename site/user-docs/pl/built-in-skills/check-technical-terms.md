# Sprawdź terminy techniczne

Użyj **Sprawdź terminy techniczne**, aby sprawdzić terminologię w informatycznym *artykule*. Funkcja wyszukuje pomylone pojęcia, mylące rozwinięcia skrótów, nieprawidłowe nazwy produktów lub API oraz niespójne nazwy tego samego pojęcia. Porównuje użycie terminów ze źródłami dotyczącymi danej dziedziny i wersji, uwzględniając lokalne definicje oraz zmieniającą się terminologię.

Otwórz *artykuł*. Jeśli chcesz skupić sprawdzenie, zaznacz fragment. W asystencie otwórz menu **Szybkie działania**, wybierz **Sprawdź terminy techniczne**, a następnie **Wyślij żądanie redakcyjne**. Otwórz ukończony wynik w widoku **Weryfikacja faktów** i przejrzyj każdą *uwagę*, jej wyjaśnienie, powiązane źródła oraz informacje o niepewności.

::: tip Przykład
W *artykule* o aplikacji do rozpoznawania drzew autor nazywa wierzbę drzewem iglastym. Poproś **Sprawdź terminy techniczne** o sprawdzenie tego terminu w źródle botanicznym.
:::

Sprawdzenie wymaga połączenia AI i modelu obsługującego weryfikację faktów ze źródłami. *Artykuł* lub zaznaczony fragment jest wysyłany do skonfigurowanej usługi AI; zapytania badawcze mogą zawierać terminy techniczne i kontekst twierdzenia. Dostawca może naliczyć opłatę. Źródła mogą być niekompletne lub używać terminów w różny sposób zależnie od dziedziny. *Uwaga* jest wskazówką; nie przeredagowuje tekstu, kodu ani identyfikatorów. Skanowanie terminologii w tle nie jest dostępne.
