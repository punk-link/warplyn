# Kreator umiejętności

Gdy wyraźnie poprosisz o utworzenie, poprawienie, przywrócenie lub usunięcie wielokrotnego użytku *umiejętności*, asystent używa wbudowanego Kreator umiejętności. Zarządza lokalnymi instrukcjami Markdown i prowadzi osobną historię każdej *umiejętności*.

Opisz powtarzane zadanie oraz zasady lub materiały źródłowe, których *umiejętność* ma przestrzegać. Jeśli niejasny cel lub procedura mogłyby zmienić wynik, asystent może zadać krótkie pytanie uzupełniające. Nowo utworzona *umiejętność* jest dostępna przy kolejnych zleceniach; jej utworzenie nie uruchamia jej na bieżącym *artykule*.

::: tip Przykład
Poproś: „Utwórz umiejętność o nazwie ‘Quiet fiction line edit’. Skróć zdania Any, zachowując jej głos, scenerię nad rzeką i wydarzenia w scenie. Nie dodawaj szczegółów; oznacz niejasne fragmenty”.
:::

Możesz poprosić asystenta o poprawienie, przywrócenie lub usunięcie *umiejętności*, podając jej nazwę. Przywrócenie tworzy nową aktywną wersję i zachowuje wcześniejsze *zapisane wersje umiejętności*. Pełny proces i opcje lokalnej edycji opisano w sekcji [Tworzenie i zarządzanie umiejętnościami](../skills.md).
