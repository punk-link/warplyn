# Skróć tekst

Użyj **Skróć tekst**, jeśli chcesz skrócić istniejący tekst. Asystent usuwa powtórzenia i zbędne słowa oraz skraca rozwlekłe sformułowania. Zachowuje sens tekstu, przytoczone dowody, zastrzeżenia i Twój styl.

Otwórz **Szybkie działania**, wybierz **Skróć tekst**, a następnie **Wyślij żądanie redakcyjne**. Dodaj wskazówki dotyczące tego, co zachować lub gdzie skrócić tekst. Zaznacz fragment, aby skrócić tylko jego treść; bez zaznaczenia asystent pracuje nad całym *artykułem*.

::: tip Przykład
Poproś: „Zaproponuj krótszą wersję zdania o rzece wijącej się wśród wierzb. Zachowaj srebrzysty obraz i spokojny nastrój”.
:::

Wynik musi być krótszy od źródła. Jeśli nie da się bezpiecznie skrócić tekstu, asystent zwróci go bez zmian. Przed zastosowaniem sprawdź *propozycję*; nazwy, twierdzenia, łącza, kod, cytaty i terminy techniczne powinny pozostać poprawne. Jeśli chcesz poprawić czytelność bez prośby o skrócenie, użyj funkcji [Popraw płynność i jasność](improve-flow-and-clarity.md).
