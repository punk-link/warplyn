# AI로 글을 수정하고 모든 변경 사항 검토하기

장면의 사건은 그대로 두고 전개 속도만 다듬고 싶다면 글쓰기 도우미에게 수정을 요청해 보세요. 한 부분 또는 *글* 전체를 대상으로 제안된 문구를 비교하고, 유지할 변경 사항을 적용하세요.

Warplyn은 Windows와 Linux용 오픈 소스 로컬 우선 글쓰기 작업 공간입니다. 글은 컴퓨터에 저장됩니다. AI 지원을 이용하려면 인터넷에 연결하고, 지원되는 제공자의 API 키를 설정하세요. 관련 텍스트와 컨텍스트가 해당 제공자에게 전송되며 제공자의 요금과 데이터 정책이 적용됩니다.

반복해서 사용할 지침은 구절의 [편집 메모](writing-and-articles.md#editor-notes)에 남기세요. 보내기 전에 **이 요청에 첨부되는 메모**을 확인하세요. 메모를 저장하는 것만으로 요청이 시작되지는 않습니다.

## 범위를 좁혀 요청 시작하기

*글*을 열고 수정할 부분을 선택합니다. 입력창에서 개선할 점과 유지할 점을 설명하세요. 예를 들어 The River at Dusk를 작업 중이라면 다음과 같이 요청할 수 있습니다.

> 아나의 시점과 조용한 분위기를 유지하면서 글의 흐름을 개선해 주세요. 새로운 사건은 추가하지 마세요.

**편집 요청 보내기**를 선택합니다. Warplyn은 선택한 부분과 그 앞뒤에서 최대 500자씩 보냅니다. 주변 글은 맥락을 파악하는 데만 쓰이며, 수정 대상은 선택한 부분입니다. 민감한 내용이 있다면 보내기 전에 입력창에서 전송 범위를 확인하세요. 자세한 내용은 [글쓰기 도우미](editorial-assistant.md)를 참조하세요.

[![소설 수정 요청이 입력된 Warplyn 입력창.](/images/editorial-assistant-example.png)](/images/editorial-assistant-example.png)

*입력창 요청 예시입니다. 스크린샷에는 이전 스킬 이름이 표시되어 있습니다.*

## 원문과 제안된 문구 비교하기

요청이 완료되면 결과 카드에서 **제안 검토**를 엽니다. **원본**과 **제안**을 비교하고, 장면의 사건, 시점, 문체가 유지되었는지 확인하세요.

[![원본과 제안 텍스트, 개별 판단, 적용를 비교하는 제안 검토 화면.](/images/proposal-review.png)](/images/proposal-review.png)

*The River at Dusk의 검토 예시입니다. 생성 문구는 요청과 모델에 따라 달라집니다.*

각 변경 사항에 대해 **수락** 또는 **거절**을 선택합니다. 적용하기 전에 **제안** 문구를 편집할 수 있습니다. Warplyn이 *제안*을 안전하게 나눌 수 없다면 전체를 검토해야 한다고 안내합니다.

## 변경 사항 적용하고 기록 유지하기

모든 변경 사항을 판단한 뒤 **적용**을 선택합니다. 승인된 텍스트는 새 *저장된 버전*이 됩니다. 모든 변경 사항을 거부하면 *글*은 그대로 유지되고 새 *저장된 버전*도 만들어지지 않습니다. 판단만으로 글이 바뀌지는 않습니다.

이전 저장 버전을 확인하려면 **저장된 버전 기록**을 엽니다. 이전 버전을 복원하면 새 *저장된 버전*이 추가되고 그 사이의 기록도 유지됩니다. 복구 방법과 오래된 *제안*에 대해서는 [글 검토하기](reviewing-articles.md)를 참조하세요.

AI 수정 결과가 의도를 놓치거나 유지하려던 세부 내용을 바꿀 수 있습니다. 적용하기 전에 결과를 검토하고, 필요하다면 범위를 더 좁혀 다시 요청하세요. 요청을 취소하거나 실패해도 *글*은 변경되지 않습니다.

## 내 글로 시작하기

[Warplyn 다운로드](https://github.com/punk-link/warplyn/releases/latest) 후 [설치 가이드](installation.md)를 따르고 지원되는 [AI 제공자](providers.md)에 연결하세요. Windows 설치 프로그램에는 디지털 서명이 없습니다. 표시될 수 있는 경고는 설치 가이드에서 설명합니다.
