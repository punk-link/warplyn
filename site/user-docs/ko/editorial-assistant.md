# 글쓰기 도우미

글을 작성하거나 수정하고, 사실을 확인하고, 문체를 검토하거나 번역을 준비할 때 글쓰기 도우미를 사용하세요. 모든 요청은 사용자가 직접 시작합니다. **빠른 작업**에서 항목을 선택하면 *스킬(Skill)* 시작 문구가 Composer에 들어갈 뿐입니다. 작업을 시작하려면 **편집 요청 보내기**를 선택하세요.

텍스트를 선택하면 해당 부분에 집중해 편집할 수 있습니다. 주변의 정의나 문체 단서는 도우미가 짧은 선택 내용을 해석하는 데 도움이 되지만, 함께 공유하면 선택하지 않은 텍스트도 제공자에게 전송됩니다. 선택 영역에 *글(Article)* 텍스트가 필요한 요청에서는 선택 부분과 앞뒤 최대 500자씩을 별도의 읽기 전용 맥락으로 전송합니다. 교체할 수 있는 부분은 선택한 문장뿐입니다. 전송 전에 Composer가 이 내용을 설명합니다. 주변 텍스트가 민감하다면 전송하지 마세요. 일반적인 조언이나 *스킬(Skill)* 관리는 이 텍스트를 필요로 하지 않습니다. Warplyn은 *글(Article)* 전체를 말없이 추가 전송하지 않습니다. 맥락이 부족하면 관련 부분을 직접 제공하거나 다른 부분을 선택해 다시 요청하세요.

::: tip 예시
단편 소설을 수정할 때 한 부분을 선택하고 이렇게 요청할 수 있습니다. “Ana의 시점과 차분한 분위기를 유지하면서 흐름을 다듬어 줘. 새로운 사건은 추가하지 마.” 도우미는 **제안 검토**에 *제안(Proposal)*을 준비합니다. 과거 시제와 현재 시제가 장에서 바뀌는지 검토해 달라고 요청할 수도 있습니다. 문체 검토 결과인 *지적 사항(Findings)*은 **문체 프로필**에 표시됩니다.
:::

*Composer에 입력한 요청 예시. 전송하기 전에 제공자를 연결하세요. 스크린샷에는 이전 스킬 이름이 표시되어 있습니다.*

도우미는 작업 중 짧은 진행 메시지를 표시합니다. 작업이 너무 오래 걸리면 **요청 중지**를 선택해 취소하세요. 취소되거나 실패한 요청은 *글(Article)*을 변경하지 않습니다. 다시 실행하려면 **다시 시도**를 선택하세요. 도우미는 프롬프트, 비공개 입력, 인증 정보, 제공자 오류를 노출하지 않습니다. 작업 결과가 준비되면 결과 카드를 열어 확인할 수 있습니다.

- 생성하거나 수정한 텍스트는 **제안 검토**에서 확인합니다.
- 권고 사항인 *지적 사항(Findings)*은 **팩트 체크**에서 확인합니다.
- 문체 검토 *지적 사항(Findings)*은 **문체 프로필**에서 확인합니다.
- 번역 *제안(Proposal)*은 **번역**에서 확인합니다.

결과를 열어도 *글(Article)*은 변경되지 않습니다. 변경 내용을 수락하기 전에 *제안(Proposal)*을 검토하세요. *지적 사항(Findings)*은 권고 사항이며, 번역 결과는 서로 연결된 별도의 *글(Articles)*로 유지됩니다. 제안, 기록, 복구, 사실 확인은 [글 검토](reviewing-articles.md)를 참조하세요. 번역 결과를 비교하고 사용하는 방법은 [번역](translations.md)을 참조하세요.

기술 용어에 초점을 맞춰 검토하려면 **빠른 작업**에서 **전문 용어 확인**을 선택하세요. 근거가 연결된 *지적 사항(Findings)*은 **팩트 체크**에 표시됩니다. 검토 단계와 한계는 [기술 용어 확인](built-in-skills/check-technical-terms.md)을 참조하세요.

**제안 검토**에서는 **나란히** 또는 **위아래로** 레이아웃에서 **제안** 텍스트를 직접 편집할 수 있습니다. **원본**은 읽기 전용으로 유지됩니다. 편집 중에도 각 변경 사항의 **수락** 또는 **거절** 결정을 유지합니다. 모든 변경 사항에 결정을 내린 다음 **적용**을 선택해 검토를 마칩니다. 수락한 문구는 새 *저장된 버전(Revision)* 하나를 만듭니다. 모든 제안을 거부하면 적용는 *글(Article)*을 변경하거나 *저장된 버전(Revision)*을 만들지 않고 검토를 닫습니다. 모든 변경 사항을 수락하려면 **모든 결정 설정…**에서 **모두 수락으로 표시**를 선택한 다음 적용하세요. **모두 거절로 표시**를 선택하면 *글(Article)*은 그대로 유지됩니다. **모든 결정 초기화**를 선택하면 제안된 텍스트의 편집 내용은 유지하면서 모든 제안을 대기 중으로 되돌립니다. 검토를 지우려면 **제안 닫기**를 선택하세요.

적용하지 않은 편집 내용은 레이아웃이나 Workspace Views를 전환해도 유지됩니다. 페이지를 다시 불러오거나, *글(Articles)*을 전환하거나, *제안(Proposal)*을 닫거나, 새 제안을 생성하면 편집 내용이 지워집니다. 적용에 실패하면 재시도할 수 있도록 편집 내용이 유지됩니다. 제안된 숫자, 링크, 코드, 기술 용어는 그대로 두세요. 오래되었거나 신뢰할 수 없거나 이미 수락된 *제안(Proposals)*은 읽기 전용입니다. 사실 정정 문구를 편집해 적용한 경우에도 관련 *지적 사항(Findings)*은 계속 권고 사항으로 남습니다.

*스킬(Skills)*은 요청을 구체화하는 데 도움을 주지만 권한을 추가하지는 않습니다. 태그가 없는 요청에서는 도우미가 관련 *스킬(Skills)*을 선택합니다. 일반 요청을 기본 편집 절차로 보내지는 않습니다. Warplyn은 백그라운드 작업을 실행하거나 직접 게시하지 않으며, 사용자 승인 없이 *글(Article)*을 변경하지 않습니다.

절차를 다시 사용할 수 있도록 만들려면 도우미에게 재사용 가능한 [스킬](skills.md)을 요청하세요. 목적, 단계 또는 참고 자료가 명확하지 않으면 짧은 추가 질문을 할 수 있습니다. 만들어진 *스킬(Skill)*은 즉시 사용할 수 있고 별도의 로컬 *스킬 버전(Skill Revision)* 기록을 가집니다. 스킬을 만들어도 *글(Article)* 본문을 읽거나 *초안(Draft)*, *제안(Proposal)*, *저장된 버전(Revision)*을 변경하지 않습니다.

글쓰기 도우미에게 **저장된 버전 기록**, 저장된 편집 작업, 게시 지침 또는 Style Corpus 준비 상태를 살펴보도록 요청할 수 있습니다. 명시적으로 요청하면 현재 변경 불가능한 *저장된 버전(Revision)*을 로컬 Style Corpus에 추가하고 문체 프로필을 다시 만들 수 있습니다. 하지만 *제안(Proposals)*을 수락하거나 *저장된 버전(Revisions)*을 복원하거나 *지적 사항(Findings)*을 해결하거나 *초안(Drafts)*을 편집하거나 스타일 샘플을 삭제하거나 게시할 수는 없습니다.

글쓰기 샘플, 재사용 가능한 지침, 타이포그래피 규칙은 [문체 프로필](style-profile.md)을 여세요. 문체 검토 *지적 사항(Findings)*은 여기에 표시되며 *글(Article)*과 별도로 유지됩니다.
