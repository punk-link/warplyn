# 스킬 만들기 및 관리

*스킬(Skills)*은 로컬 Markdown 지침 패키지입니다. Assistant가 편집 기능을 선택하고 순서를 정하도록 돕습니다. 권한을 추가하거나 *글(Article)*을 변경하지 않습니다.

## 나만의 스킬 만들기 및 관리

Assistant에게 재사용 가능한 *스킬(Skill)*을 만들어 달라고 일반적인 문장으로 요청하세요. 반복해서 할 작업과 필요한 규칙 또는 참고 자료를 설명합니다. 빠진 세부 사항에 따라 *스킬(Skill)*이 달라질 수 있으면 Assistant는 추측하지 않고 짧게 추가 질문을 합니다.

::: tip 예시
차분한 강가 장면의 문체로 소설을 수정하려면 이렇게 요청하세요. “’Quiet fiction line edit’이라는 *스킬(Skill)*을 만들어 줘. Ana의 문장과 목소리, 강가라는 배경, 장면의 사건은 유지하면서 더 간결하게 다듬어 줘. 세부 사항을 추가하지 말고 불분명한 부분은 표시해 줘.” 문장 편집을 요청할 때마다 Assistant가 이 지침을 재사용할 수 있습니다.
:::

*Composer에서 스킬 생성을 요청한 예시. 전송하기 전에 제공자를 연결하세요.*

생성이 완료되면 새 Assistant 요청에서 해당 *스킬(Skill)*을 즉시 사용할 수 있습니다. 생성 요청은 *글(Article)* 본문을 모델에 보내지 않으며 *글(Article)*, *초안(Draft)*, *제안(Proposal)*, *저장된 버전(Revision)*을 변경하지 않습니다.

만든 각 *스킬(Skill)*은 변경 불가능한 로컬 *스킬 버전(Skill Revision)* 기록을 가집니다. 이는 *글(Article)*의 저장된 버전 기록과 별개입니다. 로컬 Markdown 패키지를 직접 편집할 수도 있습니다. Warplyn은 다음 요청을 위해 카탈로그를 새로고침합니다. `SKILL.md` 파일을 제거하면 사용 가능한 *스킬(Skills)* 목록에서 해당 스킬이 삭제됩니다.

Assistant에게 이름을 지정해 *스킬(Skill)*을 수정하거나 삭제해 달라고 요청하세요. 변경하기 전에 현재 패키지를 읽고 그사이에 파일이 바뀌었는지 확인합니다. 새 버전을 저장하면 *스킬(Skill)* ID는 유지되고 새 *스킬 버전(Skill Revision)*이 추가됩니다. 삭제하면 새 요청에서 스킬을 사용할 수 없지만 기록은 보존됩니다.

이전 지침을 복원하려면 해당 *스킬(Skill)*의 *저장된 버전(Revisions)*을 요청하고 복원할 버전을 알려주세요. 복원하면 새로운 활성 버전이 기록되고 새 *스킬 버전(Skill Revision)*이 추가됩니다. 이 방법으로 삭제한 *스킬(Skill)*도 복원할 수 있습니다. Assistant 채팅 검사점을 복원해도 *스킬(Skill)*은 복원되거나 변경되지 않습니다. 스킬 복원은 별도 요청입니다.
