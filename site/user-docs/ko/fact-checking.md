# 사실 확인

*글*의 역사적 세부 사항이나 장소에 관한 설명처럼 검증 가능한 주장을 조사하려면 **사실 확인**을 사용하세요. 글쓰기 도우미는 설명, 출처, 불확실성을 포함한 권고용 *지적 사항*을 반환합니다. 사실 확인은 글을 변경하지 않습니다.

사실 확인에는 출처를 제시하는 사실 확인을 지원하는 [AI 연결 및 모델](providers.md)이 필요합니다. 제공자 요금이 부과될 수 있습니다.

## 사실 확인 시작

1. *글*을 엽니다. 특정 부분에 집중하려면 문장을 선택합니다.
2. **빠른 작업**을 열고 **사실 확인**을 선택합니다. 글쓰기 도우미에게 글의 사실을 확인해 달라고 요청할 수도 있습니다.
3. 글쓰기 도우미가 선택한 주장을 검토하고 확인하지 않을 주장은 선택 해제합니다.
4. **편집 요청 보내기**를 선택합니다.
5. **팩트 체크**를 열어 확인 대상인 저장된 *버전*의 결과를 살펴봅니다.

::: tip 예시
The River at Dusk에서 Ana는 보름달 때문에 물이 불어나 길을 덮을 거라고 말합니다. 강과 이야기의 배경에 관련된 출처로 그 주장을 확인하세요. 장면을 바꾸기 전에 출처가 해당 강을 설명하는지 살펴보세요.
:::

사실 확인이 진행되는 동안 계속 글을 쓰거나 다른 곳으로 이동할 수 있습니다. 작업이 완료되지 않았다면 완료된 *지적 사항*만 확인할 수 있습니다. 미완료된 주장은 다시 확인을 요청하세요.

## 판정과 출처 읽기

**팩트 체크**에서 주장을 선택하면 설명, 출처, 확인 날짜, 불확실성을 볼 수 있습니다.

| 판정 | 의미 |
| --- | --- |
| **근거 있음** | 찾은 근거가 주장을 뒷받침합니다. 그래도 출처가 현재 맥락에 맞는지 확인하는 편이 좋습니다. |
| **논란 있음** | 찾은 근거가 주장에 이의를 제기합니다. 무엇을 바꿀지 결정하기 전에 설명과 출처를 읽어보세요. |
| **확인 불가** | 확인 과정에서 이용 가능한 근거만으로 주장을 입증하지 못했습니다. 이것만으로 주장이 거짓이라는 뜻은 아닙니다. |

출처 링크를 열어 관련성, 날짜, 표현을 확인하세요. *지적 사항*은 조언이지 증명이 아닙니다. 확인 날짜는 주장을 확인한 시점이며 모든 출처가 그날 게시되었다는 뜻은 아닙니다.

## 지적 사항 처리 결정

현재 *버전*의 최신 사실 확인에서 해결되지 않은 *지적 사항*은 결정에 맞는 작업을 선택하세요.

| 작업 | 결과 |
| --- | --- |
| **현재 표현 수락** | 주장을 현재 표현 그대로 유지할 의도를 기록합니다. *지적 사항*에 **현재 표현 수락됨**이 표시됩니다. |
| **근거 수락** | 근거를 검토하고 수락했음을 기록합니다. *지적 사항*에 **근거 수락됨**이 표시됩니다. |
| **수정안 제안** | **논란 있음** 또는 **확인 불가** 주장에 대해 글쓰기 도우미에게 정정 *제안*을 준비하도록 요청합니다. 변경 사항을 적용하기 전에 검토하세요. |

두 수락 작업 모두 *지적 사항*을 해결된 것으로 표시하고, 결정 버튼을 제거하며, 라이브러리에서 해당 항목이 주의를 요청하지 않도록 합니다. 어느 작업도 *글*이나 판정을 바꾸지 않습니다. 각 작업은 결정 이유를 다르게 기록하지만 검토 과정에 미치는 효과는 같습니다.

예를 들어 **Disputed · 근거 수락됨**는 확인 결과가 주장에 이의를 제기했지만 제시된 근거를 수락했다는 뜻입니다. 주장이 정정되었거나 이제 뒷받침된다는 **뜻은 아닙니다**. 텍스트를 바꿔야 한다면 *글*을 직접 편집하거나 *지적 사항*을 해결하기 전에 정정을 요청하세요.

여러 주장을 한 번에 정정하려면 해결되지 않은 **논란 있음** 또는 **확인 불가** 주장을 선택하고 **수정안 제안**을 선택합니다. [제안 검토](reviewing-articles.md#review-a-proposal)에서 제안된 문구를 살펴보고 수락할 변경 사항을 적용하세요. 수락한 텍스트를 적용하면 새 *저장된 버전*이 만들어집니다.

## 변경 후 다시 확인

*지적 사항*은 확인 대상인 *버전*에 연결됩니다. 다른 *저장된 버전*이 현재 버전이 되면 이전 *지적 사항*은 계속 읽을 수 있지만 오래된 결과가 됩니다. 조치를 취하기 전에 **팩트 체크 다시 실행**을 선택하세요.

이전 실행 결과를 살펴보려면 **팩트 체크 기록**을 사용하세요. 이전 결과는 읽기 전용이며, 현재 *버전*의 최신 실행 결과에 대해서만 조치를 취할 수 있습니다.

나중의 확인에서는 표현이 바뀐 경우를 포함해 변하지 않은 사실이라고 인식하면 근거와 수락 결정을 재사용할 수 있습니다. 재사용한 결과에는 **버전의 근거를 재사용했습니다**가 표시되고 이전 확인 날짜가 유지됩니다. 사실의 의미가 바뀌었다면 새 조사가 필요할 수 있습니다.

다시 확인해도 변경되지 않은 모든 주장에 대해 새 조사가 이루어지는 것은 아닙니다. 시점에 따라 달라질 수 있는 세부 사항은 출처와 확인 날짜를 살펴보고, 현재 출처를 기준으로 검증해 달라고 글쓰기 도우미에게 명시적으로 요청하세요.
