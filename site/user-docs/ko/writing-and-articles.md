# 글 작성과 정리

*글*은 Warplyn 라이브러리에 보관하는 글입니다. 글을 쓰는 동안 Warplyn이 *초안*을 저장하므로 필요할 때 복구할 수 있습니다. *저장된 버전*에는 저장 당시의 내용이 담기며 글 기록에서 확인할 수 있습니다.

## 글 작성 및 저장

라이브러리에서 **새 글**을 선택해 시작합니다. 제목 입력란에서 *글*의 이름을 바꿉니다. 서식 도구 모음으로 제목, 목록, 강조, 링크, 인용, 코드를 적용합니다. 서식 있는 텍스트를 붙여넣으면 Warplyn은 지원되는 텍스트 서식을 유지하고 안전하지 않거나 지원되지 않는 마크업을 제거합니다. *글*은 Markdown으로 저장되므로 복잡한 페이지 레이아웃과 삽입된 항목은 유지되지 않습니다.

Warplyn은 편집 중인 *초안*을 자동으로 저장합니다. *초안* 검사점은 복구할 수 있는 작업 중 텍스트이며, 버전 기록의 새 항목은 아닙니다. 최근 편집 내용이 검사점으로 저장되었는지 확인하려면 글 상태 표시줄의 저장 상태 표시기를 살펴보세요. *글*을 전환하거나 설정을 열 때도 대기 중인 검사점을 저장합니다.

*작성 화면에서 초안으로 저장된 글의 예시.*

현재 *초안*을 기록의 이름이 지정된 시점으로 보관하려면 **버전 저장**을 선택합니다. *저장된 버전*을 저장해도 이전 *저장된 버전*은 삭제되지 않습니다. 로컬 텍스트와 저장된 *초안*이 더 이상 일치하지 않을 때는 [글 검토](reviewing-articles.md#recover-a-draft)를 참조하세요.

## 글 찾기 및 정리

라이브러리 검색으로 보관된 항목을 포함해 *글*을 찾습니다. **글**을 선택하면 고정한 작업과 최근 작업을 살펴볼 수 있고, **보관**을 선택하면 보관된 *글* 그룹을 볼 수 있습니다. 접힌 탐색 레일에는 **새 글**, **글 검색**, **글**, **보관** 바로가기가 있습니다. 원본 *글*을 탐색 레일에 고정하려면 라이브러리 메뉴에서 고정합니다. 고정된 *글*의 순서는 **위로 이동** 또는 **아래로 이동**으로 바꿉니다. 고정과 순서 변경은 *글* 내용을 바꾸지 않습니다. 제목 입력란에서 *글*의 이름을 바꿉니다.

**글 보관**을 선택하면 *글* 그룹이 활성 목록에서 사라지고 **보관**에는 남습니다. 보관된 그룹을 선택하고 **글 보관 해제**를 선택하면 다시 목록으로 가져옵니다. *글*을 삭제하려면 확인이 필요하며 해당 *저장된 버전*과 복구 가능한 *초안*도 삭제됩니다. 원본을 삭제하면 연결된 *번역*도 삭제되지만, *번역*을 삭제해도 원본 *글*은 유지됩니다. 잠시 치워두려는 경우에는 대신 보관하세요.

## 맞춤법 지원 사용

편집기는 기기의 맞춤법 기능을 사용해 오타일 수 있는 단어를 표시합니다. 데스크톱 앱에서는 표시된 단어를 마우스 오른쪽 버튼으로 클릭해 추천 대체어를 선택하거나 **사전에 추가**를 선택합니다. 대체어 적용은 일반 편집이므로 실행 취소할 수 있고 현재 *초안*에 반영됩니다. 맞춤법 검사는 기기에서 처리되며 *글* 텍스트를 AI 제공자에게 보내지 않습니다.

데스크톱 **설정** → **맞춤법**에서 **언어 필터링**으로 언어를 찾고, **오프라인 글쓰기 준비**에서 해당 언어를 선택한 다음 **사전 다운로드**를 선택합니다. 오프라인에서 사용하기 전에 상태가 **다운로드됨**으로 바뀔 때까지 기다립니다. **사용 가능**은 해당 언어가 지원된다는 뜻이며 사전 다운로드가 완료되었다는 뜻은 아닙니다. 준비한 사전을 이번 세션에서 사용하지 않으려면 **로드 해제**를 선택합니다. 사전을 준비해도 *글* 언어는 바뀌지 않습니다. 다운로드에는 인터넷 연결이 필요합니다. Windows에서는 개인 단어를 추가하거나 제거하면 운영 체제 사전에도 반영되어 다른 앱에 영향을 줄 수 있습니다.

**개인 사전**에서 저장된 단어를 검색하거나 **추가할 단어** 아래에 한 줄에 하나씩 단어 또는 전문 용어를 입력한 다음 **단어 추가**를 선택합니다. 한 번에 최대 500개까지 추가할 수 있습니다. 맞춤법 지원이 다시 표시하도록 저장된 단어를 제거할 수 있습니다. 목록은 모든 *글*과 언어에서 공유됩니다. 브라우저 앱은 브라우저의 맞춤법 설정을 사용하며 사전 관리 기능은 제공하지 않습니다.

**집중 모드**를 사용하면 글을 쓰는 동안 양쪽 보조 패널을 숨길 수 있습니다. 다시 선택하면 패널이 표시됩니다. 각 패널의 접기 컨트롤로 패널을 닫거나 다시 열고, 옆의 구분선을 끌어 크기를 조정합니다. 창이 좁으면 패널이 편집기 위에 임시 서랍 형태로 열릴 수 있습니다.

키보드에서는 **Tab**과 **Shift + Tab**으로 라이브러리, 글 머리글, 보기, 서식 도구 모음, 편집기, 상태 표시줄, 글쓰기 도우미 패널 사이를 이동합니다. 편집기, 검색, 입력창 안에서는 일반 텍스트 편집 키를 계속 사용할 수 있습니다. 설정에는 별도의 키보드 탐색 기능이 있습니다. 데스크톱 사이드바에서 **Up**, **Down**, **Home**, **End**로 섹션을 이동한 다음 **Enter** 또는 **Space**를 눌러 엽니다.

*글* 전체를 Warplyn으로 가져오거나 내보내려면 [글 파일](article-files.md)을 참조하세요. 전체 작업 공간 백업은 [백업 및 복구](backups-and-recovery.md)를 참조하세요.
