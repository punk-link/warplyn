# 스킬 만들기

재사용 가능한 *스킬(Skill)*을 만들거나 수정, 복원, 삭제해 달라고 명시적으로 요청하면 글쓰기 도우미는 기본 제공 스킬 만들기를 사용합니다. 로컬 Markdown 지침을 관리하며 각 *스킬(Skill)*의 기록을 별도로 보관합니다.

반복할 작업과 *스킬(Skill)*이 따라야 할 규칙 또는 참고 자료를 설명하세요. 목적이나 절차가 불분명해 결과가 달라질 수 있으면 글쓰기 도우미가 짧게 추가 질문을 할 수 있습니다. 새로 만든 *스킬(Skill)*은 이후 요청에서 사용할 수 있으며, 생성한다고 현재 *글(Article)*에 실행되지는 않습니다.

::: tip 예시
“’Quiet fiction line edit’이라는 스킬을 만들어 줘. Ana의 문장과 목소리, 강가라는 배경, 장면의 사건은 유지하면서 더 간결하게 다듬어 줘. 세부 사항을 추가하지 말고 불분명한 부분은 표시해 줘.”라고 요청하세요.
:::

글쓰기 도우미에게 이름을 지정해 *스킬(Skill)*을 수정, 복원, 삭제해 달라고 요청할 수 있습니다. 복원하면 새 활성 버전이 만들어지고 이전 *스킬 버전(Skill Revisions)*은 유지됩니다. 전체 절차와 로컬 편집 방법은 [스킬 만들기 및 관리](../skills.md)를 참조하세요.
