# 텍스트 줄이기

기존 문장을 더 짧게 만들려면 **텍스트 줄이기**를 사용하세요. 의미, 근거, 불확실성, 문체를 유지하면서 반복과 군더더기, 장황한 표현을 줄입니다.

**빠른 작업**을 열고 **텍스트 줄이기**를 선택한 다음 **편집 요청 보내기**를 선택합니다. 유지할 내용이나 줄일 부분에 관한 지침을 추가하세요. 해당 텍스트만 줄이려면 문장을 선택합니다. 선택하지 않으면 Assistant가 *글(Article)* 전체를 다룹니다.

::: tip 예시
“강물 사이로 버드나무가 이어지는 문장을 더 간결하게 다듬어 줘. 은빛 이미지와 차분한 분위기는 유지해 줘.”라고 요청하세요.
:::

결과는 원문보다 짧아야 합니다. 안전하게 줄일 수 없다면 Assistant는 원문을 그대로 반환합니다. 적용하기 전에 *제안(Proposal)*을 검토하세요. 이름, 주장, 링크, 코드, 인용, 기술 용어는 정확하게 유지해야 합니다. 분량을 줄이지 않고 명확하게 다듬으려면 [흐름과 명확성 개선](improve-flow-and-clarity.md)을 사용하세요.
