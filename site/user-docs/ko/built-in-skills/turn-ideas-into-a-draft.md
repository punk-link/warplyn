# 아이디어를 초안으로 만들기

참고 자료는 있지만 일관된 첫 번째 초안이 필요하다면 **아이디어를 초안으로 만들기**를 사용하세요. 제공된 아이디어를 간결한 이야기로 발전시키면서 원래 의미를 유지하고 근거 없는 주장을 피합니다.

**빠른 작업**을 열고 **아이디어를 초안으로 만들기**를 선택한 다음 원하는 방향을 설명하고 **편집 요청 보내기**를 선택합니다. 문장을 선택하면 요청에 해당 부분과 메시지에 명시적으로 포함한 자료가 사용됩니다. 선택 영역이 없으면 현재 *글(Article)*과 방향 설명을 함께 사용할 수 있습니다.

::: tip 예시
Ana가 공책을 여는 부분을 선택하고 이렇게 요청하세요. “이 부분에 이미 있는 세부 사항만 사용해 다음 문단의 초안 한 가지를 써 줘. 페이지는 빈 상태로 두고, 강이 왜 Ana를 알아보는 것처럼 보이는지는 설명하지 마.”
:::

Assistant는 검토를 위한 *제안(Proposal)*을 준비합니다. 변경 사항을 수락하기 전에 구조, 주장, 표현을 확인하세요. Assistant가 *글(Article)*을 직접 저장하거나 변경하지 않습니다. 기존 문장을 다시 쓰려면 [흐름과 명확성 개선](improve-flow-and-clarity.md)을 참조하세요.
