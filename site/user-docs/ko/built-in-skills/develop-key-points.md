# 핵심 내용 발전시키기

메모나 *글(Article)*의 주요 생각을 간결한 목록으로 정리하려면 **핵심 내용 발전시키기**를 사용하세요. 기본적으로 서로 다른 세 가지에서 다섯 가지 요점을 준비하며 *글(Article)*을 다시 쓰지 않습니다.

**빠른 작업**을 열고 **핵심 내용 발전시키기**를 선택한 뒤 Composer에 지침을 추가하고 **편집 요청 보내기**를 선택합니다. 문장을 선택하면 해당 선택 영역과 메시지의 내용이 결과를 이끕니다. 선택 영역이 없으면 Assistant는 먼저 메시지를 따르며, 메시지가 비어 있을 때 *글(Article)*을 사용합니다.

::: tip 예시
Ana가 강가에 앉아 있는 장면을 선택하고 이렇게 요청하세요. “이 부분을 바탕으로 Ana와 강의 관계를 해석할 수 있는 세 가지 관점을 제시해 줘.”
:::

반환된 요점은 수정하거나 강조점을 바꿔야 할 수 있습니다. *글(Article)*에 사용하기 전에 검토하세요. 제공된 자료를 바탕으로 전체 초안을 작성하려면 [아이디어를 초안으로 만들기](turn-ideas-into-a-draft.md)를 참조하세요.
