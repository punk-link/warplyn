# 흐름과 명료성 개선

글을 따라가기 어렵고 구조를 명확하게 하거나 전환을 자연스럽게 만들고 싶다면 **흐름과 명료성 개선**을 사용하세요. *글(Article)*의 의미, 주장, 불확실성, 문체를 유지하면서 가독성을 높이는 것이 목표입니다.

**빠른 작업**을 열고 **흐름과 명료성 개선**을 선택한 다음 **편집 요청 보내기**를 선택합니다. 발견이 등장인물의 다음 선택을 어떻게 바꾸는지 명확히 하는 것처럼 특정 부분에 초점을 맞춰 요청할 수 있습니다. 교체 범위를 해당 문장으로 제한하려면 일부를 선택하세요. 선택하지 않으면 글쓰기 도우미가 *글(Article)* 전체를 다룹니다.

::: tip 예시
“물살을 바라보다 공책을 펼치는 흐름이 더 분명해지도록 작은 수정을 제안해 줘. 장면의 차분한 분위기는 유지하고 사건은 바꾸지 마.”라고 요청하세요.
:::

적용하기 전에 *제안(Proposal)*의 의미, 기술 세부 정보, 작성자의 문체를 검토하세요. 분량을 줄이려면 [텍스트 줄이기](shorten-text.md)를 사용하세요.
