# 텍스트 번역

선택한 언어로 전체 *글(Article)*의 번역을 준비하려면 **텍스트 번역**을 사용하세요. 주장, 숫자, 문체, Markdown 서식을 유지하면서 제목과 본문을 번역합니다. 문장을 선택했더라도 이 *스킬(Skill)*은 *글(Article)* 전체를 사용합니다.

*글(Article)*의 **번역** 보기에서 **새 번역…**을 선택합니다. 대상 언어를 선택하고 요청을 확인합니다. 원본에 저장하지 않은 편집 내용이 있으면 번역하려는 텍스트와 결과가 연결되도록 먼저 *저장된 버전(Revision)*으로 저장하세요.

::: tip 예시
대화, 시점, 차분한 분위기, 이름, 보호 대상 텍스트를 유지하면서 Ana의 강가 장면을 번역하도록 요청하세요. **편집**으로 연결된 번역 *글(Article)*을 열거나 **업데이트**로 기존 글에 결과를 새 *저장된 버전(Revision)*으로 추가할 수 있습니다.
:::

번역은 원본과 별도로 유지됩니다. 결과 비교, 연결된 *글(Article)* 업데이트, 오래된 결과 처리는 [번역](../translations.md)을 참조하세요.
