# 전문 용어 확인

IT *글(Article)*의 용어를 검토하려면 **전문 용어 확인**을 사용하세요. 개념 혼동, 오해를 부르는 약어 풀이, 잘못된 제품 또는 API 이름, 같은 개념에 일관되지 않게 사용한 이름을 찾습니다. 해당 분야와 버전에 관련된 출처를 기준으로 용례를 비교하면서도 분야별 정의와 변화하는 용어를 고려합니다.

*글(Article)*을 엽니다. 특정 부분에 집중하려면 문장을 선택합니다. 글쓰기 도우미에서 **빠른 작업**을 열고 **전문 용어 확인**을 선택한 다음 **편집 요청 보내기**를 선택합니다. 완료된 결과를 **팩트 체크**에서 열어 각 *지적 사항(Finding)*, 설명, 연결된 출처, 불확실성을 살펴봅니다.

::: tip 예시
나무 식별 앱에 관한 *글(Article)*에서 작성자가 버드나무를 침엽수라고 부릅니다. 식물학 출처를 기준으로 해당 용어를 확인해 달라고 **전문 용어 확인**에 요청하세요.
:::

이 확인에는 출처를 제시하는 사실 확인을 지원하는 AI 연결과 모델이 필요합니다. *글(Article)* 또는 선택한 부분은 설정된 AI 서비스로 전송되며 조사 쿼리에 해당 기술 용어와 주장 맥락이 포함될 수 있습니다. 제공자 요금이 부과될 수 있습니다. 출처가 불완전하거나 분야마다 용어를 다르게 사용할 수 있습니다. *지적 사항(Finding)*은 조언이며 문장, 코드, 식별자를 다시 쓰지 않습니다. 백그라운드 용어 검사는 제공되지 않습니다.
