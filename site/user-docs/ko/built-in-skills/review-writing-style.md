# 글의 문체 검토

저장된 *문체 프로필*과 *글*을 비교하려면 **글의 문체 검토**를 사용하세요. 글쓰기 도우미는 프로필의 문체 특성 및 규칙과 구체적으로 다른 부분을 찾습니다. 신뢰도가 낮은 프로필은 잠정적인 것으로 취급됩니다.

요청을 보내기 전에 [문체 프로필](../style-profile.md)에 글쓰기 샘플이나 직접 입력한 지침을 추가하고 프로필을 다시 만드세요. 그런 다음 **빠른 작업**을 열고 **글의 문체 검토**를 선택한 뒤 **편집 요청 보내기**를 선택합니다. 검토할 부분에 집중하려면 문장을 선택하세요. 선택하지 않으면 *글* 전체를 사용합니다.

::: tip 예시
“강가에 있는 Ana에 관한 이 부분을 내 글쓰기 샘플의 가까운 시점과 비교해 줘. 차이점 한 가지를 짚고 어떤 프로필 특성과 관련이 있는지 설명해 줘.”라고 요청하세요.
:::

::: tip 제안된 변경 사항 검토
*제안*과 이를 뒷받침하는 *지적 사항*을 읽어보세요. 각 *지적 사항*은 프로필 특성이나 규칙을 짚어야 합니다. 변경 사항을 수락하기 전에 각 제안이 *글*에 적합한지 결정하세요.
:::

문체 검토에는 사용 가능한 *문체 프로필*과 AI 연결이 필요합니다. 글쓰기 샘플은 기기에 남습니다. 글쓰기 도우미는 Warplyn이 기기에서 샘플의 특징을 간추려 만든 프로필을 사용합니다. 요청에서 *글* 또는 선택한 부분이 설정된 AI 제공자에게 전송될 수 있습니다.
