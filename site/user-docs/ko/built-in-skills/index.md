# 기본 제공 스킬

기본 제공 *스킬(Skills)*은 글쓰기 도우미가 일반적인 글쓰기 작업을 수행하도록 돕습니다. **빠른 작업**에서 편집 *스킬(Skill)*을 선택하거나 요청을 설명해 관련 *스킬(Skill)*을 글쓰기 도우미가 추론하도록 하세요. 선택한 스킬 칩만 단독으로 전송할 수 있습니다. 요청에 추가 맥락이나 제약이 있을 때만 메시지를 덧붙이세요. 시작하려면 **편집 요청 보내기**를 선택합니다. 재사용 가능한 *스킬(Skill)*을 만들거나 관리하려면 글쓰기 도우미에게 직접 요청하세요. **스킬 만들기**는 Composer의 빠른 작업 항목이 아닙니다.

각 페이지에서는 스킬의 목적과 결과에서 검토할 내용을 설명합니다. 글쓰기 도우미가 준비한 작업은 검토할 수 있습니다. 결과를 다루는 방법은 [글쓰기 도우미](../editorial-assistant.md)와 [글 검토](../reviewing-articles.md)를 참조하세요.
