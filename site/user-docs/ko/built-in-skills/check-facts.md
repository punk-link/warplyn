# 사실 확인

*글*의 사실 주장을 확인하려면 **사실 확인**을 사용하세요. 출처를 바탕으로 주장을 조사하고 권고용 *지적 사항*을 준비하며, *글*을 다시 쓰지는 않습니다.

**빠른 작업**을 열고 **사실 확인**을 선택한 다음 글쓰기 도우미가 고른 주장을 살펴보고 확인하지 않을 주장은 선택 해제합니다. 그런 다음 **편집 요청 보내기**를 선택합니다. 특정 부분에 집중하려면 문장을 선택할 수 있습니다. 결과는 확인 대상인 저장된 *버전*에 연결됩니다.

::: tip 예시
강가를 배경으로 한 장에서 Ana는 보름달 때문에 물이 불어나 길을 덮을 거라고 말합니다. 이야기의 배경과 관련된 출처를 기준으로 그 세부 사항을 확인해 달라고 **사실 확인**에 요청하세요.
:::

::: tip 근거 검토
**팩트 체크**를 열고 각 *지적 사항*과 출처, 날짜, 불확실성을 읽어보세요. 출처가 불완전하거나 오래되었을 수 있으므로 근거를 활용해 무엇을 확인하거나 수정할지 결정하세요.
:::

판정, 수락 결정, 정정, 재사용된 근거는 [사실 확인 안내](../fact-checking.md)를 참조하세요. 사실 확인에는 출처를 제시하는 확인을 지원하는 AI 연결과 모델이 필요합니다. 제공자 요금이 부과될 수 있습니다. *지적 사항*은 조언이지 주장이 틀렸다는 증거가 아닙니다. 기술 용어를 중점적으로 확인하려면 [기술 용어 확인](check-technical-terms.md)을 참조하세요.
