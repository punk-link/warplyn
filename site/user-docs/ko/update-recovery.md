# 데스크톱 업데이트 복구

프리뷰 업데이트는 선택 사항입니다. 업데이트 후 Warplyn을 시작할 수 없다면 이전 프리뷰를 다시 설치하고 이에 맞는 업데이트 전 스냅샷을 복원하세요.

::: warning 새 데이터베이스를 열지 마세요
새 프리뷰에서 만든 데이터베이스를 이전 버전으로 열지 마세요. 먼저 업데이트 전에 기록된 스냅샷을 복원하세요.
:::

1. [GitHub 릴리스](https://github.com/punk-link/warplyn/releases)에서 이전 프리뷰를 다운로드해 다시 설치합니다.
2. 업데이트 전에 Warplyn이 기록한 해당 업데이트 전 SQLite 스냅샷을 복원합니다.
3. 이전 프리뷰를 시작하고 *글(Articles)*, *초안(Drafts)*, *저장된 버전(Revisions)*, 설정을 확인합니다.

## Linux AppImage

쓰기 권한이 있는 폴더에 AppImage를 보관하세요. 런타임 요구 사항, 실행 방법, 선택적 데스크톱 통합은 [Warplyn 설치](installation.md#linux-appimage)를 참조하세요. AppImage 설치 환경의 데스크톱 승인 테스트는 아직 완료되지 않았습니다.

GitHub 업데이트 접근을 허용한 다음 **다운로드**를 선택하고 **다시 시작 및 업데이트**를 선택합니다. 일반 종료로는 다운로드한 업데이트가 설치되지 않습니다. Debian 패키지는 계속 패키지 관리자를 사용합니다.

AppImage 업데이트 후 실행되지 않으면 Warplyn을 종료하세요. 이전 실행 파일은 이미지 옆에 `.previous` 접미사가 붙은 파일로 보관됩니다. 위 경고를 확인하고 이전 버전을 실행하기 전에 해당 업데이트 전 스냅샷을 복원하세요. 복구가 완료될 때까지 두 실행 파일과 스냅샷을 모두 보관하세요. 이미지 폴더에 쓰기 권한이 없다면 소유한 폴더로 이미지를 옮기거나 대체 파일을 직접 다운로드하세요. 이미지를 실행하기 위해 Electron 샌드박스를 비활성화하지 마세요.
