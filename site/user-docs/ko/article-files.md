# 글 파일

**파일로 저장**과 **파일에서 불러오기**를 사용해 Warplyn과 다른 글쓰기 도구 사이에서 전체 *글(Articles)*을 이동할 수 있습니다. 데스크톱 앱과 웹 앱에서 모두 사용할 수 있습니다.

## 파일로 저장

1. 저장할 *글(Article)*을 엽니다.
2. 글 머리글에서 **버전 저장** 옆의 **파일로 저장**을 선택합니다. 또는 라이브러리에서 *글(Article)*을 마우스 오른쪽 버튼으로 클릭하고 **파일로 저장…**을 선택해 열지 않고 저장할 수도 있습니다.
3. 데스크톱 앱의 저장 창에서 파일 형식 드롭다운으로 Markdown, HTML, DOCX, RTF 중 하나를 선택한 다음 파일 이름과 위치를 지정합니다. 파일 형식에 맞는 확장자를 유지하세요. 웹 앱에서는 **파일 형식**을 선택한 다음 **다운로드**를 선택하고 브라우저의 다운로드 기능을 사용합니다.

파일에는 저장되지 않은 편집 내용까지 포함한 현재 *초안(Draft)* 전체가 들어갑니다. 텍스트를 일부 선택해도 저장 범위가 제한되지는 않습니다. 이 작업은 *저장된 버전(Revision)*을 만들지 않습니다. 현재 *초안(Draft)*을 기록에 추가하려면 계속 **버전 저장**을 사용하세요.

::: tip 작업 공간 전체를 보관 가능한 사본으로 남기려면?
*글(Article)* 파일에는 글 내용만 들어갑니다. 기록, Assistant 작업, *스킬(Skills)*, 설정도 보존하려면 [백업](backups-and-recovery.md)을 만드세요.
:::

웹 앱은 파일을 브라우저에 전달하면 **글 다운로드를 시작했습니다**를 표시합니다. 완료 여부나 오류는 브라우저 다운로드 항목에서 확인하세요.

## 파일에서 불러오기

1. 글 머리글에서 **버전 저장** 옆의 **파일에서 불러오기**를 선택하거나, 라이브러리에서 *글(Article)*을 마우스 오른쪽 버튼으로 클릭하고 **파일에서 불러오기…**를 선택합니다. 라이브러리가 비어 있으면 먼저 **만들기**를 선택합니다.
2. `.md`, `.html`, `.htm`, `.docx`, `.rtf` 파일 하나를 선택합니다.
3. HTML, DOCX, RTF 파일은 **가져올 글 검토**를 선택하고 **가져오기**를 누릅니다. 검토는 취소할 수 있습니다. Markdown은 바로 열립니다.
4. Warplyn은 불러온 텍스트를 별도의 *글(Article)*로 엽니다. 이전 *글(Article)*과 복구 가능한 *초안(Draft)*은 라이브러리에 그대로 남습니다.

문서 맨 앞에 1단계 제목이 있으면 새 제목으로 사용합니다. 제목이 없으면 확장자를 뺀 파일 이름을 사용합니다. 제목은 *글(Article)* 본문에도 남습니다. 같은 파일을 다시 불러오면 서로 독립된 *글(Article)*이 하나 더 생성됩니다.

::: warning 파일을 불러오면 별도의 글이 생성됩니다
파일을 불러와도 파일 선택기를 연 *글(Article)*을 대체하지 않습니다. 불러온 *글(Article)*을 검토한 뒤 필요에 따라 둘 중 하나를 이동하거나 삭제하세요.
:::

10 MiB 이하의 파일을 선택하세요. Markdown과 HTML은 UTF-8이어야 합니다. DOCX와 RTF는 Microsoft Office가 설치되어 있지 않아도 사용할 수 있습니다.

Warplyn은 원본 형식에서 지원하는 문단, 제목, 편집 가능한 중첩 목록과 번호 매기기, 굵게, 기울임, 취소선, 안전한 링크, 인용, 코드, 유니코드 텍스트를 유지합니다. 페이지 레이아웃, 글꼴, 이미지, 삽입 개체, 형식별 복잡한 기능은 생략되거나 단순화될 수 있습니다. 표의 텍스트는 일반 *글(Article)* 콘텐츠가 됩니다. 계속하기 전에 가져오기 미리보기를 확인하세요. 지원되지 않는 Markdown 확장 기능은 편집기에서 서식을 잃을 수도 있습니다.

파일 선택기를 취소하면 아무것도 불러오지 않습니다. 현재 *초안(Draft)*을 복구용으로 저장할 수 없다면 저장 오류를 해결한 뒤 다시 불러오세요.

## 저장된 버전을 파일로 저장

1. **버전**을 엽니다.
2. 내보낼 저장된 *버전(Revision)*을 엽니다.
3. 세부 정보 옆의 **파일로 저장**을 선택합니다.

파일에는 현재 *초안(Draft)*과 관계없이 해당 *저장된 버전(Revision)*의 *글(Article)* 전체가 들어갑니다. 내보내기는 *저장된 버전(Revision)*을 복원하거나 기록을 변경하지 않습니다. 제안된 파일 이름에는 *저장된 버전(Revision)* 번호가 포함됩니다.

파일 내보내기에도 10 MiB 제한이 적용됩니다. 데스크톱 저장에 실패하면 쓰기 가능한 위치를 선택해 다시 시도하세요. 교체 작업이 실패하면 기존 대상 파일은 그대로 유지됩니다.

내보낸 파일에는 *글(Article)* 텍스트만 들어가며 전체 기록, 대화, 설정은 포함되지 않습니다. 전체 작업 공간을 보호하려면 [백업 및 복구](backups-and-recovery.md)를 사용하세요.
