# 문체 프로필

**문체 프로필**에 내 글의 샘플을 추가하고, 글쓰기 도우미가 편집할 때 지킬 규칙을 적어 둘 수 있습니다. 샘플은 이 기기에 보관되며 *글*이나 *저장된 버전*의 일부가 되지 않습니다.

아티클 라이브러리 패널의 도구 영역에서 **문체 프로필**을 엽니다. 측면 메뉴 또는 좁은 창의 섹션 선택기로 **글 샘플**, **수동 규칙**, **타이포그래피 규칙**을 선택합니다. **뒤로**를 선택하면 원래 열려 있던 *글*과 보기로 돌아갑니다.

::: tip 시작 방법 선택
감지된 문체 특성을 확인하려면 글쓰기 샘플을 추가하고, 제공할 지침을 이미 알고 있다면 **수동 규칙**을 추가하세요. 두 기능은 각각 따로 사용할 수 있습니다.
:::

## 글쓰기 샘플 추가

글쓰기 도우미가 기존 글을 참고하게 하려면 **글 샘플**을 엽니다. **글 샘플 추가**를 선택해 텍스트를 붙여넣거나 `.txt` 또는 `.md` 파일을 업로드합니다. 저장된 *글* 버전을 샘플로 사용하려면 **이 글 추가**를 선택할 수도 있습니다. 나중에 알아보기 쉬운 이름을 지정하세요.

샘플의 체크박스를 선택해 프로필에 포함하거나 제외합니다. 샘플을 제외해도 목록에서는 삭제되지 않습니다. 더 이상 필요하지 않은 샘플은 제거하세요. 문체 프로필에서 샘플이 삭제되므로 제거 전에 확인을 요청합니다.

## 지침 추가 및 다시 만들기

글쓰기 도우미가 따를 선호 사항을 설명하려면 **수동 규칙**을 사용하세요. 예를 들어 1인칭 서술을 유지하거나 약어가 처음 나올 때 풀어 설명하라고 요청할 수 있습니다. 샘플 없이도 지침을 추가할 수 있습니다.

샘플이나 지침을 변경한 뒤 **프로필 다시 만들기**를 선택해 감지된 특성을 갱신합니다. 프로필에는 사용된 샘플과 다시 만든 시점이 표시됩니다. 프로필을 다시 만들기 전에는 이전에 선택한 샘플을 바탕으로 파악한 특성이 계속 표시될 수 있습니다. 문체 검토 *지적 사항*은 조언이며 *글* 텍스트와 별도로 유지됩니다.

## 타이포그래피 규칙

**타이포그래피 규칙**을 연 다음 **타이포그래피 언어**를 선택합니다. 표기 관례는 인터페이스 언어와 별개로 각 작성 언어에 저장됩니다. **규칙 적용 대상**에서 **이 언어로 작성된 모든 글** 또는 **이 글만**을 선택합니다. *번역*은 자체 언어와 선호 사항을 사용합니다.

상태 표시줄의 **원문 언어** 메뉴에는 사전 설정 카탈로그의 지역 언어가 포함되어 있습니다. 다른 언어를 사용하려면 **다른 언어…**를 선택하고 일본어의 `ja`와 같은 언어 코드를 입력합니다. 그러면 기본 제공 사전 설정이 없는 언어에도 사용자 지정 타이포그래피 규칙을 저장할 수 있습니다.

**규칙 추가**를 사용해 따옴표, 산문용 대시, 줄임표, 문장 부호 간격, 연속 공백, `10 kg`와 같은 줄 바꿈 방지 토큰 쌍을 선택합니다. **사용자 지정 쌍**에서는 여는 따옴표와 닫는 따옴표 및 그 안의 간격을 설정할 수 있습니다. **문장 부호 직접 치환**은 문장 부호나 간격 관례를 정확히 적용합니다. 판단이 필요한 규칙에는 **맥락별 타이포그래피 지침**을 사용합니다.

::: info 언어와 적용 범위
작성 언어와 규칙 적용 범위를 선택하세요. 해당 언어의 모든 *글*에 적용하거나 현재 *글*에만 적용할 수 있습니다. *번역*은 자체 언어와 타이포그래피 선호 사항을 가집니다.
:::

**표기 규칙 프리셋**에는 지역별 관례 미리보기가 표시됩니다. **원어민 검토 대기 중**으로 표시된 미리보기는 아직 적용할 수 없지만 직접 규칙을 설정할 수 있습니다. 지역 관례는 다른 지역에 자동으로 적용되지 않습니다. 이전 규칙이 전체 언어에 적용되었다면 **이전 규칙 복사**를 선택해 원본을 삭제하지 않고 복사본을 지정할 수 있습니다.

*글* 규칙은 저장된 언어별 관례를 상속합니다. 상속된 규칙을 편집하면 해당 규칙을 덮어쓰고, 제거하면 그 범위에서 비활성화합니다. **상속된 규칙 복원**을 선택하면 덮어쓰기를 지웁니다. 문체 프로필이 열린 동안 언어를 전환해도 저장하지 않은 규칙 편집 내용은 유지됩니다.

규칙은 **저장됨** 또는 **저장되지 않음**으로 표시되는 간결한 요약으로 나타납니다. **편집**을 선택하면 규칙을 열 수 있으며 한 번에 하나씩만 편집합니다. **저장**은 선택한 범위의 규칙을 저장합니다. 언어별 설정을 저장하면 Warplyn이 기기에서 *문체 프로필*을 다시 만듭니다. 이때 현재 선택된 샘플과 저장된 지침을 사용합니다. *글*별 덮어쓰기는 해당 *글*에 저장됩니다. 다른 입력란의 저장하지 않은 텍스트는 저장되지 않습니다. 샘플 없이 명시적 타이포그래피 규칙을 사용할 수 있지만, 문체 특성을 도출하려면 샘플이 필요합니다.

현재 *초안*을 저장한 뒤 AI 연결 없이 선택한 *글*을 확인하려면 **타이포그래피 검사**를 선택합니다. 확인에는 저장된 *버전*과 상태 표시줄에 나타난 해당 언어를 사용합니다. 확인할 때는 **타이포그래피 언어**에서 같은 언어를 선택하세요. 코드, URL, 기술 식별자, 판단이 모호한 따옴표 사례는 변경되지 않습니다. 맥락에 따른 규칙을 확인하려면 글쓰기 도우미를 통해 **글의 문체 검토**를 전체 실행해야 합니다. 적용할 기계적 규칙이 없는 언어는 로컬 타이포그래피 적용 범위가 없습니다. 확인 전에 직접 규칙을 추가하고 저장하세요.

수정 사항과 적용된 규칙을 살펴보려면 **제안 검토**를 엽니다. 수락할 수정 사항을 표시한 다음 **적용**을 선택합니다. 수락한 수정 사항은 *저장된 버전*을 만들며 모든 수정 사항을 거부하면 *글*은 변경되지 않습니다. 규칙을 저장하거나 확인을 실행해도 수정 사항은 적용되지 않습니다. 검토 결과에는 사용된 언어와 규칙 정의가 유지됩니다. 언어나 적용 설정을 변경한 뒤에는 다시 실행하라는 알림이 표시됩니다. 타이포그래피 기능은 혼합 언어 문장에서 언어 경계를 감지하지 않습니다. 모호한 사례는 변경되지 않습니다.
