# 진단 및 사용 데이터 공유

공유를 활성화하면 패키지로 설치한 Warplyn Windows 및 Linux 앱은 미국 버지니아의 PostHog Cloud에 가명 처리된 안정성 및 사용 이벤트를 보냅니다. 기본적으로 공유는 꺼져 있습니다. 사용 경험을 파악하고 Warplyn을 개선할 수 있도록 공유를 활성화해 주세요. **설정** → **일반** → **개인정보 및 진단**에서 언제든지 선택을 변경할 수 있습니다.

공유를 끄면 이후 수집이 중단되고 대기 중인 이벤트와 로컬 원격 측정 ID이 삭제됩니다. 나중에 공유를 다시 켜면 새 ID가 만들어집니다. 이미 전송된 이벤트는 회수할 수 없습니다.

연결이 복구되면 Warplyn이 다시 전송할 수 있도록 대기 이벤트는 앱의 로컬 프로필에 보관됩니다. 앱이 다음에 대기열을 확인할 때 24시간이 지난 이벤트는 삭제됩니다. 공유를 끄면 대기열도 삭제됩니다.

## Warplyn이 수집하는 정보

이벤트에는 다음 내용이 포함됩니다.

- 연결 이름이나 제공자 세부 정보가 없는 연결 확인 성공 또는 실패
- 앱 시작 및 안전한 시작, 렌더러, 자식 프로세스 실패 범주
- 완료, 실패, 취소된 AI 작업과 단계. 가능한 경우 실패 범주와 HTTP 상태 포함
- 명시적인 *제안(Proposal)* 검토 및 집계된 *초안(Draft)* 검사점
- 백업 및 복구 결과

이벤트에는 *글(Article)* 텍스트, 프롬프트, AI 응답, API 키가 포함되지 않습니다.

::: details 기타 이벤트 필드
각 이벤트에는 데스크톱 분석 출처, 스키마 버전, 애플리케이션 버전, 플랫폼, 아키텍처, 운영 체제 버전, 타임스탬프가 포함됩니다. 개별 이벤트 필드는 알려진 범주, 0 이상의 카운터 또는 제한된 시간 값으로 한정됩니다.

AI 작업 및 단계 이벤트에는 같은 작업의 이벤트를 연결하는 임의 ID가 포함될 수 있습니다. 이 ID는 글 및 요청 ID와 별개입니다.

이벤트에는 *글(Article)* 또는 *저장된 버전(Revision)*의 ID나 제목, 환경 변수 값, 파일 경로, URL, 원시 오류, 프로세스 종료 세부 정보, 요청 및 응답 본문이 포함되지 않습니다.
:::

## 삭제 요청

열람, 정정 또는 기타 개인정보 요청은 [데이터 요청](data-request.md)을 참조하세요.

1. **설정** → **일반** → **개인정보 및 진단**에서 **ID 복사**를 선택합니다.
2. ID를 [kirill.taran@punk.link](mailto:kirill.taran@punk.link)으로 보내고 삭제를 요청합니다.
3. **진단 및 사용 데이터 공유**를 끕니다.

공유를 끄기 전에 ID를 복사하세요. 공유를 끄면 ID가 기기에서 삭제됩니다. 프로젝트 관리자는 해당하는 가명 기록을 삭제하고 이메일로 확인해 줍니다.

## 웹사이트 분석 {#website-analytics}

랜딩 페이지와 요금제 페이지는 PostHog를 사용해 방문, 유입 경로 및 캠페인 정보, 다운로드 링크 클릭을 측정합니다. PostHog 다운로드 이벤트에는 페이지에서 버튼이 표시된 위치가 포함됩니다. 누군가 랜딩 페이지, 요금제 페이지 또는 사용자 가이드에서 최신 릴리스 링크를 열면 Google Analytics에도 `download_clicked` 이벤트가 기록됩니다. 링크 클릭은 다운로드나 설치를 확인하는 정보가 아닙니다.

웹사이트의 PostHog 추적은 쿠키나 브라우저 저장소를 사용하지 않고, 사용자 프로필을 만들지 않으며, 세션 재생이나 일반적인 클릭 활동을 기록하지 않습니다. PostHog는 서버에서 생성한 해시를 사용해 방문자 수를 추정합니다. 웹사이트 이벤트는 데스크톱 원격 측정 ID과 별개이며 데스크톱 공유 스위치로 웹사이트 추적을 제어할 수 없습니다.

랜딩 페이지와 사용자 가이드는 방문 및 트래픽 출처를 측정하기 위해 쿠키를 사용할 수 있는 Google Analytics도 사용합니다. 브라우저에서 Do Not Track 또는 Global Privacy Control을 보내면 Google Analytics와 PostHog 추적이 모두 생략됩니다. 위에서 설명한 쿠키를 사용하지 않는 동작은 PostHog에 적용됩니다.
