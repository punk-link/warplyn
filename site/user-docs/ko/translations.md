# 번역

*번역*은 별도로 연결된 *글*입니다. 자체 제목, *초안*, *저장된 버전* 기록이 있으므로 한 언어에서의 작업이 원본을 덮어쓰지 않습니다.

## 번역 요청

원본 *글*을 열고 **번역**에서 **새 번역…**을 선택합니다. 대화상자에 현재 *글* 언어가 미리 선택될 수 있습니다. 사용할 조회 언어가 없으면 **설정** → **기본 언어**에서 선호 언어를 제안합니다. 대상 언어를 하나씩 선택하고 확인합니다. 편집기에서 특정 부분을 선택했더라도 번역에는 *글* 전체가 사용됩니다. 원본에 저장하지 않은 편집 내용이 있으면 먼저 *저장된 버전*으로 저장하세요. 그래야 *번역*에서 사용한 정확한 텍스트를 확인할 수 있습니다.

글쓰기 도우미는 각 언어에 대해 검토할 수 있는 *번역* 결과를 만듭니다. 결과를 열어 제목과 텍스트를 원본과 비교하세요. 전체 문장을 비교하려면 **나란히**를 선택하고 대응하는 문단을 함께 보려면 **문단 맞춤**을 선택합니다. 이름, 숫자, URL, 코드 같은 보호 대상 텍스트는 그대로 유지되어야 합니다. 보호 대상 텍스트가 바뀌었거나 이전 원본 *저장된 버전*을 사용한 결과에는 Warplyn이 표시를 남깁니다. 계속하기 전에 해당 알림을 검토하세요.

::: warning 먼저 원본을 저장하세요
*번역* 요청은 저장된 *버전*을 사용합니다. 저장하지 않은 편집 내용이 있다면 의도한 텍스트에 결과가 연결되도록 요청 전에 *저장된 버전*으로 저장하세요.
:::

## 번역 글 만들기 또는 업데이트

결과가 준비되면 **편집**을 사용해 연결된 *번역 글*을 엽니다. 아직 없다면 Warplyn이 만듭니다. *번역*을 검토한 뒤 준비가 되면 *초안*을 저장하거나 **버전 저장**을 선택합니다. 원본 *글*은 변경되지 않습니다.

기존 *번역*에 새 결과를 사용하려면 **업데이트**를 선택하고 대상 *글*을 확인합니다. Warplyn은 번역 텍스트를 새 *저장된 버전*으로 추가하며 *번역*의 제목과 이전 기록을 유지합니다. 검토 이후 원본이나 대상이 변경되었거나, 대상에 저장되지 않은 *초안*이 있거나, 결과가 더 이상 검증을 통과하지 못하면 업데이트가 차단됩니다.

생성된 결과의 승인을 거부하려면 **거절**을 선택합니다. 원본이나 이미 만든 *번역 글*은 삭제되지 않습니다. 이전 결과도 계속 확인할 수 있습니다. **새 번역…**에서 새 결과를 만들 수 있습니다.

::: tip 업데이트해도 번역 기록은 유지됩니다
**업데이트**를 선택하면 Warplyn은 연결된 *번역 글*에 결과를 새 *저장된 버전*으로 추가합니다. 제목과 이전 *저장된 버전*은 계속 사용할 수 있습니다.
:::

언어마다 자체 결과가 유지됩니다. 언어 탭과 결과 선택기로 *번역*을 다시 살펴보거나 새 시도를 이전 결과와 비교하세요. 결과에는 만든 시점과 사용한 원본 *저장된 버전*이 표시됩니다. 원본이 변경되면 결과는 오래된 상태가 되어 새 연결 *글*을 만들 수 없습니다. 새 *번역*을 요청하고 현재 원본 *저장된 버전*과 비교해 검토하세요.
