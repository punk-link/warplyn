# AI 제공자 비용

AI 지원은 선택 사항입니다. Warplyn은 요청 비용을 청구하지 않습니다. Warplyn이 요청을 보내면 AI 제공자가 계정에 요금을 청구할 수 있습니다.

## 비용에 영향을 주는 요소

제공자가 자체 요율을 정합니다. 요청 비용은 다음 요소에 따라 달라질 수 있습니다.

- 선택한 제공자와 모델
- 요청에 포함되는 *글(Article)* 텍스트와 지침 맥락의 양
- 모델이 반환하는 텍스트의 양

주변 텍스트를 보내면 짧게 선택한 부분을 더 잘 해석할 수 있지만, 선택하지 않은 글도 일부 전송됩니다. *글(Article)* 텍스트가 필요한 선택 요청은 선택 부분과 앞뒤 최대 500자씩을 읽기 전용 맥락으로 전송합니다. 추가로 전송되는 텍스트는 최대 1,000자입니다. 편집 대상으로 지정되는 부분은 선택 영역뿐입니다. 선택 영역이 없으면 요청에 *글(Article)* 전체와 관련 맥락이 포함될 수 있습니다. 요청 범위를 좁히면 제공자 요율에 따라 비용이 줄어들 수 있습니다.

::: tip API 요금 청구
제공자의 채팅 서비스 구독에 API 사용이 포함되지 않을 수 있습니다. 키를 연결하기 전에 제공자의 최신 API 요금과 청구 약관을 확인하세요.
:::

문장 다듬기나 특정 부분 수정처럼 일상적인 작업에는 먼저 비용이 낮은 모델을 사용해 보세요. 결과를 보고 작업에 더 적합하다고 판단되면 비용이 높은 모델을 사용하세요.

## 사용량 확인

사용량, 요금, 알림, 지출 한도는 제공자 계정에서 확인하세요. Warplyn은 제공자 청구 내역을 표시하거나 지출 한도를 적용하지 않습니다. 청구, 환불, 계정 요금 관련 문의는 제공자에게 하세요.

요청에 사용되는 모델은 비용에 영향을 줍니다. **설정** → **AI 도우미**에서 **기본 모델**, **앱 모델**, 특정 작업에 사용할 모델을 선택합니다. 설정 방법은 [AI 제공자 및 모델](providers.md)을 참조하세요.

::: tip AI 없이도 작업할 수 있습니다
AI 연결 없이도 *글(Articles)*을 작성하고 관리할 수 있습니다. 편집, *저장된 버전(Revisions)* 저장, 로컬 백업에는 AI 요청이 전송되지 않습니다.
:::
