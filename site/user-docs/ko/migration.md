# Skladno에서 Warplyn으로 이전하기

Warplyn은 별도의 애플리케이션으로 제공됩니다. 복원된 작업을 확인할 때까지 Skladno와 해당 데이터를 유지하세요. 사용 중인 데이터 폴더를 Warplyn으로 옮기지 마세요.

[최신 Warplyn 릴리스](https://github.com/punk-link/warplyn/releases/latest)에서 Windows 11 x64 설치 프로그램 또는 Debian x64 패키지를 다운로드하세요. 플랫폼별 안내는 [설치](installation.md)를 참조하세요.

이전하기 전에 **설정** → **데이터 및 백업**에서 **백업 폴더**를 선택한 다음 **백업 만들기**를 누르세요. 각 `.sqlite` 백업 파일은 옆에 있는 `.sqlite.skills` 폴더와 함께 보관하세요. 자세한 내용은 [백업 및 복구](backups-and-recovery.md)를 참조하세요.

## 이전 절차

1. Skladno에서 진행 중인 AI 작업을 완료하거나 취소한 다음 앱을 닫았다가 다시 열어 최신 검사점을 저장합니다. 백업을 만드는 동안 다른 프로그램에서 직접 만든 *스킬* 파일을 수정하지 마세요.
2. 사용자 지정 데이터 디렉터리를 사용하는 경우에도 실행 중인 Skladno 앱에서 수동 백업을 만듭니다. `.sqlite` 파일과 옆의 `.sqlite.skills` 폴더를 원래 이름 그대로 함께 보관하세요. 백업 생성이 끝나면 Skladno를 닫습니다.
3. 별도의 빈 프로필에 Warplyn을 설치하고 실행합니다. 사용 중인 Skladno 데이터 디렉터리를 Warplyn에 지정하지 마세요.
4. **설정** → **데이터 및 백업**에서 이전용 백업 폴더를 선택하고 **백업 복원**을 누릅니다. Skladno 스냅샷을 선택하고 교체를 확인한 뒤 Warplyn이 재시작할 때까지 기다립니다. Warplyn에 이미 작업 데이터가 있다면 먼저 Warplyn 자체 백업을 만드세요. 복원하면 기존 작업이 교체되며 데이터베이스가 병합되지는 않습니다.
5. 새로 작성하기 전에 *글*, 최신 *초안*, *저장된 버전* 기록, 도우미 대화, *설정*, 게시 프로필, 작성자가 만든 *스킬*을 확인하세요.
6. **설정** → **AI 도우미**에서 연결을 다시 추가하고 각 역할에 사용할 모델을 선택합니다. 자격 증명은 백업에 포함되지 않으므로 복원하면 저장된 연결과 모델 선택이 지워집니다. Skladno의 자격 증명은 변경되지 않습니다.
7. 환경 변수 연결을 사용한다면 변수 이름을 다시 추가하고 Warplyn이 해당 변수를 읽을 수 있는지 확인하세요. 백업은 `.env` 파일이나 그 값을 복사하지 않습니다.
8. Warplyn에서 계속 사용할 별도의 백업 폴더를 선택하세요. 업데이트 네트워크 접근과 텔레메트리 설정도 다시 선택해야 합니다. 이전 과정에서는 백업 폴더 설정, 텔레메트리 ID, 적용 대기 중인 업데이트, 복구 대기 기록이 복사되지 않습니다.

`.sqlite.skills` 폴더가 포함된 네이티브 백업은 현재 작성자 *스킬*과 변경 불가능한 *스킬* 기록을 복원합니다. 데이터베이스만 포함된 오래된 `.sqlite` 스냅샷은 데이터베이스를 복원하고 대상의 *스킬*은 그대로 둡니다. 백업에 들어 있지 않았던 파일은 복원할 수 없습니다. 데이터베이스 파일 이름과 매니페스트 형식은 Skladno와 호환됩니다.

## 복구

복원이 제대로 되었는지 확인할 때까지 Skladno를 설치된 상태로 두세요. 두 앱은 이후의 편집 내용을 동기화하거나 병합하지 않습니다. Skladno로 돌아가면 이전 상태로 돌아갑니다.

복원에 실패하면 Skladno를 계속 사용하고 원래 백업 파일과 폴더를 보관하세요. Warplyn은 백업을 검사하고, 복원하기 전에 현재 데이터를 스냅샷으로 저장합니다. 복원 후 Warplyn이 시작되지 않으면 그 스냅샷에서 데이터를 되돌립니다. 보고된 문제를 해결한 뒤 다시 시도하세요. [백업 및 복구](backups-and-recovery.md)와 [업데이트 복구](update-recovery.md)를 참조하세요.

Warplyn은 기본적으로 `~/.warplyn`을 사용하며, 사용자 지정 폴더에는 `WARPLYN_DATA_DIR`을 사용합니다. 실제 데이터 저장에는 `SKLADNO_DATA_DIR`을 무시하며, 알려진 기존 위치와 겹치는 경로는 거부합니다. 사용 중인 SQLite 데이터베이스를 복사하는 대신 별도의 빈 폴더를 사용해 백업을 복원하세요.
