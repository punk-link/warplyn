# 백업 및 복구

## 백업 만들기

**설정** → **데이터 및 백업**에서 **백업 폴더**를 선택한 다음 **백업 만들기**를 선택합니다. 지원되는 브라우저에서는 Warplyn이 해당 폴더에만 백업을 쓸 수 있도록 권한을 요청합니다.

[![백업 폴더, 백업 만들기 및 백업 복원 컨트롤, 자동 백업 옵션이 표시된 데이터 및 백업 설정.](/images/backups-and-recovery.png)](/images/backups-and-recovery.png)

*데스크톱 앱의 데이터 및 백업 설정.*

::: tip 백업에 포함되는 항목
새 `.skladno` 백업에는 데이터베이스, 현재 작성자 *스킬*, 해당 *스킬 버전* 기록, 파일 매니페스트가 포함됩니다. `.env` 파일과 API 키는 백업에 포함되지 않습니다.
:::

::: tip 브라우저 백업 제한
브라우저 백업 전송은 파일 하나당 최대 100 MB, 전체 500 MB까지 지원합니다. 백업이 이 한도를 넘으면 데스크톱 앱을 사용하세요.
:::

데스크톱 앱에서 데이터베이스 스냅샷 옆에는 현재 작성자 *스킬*, 해당 *스킬 버전* 기록, 개인 맞춤법 단어, 매니페스트가 들어 있는 `.sqlite.skills` 폴더가 있습니다. 스냅샷을 복사하거나 복원할 때는 `.sqlite` 파일과 `.sqlite.skills` 폴더를 함께 보관하세요. 브라우저 백업에는 개인 맞춤법 단어가 포함되지 않습니다.

이전 `.sqlite` 백업에는 데이터베이스만 들어 있습니다. 이를 복원해도 현재 *스킬* 파일과 기록은 유지됩니다.

## 자동 백업

**자동 백업**을 **매일**로 설정하면 Warplyn이 시작된 직후 스냅샷을 만들고, 앱을 계속 열어 둔 동안 24시간마다 새 스냅샷을 만듭니다. 브라우저에서는 Warplyn이 선택한 폴더를 사용할 수 있도록 권한이 필요합니다. 자동 백업에 실패하면 폴더를 확인하고 수동 백업을 만드세요. Warplyn은 다음에 예정된 시간에 자동 백업을 다시 시도합니다.

**자동 백업 보관**은 Warplyn이 보관할 자동 스냅샷 수를 설정합니다. 오래된 자동 스냅샷만 삭제하며 직접 만든 백업은 항상 보관합니다.

## 백업 복원

1. **설정** → **데이터 및 백업**에서 **백업 복원**을 선택합니다.
2. 복원할 백업을 선택합니다. Warplyn이 백업 파일을 확인한 뒤 현재 데이터베이스와 *스킬* 파일의 사본을 기기에 저장합니다. 필요한 경우 이 사본으로 복원 전 상태로 돌아갈 수 있습니다.
3. 복원이 끝나면 *글*과 *저장된 버전*을 확인합니다.

`.skladno` 백업 또는 동반 폴더가 있는 데스크톱 스냅샷을 복원하면 데이터베이스와 저장된 *스킬*이 교체됩니다. 이전의 데이터베이스 전용 `.sqlite` 백업을 복원하면 데이터베이스만 교체됩니다.

데스크톱 백업을 복원하면 저장된 개인 맞춤법 단어도 사전에 추가됩니다. 기존 단어는 유지됩니다. 개인 단어가 없던 이전 백업은 사전을 변경하지 않습니다. 다운로드한 언어 사전과 맞춤법 사전 미리 불러오기 설정은 포함되지 않습니다.

::: warning 복원 후 AI 설정
복원해도 이 설치의 기존 AI 연결, 인증 정보, 모델 선택은 유지됩니다. 연결이 설정되어 있지 않으면 Warplyn은 백업에 있는 환경 변수 이름과 참조를 복원하지만 API 키나 환경 변수 값은 복원하지 않습니다. 이 컴퓨터에 필요한 변수를 설정한 뒤 **설정** → **AI 도우미**에서 모델을 선택하세요. 저장된 API 키를 사용하는 연결은 새 설치로 가져오지 않으므로 설정에서 추가해야 합니다. 나머지 설정은 복원됩니다. 복원에 실패해 이전 상태로 돌아가면 기존 AI 설정이 유지됩니다.
:::

## 데이터베이스 전용 백업 수동 복구

이 단계는 이전 형식의 `.sqlite` 백업에만 사용하세요. 데이터베이스가 원래 위치로 돌아올 때까지 Warplyn을 종료된 상태로 두세요.

1. 현재 로컬 데이터베이스를 복사해 둡니다.
2. Warplyn 데이터 폴더의 `skladno.sqlite` 파일을 백업 파일로 교체합니다.
3. Warplyn을 시작하고 *글*과 *저장된 버전*을 확인합니다.

*스킬*을 포함한 백업은 **설정**의 **백업 복원**으로 복원하세요. 그래야 Warplyn이 매니페스트와 *스킬* 기록도 확인하고 복원할 수 있습니다.

## 백업을 만들 수 없는 경우

Warplyn은 활성 데이터베이스와 편집 세션을 변경하지 않습니다. 대상 폴더가 존재하고 계정에 쓰기 권한이 있는지 확인한 뒤 다시 시도하세요.

## 파일 권한

기본적으로 로컬 서비스는 데이터베이스를 `~/.warplyn`에 저장합니다. 다른 폴더를 사용하려면 `WARPLYN_DATA_DIR`을 설정하세요. Warplyn은 `SKLADNO_DATA_DIR`을 무시하며 Skladno의 이전 데이터 위치와 겹치는 폴더는 사용하지 않습니다. Skladno에서 이전하는 경우 별도의 Warplyn 폴더를 선택하고 백업을 복원하세요.

POSIX 시스템에서 Warplyn은 업그레이드 후에도 데이터 폴더와 SQLite 파일에 대한 접근을 계정으로 제한합니다. Windows에서는 Windows가 관리하는 파일 시스템 권한을 사용합니다. 브라우저에서 만든 백업 파일은 선택한 폴더의 권한을 따릅니다. 따라서 백업을 비공개 폴더에 보관하고 공유 또는 동기화 위치를 사용하기 전에 공유 설정을 확인하세요.
