# 애플리케이션 설정

애플리케이션 설정은 Warplyn의 모양과 동작을 제어합니다. *글*의 *저장된 버전* 기록에는 포함되지 않습니다. **아티클 라이브러리 패널의 도구 영역**에서 **설정**을 엽니다. 데스크톱 전용 설정은 아래에 표시되어 있습니다.

## 모양 및 언어 설정

**일반** → **화면 및 언어**에서 **기본 화면 모드**를 **시스템**, **라이트**, **다크** 중에서 선택합니다. **시스템**을 선택하면 Warplyn의 화면 모드가 기기 설정을 따릅니다. 앱을 열어 둔 채 기기 설정을 바꿔도 바로 반영됩니다. 메뉴와 메시지에 사용할 **인터페이스 언어**를 선택합니다. 현재 완전히 제공되는 인터페이스 언어는 영어뿐입니다. 이 설정은 *글*의 작성 언어나 타이포그래피 규칙을 바꾸지 않습니다.

**날짜 및 시간**에서 날짜 형식, 12시간제 또는 24시간제, 시간대를 선택합니다. 시스템 옵션은 기기 설정을 따릅니다. 이 설정은 Warplyn에 표시되는 저장 시각의 형식만 바꾸며 저장된 시각 자체는 바꾸지 않습니다.

## 글쓰기 기본값 설정

**기본 언어**에서 새 *글*에 적용할 **새 글의 기본 언어**를 설정합니다. **기본 번역 언어**를 설정하면 *번역*을 요청할 때 해당 언어가 먼저 제안됩니다. 언어 이름, 지역 변형 또는 코드를 입력한 다음 **추가**를 선택합니다. 번역을 요청할 때마다 Warplyn은 계속 확인을 요청합니다.

## 글쓰기 도우미 동작 설정

**AI 도우미**에서 새 *글* 대화의 기본값으로 **검토할 편집 제안**을 선택하거나, 명시적으로 요청한 편집에 **편집 바로 적용**을 사용하도록 설정합니다. 이 기본값은 기존 대화에 영향을 주지 않으며, 생성된 다른 결과도 계속 검토해야 합니다.

**요청 제한 시간**은 새 요청과 재시도 각각에 적용되며 기본값은 2분입니다. 더 오래 걸리는 작업에는 시간을 늘리거나 **무제한**을 선택합니다. 요청 시간이 초과되어도 *글*은 변경되지 않습니다.

글쓰기 도우미에 요청을 보낼 키로 **Enter** 또는 **Ctrl + Enter**를 선택합니다. 다른 앱 단축키는 **단축키**에서 변경할 수 있습니다. Warplyn은 단축키를 저장하기 전에 충돌을 알려줍니다.

## 게시 지침 설정

**게시**에서 새 *글*에 적용할 기본 프로필을 선택합니다. **LinkedIn 게시물**, **LinkedIn 글** 같은 프로필은 글 상태 표시줄에 글자 수 지침을 표시합니다. **제한 없음**을 선택하거나 이름과 정수 글자 수 제한이 있는 사용자 지정 프로필을 추가할 수도 있습니다. 기본 프로필은 새 *글*에 적용되며 기존 *글*은 자체 프로필을 유지할 수 있습니다. 제한은 지침일 뿐 복사를 막지 않습니다. 글 상태 표시줄에서 **Markdown 복사**를 선택하거나 메뉴를 열어 **일반 텍스트 복사**를 선택합니다. Warplyn은 요청할 때 텍스트를 복사하며 직접 게시하지 않습니다.

## AI 모델 옵션 검토

**AI 도우미**에서는 여러 제공자 연결을 유지하고 사용할 연결만 활성화하며, 일반 글쓰기 도우미 작업과 특정 *스킬*에 서로 다른 모델을 지정할 수 있습니다. 작업별 모델이 지정되지 않으면 **기본 모델**이 AI 작업에 사용됩니다. 요약이나 제목 만들기 같은 보조 작업에는 **앱 모델**을 따로 지정할 수 있습니다. 지정하지 않으면 Warplyn은 **기본 모델**을 사용합니다. **즐겨찾기**, 검색 또는 제공자 필터로 모델을 찾습니다. **추론 수준**은 지원되는 OpenAI 모델에서 표시됩니다. 사용할 수 있는 작업과 컨트롤은 모델에 따라 다릅니다. 연결 설정과 제공자별 제한은 [AI 제공자 및 모델](providers.md)을 참조하세요.

**단축키**에서 동작 옆의 단축키를 선택한 뒤 원하는 키 조합을 누릅니다. *저장된 버전* 저장, 보기 전환, 집중 모드 전환 단축키를 설정할 수 있습니다. 이미 사용 중인 단축키와 충돌하면 Warplyn이 해당 동작을 표시하므로 다른 조합을 선택하세요. **보내기 키**는 **Enter** 또는 **Ctrl + Enter** 중 어느 키로 글쓰기 도우미 요청을 전송할지 설정합니다. 단축키를 바꿔도 *글* 내용은 변경되지 않습니다.

## 데스크톱 업데이트 확인

패키지로 설치한 데스크톱 앱은 **설정** → **Warplyn 정보** → **업데이트**에서 새 버전을 확인할 수 있습니다. 먼저 **업데이트를 위한 네트워크 접근 허용**을 켭니다. 이를 통해 Warplyn은 GitHub에 연결해 공개된 버전 정보를 확인하고 사용자가 선택한 업데이트를 다운로드합니다. 그런 다음 **자동으로 업데이트 확인**과 **미리 보기 업데이트 포함** 여부를 선택합니다. 언제든지 확인하려면 **지금 확인**을 선택합니다. 업데이트를 사용할 수 있으면 변경 사항이 표시됩니다. Windows와 Linux AppImage 설치에서는 **다운로드**와 **다시 시작 및 업데이트** 작업을 제공합니다. Debian 설치에서는 **릴리스 노트 보기**를 선택한 다음 패키지 관리자로 업그레이드하거나 최신 `.deb` 설치 프로그램을 사용합니다. 업데이트 후 앱을 시작할 수 없다면 [데스크톱 업데이트 복구](update-recovery.md)를 참조하세요.

## 로컬 데이터 삭제

데스크톱 앱에서 **로컬 데이터 삭제**는 활성 Warplyn 데이터와 함께 *글*, *저장된 버전*, *초안* 검사점, 글쓰기 도우미 기록, 스타일 데이터, 설정 및 해당 데이터 폴더 안에 저장된 로컬 백업을 영구적으로 삭제합니다. 백업 폴더가 설정되어 있으면 확인 화면에 **삭제 전 백업 만들기**가 표시됩니다. Warplyn은 백업을 완료한 뒤에만 데이터를 삭제합니다. 삭제가 완료되면 앱이 닫힙니다. 일반적인 앱 제거는 글쓰기 데이터를 삭제하지 않습니다. 운영 체제 사전에 저장된 개인 맞춤법 단어는 그대로 남으므로 함께 삭제하려면 **설정** → **맞춤법**에서 별도로 제거하세요.

**설정** → **Warplyn 정보**에서 사용자 가이드, 소스 저장소, 이슈 트래커, 라이선스를 확인할 수 있습니다. 첫 실행 소개를 다시 보려면 **시작 가이드 열기**를 선택합니다.
