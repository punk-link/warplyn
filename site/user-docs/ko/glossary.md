# Warplyn 용어집

이 용어는 작성자에게 표시되는 개념과 Warplyn 전반에서 사용하는 도메인 언어를 설명합니다.

## 글과 저장된 버전

- **글**: 독립적으로 복구할 수 있는 편집 작업 단위입니다. Warplyn에서는 “문서” 대신 “글”을 사용합니다.
- **글 라이브러리**: 작성자의 로컬 *글* 모음입니다. **현재 글**은 작업 공간에서 열린 글이며 **글 목록**은 모음을 보여줍니다.
- **초안**: 현재 편집 중이며 아직 *저장된 버전*으로 저장되지 않은 *글* 텍스트입니다.
- **초안 검사점**: 로컬에 저장되며 기준 *저장된 버전*에 연결된 복구 가능한 변경형 *초안* 상태입니다. *저장된 버전*은 아닙니다. **현재 초안**은 *글*의 현재 *저장된 버전*을 기준으로 하며 **오래된 초안**은 이전 *저장된 버전*을 기준으로 합니다.
- **저장된 버전**: *글*의 변경 불가능한 저장 스냅샷입니다.
- **버전 저장**: 현재 *초안*을 새 *저장된 버전*으로 저장하는 작성자의 명시적 작업입니다. 일치하는 *초안* 검사점만 지웁니다.
- **제안**: 작성자의 명시적 승인이 필요한 AI 생성 후보 콘텐츠 또는 변경 사항입니다.
- **제안 기준 버전**: *제안*을 만들기 위해 검토한 *저장된 버전*입니다. 현재 *저장된 버전*과 일치하지 않게 되면 *제안*은 오래된 상태가 됩니다.
- **변경 사항 선택**: 작성자가 수락하기로 선택한 *제안*의 일부입니다. 수락하면 새 *저장된 버전*이 만들어집니다.
- **지적 사항**: *글*을 변경하지 않는 사실 확인 또는 문체 검토 결과와 같은 권고 사항입니다.
- **원문 글** 및 **번역 글**: 서로 연결되어 있지만 독립적으로 복구할 수 있는 *글*입니다. 번역은 원문의 *저장된 버전*이 아닙니다.

## 편집 작업

- **편집 기능**: 사용할 수 있는 *글* 맥락, 전제 조건, 결과를 선언하는 검증된 Warplyn 작업입니다. 작업 공간 보기와 글쓰기 도우미 스킬에서 동일한 기능을 호출할 수 있습니다.
- **스킬**: 작성자의 요청에 따라 편집 기능을 선택하고 순서를 정하도록 글쓰기 도우미를 돕는 재사용 가능한 지침 패키지입니다. *스킬*은 기능이나 권한을 부여하지 않습니다. **기본 제공 스킬**은 Warplyn에 포함됩니다. **작성자가 만든 스킬**은 글쓰기 도우미 대화에서 만든 로컬 Markdown 패키지이며 별도의 *스킬 버전* 기록을 가집니다.
- **편집 작업**: 글 작성, 다듬기, 사실 확인, 문체 검토, 번역과 같이 작성자가 요청한 글쓰기 도우미 작업입니다.
- **편집 요청**: 하나의 편집 작업을 실행하는 요청입니다.
- **편집 세션**: 편집 요청의 상호작용 순서와 활동 기록입니다.
- **편집 지침**: 편집 요청에 작성자가 입력한 지침 또는 맥락입니다.
- **스타일 말뭉치**: 작성자가 제공한 로컬 글쓰기 샘플입니다. **스타일 프로필**은 그 샘플에서 도출한 간결한 표현입니다.
- **작업 단계**: 선택 사항인 작성자 지정 진행 안내입니다. AI를 실행하거나 *글* 콘텐츠를 변경하지 않습니다.

## 게시 및 설정

- **게시 프로필**: 글자 수 제한을 포함할 수 있는 플랫폼별 설정 지침입니다. 기본값은 새 *글*에만 적용됩니다.
- **게시용 복사 텍스트**: 글 상태 표시줄을 통해 현재 *글*에서 명시적으로 복사한 Markdown 또는 일반 텍스트입니다. Warplyn은 게시 미리보기 작업 공간 보기를 제공하지 않습니다.
- **앱 설정**: 작업 공간 수준 기본 설정, AI 구성, 게시 프로필, 로컬 데이터 관리입니다. 설정은 *글*의 *저장된 버전* 기록에 포함되지 않습니다.
- **AI 연결**: 인증 정보 출처가 지정된 이름 있는 서버 측 제공자 구성입니다. 새 편집 요청은 **활성 AI 연결**을 사용합니다.
- **인증 정보 출처**: AI 연결이 사용하는 비공개 인증 정보의 출처입니다. 환경 변수 참조 또는 관리되는 자격 증명 중 하나입니다.
- **관리되는 자격 증명**: 운영 체제의 인증 정보 저장소에 보관되는 API 키입니다. Warplyn은 연결 메타데이터를 저장하지만 키를 SQLite 또는 백업 스냅샷에 쓰지 않습니다.
- **모델 설정**: 기본 모델 식별자 또는 편집 작업별 모델 재정의입니다.
- **인터페이스 언어**: Warplyn 인터페이스의 언어로, *글* 및 번역 언어와 별개입니다.
- **새 글의 기본 언어**: 별도로 지정하지 않은 새 *글*에 할당되는 언어입니다.
- **기본 번역 언어**: 번역 요청 때 먼저 제안되는 순서가 있는 언어 목록입니다. 번역을 자동으로 시작하지 않습니다.
- **백업 위치**: Warplyn이 백업 스냅샷을 기록하는 로컬 디렉터리입니다.
- **백업 스냅샷**: 활성 데이터베이스와 별도로 보관하는 로컬 데이터의 일관된 특정 시점 사본입니다. 인증 정보는 포함되지 않습니다.
- **데이터 위치**: Warplyn의 SQLite 데이터가 있는 활성 로컬 디렉터리입니다.
- **데이터 이동**: 작성자의 확인을 받아 데이터를 복사하고 다시 시작해 Warplyn을 새 데이터 위치로 전환하는 작업입니다. 복구를 위해 이전 사본은 보존됩니다.
- **복구 스냅샷**: 복원 중 Warplyn이 활성 데이터를 교체하기 전에 보관하는 백업 스냅샷입니다.
- **앱 업데이트**: 데스크톱 클라이언트가 확인하고 다운로드할 수 있는 새 Warplyn 패키지 버전입니다. 작성자가 직접 단계를 선택해야만 적용됩니다. 업데이트 자체는 *글* 콘텐츠를 변경하지 않습니다.
- **보안 업데이트**: 릴리스 태그에 `.security` 접미사가 붙은 애플리케이션 업데이트입니다. Warplyn은 이를 알리지만 확인, 다운로드, 다시 시작을 강제하지 않습니다.
- **대기 중인 업데이트**: 다운로드되어 작성자가 다시 시작 및 업데이트를 선택하기를 기다리는 앱 업데이트입니다. 일반 종료로는 적용되지 않습니다.
- **업데이트 전 스냅샷**: Warplyn이 대기 중인 업데이트를 적용하기 전에 만든 로컬 데이터 백업 스냅샷입니다. 복원에는 이에 맞는 이전 앱 버전이 필요합니다.
- **진단 이벤트**: 시작 또는 복구 가능한 실패를 지원하기 위해 호스트 프로세스 로그에 기록하는 비식별화된 로컬 서비스 기록입니다. 비공개 *글* 콘텐츠, 모델 본문, 환경 변수 값은 포함하지 않습니다.

## 인터페이스

### 작업 공간 구성

두 측면 패널을 펼치고 글 편집기를 선택한 데스크톱 레이아웃입니다. 상자는 위치와 포함 관계를 보여주며 정확한 크기를 나타내지 않습니다.

```text
편집 작업 공간
┌──────────────────────────┬──────────────────────────────┬──────────────────────────┐
│ 글 라이브러리 패널       │ 글 작업 공간                 │ 글쓰기 도우미 패널       │
├──────────────────────────┼──────────────────────────────┼──────────────────────────┤
│ Warplyn · 새 글          │ 글 머리글                    │ 도우미 머리글            │
│ 접기 컨트롤              │ 제목 및 글 메타데이터        │ 접기 컨트롤              │
├──────────────────────────┼──────────────────────────────┤
│ 글 검색                  │ 작업 공간 탭                 │ 대화                     │
├──────────────────────────┼──────────────────────────────┤ 요청 상태                │
│ 글 목록                  │ 작업 공간 보기               │ 및 활동                  │
│                          │                              │                          │
│                          │ 글 편집기                     │                          │
│                          │ ┌──────────────────────────┐ │                          │
│                          │ │ 글쓰기 영역              │ │                          │
│                          │ │                          │ │                          │
│                          │ └──────────────────────────┘ │                          │
├──────────────────────────┤                              ├──────────────────────────┤
│ 글 라이브러리            │                              │ 빠른 작업                │
│ 도구 영역                │                              │ 메시지 입력란            │
│ 문체 프로필 · 설정       ├──────────────────────────────┤ 편집 지침                │
│ 업데이트 · 언어          │ 글 상태 표시줄               │ 및 보내기                │
│ 언어 · 로컬                  │ 저장 상태 · 메타데이터 · 복사            │                          │
└──────────────────────────┴──────────────────────────────┴──────────────────────────┘
```

패널을 펼친 레이아웃에서 글 라이브러리 패널 아래쪽 바닥글은 **글 라이브러리 패널의 도구 영역**입니다. 맨 아래 행에는 현재 *글* 언어 코드와 **로컬** 레이블이 표시됩니다. 중앙 글 보기 아래의 **글 상태 표시줄**에는 저장 상태가 표시됩니다.

### 인터페이스 용어

- **편집 작업 공간**: 글 라이브러리 패널, 글 작업 공간, 글쓰기 도우미 패널로 구성된 기본 작성 화면입니다.
- **글 라이브러리 패널**: 글 검색, 글 목록, 작업 공간 수준 진입점을 포함합니다. 접힌 형태는 **탐색 레일**, 작은 화면의 임시 형태는 **탐색 서랍**입니다.
- **글 라이브러리 패널의 도구 영역**: 펼쳐진 글 라이브러리 패널의 바닥글입니다. 문체 프로필, 설정, 관련 업데이트 컨트롤, 현재 글 언어 코드와 **로컬** 레이블을 포함합니다.
- **저장 상태 표시기**: 현재 *초안*이 저장되었는지, 저장 중인지, 확인이 필요한지 글 상태 표시줄에 나타내는 상태입니다.
- **글 작업 공간**: 글 머리글, 작업 공간 탭, 선택된 작업 공간 보기, 글 상태 표시줄로 구성됩니다.
- **글 머리글**: 작업 공간 탭 위에 있는 제목 및 메타데이터 컨트롤입니다.
- **작업 공간 탭**: 작업 공간 보기를 선택하는 탭입니다.
- **작업 공간 보기**: 선택된 글 편집기 또는 지원 보기인 제안 검토, 저장된 버전 기록, 사실 확인, 번역입니다.
- **문체 프로필**: 감지된 특성, 문체 검토 *지적 사항*, 타이포그래피 규칙, 직접 입력한 지침, 글쓰기 샘플을 위한 별도 화면입니다.
- **글 편집기**: 글쓰기 화면입니다. 기본 편집 영역은 **글쓰기 영역**입니다.
- **글 상태 표시줄**: 선택된 작업 공간 보기 아래에 있는 표시줄입니다. 글 상태 및 메타데이터, 언어 선택, 게시 프로필 지침, 복사 컨트롤을 표시합니다.
- **글쓰기 도우미 패널**: 편집 지침, 작업, 요청 상태, 활동을 표시합니다. 작은 화면에서는 임시로 **글쓰기 도우미 서랍** 형태로 나타납니다.
- **빠른 작업**: 요청에 기본 제공 스킬을 넣기 위해 글쓰기 도우미 입력창 위에서 여는 드롭다운입니다.
- **요청 입력란**: 작성자가 편집 지침을 입력하고 요청을 전송하는 글쓰기 도우미 패널 하단의 입력란입니다.
- **앱 설정 탐색**: **일반**, **단축키**, **제공업체**, **AI 도우미**, **게시**, **기본 언어**, **맞춤법**, **데이터 및 백업**, **Warplyn 정보** 사이를 이동하는 메뉴입니다.
