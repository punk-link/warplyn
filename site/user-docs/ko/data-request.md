# 데이터 열람 또는 삭제 요청

Warplyn 프로젝트가 받은 개인 데이터에 대해 문의하거나 열람 또는 정정을 요청하려면 [kirill.taran@punk.link](mailto:kirill.taran@punk.link)으로 이메일을 보내세요. 삭제를 요청할 수도 있습니다. 어떤 데이터 또는 상호작용에 관한 요청인지 설명하세요. 프로젝트 관리자는 이메일로 답변하며 데이터를 찾거나 요청을 확인하는 데 필요한 정보를 추가로 요청할 수 있습니다.

첫 이메일에는 *글(Article)* 내용, API 키, 비밀번호, 신분증을 포함하지 마세요.

## 선택적 데스크톱 원격 분석

진단 및 사용 데이터 공유를 활성화했다면 다음을 수행하세요.

1. **설정** → **일반** → **개인정보 및 진단**을 열고 **ID 복사**를 선택합니다.
2. 위 주소로 ID를 이메일에 보내고 요청 내용을 설명합니다.
3. 이후 수집을 중단하려면 **진단 및 사용 데이터 공유**를 끕니다.

공유를 끄면 ID가 기기에서 삭제되므로 먼저 ID를 복사하세요. 공유를 꺼도 이미 전송된 이벤트는 회수할 수 없습니다. 삭제 요청을 받으면 프로젝트 관리자가 해당하는 가명 기록을 삭제하고 이메일로 확인해 줍니다.

수집 항목과 공유 제어 방법은 [진단 및 사용 데이터](telemetry.md)를 참조하세요.

## 글과 AI 제공자

사용자의 *글(Articles)*과 기록은 로컬에 저장됩니다. 프로젝트 관리자에게 요청해도 컴퓨터의 파일이나 앱 데이터는 삭제되지 않습니다. 로컬 데이터를 제거하기 전에 보존할 글을 백업하세요.

AI 기능을 사용하면 관련 텍스트와 맥락이 선택한 제공자에게 전송됩니다. 해당 제공자가 보유한 데이터에 관한 요청은 그 제공자에게 별도로 보내야 합니다.

## 웹사이트 분석

웹사이트 분석은 데스크톱 원격 분석과 별개입니다. 웹사이트 방문에 관한 요청이라면 대략적인 날짜와 페이지 주소를 알려주세요. 데스크톱 원격 측정 ID으로는 웹사이트 방문을 식별할 수 없으며 분석 데이터에서 개별 방문을 찾지 못할 수도 있습니다.

사용 중인 서비스와 추적을 끄는 브라우저 개인정보 보호 신호는 [웹사이트 분석](telemetry.md#website-analytics)을 참조하세요.
