# AI 제공자 및 모델

Warplyn은 **설정** → **AI 도우미**에서 설정한 제공자에게 AI 요청을 보냅니다. 해당 제공자의 계정과 API 키가 필요합니다. 제공자는 API 사용료를 청구할 수 있습니다.

## 연결 추가

데스크톱 앱에서 **설정** → **AI 도우미**를 엽니다. **키를 어떻게 제공하시겠습니까?**에서 **API 키 추가** 또는 **환경 변수**를 선택합니다.

- **API 키 추가:** 제공자를 선택하고 연결 이름을 입력한 뒤 키를 입력합니다. Warplyn은 키를 Windows Credential Manager 또는 Linux Secret Service에 저장합니다. 키는 다시 표시되지 않으며 Warplyn 데이터베이스나 백업에는 저장되지 않습니다.
- **환경 변수:** 제공자를 선택하고 연결 이름을 입력한 뒤 키가 들어 있는 변수 이름을 입력합니다. Warplyn은 변수 이름만 저장하며 값은 저장하지 않습니다. 애플리케이션 서비스가 해당 변수가 설정된 상태로 시작되어야 합니다.

::: tip 인증 정보 안내
관리형 API 키를 사용하려면 데스크톱 앱과 운영 체제 인증 정보 서비스가 필요합니다. Linux에서는 Secret Service가 잠금 해제되어 있어야 합니다. 브라우저 앱은 환경 변수 연결을 지원하지만 운영 체제 인증 정보는 관리할 수 없습니다. 설치 프로그램은 `.env` 파일을 만들거나 가져오지 않습니다.
:::

API 키 연결을 추가하면 제공자에게 키를 확인합니다. 환경 변수 연결은 설정만 저장합니다. 모델을 새로고침하거나 AI 요청을 보내면 Warplyn이 제공자에게 다시 연결합니다. 이 확인 과정에는 *글* 내용이 포함되지 않습니다.

연결은 **설정** → **AI 도우미**에 표시됩니다. **활성**, **활성화**, **비활성화**를 사용해 새 요청에 Warplyn이 사용할 수 있는 연결을 정합니다. 연결의 로컬 표시 이름을 바꾸려면 **이름 바꾸기**를 선택하고, Warplyn에서 연결을 제거하려면 **제거**를 선택한 뒤 확인합니다. 환경 변수 연결을 제거해도 변수나 해당 키는 삭제되지 않습니다.

::: tip 모델 새로고침에 실패하는 경우
연결이 **활성**인지, 저장된 키가 유효하거나 환경 변수를 애플리케이션 서비스가 사용할 수 있는지, 제공자 계정으로 API에 접근할 수 있는지 확인하세요.
:::

## 제공자 및 모델 선택

Warplyn은 OpenAI, OpenCode Zen, Anthropic, Google Gemini API, xAI Grok, DeepSeek를 지원합니다. OpenCode Zen 카탈로그에서는 다른 업체의 모델도 사용할 수 있습니다.

**설정** → **AI 도우미**에서 **목록 새로 고침**을 선택한 다음 **기본 모델**을 선택합니다. 특정 *스킬*에 다른 모델을 사용하려면 **작업별 모델**에서 선택합니다. 작업에 **기본 모델 사용**을 설정하면 기본 모델을 사용합니다.

연결을 변경했거나 제공자의 최신 카탈로그를 확인하려면 모델 목록을 새로고침합니다. **모델 검색**, **개발사별 모델 필터링**, **즐겨찾기**를 사용해 목록을 좁힙니다. 모델 선택은 이후 요청에 적용됩니다. 선택한 OpenAI 모델에 **추론 수준**이 표시되면 사용할 수 있습니다. 더 높은 수준은 처리 시간이 길어질 수 있습니다. **설정** → **AI 도우미**의 선택 항목인 **앱 모델**은 기본 모델과 별개이며 요약과 제목 같은 Warplyn 보조 작업을 처리합니다.

::: tip 모델 사용 가능 여부
사용할 수 있는 편집 작업은 모델에 따라 다릅니다. 일부 모델은 출처가 있는 사실 확인, 구조화된 출력, 추론 제어를 지원하지 않습니다. OpenCode Zen 모델은 해당 카탈로그의 기능과 사용 가능 여부를 따릅니다.
:::

### 앱 모델

**앱 모델**은 *제안* 요약, 제목, 글쓰기 도우미 요청 의도 파악과 같은 짧은 보조 작업을 처리합니다. 설정하지 않으면 Warplyn은 기본 모델을 사용합니다.

효율적이고 비용이 낮은 텍스트 모델을 선택하세요. **GPT-6 Luna**는 이러한 특정 작업에 사용할 수 있는 OpenAI 모델입니다([모델 세부 정보](https://developers.openai.com/api/docs/models/gpt-6-luna)). 다른 제공자를 사용한다면 비슷한 모델을 선택하세요. 결과가 충분하지 않으면 더 강력한 모델을 사용해 보세요.
