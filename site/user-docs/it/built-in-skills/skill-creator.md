# Creatore di abilità

L’assistente usa Creatore di abilità integrato quando gli chiedi esplicitamente di creare, modificare, ripristinare o eliminare un’*abilità* riutilizzabile. Gestisce istruzioni Markdown locali e conserva una cronologia separata per ogni *abilità*.

Descrivi l’attività ricorrente e le regole o i riferimenti che l’*abilità* deve seguire. L’assistente potrebbe farti una breve domanda di chiarimento se un obiettivo o una procedura poco chiari potrebbero cambiare il risultato. Una nuova *abilità* sarà disponibile per le richieste successive; crearla non la esegue sull’*articolo* attuale.

::: tip Esempio
Chiedi: «Crea un’abilità chiamata “Revisione di narrativa sobria”. Rendi più essenziali le frasi di Ana preservando la sua voce, l’ambientazione sul fiume e gli eventi della scena. Non aggiungere dettagli; segnala invece i passaggi poco chiari».
:::

Puoi chiedere all’assistente di modificare, ripristinare o eliminare un’*abilità* indicandone il nome. Il ripristino crea una nuova versione attiva e conserva le *versioni precedenti dell’abilità*. Consulta [Creare e gestire abilità](../skills.md) per il flusso di lavoro completo e le opzioni di modifica locale.
