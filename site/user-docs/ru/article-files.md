# Файлы статей

Используйте **Сохранить в файл** и **Загрузить из файла**, чтобы переносить статьи целиком между Warplyn и другими редакторами. Эти действия доступны в настольном и веб-приложении.

## Сохранить в файл

1. Откройте *статью*, которую хотите сохранить.
2. В заголовке статьи нажмите **Сохранить в файл** рядом с **Сохранить версию**. Можно также щёлкнуть правой кнопкой мыши по *статье* в библиотеке и выбрать **Сохранить в файл…**, не открывая её.
3. В окне сохранения настольного приложения выберите Markdown, HTML, DOCX или RTF в списке типов файлов, затем укажите имя и расположение файла. Сохраните соответствующее расширение. В веб-приложении нажмите **Формат файла**, затем **Скачать** и воспользуйтесь средствами браузера для загрузок.

Файл содержит весь текущий *черновик*, включая несохранённые изменения. Выделение текста не ограничивает сохраняемое содержимое. Это действие не создаёт *сохранённую версию*. **Сохранить версию** по-прежнему добавляет текущий *черновик* в историю.

::: tip Нужна переносимая копия рабочего пространства?
Файлы *статей* содержат только текст. Чтобы сохранить историю, работу помощника, *навыки* и настройки, создайте [резервную копию](backups-and-recovery.md).
:::

Веб-приложение показывает сообщение **Скачивание статьи началось**, когда передаёт файл браузеру. Проверьте раздел загрузок браузера, чтобы узнать о завершении или ошибках.

## Загрузить из файла

1. В заголовке статьи нажмите **Загрузить из файла** рядом с **Сохранить версию** или щёлкните правой кнопкой мыши по *статье* в библиотеке и выберите **Загрузить из файла…**. Если библиотека пуста, сначала нажмите **Создать**.
2. Выберите файл с расширением `.md`, `.html`, `.htm`, `.docx` или `.rtf`.
3. Для HTML, DOCX и RTF отметьте **Проверить импортируемую статью**, затем нажмите **Импортировать**. Проверку можно отменить. Файлы Markdown открываются сразу.
4. Warplyn откроет импортированный текст как отдельную *статью*. Предыдущая *статья* и её восстанавливаемый *черновик* останутся в библиотеке.

Начальный заголовок первого уровня задаёт новое название. Если его нет, Warplyn использует имя файла без расширения. Сам заголовок остаётся в тексте *статьи*. Повторная загрузка одного файла создаёт ещё одну независимую *статью*.

::: warning При импорте создаётся отдельная статья
Загрузка файла не заменяет *статью*, из которой вы открыли окно выбора файла. Проверьте импортированную *статью*, затем при необходимости переместите или удалите любую из них.
:::

Размер файла не должен превышать 10 МиБ. Markdown и HTML должны быть в UTF-8. Для работы с DOCX и RTF Microsoft Office не требуется.

Warplyn сохраняет абзацы, заголовки, редактируемые вложенные списки и нумерацию, полужирный и курсивный шрифт, зачёркивание, безопасные ссылки, цитаты, код и текст Unicode, если это поддерживается исходным форматом. Разметка страницы, шрифты, изображения, встроенные объекты и сложные возможности отдельных форматов могут быть упрощены или пропущены. Текст таблиц преобразуется в обычный текст *статьи*. Перед продолжением проверьте предварительный просмотр импорта. Неподдерживаемые расширения Markdown также могут потерять форматирование в редакторе.

Можно закрыть окно выбора файла, не импортируя его. Если текущий *черновик* не удаётся сохранить для восстановления, устраните ошибку сохранения и повторите загрузку.

## Сохранить версию статьи в файл

1. Откройте **Версии**.
2. Откройте *сохранённую версию*, которую хотите экспортировать.
3. Рядом с её сведениями нажмите **Сохранить в файл**.

Файл содержит всю *статью* из этой *сохранённой версии*, независимо от текущего *черновика*. Экспорт не восстанавливает *сохранённую версию* и не меняет историю. В предлагаемое имя файла входит номер *сохранённой версии*.

Для экспорта также действует лимит 10 МиБ. Если сохранение в настольном приложении не удалось, выберите папку с правом записи и повторите попытку. При неудачной замене существующий файл назначения останется целым.

Экспортированные файлы содержат текст *статьи*, но не всю историю, переписки или настройки. Используйте [Резервное копирование и восстановление](backups-and-recovery.md), чтобы защитить всё рабочее пространство.
