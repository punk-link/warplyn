# Профиль стиля

В разделе **Профиль стиля** можно дать помощнику образцы своих текстов и указать, какие правила учитывать при правке. Образцы остаются на устройстве. Они не входят в *статью* или *сохранённую версию*.

Откройте **Профиль стиля** в области инструментов библиотеки статей. В боковом меню выберите **Образцы текстов**, **Ручные правила** либо **Правила типографики**. В узком окне эти пункты находятся в списке разделов. Кнопка **Назад** возвращает к *статье* и представлению, которое было открыто.

::: tip Выберите, с чего начать
Добавьте образцы текстов, если хотите определить особенности авторского голоса, или задайте **Ручные правила**, если уже знаете, какие рекомендации дать. Можно использовать любой из этих вариантов отдельно.
:::

## Добавить образцы текстов

Откройте **Образцы текстов**, чтобы подобрать примеры, по которым Warplyn определит особенности вашего стиля. Нажмите **Добавить образец текста**, чтобы вставить текст, или загрузите файл `.txt` либо `.md`. Можно также выбрать **Добавить эту статью**, чтобы использовать как образец сохранённую версию *статьи*. Дайте образцу название, по которому его будет легко узнать.

Снимите или поставьте флажок образца, чтобы исключить его из профиля или включить в него. Исключённый образец останется в списке. Удалите образец, когда он больше не нужен. Перед удалением потребуется подтверждение, поскольку образец будет удалён из профиля стиля.

## Добавить рекомендации и обновить профиль

В разделе **Ручные правила** опишите предпочтения, которым должен следовать помощник. Например, попросите сохранить повествование от первого лица или расшифровывать сокращение при первом упоминании. Рекомендации можно добавить и без образцов.

После изменения образцов или рекомендаций нажмите **Перестроить профиль**, чтобы обновить выявленные особенности. В профиле показано, какие образцы были использованы и когда он перестроен. Пока вы не перестроите профиль, в нём могут отображаться особенности прежнего набора образцов. *Замечания* о стиле носят рекомендательный характер и не меняют текст *статьи*.

## Правила типографики

Откройте **Правила типографики**, затем выберите **Язык типографики**. Правила сохраняются отдельно для каждого языка письма, независимо от языка интерфейса. Параметр **Применять правила к** позволяет выбрать **Всем статьям на этом языке** или **Только этой статье**. Для *перевода* используются его собственный язык и настройки.

В меню **Исходный язык** строки состояния есть региональные языки из каталога предустановок. Для другого языка выберите **Другой язык…** и введите его код, например `ja` для японского. Затем можно сохранить пользовательские правила типографики без встроенной предустановки.

С помощью **Добавить правило** выберите кавычки, тире в прозе, многоточие, интервалы вокруг знаков препинания, повторяющиеся пробелы или неразрывную пару, например `10 kg`. Для кавычек и пробелов внутри них используйте **Своя пара**. **Точная замена пунктуации** задаёт точное правило пунктуации или пробелов. Если для правила нужно учитывать контекст, выберите **Контекстное указание по типографике**.

::: info Язык и область действия
Выберите язык письма и укажите, применять ли правила ко всем *статьям* на этом языке или только к текущей *статье*. У *перевода* собственные язык и параметры типографики.
:::

Параметр **Готовый набор правил** показывает примеры региональных правил. Предустановки с пометкой **ожидает проверки носителем языка** пока нельзя применить; вместо них можно настроить собственные правила. Региональные правила не распространяются автоматически на другие регионы. Если прежние правила действовали глобально, **Копировать прежние правила** скопирует их, не удаляя оригиналы.

Правила *статьи* наследуют сохранённые настройки языка. При редактировании унаследованного правила создаётся переопределение; его удаление отключает правило для этой области. **Сбросить изменения** сбрасывает переопределения. При переключении языка несохранённые правки правил сохраняются, пока открыт профиль стиля.

Краткие описания правил отмечены статусом **Сохранено** или **Не сохранено**. Нажмите **Изменить**, чтобы открыть правило; одновременно редактировать можно только одно. **Сохранить** сохраняет выбранную область. Когда вы сохраняете языковые параметры, Warplyn перестраивает *профиль стиля* на вашем компьютере. В новый профиль входят образцы, отмеченные в списке, и сохранённые рекомендации. Переопределения *статьи* сохраняются для этой *статьи*. Несохранённый текст в других формах остаётся несохранённым. Можно задать явные правила типографики и без образцов текстов; образцы нужны для определения особенностей авторского голоса.

Сохраните текущий *черновик*, затем нажмите **Проверить типографику**, чтобы проверить выбранную *статью* без подключения к ИИ. Проверка использует *сохранённую версию* и её язык, указанный в строке состояния. Для проверки выберите этот же язык из списка **Язык типографики**. Код, URL, технические идентификаторы и неоднозначные случаи с кавычками не меняются. Для проверки контекстных правил запустите помощника и выберите **Проверить стиль текста**. Если для языка нет подходящих механических правил, локальная проверка типографики его не охватывает; сначала добавьте и сохраните собственные правила.

Откройте **Проверить предложение**, чтобы проверить исправления и правила, на которых они основаны. Отметьте исправления, которые хотите принять, и нажмите **Применить**. Принятые исправления создают *сохранённую версию*; отклонение всех исправлений оставляет *статью* без изменений. Сохранение правил или запуск проверки не применяют исправления. В проверке сохраняются использованные язык и определения правил; после изменения языка или применимых настроек появится предложение запустить проверку заново. Типографика не определяет границы языков во фрагментах на нескольких языках. Неоднозначные случаи остаются без изменений.
