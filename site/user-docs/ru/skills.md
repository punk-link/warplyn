# Создание навыков и управление ими

*Навыки* — это локальные пакеты инструкций в Markdown. Они помогают помощнику выбирать и упорядочивать редакторские возможности. Навыки не предоставляют дополнительных разрешений и не меняют *статью*.

## Создать собственные навыки и управлять ими

Попросите помощника обычными словами создать повторно используемый *навык*. Опишите повторяющуюся задачу и нужные правила или источники. Если недостающая деталь может изменить *навык*, помощник задаст короткий уточняющий вопрос, а не станет угадывать.

::: tip Пример
Чтобы редактировать художественный текст в стиле спокойной речной сцены, попросите: «Создай *навык* „Линейная правка спокойной прозы“. Сделай предложения Аны ёмче, сохранив её голос, обстановку у реки и события сцены. Не добавляй подробностей, а отмечай неясные места». Помощник сможет использовать эти инструкции при каждой просьбе о линейной правке.
:::

*Пример запроса на создание навыка в Composer. Перед отправкой подключите провайдера.*

После успешного создания *навык* сразу становится доступен для новых запросов помощнику. Этот запрос не отправляет модели текст *статьи* и не меняет *статью*, *черновик*, *предложение* или *сохранённую версию*.

У каждого созданного *навыка* есть локальная неизменяемая история *сохранённых версий навыка*. Она не связана с историей *сохранённых версий* *статьи*. Можно также отредактировать локальный пакет Markdown напрямую. Warplyn обновит каталог к следующему запросу. Если удалить файл `SKILL.md`, *навык* исчезнет из списка доступных *навыков*.

Попросите помощника изменить или удалить *навык* по имени. Перед изменением он прочитает текущий пакет и проверит, не менялся ли файл за это время. При редактировании сохраняется идентификатор *навыка* и добавляется новая *сохранённая версия навыка*. Удаление убирает его из новых запросов, но история сохраняется.

Чтобы вернуть прежние инструкции, запросите *сохранённые версии* нужного *навыка* и укажите, какую восстановить. При восстановлении записывается новая активная версия и добавляется ещё одна *сохранённая версия навыка*. Так же можно восстановить удалённый *навык*. Восстановление чекпоинта переписки с помощником не восстанавливает и не меняет *навык*: для этого нужен отдельный запрос.
