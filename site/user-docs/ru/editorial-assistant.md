# Редакторский помощник

Редакторский помощник поможет написать или отредактировать текст, проверить факты и стиль либо подготовить перевод. Каждый запрос отправляется явно. Выбор действия в **Быстрые действия** только добавляет заготовку *навыка* в Composer. Чтобы начать работу, нажмите **Отправить запрос помощнику**.

Выделение текста ограничивает правки этой частью. Определения и подсказки о голосе рядом с ней могут помочь помощнику понять короткий фрагмент, но при их передаче провайдеру будет раскрыт и невыделенный текст. Если запрос с выделением требует текста *статьи*, Warplyn отправит выделенный фрагмент и до 500 символов до и после него как отдельный контекст только для чтения. Заменить можно только выделенный фрагмент. Перед отправкой Composer объяснит это; не отправляйте запрос, если соседний текст конфиденциален. Для общих советов и управления *навыками* этот текст не нужен. Warplyn никогда незаметно не расширяет запрос на всю *статью*. Если контекста недостаточно, явно добавьте нужный фрагмент или повторите запрос с другим выделением.

::: tip Пример
При редактировании рассказа выделите фрагмент и попросите: «Улучшить связность, сохранив точку зрения Аны и спокойное настроение. Не добавлять новых событий». Помощник подготовит *предложение* для проверки. Можно также попросить проверить, не переключается ли время повествования между прошедшим и настоящим; *замечания* о стиле появятся на экране **Профиль стиля**.
:::

*Пример запроса в Composer. Перед отправкой подключите провайдера. На снимке экрана показано прежнее название навыка.*

Во время работы помощник показывает короткое сообщение о ходе выполнения. Нажмите **Остановить запрос**, чтобы отменить слишком долгую задачу. Отменённый или неудачный запрос не меняет *статью*; нажмите **Повторить**, чтобы повторить его. Помощник не показывает инструкции, личные входные данные, учётные данные или ошибки провайдера. Когда результат готов, откройте его через карточку результата:

- **Проверка предложения** — для нового или отредактированного текста.
- **Проверка фактов** — для консультативных *замечаний*.
- **Профиль стиля** — для *замечаний* о стиле.
- **Переводы** — для *предложения* перевода.

Открытие результата не меняет *статью*. Проверьте *предложение* до принятия изменений. *Замечания* остаются консультативными, а переводы — отдельными связанными *статьями*. О предложениях, истории, восстановлении и проверке фактов см. [Проверка статей](reviewing-articles.md). Сравнение и применение результатов перевода описаны в разделе [Переводы](translations.md).

Чтобы проверить технические термины, выберите **Проверить технические термины** в меню **Быстрые действия**. *Замечания* с источниками появятся в разделе **Проверка фактов**. О шагах и ограничениях проверки см. [Проверка технических терминов](built-in-skills/check-technical-terms.md).

В окне **Проверка предложения** редактируйте текст **Предложение** в макете **Рядом** или **Друг под другом**. **Оригинал** доступен только для чтения. Для каждого изменения сохраняется решение **Принять** или **Отклонить**. Выберите решение для каждого изменения и нажмите **Применить**, чтобы завершить проверку. Принятый текст создаёт одну новую *сохранённую версию*. Если отклонить все предложения, кнопка **Применить** закроет проверку, не меняя *статью* и не создавая *сохранённую версию*. Чтобы принять всё, выберите **Пометить все как принятые** в меню **Задать все решения…**, а затем примените изменения. **Пометить все как отклонённые** оставляет *статью* без изменений. **Сбросить все решения** сбрасывает все решения к состоянию «Ожидает решения», сохраняя отредактированный текст предложения. Нажмите **Закрыть предложение**, чтобы закрыть проверку.

Не применённые изменения сохраняются при переключении макетов и представлений рабочего пространства. Перезагрузка, переключение *статей*, закрытие *предложения* или создание нового удаляют эти изменения. Если применение не удалось, изменения сохраняются для повторной попытки. Не меняйте предложенные числа, ссылки, код и технические термины. Устаревшие, ненадёжные и уже принятые *предложения* доступны только для чтения. Если изменить текст исправления факта, его *замечания* и после применения останутся консультативными.

*Навыки* помогают сформулировать запрос, но не предоставляют дополнительных разрешений. Для запроса без метки помощник сам выбирает подходящие *навыки*. Обычные запросы не направляются через стандартный процесс редактирования. Warplyn не выполняет работу в фоновом режиме, не публикует напрямую и не меняет *статью* без вашего одобрения.

Попросите помощника создать повторно используемый [навык](skills.md), если процедура понадобится ещё раз. Если цель, шаги или источники неясны, он может задать короткий уточняющий вопрос. Созданный *навык* сразу становится доступен и получает собственную локальную историю *сохранённых версий навыка*. Создание навыка не читает текст *статьи* и не меняет её *черновик*, *предложение* или *сохранённую версию*.

Можно попросить редакторского помощника проверить **История версий**, сохранённые редакторские результаты, рекомендации для публикации или готовность Style Corpus. По явному запросу он может добавить текущую неизменяемую *сохранённую версию* в локальный Style Corpus и пересобрать Профиль стиля. Он не может принимать *предложения*, восстанавливать *сохранённые версии*, разрешать *замечания*, редактировать *черновики*, удалять образцы стиля или публиковать.

Чтобы просмотреть примеры письма, повторно используемые рекомендации или правила типографики, откройте [Профиль стиля](style-profile.md). *Замечания* о стиле отображаются там отдельно от *статьи*.
