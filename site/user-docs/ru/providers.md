# Провайдеры и модели ИИ

Warplyn отправляет запросы провайдеру ИИ, настроенному в разделе **Настройки** → **ИИ-помощник**. Вам понадобятся учётная запись и ключ API этого провайдера. За использование API может взиматься плата.

## Добавить подключение

В настольном приложении откройте **Настройки** → **ИИ-помощник**. В разделе **Как вы хотите предоставить ключ?** выберите **Добавить ключ API** или **Переменная окружения**.

- **Добавить ключ API:** выберите провайдера, укажите имя подключения и введите ключ. Warplyn сохранит его в Windows Credential Manager или Linux Secret Service. После сохранения Warplyn больше не показывает ключ. В базу данных и резервные копии ключ не попадает.
- **Переменная окружения:** выберите провайдера, укажите имя подключения и введите название переменной окружения с ключом. Warplyn сохраняет название, но не значение. Служба приложения должна запускаться с заданной переменной.

::: tip Об учётных данных
Для управляемых ключей API нужны настольное приложение и доступная системная служба учётных данных. В Linux Secret Service должен быть разблокирован. Веб-приложение поддерживает подключения через переменные окружения, но не управляет системными учётными данными. Установщик не создаёт и не импортирует файл `.env`.
:::

При добавлении подключения с ключом API Warplyn проверяет ключ у провайдера. При добавлении подключения через переменную окружения Warplyn сохраняет настройки без проверки ключа. Warplyn снова обращается к провайдеру при обновлении списка моделей или отправке запроса ИИ. При этих проверках содержимое *статьи* не передаётся.

Подключения перечислены в разделе **Настройки** → **ИИ-помощник**. Используйте **Активно**, **Включить** или **Выключить**, чтобы выбрать, какие из них Warplyn будет использовать для новых запросов. Нажмите **Переименовать**, чтобы изменить локальное отображаемое имя, или **Удалить** и подтвердите удаление подключения из Warplyn. Удаление подключения через переменную окружения не удаляет саму переменную или её ключ.

::: tip Если не удаётся обновить список моделей
Убедитесь, что подключение **Активно**, сохранённый ключ действителен или переменная окружения доступна службе приложения, а учётная запись провайдера имеет доступ к API.
:::

## Выбрать провайдеров и модели

Warplyn поддерживает OpenAI, OpenCode Zen, Anthropic, Google Gemini API, xAI Grok и DeepSeek. В каталоге OpenCode Zen также доступны модели других поставщиков.

В разделе **Настройки** → **ИИ-помощник** нажмите **Обновить список**, затем выберите **Модель по умолчанию**. Если для отдельного *навыка* нужна другая модель, выберите её в разделе **Модели для отдельных задач**. Для задач с параметром **По умолчанию** используется модель по умолчанию.

Обновляйте список моделей после смены подключений или для просмотра текущего каталога провайдера. Сузить список можно с помощью **Поиск моделей**, **Фильтр моделей по разработчику** и **Избранное**. Выбор модели влияет на будущие запросы. Для выбранной модели OpenAI можно настроить **Уровень рассуждений**; более высокий уровень может увеличить время ответа. При желании задайте отдельную **Модель приложения** для вспомогательных задач Warplyn, например для подготовки сводок и заголовков.

::: tip Доступность моделей
Набор доступных редакторских операций зависит от модели. Некоторые модели не поддерживают проверку фактов с источниками, структурированный вывод или настройки рассуждения. Список моделей OpenCode Zen и их возможности зависят от каталога этого провайдера.
:::

### Модель приложения

**Модель приложения** составляет сводки *предложений* и заголовки, а также определяет, какую задачу вы поручили помощнику. Если отдельная модель для этих задач не задана, Warplyn берёт модель из поля **Модель по умолчанию**.

Выберите эффективную текстовую модель с невысокой стоимостью. Для этих задач подойдёт, например, модель OpenAI **GPT-6 Luna** ([сведения о модели](https://developers.openai.com/api/docs/models/gpt-6-luna)). У другого провайдера выберите сопоставимую модель. Если качество результата недостаточно, попробуйте более мощную модель.
