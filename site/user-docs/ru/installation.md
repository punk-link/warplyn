# Установить Warplyn

Warplyn доступен для Windows 11 x64 и Linux. Скачайте актуальные установщики со страницы [выпусков Warplyn](https://github.com/punk-link/warplyn/releases). Если вы пользуетесь Skladno, выполните [руководство по переходу](migration.md) и сохраните прежнюю установку и резервные копии, пока не проверите восстановленные данные.

## Windows

1. Откройте страницу [выпусков Warplyn](https://github.com/punk-link/warplyn/releases).
2. В разделе **Assets** скачайте установщик Windows `.exe` и запустите его.
3. Если Windows покажет предупреждение SmartScreen, убедитесь, что установщик скачан со страницы выпусков этого репозитория. Выпуски пока не подписаны цифровой подписью.
4. Откройте Warplyn из меню «Пуск».

Информацию об обновлениях и восстановлении см. в разделе [Восстановление после обновления настольного приложения](update-recovery.md).

::: info О цифровых подписях
Цифровая подпись использует сертификат подписи кода, чтобы идентифицировать издателя и показать, менялся ли установщик после подписания. Она не гарантирует безопасность программы. Warplyn пока не настроил подпись издателя, поэтому Windows не может проверить его по установщику. Скачивайте установщик только с официальной страницы выпусков.
:::

## Debian и основанные на Debian дистрибутивы

Основной проверенный целевой вариант Debian — Ubuntu 22.04 x64; совместимость с другими версиями дистрибутивов не гарантируется. Используйте систему amd64 с графической рабочей средой.

1. Откройте страницу [выпусков Warplyn](https://github.com/punk-link/warplyn/releases).
2. В разделе **Assets** скачайте пакет `warplyn_VERSION_amd64.deb`.
3. Откройте терминал в папке загрузки. Если в ней находится только этот пакет Warplyn, установите его командой:

   ```sh
   sudo apt install ./warplyn_*.deb
   ```

4. Запустите Warplyn из меню приложений.

Для ручного обновления скачайте более новый `.deb` и выполните ту же команду `sudo apt install`, указав этот файл. Скачивание не настраивает автоматический репозиторий пакетов. Apt разрешает заявленные зависимости; не устанавливайте пакет принудительно, если зависимости не удаётся удовлетворить.

По умолчанию тексты хранятся в `~/.warplyn`. Перед обновлением создайте резервную копию. Переустановка или удаление приложения должны сохранить эту папку и учётные данные в настольном хранилище ключей.

Для управляемых ключей API в Linux требуется доступная и разблокированная служба Secret Service, например GNOME Keyring. Другие варианты подключения см. в разделе [Провайдеры и модели ИИ](providers.md).

Если ключ не удаётся сохранить или прочитать, разблокируйте настольное хранилище ключей и повторите попытку. Если в сеансе нет Secret Service, включите эту службу или используйте подключение через переменную окружения из указанного руководства. Редактировать текст можно и без подключения. Не отключайте песочницу для обхода сбоев запуска; сообщите дистрибутив, версию и текст ошибки.

### Linux AppImage {#linux-appimage}

Для выпусков, содержащих файл `.AppImage` x64, выберите папку, в которую можно записывать. Скачайте файл со страницы [выпусков Warplyn](https://github.com/punk-link/warplyn/releases), сделайте его исполняемым в файловом менеджере и запустите. Также можно выполнить `chmod +x Warplyn-*-linux-x64.AppImage` в папке загрузок. Linux необходима поддержка FUSE с доступом к `/dev/fuse`, настольные библиотеки Electron и хранилище ключей Secret Service для управляемых учётных данных. AppImage не включает графическую среду или хранилище ключей.

Для целевой Ubuntu 22.04 среди настольных зависимостей есть `libgtk-3-0`, `libnss3`, `libasound2`, `libatk-bridge2.0-0`, `libdrm2`, `libgbm1`, `libxkbcommon0`, `libnotify4`, `libxcb-dri3-0` и `xdg-utils`. Secret Service предоставляет GNOME Keyring. В обычной установке GNOME присутствует большинство этих пакетов. В других дистрибутивах используются иные названия пакетов, поэтому совместимость нужно проверять отдельно.

Интеграция с рабочим столом необязательна: создайте ярлык, указав полный путь к образу. При обновлении сохраняйте тот же путь. Проверка AppImage как установленного настольного приложения ещё не завершена. Основная цель проверки — Ubuntu 22.04 x64; Ubuntu 24.04 x64 и Fedora 43 x64 — дополнительные цели совместимости. Это не означает поддержку всех вариантов Linux.

Подробные шаги скачивания, перезапуска и восстановления см. в разделе [Восстановление после обновления настольного приложения](update-recovery.md).

Чтобы добавить пункт в меню приложений, можно переименовать образ в `Warplyn.AppImage` и поместить его в папку `Applications` в домашней папке. Если папки `~/.local/share/applications` нет, создайте её и сохраните там файл `warplyn.desktop` со следующим содержимым. Замените `YOUR_USER` на имя пользователя Linux или укажите полный путь к образу:

```ini
[Desktop Entry]
Type=Application
Name=Warplyn
Exec="/home/YOUR_USER/Applications/Warplyn.AppImage" %U
Terminal=false
Categories=Office;
StartupWMClass=Warplyn
```

Пункт меню останется рабочим, поскольку встроенное обновление заменяет образ по тому же пути. Чтобы добавить значок Warplyn, выполните `./Warplyn.AppImage --appimage-extract warplyn.png` рядом с образом, сохраните извлечённый PNG в постоянном месте и добавьте в файл ярлыка строку `Icon=` с полным путём к нему.

## После установки

Чтобы использовать функции ИИ, добавьте подключение к провайдеру в **Настройки** → **ИИ-помощник**. Выберите **Папка резервных копий** в **Настройки** → **Данные и копии**, чтобы защитить *статьи*.

Warplyn хранит на компьютере *статьи* и чекпоинты *черновиков*. Для запросов ИИ требуется подключение к интернету; провайдеру отправляется релевантный текст *статьи* и контекст. Применяются правила обработки данных и тарифы провайдера.
