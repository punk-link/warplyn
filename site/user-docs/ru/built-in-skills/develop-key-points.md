# Развить ключевые идеи

Используйте **Развить тезисы**, если нужен краткий список основных идей из заметок или *статьи*. По умолчанию инструмент готовит от трёх до пяти отдельных пунктов и не переписывает *статью*.

Откройте **Быстрые действия**, выберите **Развить тезисы**, при необходимости добавьте указания в поле ввода, затем нажмите **Отправить запрос помощнику**. Если выделен фрагмент, результат будет учитывать его и материал, включённый в сообщение. Если ничего не выделено, помощник опирается на ваше сообщение. Если и сообщения нет, он использует текст *статьи*.

::: tip Пример
Выделите сцену, где Ана сидит у реки, и попросите: «Предложи три возможные трактовки отношений Аны с рекой на основе этого фрагмента».
:::

Просмотрите список перед тем, как использовать его в *статье*. Возможно, стоит уточнить формулировку или перенести акцент. Чтобы создать полноценный черновик на основе предоставленного материала, см. раздел [Превратить идеи в черновик](turn-ideas-into-a-draft.md).
