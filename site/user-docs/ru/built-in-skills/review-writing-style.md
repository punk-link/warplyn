# Проверка стиля письма

Используйте **Проверить стиль текста**, чтобы сравнить *статью* с сохранённым *Профиль стиля*. Помощник ищет конкретные расхождения с особенностями авторского голоса и правилами профиля. Профиль с низкой уверенностью считается предварительным.

Перед отправкой запроса добавьте образцы текстов или ручные рекомендации в [Профиль стиля](../style-profile.md) и перестройте профиль. Затем откройте **Быстрые действия**, выберите **Проверить стиль текста** и нажмите **Отправить запрос помощнику**. Выделите фрагмент, чтобы ограничить им проверку; иначе будет использована вся *статья*.

::: tip Пример
Попросите: «Сравни этот фрагмент об Ане у реки с близкой точкой зрения в моих образцах. Укажи одно различие и объясни, с какой особенностью профиля оно связано».
:::

::: tip Проверить предложенные изменения
Прочитайте *предложение* и подтверждающие его *замечания*. В каждом *замечании* должна быть указана особенность или правило профиля. До принятия изменений решите, какие предложения подходят к *статье*.
:::

Для проверки стиля необходим доступный *Профиль стиля* и подключение к ИИ. Исходные образцы текстов не отправляются; помощник использует компактный профиль, сформированный локально. Провайдеру ИИ может быть отправлена *статья* или выделенный фрагмент.
