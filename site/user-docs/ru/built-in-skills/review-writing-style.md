# Проверка стиля письма

Действие **Проверить стиль текста** помогает сверить *статью* с сохранённым профилем стиля. Помощник укажет, где текст расходится с характерными чертами вашего письма или с правилами профиля. Если степень уверенности низкая, считайте профиль предварительным.

Перед отправкой запроса добавьте образцы текстов или свои правила в разделе [Профиль стиля](../style-profile.md) и перестройте профиль. Затем откройте **Быстрые действия**, выберите **Проверить стиль текста** и нажмите **Отправить запрос помощнику**. Чтобы проверить только часть *статьи*, выделите её перед отправкой.

::: tip Пример
Попросите: «Сравни этот фрагмент об Ане у реки с близкой точкой зрения в моих образцах. Укажи одно различие и объясни, с какой особенностью профиля оно связано».
:::

::: tip Проверить предложенные изменения
Прочитайте *предложение* и подтверждающие его *замечания*. В каждом *замечании* должна быть указана особенность или правило профиля. До принятия изменений решите, какие предложения подходят к *статье*.
:::

Для проверки стиля нужен профиль стиля и подключение к ИИ. Помощник опирается на краткий профиль, который Warplyn составляет на вашем компьютере. Образцы текстов остаются на устройстве. Warplyn может отправить провайдеру ИИ *статью* или выделенный фрагмент.
