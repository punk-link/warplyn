# Сократить текст

Выберите **Сократить текст**, чтобы убрать повторы и лишние слова. Помощник сохраняет смысл, аргументы, оговорки и авторский голос.

Откройте **Быстрые действия**, выберите **Сократить текст** и нажмите **Отправить запрос помощнику**. Уточните, что важно сохранить или где убрать лишнее. Если нужно сократить только часть *статьи*, выделите её перед отправкой.

::: tip Пример
Попросите: «Предложи более ёмкий вариант предложения о реке, которая петляет между ивами. Сохрани серебристый образ и спокойное настроение».
:::

Результат должен быть короче исходного текста. Если безопасно сократить текст невозможно, помощник вернёт его без изменений. До применения проверьте *предложение*: имена, утверждения, ссылки, код, цитаты и технические термины должны остаться корректными. Если нужно повысить ясность без сокращения, используйте [Улучшить связность и ясность](improve-flow-and-clarity.md).
