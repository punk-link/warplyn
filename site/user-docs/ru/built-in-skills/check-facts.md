# Проверка фактов

Действие **Проверить факты** помогает сверить утверждения в *статье* с источниками. Помощник приводит источники и оставляет *замечания*. Текст *статьи* при этом не меняется.

Откройте **Быстрые действия**, выберите **Проверить факты**, просмотрите утверждения, отобранные помощником, и снимите отметку с ненужных. Затем нажмите **Отправить запрос помощнику**. Чтобы сузить проверку, можно выделить фрагмент. Результаты относятся к проверяемой *сохранённой версии*.

::: tip Пример
В сцене у реки Ана говорит, что в полнолуние вода поднимется и затопит тропу. Выберите **Проверить факты** и попросите помощника найти источники о месте действия.
:::

::: tip Изучите данные
На вкладке **Проверка фактов** прочитайте каждое *замечание*. Посмотрите, на какие источники оно опирается, когда они опубликованы и в чём помощник сомневается. Источники могут быть неполными или устаревшими. По ним можно понять, что стоит проверить дополнительно.
:::

О вердиктах, решениях о принятии, исправлениях и повторном использовании данных см. [Руководство по проверке фактов](../fact-checking.md). Для проверки нужны подключение к ИИ и модель с поддержкой проверки по источникам. Провайдер может взимать плату. *Замечание* — это рекомендация, а не доказательство ошибочности утверждения. Для проверки технической терминологии используйте [Проверить технические термины](check-technical-terms.md).
