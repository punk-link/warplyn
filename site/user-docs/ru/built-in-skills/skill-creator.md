# Создание навыков

Помощник использует встроенный Создание навыков, когда вы явно просите его создать, отредактировать, восстановить или удалить повторно используемый *навык*. Инструмент управляет локальными инструкциями Markdown и ведёт отдельную историю для каждого *навыка*.

Опишите повторяющуюся задачу и правила или источники, которым должен следовать *навык*. Если неясная цель или процедура могут повлиять на результат, помощник задаст короткий уточняющий вопрос. Новый *навык* становится доступен для будущих запросов; его создание не запускает выполнение на текущей *статье*.

::: tip Пример
Попросите: «Создай навык „Линейная правка спокойной прозы“. Сделай предложения Аны ёмче, сохранив её голос, обстановку у реки и события сцены. Не добавляй подробностей, а отмечай неясные места».
:::

Можно попросить помощника изменить, восстановить или удалить *навык* по имени. Восстановление создаёт новую активную версию, сохраняя прежние *сохранённые версии навыка*. Полный процесс и варианты локального редактирования описаны в разделе [Создание навыков и управление ими](../skills.md).
