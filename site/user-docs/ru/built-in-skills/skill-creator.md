# Создание навыков

Попросите помощника создать, изменить, восстановить или удалить *навык*. Для этого он использует встроенный навык **Создание навыков**. Инструкции хранятся на вашем компьютере в формате Markdown, а у каждого *навыка* есть своя история версий.

Опишите задачу, которую приходится выполнять регулярно. Укажите, какие правила соблюдать и к каким источникам обращаться. Если для результата важно уточнить цель или порядок действий, помощник задаст вопрос. Новый *навык* можно использовать в следующих запросах. При создании он не применяется к открытой *статье*.

::: tip Пример
Попросите помощника создать навык «Правка спокойной прозы». Например, «Сделай фразы Аны короче, сохрани её интонацию и события сцены у реки. Если что-то неясно, отметь это место. Подробностей от себя не добавляй».
:::

Можно попросить помощника изменить, восстановить или удалить *навык* по имени. Восстановление создаёт новую активную версию, сохраняя прежние *сохранённые версии навыка*. Полный процесс и варианты локального редактирования описаны в разделе [Создание навыков и управление ими](../skills.md).
