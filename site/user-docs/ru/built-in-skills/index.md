# Встроенные навыки

Встроенные *навыки* помогают редакторскому помощнику выполнять распространённые задачи письма. Выберите редакторский *навык* в меню **Быстрые действия** или опишите запрос, чтобы помощник сам определил подходящий. Выбранный чип навыка можно отправить без сообщения; добавьте сообщение, только если нужно указать дополнительный контекст или ограничение. Чтобы начать, нажмите **Отправить запрос помощнику**. Чтобы создать повторно используемый *навык* или управлять им, обратитесь напрямую к помощнику; **Создание навыков** не является быстрым действием в поле ввода.

На каждой странице описано назначение *навыка* и то, что следует проверить в результате. Помощник подготавливает результат для проверки. О работе с ним см. разделы [Редакторский помощник](../editorial-assistant.md) и [Проверка статей](../reviewing-articles.md).
