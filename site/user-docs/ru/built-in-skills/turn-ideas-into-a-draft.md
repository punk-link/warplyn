# Превратить идеи в черновик

Если у вас есть заметки или наброски, выберите **Превратить идеи в черновик**. Помощник соберёт из них связный текст, сохранит смысл ваших идей и постарается обойтись без неподтверждённых утверждений.

Откройте **Быстрые действия**, выберите **Превратить идеи в черновик**, опишите желаемое направление и нажмите **Отправить запрос помощнику**. Если выделен фрагмент, запрос учитывает его и материалы, явно включённые в сообщение. Без выделения можно использовать текущую *статью* и ваши указания.

::: tip Пример
Выделите фрагмент, где Ана открывает блокнот, и попросите: «Помоги написать возможный следующий абзац на основе деталей из этого фрагмента. Пусть страница останется пустой. Не объясняй, почему Ане кажется, будто река её узнала».
:::

Помощник подготовит *предложение* для проверки. До принятия изменений изучите его структуру, утверждения и формулировки. Само *предложение* не сохраняет и не меняет *статью*. Чтобы переписать существующий текст, см. раздел [Улучшить связность и ясность](improve-flow-and-clarity.md).
