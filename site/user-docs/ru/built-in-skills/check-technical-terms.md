# Проверка технических терминов

Действие **Проверить технические термины** помогает найти ошибки в *статье* об ИТ. Помощник отмечает, где перепутаны понятия, неверно расшифрованы аббревиатуры или указаны неточные названия продуктов и API. Он также замечает, когда одно понятие называют по-разному. При проверке он сверяется с источниками для нужной области и версии, учитывает определения из текста и то, как со временем менялись термины.

Откройте *статью*. Чтобы ограничить проверку, выделите фрагмент. В помощнике откройте **Быстрые действия**, выберите **Проверить технические термины**, затем нажмите **Отправить запрос помощнику**. Откройте готовый результат во вкладке **Проверка фактов** и изучите каждое *замечание*, объяснение, ссылки на источники и сведения о неопределённости.

::: tip Пример
В *статье* о приложении для распознавания деревьев автор называет иву хвойным деревом. Попросите **Проверить технические термины** проверить термин по ботаническому источнику.
:::

Для проверки нужны подключение к ИИ и модель с поддержкой проверки фактов по источникам. В настроенную службу ИИ отправляется *статья* или выделенный фрагмент; поисковый запрос может содержать технические термины и контекст утверждения. Провайдер может взимать плату. Источники могут быть неполными или по-разному использовать термины в разных областях. *Замечание* — это рекомендация; инструмент не переписывает прозу, код или идентификаторы. Фоновая проверка терминов не выполняется.
