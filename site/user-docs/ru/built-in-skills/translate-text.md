# Перевести текст

Используйте **Перевести текст**, чтобы подготовить перевод всей *статьи* на выбранный язык. Переводятся название и текст, при этом сохраняются утверждения, числа, авторский голос и форматирование Markdown. Этот *навык* использует всю *статью*, даже если был выделен отдельный фрагмент.

Откройте представление **Переводы** у *статьи* и выберите **Новый перевод…**. Укажите целевой язык и подтвердите запрос. Если в источнике есть несохранённые изменения, сначала сохраните их как *сохранённую версию*, чтобы результат был привязан к нужному тексту.

::: tip Пример
Попросите подготовить черновой перевод сцены Аны у реки, сохранив диалог, точку зрения, спокойное настроение, имена и защищённый текст. Нажмите **Изменить**, чтобы открыть связанную *статью-перевод*, или **Обновить**, чтобы добавить результат в существующую статью как новую *сохранённую версию*.
:::

Перевод остаётся отдельным от исходника. Сравнение результатов, обновление связанной *статьи* и работа с устаревшими результатами описаны в разделе [Переводы](../translations.md).
