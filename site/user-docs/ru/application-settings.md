# Настройки приложения

Настройки приложения определяют внешний вид и поведение Warplyn. Они не входят в историю *сохранённых версий* *статьи*. Откройте **Настройки** в **область инструментов библиотеки статей**. Некоторые настройки доступны только в настольном приложении; они отмечены ниже.

## Настроить внешний вид и язык

В разделе **Общие** → **Оформление и язык** выберите **Системное**, **Светлое** или **Тёмное** для параметра **Оформление**. **Системное** следует настройкам устройства и обновляется, пока открыт Warplyn. Выберите **Язык интерфейса** для меню и сообщений. Сейчас английский — единственный язык интерфейса, переведённый полностью. Эти параметры не меняют язык письма или правила типографики *статьи*.

В разделе **Дата и время** выберите формат даты, 12- или 24-часовой формат времени и часовой пояс. Системные параметры следуют настройкам устройства. Они меняют только отображение сохранённого времени в Warplyn, но не само время.

## Настроить язык по умолчанию

В разделе **Языки по умолчанию** задайте **Язык новых статей** для новых *статей*. Укажите **Языки перевода**, чтобы при запросе *перевода* эти языки предлагались первыми. Введите название языка, региональный вариант или код, затем нажмите **Добавить**. Warplyn всё равно попросит подтвердить каждый запрос на перевод.

## Настроить поведение помощника

В разделе **ИИ-помощник** выберите **Предлагать правки для проверки** по умолчанию для новых диалогов об *статьях* или включите **Применять правки сразу** для явно запрошенных правок. Значение по умолчанию не меняет существующие диалоги, а другие сгенерированные результаты всё равно нужно проверять.

**Лимит времени запроса** применяется к каждому новому запросу и повторной попытке. По умолчанию — две минуты. Для задач, которым нужно больше времени, выберите больший лимит или **Без ограничений**. Если время запроса истечёт, *статья* не изменится.

Выберите **Enter** или **Ctrl + Enter** как клавишу отправки запроса помощнику. Другие сочетания клавиш приложения можно изменить в **Сочетания клавиш**. Перед сохранением сочетания Warplyn сообщит о конфликтах.

## Настроить рекомендации для публикации

В разделе **Публикация** выберите профиль по умолчанию для новых *статей*. Профили вроде **LinkedIn Post** и **LinkedIn Article** показывают рекомендации по количеству символов в **Article Status Bar**. Можно также выбрать **Без ограничений** или добавить пользовательский профиль с названием и целочисленным лимитом символов. Параметр по умолчанию действует для новых *статей*; существующая *статья* может сохранить собственный профиль. Лимиты служат только рекомендацией и не мешают копированию. В **Article Status Bar** выберите **Копировать Markdown** или откройте меню и нажмите **Копировать обычный текст**. Warplyn копирует текст по вашему запросу, но не публикует его.

## Просмотреть параметры моделей ИИ

В разделе **ИИ-помощник** можно хранить несколько подключений к провайдерам, активировать только нужные и назначать разные модели для общих задач помощника и отдельных *навыков*. Для задач ИИ используется **Модель по умолчанию**, если у конкретной задачи нет собственного выбора. Необязательная **Модель приложения** выполняет задачи Warplyn, например составляет сводки и заголовки; если модель не задана, используется Модель по умолчанию. Найдите модель с помощью **Избранное**, поиска или фильтра по поставщику. Параметр **Уровень рассуждений** показывается для поддерживаемых моделей OpenAI. Доступные задачи и настройки зависят от модели. Подробнее о подключении и ограничениях провайдеров см. в разделе [Провайдеры и модели ИИ](providers.md).

В разделе **Сочетания клавиш** выберите действие и нажмите нужное сочетание клавиш. Можно назначить сочетания для сохранения *сохранённой версии*, переключения представлений или включения режима Focus. Warplyn покажет, какое действие уже использует конфликтующее сочетание; выберите другое. Параметр **Отправлять клавишами** определяет, отправляет ли запрос помощнику клавиша **Enter** или **Ctrl + Enter**. Смена сочетаний не меняет содержимое *статьи*.

## Проверить обновления настольного приложения

Установленные настольные приложения могут проверять выпуски в **Настройки** → **О Warplyn** → **Обновления**. Сначала разрешите **Разрешить доступ к сети для обновлений**. Тогда Warplyn сможет обращаться к GitHub за общедоступной информацией о выпусках и выбранными вами обновлениями для скачивания. Затем включите **Автоматически проверять обновления** и при необходимости **Включать предварительные выпуски**. Нажмите **Проверить сейчас**, чтобы проверить обновления в любое время. Если доступен выпуск, появятся его примечания. Установщики для Windows и Linux AppImage предлагают действия **Скачать** и **Перезапустить и обновить**. Для Debian используйте **Что нового**, затем обновите приложение через менеджер пакетов или установите более новый файл `.deb`. Если после обновления приложение не запускается, см. [Восстановление после обновления](update-recovery.md).

## Удалить локальные данные

В настольном приложении команда **Удалить локальные данные** безвозвратно удаляет активные данные Warplyn, в том числе *статьи*, *сохранённые версии*, чекпоинты *черновиков*, историю помощника, данные стиля, настройки и локальные резервные копии в папке данных. Если настроена папка резервных копий, в подтверждении будет предложено **Создать резервную копию перед удалением**. Сначала Warplyn должен создать резервную копию и только потом удалять данные. После успешного удаления приложение закроется. Обычное удаление приложения не удаляет ваши тексты. Личные слова для проверки орфографии, сохранённые в системном словаре, останутся там; чтобы удалить и их, откройте **Настройки** → **Правописание**.

Откройте **Настройки** → **О Warplyn**, чтобы найти руководство пользователя, репозиторий исходного кода, трекер ошибок и лицензию. Нажмите **Открыть быстрый старт**, чтобы снова просмотреть вводное знакомство при первом запуске.
