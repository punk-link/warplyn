# Переход со Skladno на Warplyn

Warplyn — отдельное приложение. Не удаляйте Skladno и его данные, пока не проверите восстановленные данные. Не переносите активную папку данных Skladno в Warplyn.

Скачайте установщик Windows 11 x64 или пакет Debian x64 из [последнего выпуска Warplyn](https://github.com/punk-link/warplyn/releases/latest). Инструкции для платформ см. в разделе [Установка](installation.md).

До перехода укажите путь в поле **Папка резервных копий** в разделе **Настройки** → **Данные и копии** и нажмите **Создать копию**. Храните каждую копию `.sqlite` вместе с соответствующей папкой `.sqlite.skills`. Подробнее см. в разделе [Резервное копирование и восстановление](backups-and-recovery.md).

## Порядок перехода

1. Дождитесь завершения задач ИИ в Skladno или отмените их. Затем закройте и снова откройте Skladno, чтобы сохранить последний чекпоинт. Пока создаётся резервная копия, не меняйте файлы своих *навыков* в других редакторах.
2. Создайте резервную копию вручную из работающего приложения Skladno, даже если используется пользовательский каталог данных. Храните файл `.sqlite` и соседнюю папку `.sqlite.skills` вместе и не меняйте их исходные имена. После создания копии закройте Skladno.
3. Установите и откройте Warplyn в отдельном пустом профиле. Не указывайте активный каталог данных Skladno.
4. В разделе **Настройки** → **Данные и копии** выберите папку резервной копии для перехода и нажмите **Восстановить…**. Выберите снимок Skladno, подтвердите замену и дождитесь перезапуска Warplyn. Если в Warplyn уже есть работа, сначала создайте собственную резервную копию: восстановление заменяет данные, а не объединяет базы.
5. До начала новой работы проверьте *статьи*, последние *черновики*, историю *сохранённых версий*, переписки с помощником, **Настройки**, профили публикации и *навыки* автора.
6. В разделе **Настройки** → **ИИ-помощник** снова добавьте подключения и выберите модели для нужных ролей. При восстановлении сохранённые подключения и выбор моделей удаляются, поскольку учётные данные не входят в резервную копию. Учётные данные Skladno остаются без изменений.
7. Для подключений через переменные окружения снова укажите имя переменной и проверьте, что Warplyn видит эту переменную. В резервные копии не входят файлы `.env` и их значения.
8. Выберите отдельную папку для дальнейших резервных копий Warplyn. Заново задайте параметры сети для обновлений и телеметрии. При переходе не копируются настройки папки резервного копирования, идентификатор телеметрии, подготовленные обновления и ожидающие записи восстановления.

Встроенные резервные копии с папкой `.sqlite.skills` восстанавливают текущие *навыки* автора и неизменяемую историю *навыков*. Старые снимки `.sqlite`, содержащие только базу данных, восстанавливают базу и оставляют *навыки* назначения без изменений; они не могут восстановить файлы, которых в копии не было. Имена файлов базы данных и форматы манифеста совместимы со Skladno.

## Восстановление

Не удаляйте Skladno, пока не проверите результат восстановления. Приложения не синхронизируют и не объединяют последующие изменения. Если вернуться к Skladno, оно будет в состоянии до перехода.

Если восстановить данные не удалось, продолжайте пользоваться Skladno и сохраните исходную пару файлов резервной копии. Warplyn проверяет резервную копию и сохраняет снимок своих текущих данных. Если после восстановления приложение не запустится, Warplyn вернёт данные из этого снимка. После устранения указанной проблемы повторите попытку. См. разделы [Резервное копирование и восстановление](backups-and-recovery.md) и [Восстановление после обновления](update-recovery.md).

По умолчанию Warplyn использует `~/.warplyn`; для пользовательской папки задайте `WARPLYN_DATA_DIR`. Для активного хранилища он игнорирует `SKLADNO_DATA_DIR` и запрещает пути, пересекающиеся с известными устаревшими расположениями. Выберите отдельную пустую папку и восстановите резервную копию вместо копирования активной базы SQLite.
