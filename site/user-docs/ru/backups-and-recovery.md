# Резервное копирование и восстановление

## Создать резервную копию

В **Настройки** → **Данные и копии** укажите **Папка резервных копий**, затем нажмите **Создать копию**. В поддерживаемых браузерах Warplyn запрашивает разрешение записывать резервные копии только в эту папку.

[![Настройки данных и резервных копий: папка, кнопки Создать копию и Восстановить…, а также параметры автоматического резервирования.](/images/backups-and-recovery.png)](/images/backups-and-recovery.png)

*Настройки данных и резервных копий в настольном приложении.*

::: tip Содержимое резервной копии
Новая копия `.skladno` включает базу данных, текущие *навыки* автора, историю их *сохранённых версий*, а также манифест файлов. Резервные копии не содержат файлы `.env` и ключи API.
:::

::: tip Ограничения браузерного резервирования
Браузер поддерживает передачу файлов размером до 100 МБ каждый и общим размером до 500 МБ. Для больших локальных данных используйте настольное приложение.
:::

В настольном приложении рядом с каждым снимком базы данных находится папка `.sqlite.skills` с текущими *навыками* автора, историей их *сохранённых версий*, личными словами для проверки орфографии и манифестом. При копировании или восстановлении храните файл `.sqlite` и папку `.sqlite.skills` вместе. Браузерные копии не включают личные слова для проверки орфографии.

Старые резервные копии `.sqlite` содержат только базу данных. После восстановления такой копии текущие файлы *навыков* и их история сохраняются.

## Автоматические копии

Выберите **Ежедневно** для параметра **Автоматические резервные копии**, чтобы создавать снимок вскоре после запуска Warplyn, а затем каждые 24 часа, пока приложение открыто. В браузере Warplyn потребуется разрешение на использование выбранной папки. Если автоматическое резервирование не удалось, проверьте папку и создайте копию вручную; следующая попытка по расписанию останется включённой.

Параметр **Хранение автоматических копий** определяет, сколько автоматических снимков хранить. Warplyn удаляет только самые старые автоматические снимки; созданные вручную копии сохраняются всегда.

## Восстановить резервную копию

1. В **Настройки** → **Данные и копии** выберите **Восстановить…**.
2. Выберите нужную копию. Warplyn проверит файлы и сохранит локальную резервную копию текущей базы данных и файлов *навыков* для восстановления.
3. После завершения проверьте *статьи* и *сохранённые версии*.

Восстановление копии `.skladno` или настольного снимка с сопутствующей папкой заменяет базу данных и сохранённые *навыки*. Старая копия `.sqlite`, содержащая только базу данных, заменяет только её.

При восстановлении настольной копии сохранённые в ней личные слова для проверки орфографии также добавляются в словарь. Существующие слова остаются. Старые копии без личных слов не меняют словарь. Загруженные языковые словари и параметры предварительной загрузки орфографии не включаются.

::: warning Настройки ИИ после восстановления
При восстановлении сохраняются текущие подключения к ИИ, учётные данные и выбранные модели этой установки. Если подключения не настроены, Warplyn восстанавливает из резервной копии имена и ссылки на переменные окружения, но не ключи API и не значения переменных. Задайте недостающие переменные на этом компьютере, затем выберите модели в **Настройки** → **ИИ-помощник**. Подключения с сохранёнными ключами API не импортируются в новую установку; добавьте их в Settings. Остальные настройки восстанавливаются. При сбое восстановления и откате прежние настройки ИИ сохраняются.
:::

## Вручную восстановить копию только базы данных

Эти действия предназначены только для старой копии `.sqlite`. Не запускайте Warplyn, пока не вернёте базу на место.

1. Создайте копию текущей локальной базы данных.
2. Скопируйте резервную копию поверх файла `skladno.sqlite` в настроенной папке данных Warplyn.
3. Запустите Warplyn и проверьте *статьи* и *сохранённые версии*.

Чтобы восстановить копию с *навыками*, используйте **Восстановить…** в **Настройки**: так Warplyn сможет проверить и восстановить манифест и историю *навыков*.

## Если не удаётся создать резервную копию

Warplyn не меняет активную базу данных и текущий сеанс редактирования. Проверьте, что папка назначения существует и у вашей учётной записи есть право записи, затем повторите попытку.

## Разрешения на файлы

По умолчанию локальная служба хранит базу данных в `~/.warplyn`. Чтобы выбрать другую папку, задайте `WARPLYN_DATA_DIR`. Warplyn игнорирует `SKLADNO_DATA_DIR` и не использует папки, пересекающиеся со старым расположением данных Skladno. При переходе со Skladno выберите отдельную папку Warplyn и восстановите резервную копию.

В POSIX-системах Warplyn ограничивает доступ к папке данных и файлам SQLite вашей учётной записью, в том числе после обновления. В Windows разрешениями файловой системы управляет сама Windows. Файлы резервных копий, созданные браузером, используют разрешения выбранной папки; храните их в личной папке и проверьте параметры общего доступа, прежде чем выбирать общую или синхронизируемую папку.
