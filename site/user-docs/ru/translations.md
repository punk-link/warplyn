# Переводы

Warplyn создаёт для каждого *перевода* отдельную *статью* и связывает её с оригиналом. У перевода свои название, *черновик* и история *сохранённых версий*. Правки в переводе не меняют оригинал.

## Запросить перевод

Откройте исходную *статью* и выберите **Новый перевод…** в разделе **Переводы**. Диалог может заранее выбрать язык текущей *статьи*. Если подходящего языка нет, он предложит предпочтительные языки из **Настройки** → **Языки по умолчанию**. Выберите и подтвердите каждый язык назначения. Warplyn переводит всю *статью*, даже если в редакторе был выделен фрагмент. Если в исходнике есть несохранённые изменения, сначала сохраните их как *сохранённую версию*, чтобы перевод был привязан к точному тексту.

Для каждого языка помощник создаёт результат *перевода* для проверки. Откройте его, чтобы сравнить название и текст с оригиналом. Выберите **Рядом** для сравнения целых фрагментов или **Сопоставленные абзацы**, чтобы видеть соответствующие абзацы рядом. Защищённый текст — например, имена, числа, URL и код — должен оставаться без изменений. Warplyn отмечает результаты, которые изменяют защищённый текст или используют прежнюю исходную *сохранённую версию*. Прежде чем продолжить, проверьте эти предупреждения.

::: warning Сначала сохраните источник
Запрос на *перевод* использует сохранённую *версию*. Если в исходнике есть несохранённые изменения, сначала сохраните их как *сохранённую версию*, чтобы результат соответствовал нужному тексту.
:::

## Создать или обновить статью-перевод

Когда результат готов, нажмите **Изменить**, чтобы открыть связанную *статью-перевод*. Если её ещё нет, Warplyn создаст её. Проверьте *перевод* и, когда будете готовы, сохраните его как *черновик* или нажмите **Сохранить версию**. Исходная *статья* не меняется.

Чтобы применить новый результат к существующему *переводу*, нажмите **Обновить** и подтвердите целевую *статью*. Warplyn добавит перевод как новую *сохранённую версию*, сохранив название и историю *перевода*. Обновление заблокировано, если с момента проверки изменился источник или цель, у целевой статьи есть несохранённый *черновик* либо результат больше не проходит проверку.

Нажмите **Отклонить**, чтобы убрать сгенерированный результат из процесса принятия. Это не удалит источник или уже созданную *статью-перевод*. Прежние результаты останутся доступны. Новый результат можно создать через **Новый перевод…**.

::: tip Обновление сохраняет историю перевода
При выборе **Обновить** Warplyn добавляет результат как новую *сохранённую версию* связанной *статьи-перевода*. Её название и предыдущие *сохранённые версии* остаются доступны.
:::

У каждого языка свои результаты. Используйте языковые вкладки и селектор результатов, чтобы снова открыть *перевод* или сравнить новую попытку с предыдущей. В результате указано время создания и использованная исходная *сохранённая версия*. Если источник изменился, результат устарел и не может создать новую связанную *статью*. Запросите новый *перевод* и сравните его с текущей исходной *сохранённой версией*.
