# Восстановление после обновления настольного приложения

Установка предварительных версий необязательна. Если после обновления Warplyn перестал запускаться, переустановите предыдущую предварительную версию и восстановите данные из снимка, сделанного перед этим обновлением.

::: warning Не открывайте базу данных из новой версии
Не открывайте в старой версии базу данных, созданную более новой предварительной версией. Сначала восстановите снимок, сохранённый до обновления.
:::

1. Скачайте и переустановите предыдущую предварительную версию из [выпуска GitHub](https://github.com/punk-link/warplyn/releases).
2. Восстановите соответствующий снимок SQLite, который Warplyn записал перед обновлением.
3. Запустите предыдущую предварительную версию и проверьте *статьи*, *черновики*, *сохранённые версии* и настройки.

## Linux AppImage

Храните AppImage в папке, в которую у вас есть право записи. О требованиях к системе, запуске и создании ярлыка рассказывается в разделе [Установить Warplyn](installation.md#linux-appimage). Проверка AppImage как установленного настольного приложения пока не завершена.

Разрешите доступ к обновлениям GitHub и нажмите **Скачать**. Чтобы установить скачанное обновление, нажмите **Перезапустить и обновить**. Пакеты Debian по-прежнему обновляются через менеджер пакетов.

Если после обновления AppImage не запускается, закройте Warplyn. Рядом с образом останется файл предыдущей версии с суффиксом `.previous`. До запуска предыдущей версии восстановите соответствующий снимок, созданный до обновления, соблюдая приведённое выше предупреждение. Храните оба исполняемых файла и снимок, пока восстановление не завершится. Если в папку образа нельзя записывать, переместите его в свою папку или скачайте замену вручную. Не отключайте песочницу Electron ради запуска образа.
