# Стоимость провайдеров ИИ

Помощник ИИ необязателен. Warplyn не взимает плату за запросы. Провайдер ИИ может списывать средства с вашей учётной записи, когда Warplyn отправляет ему запрос.

## Что влияет на стоимость

У каждого провайдера свои тарифы. Стоимость запроса зависит от нескольких факторов:

- выбранные провайдер и модель;
- объём текста *статьи* и контекста инструкций в запросе;
- объём текста, который возвращает модель.

Окружающий текст помогает понять короткий фрагмент, но для этого часть невыделенного текста отправляется провайдеру. Если для запроса с выделением нужен текст *статьи*, отправляется выбранный фрагмент и до 500 символов до и после него — не более 1000 дополнительных символов только для чтения. Изменять можно только выделенный фрагмент. Без выделения запрос может включать всю *статью* и релевантный контекст. Более узкий запрос может быть дешевле — в зависимости от тарифов провайдера.

::: tip Оплата API
Подписка на чат-сервис провайдера может не включать использование API. Перед подключением ключа проверьте актуальные цены API и условия оплаты.
:::

Для обычных задач, например сглаживания фрагмента или точечной правки, сначала попробуйте недорогую модель. Используйте более дорогую, если результаты показывают, что задача требует её возможностей.

## Проверить расходы

Проверяйте использование, списания, уведомления и лимиты расходов в учётной записи провайдера. Warplyn не показывает счёт провайдера и не устанавливает лимиты расходов. По вопросам оплаты, возвратов и списаний обратитесь к провайдеру.

Используемая модель влияет на стоимость запроса. В **Настройки** → **ИИ-помощник** выберите **Модель по умолчанию**, **Модель приложения** и модели для отдельных задач. Инструкции по настройке см. в разделе [Провайдеры и модели ИИ](providers.md).

::: tip Можно работать без ИИ
Для письма и управления *статьями* подключение к ИИ не нужно. Редактирование, сохранение *сохранённых версий* и использование локальных резервных копий не отправляют запросы ИИ.
:::
