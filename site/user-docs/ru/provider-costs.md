# Стоимость провайдеров ИИ

Пользоваться ИИ-помощником можно по желанию. Warplyn не берёт плату за запросы. Когда приложение отправляет запрос провайдеру ИИ, тот может списать плату с вашей учётной записи.

## Что влияет на стоимость

У каждого провайдера свои тарифы. Стоимость запроса зависит от нескольких факторов:

- выбранные провайдер и модель;
- объём текста *статьи* и дополнительных указаний в запросе;
- объём текста, который возвращает модель.

Окружающий текст помогает понять короткий фрагмент, но для этого часть невыделенного текста отправляется провайдеру. Если для запроса нужен текст *статьи* и вы выделили фрагмент, Warplyn отправит его и до 500 символов с каждой стороны. Эти дополнительные 1000 символов передаются только для чтения. Изменять можно только выделенный фрагмент. Без выделения запрос может включать всю *статью* и релевантный контекст. Более узкий запрос может быть дешевле — в зависимости от тарифов провайдера.

::: tip Оплата API
Подписка на чат-сервис провайдера может не включать использование API. Перед подключением ключа проверьте актуальные цены API и условия оплаты.
:::

Для обычных задач, например правки одного предложения или перехода между абзацами, сначала попробуйте недорогую модель. Используйте более дорогую, если результаты показывают, что задача требует её возможностей.

## Проверить расходы

Проверяйте использование, списания, уведомления и лимиты расходов в учётной записи провайдера. Warplyn не показывает счёт провайдера и не устанавливает лимиты расходов. По вопросам оплаты, возвратов и списаний обратитесь к провайдеру.

Используемая модель влияет на стоимость запроса. В разделе **Настройки** → **ИИ-помощник** выберите **Модель по умолчанию**, **Модель приложения** и модели для отдельных задач. Инструкции по настройке см. в разделе [Провайдеры и модели ИИ](providers.md).

::: tip Можно работать без ИИ
Для письма и управления *статьями* подключение к ИИ не нужно. Вы можете редактировать текст, создавать *сохранённые версии* и работать с локальными резервными копиями без запросов к ИИ.
:::
