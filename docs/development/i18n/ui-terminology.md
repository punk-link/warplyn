# UI terminology for localized documentation

Use this generated reference to look up exact interface wording in all installed languages when writing user documentation.

## Source of truth

This table contains only interface terms named in user documentation. Its message IDs are curated here; localized values come from the keyed catalogs in `packages/web/src/i18n/locales`, with English from `packages/web/src/i18n/messages.ts`. Add a row when documentation names another control, and remove it when documentation no longer uses it. Run `npm run docs:i18n-terminology` to refresh the selected rows. Do not reuse a shorter tab name for a full view.

Use the [internationalization guide](../guides/internationalization.md) for catalog rules and the [user-docs glossary](../../../site/user-docs/glossary.md) and locale terminology record for domain concepts. If a localized label does not fit a sentence grammatically, restructure the sentence around it; do not alter the control label.

Core verification checks this table after typecheck builds the shared package. Run `npm run docs:i18n-terminology -- --check` to check it without rewriting the file. A stale table fails verification and names the regeneration command.

## Variable labels

Keep message parameters and the surrounding wording from the locale catalog. For example, the proposal action is `views.proposeFactCorrections` and includes `({count})`; the typography preset status is `typography.presetPending` and includes `{language}{separator}`. If documentation omits a dynamic count or language, use a natural, reviewed form of the localized label rather than leaving the English fragment.

The **Article Library utility area** is a documentation term for the panel footer, not a visible control. Describe it in the reader’s language; do not present the English term as an interface label.

## Review

Update this reference when one of these message IDs changes. For other labels, read the message ID used by the screen and copy its localized value. A complete catalog and a matching label do not replace native-language review of the surrounding sentence.
